## 当前工作流：三层价值选股 + 个人交易系统搭建

### 工作流概述
本项目是AI辅助的A股长期价值投资分析系统。2026-10-12 起主线转为"提升用户自己的能力"（用户原话："你对我最大的帮助是提升我的能力"）：

**核心循环（每个交易日，在界面里完成）：**
1. 盘前/盘中：每日跟盘页写"我的想法"
2. 收盘后：刷新行情 → 写操作和复盘 → Claude 点评（需求5）
3. 复盘暴露出规则空白 → 去访谈页聊对应主题 → 采纳为 🟡 → 用户确认为 ✅（需求6）

**核心循环（每次选股）：**
1. 输入候选股票代码
2. 运行三层筛选脚本（量化→产业链→财务）
3. 可选：运行行业横向对比（P1）
4. 生成报告，人工审核决策
5. 与Druckenmiller框架校验仓位配置

## 需求清单

### 需求1：三层选股分析（核心）
**触发时机**：用户说"分析这些股票"、"帮我筛选"、提供股票代码列表
**执行步骤**：
1. 进入scripts目录
2. 运行：`python run_analysis.py [股票代码，空格分隔]`
3. 报告自动保存到 output/screening_YYYYMMDD_HHMM.md
4. 呈现关键结论（通过/未通过 + 评分排名）

**验收标准**：
- [ ] PE分位基于真实5年历史数据（非hardcoded区间）
- [ ] PEG指标正确计算（PE÷净利润增速，负增长时标注警示）
- [ ] ROE/营收增速/净利率来自AKShare年报数据
- [ ] 产业链AI分析包含上下游关系和护城河描述
- [ ] 综合评分排序正确（低PE分位+低PEG+高ROE = 高分）

### 需求6：访谈板块——搭建个人交易系统（2026-10-12 新增）
**目标**：通过对话理清用户的选股思路，把用户自己的风险偏好和操作习惯沉淀成规则（提升用户能力，不是替用户选股）
**触发时机**：用户说"访谈"、"聊聊"、"帮我理思路"；买入新股票前；每日复盘暴露出规则空白时
**入口**：界面"访谈"页（选主题 → 开始访谈 → 对话）；"交易系统"页查看/确认规则
**执行步骤**：
1. 主题来自 interview/访谈提纲.md（A~G + 自由聊）；新买入/准备买入的股票优先做个股访谈（A）
2. 访谈 AI 的提示词在 scripts/coach.py：铁律原文、交易系统现状、持仓、最新行情、筛选结论全部从文件读取后发给模型，模型不得用其他数字
3. AI 回复末尾的 [[SUGGEST]] 显示为"可沉淀"卡片；用户点"采纳"→ 交易系统条目变 🟡 草案，或写入 position.json 的 thesis/invalidation
4. 🟡 → ✅ 只能由用户在"交易系统"页点"确认"，AI 无权确认
5. 数据：data/trading_system.json、data/interviews/{id}.json；只读 Markdown 自动生成到 interview/交易系统.md、interview/访谈记录-{id}.md
**验收标准**：
- [ ] 交易系统.md 里的 ✅ 条目都有用户原话或确认来源
- [ ] Claude 的建议和用户的规则分开标注，没有把建议写成 ✅
- [ ] 每次访谈至少推进一个 ⬜ 项

### 需求8：手机离线复盘 + 同步到电脑（2026-10-13 新增）
**目标**：用户原话"我需要手机端能进行离线复盘记录后，同步到电脑上，然后电脑再根据AI这边来进行分析处理"（参考 2-时间管理助手 的同步设计）
**用户已选**：手机记 想法/操作/复盘 + 成交 + 候选池理由；独立同步端口+配对；AI 在电脑上手动点；冲突按字段新的覆盖旧的
**入口**：电脑界面"手机同步"页（生成配对码、设备、待确认成交、同步记录）；手机 Safari 打开 https://<电脑局域网IP>:5443/
**执行步骤**：
1. 启动界面.bat 时 app.py 同时启动 mobile_server（局域网 HTTPS 5443，证书用时间管理助手的 CA 签发，IP 变了自动重签）
2. 电脑生成 6 位配对码（5 分钟、一次性、错 5 次作废）→ 手机输入 → 拿到设备令牌（电脑只存哈希，最多 3 台）
3. 手机离线写的内容存 localStorage 队列；联网/打开页面时推送 → 再拉取电脑最新数据
4. 合并：每个字段带修改时间（毫秒，手机按电脑时间校正），新的覆盖旧的；电脑旧页面要覆盖手机新内容时拒绝保存并提示刷新
5. 手机成交进 data/mobile/pending_trades.json，电脑点"确认写入持仓"才写 position.json
6. 回电脑后在跟盘页看到"来自手机"标记，手动点"让 Claude 点评"
**验收标准**：
- [ ] 离线能打开页面、能保存，联网后自动上传（右上角"已同步"）
- [ ] 手机改不了持仓/止损基准/交易系统/AI 点评
- [ ] 未配对或已解绑的手机拿不到任何数据（401）
- [ ] 同一字段两边都改过时，以后改的为准，不丢电脑上刚写的内容

**数据相关**：
- ❌ 使用hardcoded PE历史区间（如 '白酒': (15, 50)）
- ❌ 不运行脚本就给出PE历史分位数字
- ❌ 凭记忆输出财务数据（必须通过AKShare获取）

**推荐相关**：
- ❌ 推荐PE历史分位>60%的股票（除非明确说明是成长逻辑）
- ❌ 把Druckenmiller信念评分当作唯一/主要决策依据
- ❌ 混用价值投资逻辑和动量逻辑，不加区分

**流程相关**：
- ❌ 不做行业横向对比就说"这只股票在板块里便宜"
- ❌ 不跑screener.py就生成选股建议
- ❌ 没有PEG数据就说"PE低因此便宜"

**仓位相关（决策铁律，2026-10-12）**：
- ❌ 建议满仓、全仓、单只重仓、融资加杠杆（绝不梭哈）

- ❌ 基于技术面/短期走势建议底仓的建仓或清仓（绝不短线）
- ✅ 允许：底仓不变的前提下频繁做T（降成本、产子弹）

**访谈/交易系统相关（2026-10-12）**：

## 投资哲学定位（P1修复后明确）

**主框架：价值投资**
- 安全边际：PE历史真实低位（<35分位）+ ROE>12%
- 护城河：不可复制的竞争优势（品牌/专利/资源）
- 催化剂：估值均值回归（PE回到历史中位）

**辅助框架：Druckenmiller宏观**
- 仅用于判断"现在是否是进场时机"
- 不改变"哪只股票值得买"的判断
- 信念评分<40分时 = 即使有好标的也保留更多现金

**明确不做**：
- 纯技术面追涨杀跌
- 高PE成长股（除非用PEG评估已合理）
- 无护城河的周期股

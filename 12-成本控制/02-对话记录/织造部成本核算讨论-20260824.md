## 以公斤为单位，核心逻辑变了一处

以米计量时，关键是"每米用多少克纱"；以公斤计量时，关键换成：

**成布率 = 成品入库重量(kg) ÷ 领料重量(kg) × 100%**

即：投入1kg棉纱，能产出多少kg布。这个比率就是材料成本的核心驱动。

## 标准成本卡（修订版，单位：元/kg布）

```
品种：30S纯棉（示例，数字待实际填入）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【直接材料】
  成布率：____%（如92%，表示1kg纱→0.92kg布）
  需投入原纱：1÷ 成布率 = ___kg/kg布
  棉纱采购价：___元/kg
  → 材料成本 = (1÷成布率) × 采购价 = ___元/kg布

  若含氨纶（如棉95%+氨5%混纺）：
  棉纱：(1÷成布率) × 95% × ___元/kg
  氨纶：(1÷成布率) × 5% × ___元/kg（氨纶贵很多，需单独核）
  → 材料合计 = ___元/kg布

【直接人工】
  台产效率：___kg/台时
  台班工资：___元/台时
  → 人工成本 = 台班工资 ÷ 台产效率 = ___元/kg布

【制造费用】
  折旧：___元/台时 ÷ 台产效率 = ___元/kg布
  水电：___元/台时 ÷ 台产效率 = ___元/kg布
  → 合计 = ___元/kg布

━━━━━━━━━━━━━━━━━━━━━━
标准总成本 = ___元/kg布
成本底线报价 = 成本 ÷ (1 - 保本毛利率)
建议报价    = 成本 ÷ (1 - 目标毛利率)
```

## 第一个参数：S（纱支）— 纱线粗细

**S = 英支**，是衡量纱线细度的单位。

核心记忆法：**数字越大，纱越细，品质越高，价格越贵**

| 纱支 | 粗细感 | 典型用途 | 成本参考 |
|------|-------|---------|---------|
| 10S-20S | 粗，像绳子 | 牛仔布、帆布、毛巾 | 便宜 |
| **21S-32S** | **中等，最常见** | **T恤、卫衣、运动面料** | **中等** |
| 33S-40S | 细，手感好 | 高档T恤、衬衫 | 贵 |
| 60S以上 | 很细，像丝 | 高端内衣、精纺布 | 很贵 |

**为什么叫"支"？**
来自英制：1磅棉花，纺出的纱越长（越细），支数越高。30S意思是1磅棉花能纺出30×840码的纱线。这个不用记，知道"越大越细越贵"就够了。

| **棉氨** | 棉95%+氨纶5% | 有弹性、贴身，运动服常用 | 贵（氨纶是棉价2倍以上） |

## 对你的成本核算，这两个参数意味着什么

**纱支影响采购单价：**

同样是棉纱，市场价大概是：
- 21S棉纱：约 23~26元/kg
- 30S棉纱：约 28~32元/kg
- 40S棉纱：约 35~42元/kg

纱越细，纺纱工艺难度大，价格就高。**同样是一公斤布，40S的原料成本可能比21S高30%~50%。**

**材质影响配比成本：**

棉氨混纺品种要特别注意：
- 棉纱：约30元/kg
- 氨纶：约60~80元/kg（贵一倍多）

一个95%棉+5%氨纶的品种，哪怕只有5%的氨纶，对成本的影响也显著，**报价时绝不能按纯棉算**。

## D = 旦尼尔（Denier）— 化纤的"粗细"单位

**定义**：9000米长的纤维，重多少克，就是多少旦。

核心记忆法：**S是反的（越大越细），D是正的（越大越粗）**

| 对比 | S（棉纱） | D（化纤） |
|------|---------|---------|
| 数字越大 | 纱越细，越贵 | 纱越粗，越重 |
| 数字越小 | 纱越粗，越便宜 | 纱越细，越贵 |

---

## 次品的财务处理：三种情况，三种核算方式

### 情况1：次品可以返工（最常见）

**流程**：
```
合格品入库 → 正常成品仓
次品 → 次品仓（待返工）→ 返工后 → 重新验布 → 合格品仓
```

**成本处理**：
```
次品成本 = 原料成本 + 已发生人工
返工成本 = 额外人工 + 额外损耗

会计分录：
1. 次品检出时：
   借：次品仓（存货）
      贷：在产品

2. 返工时：
   借：生产成本-返工
      贷：工资/材料等

3. 返工合格后：
   借：产成品
      贷：次品仓
          生产成本-返工
```

### 情况2：次品降价销售

**流程**：
```
次品 → 次品仓 → 客户同意降价收货 → 出库
```

**成本处理**：
```
次品按正常成本入账，但售价打折

例：正常品50元/kg，次品30元/kg
    正常成本42元/kg，次品成本也是42元/kg
    
次品销售时：
  收入：30元/kg
  成本：42元/kg
  毛利：-12元/kg（亏损，但比报废强）
```

### 情况3：次品报废（最坏情况）

**流程**：
```
次品 → 次品仓 → 审批报废 → 出库销毁/卖废品
```

**成本处理**：
```
报废损失计入当期损益（管理费用-存货损失）

会计分录：
借：管理费用-存货报废损失
    贷：次品仓
```

## 两种织损率定义，解决不同问题

### 定义1：**材料损耗率**（包含次品）

**公式**：
```
材料损耗率 = (投入原料kg - 产出总重kg) ÷ 投入原料kg × 100%
产出总重 = 合格品kg + 次品kg
```

**例子**：
```
投入：100kg棉纱
产出：92kg合格品 + 5kg次品 = 97kg总布
材料损耗率 = (100 - 97) ÷ 100 = 3%
```

**这个指标衡量的是**：
- ✅ **原料在织造过程中的物理损失**（落纱、断头、边角料）
- ✅ **工艺稳定性**（损耗越低，说明断纱少、浪费少）
- ✅ **与成布率对应**：成布率 = 97%，损耗率 = 3%，两者加起来100%

---

### 定义2：**综合损失率**（不包含次品，单独核算）

**公式**：
```
成布率（合格品） = 合格品kg ÷ 投入原料kg × 100%
次品率 = 次品kg ÷ 总产出kg × 100%
综合损失率 = 材料损耗率 + 次品率
```

**例子**：
```
投入：100kg棉纱
产出：92kg合格品 + 5kg次品
材料损耗率 = (100 - 97) ÷ 100 = 3%
次品率 = 5 ÷ 97 = 5.15%
综合损失率 = 3% + 5.15% = 8.15%
```

**这个指标衡量的是**：
- ✅ **材料损耗**和**质量问题**分开看（责任归属清晰）
- ✅ **次品率单独考核质检环节**
- ✅ **更精细的成本控制**

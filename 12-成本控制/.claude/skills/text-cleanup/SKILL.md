# 文本清洗器 (Text Cleanup)

## 概述

专为语音转录后文本设计。语音转文字后往往包含大量口语化的感叹词、填充词、重复表达，这个 skill 指导 Claude 系统性地清理这些内容。

## 工作流程

当用户提供需要清洗的文本时，按以下步骤处理：

### 第一遍：去除赘语
删除以下类别的内容：
- **语气词**：嗯、啊、呃、哦、额、诶、唔、嘛、呢
- **填充词**：这个、那个、就是说、然后就是、那个什么、那个啥
- **口头禅**：对吧、你知道吗、你懂吗、明白吗、对不对
- **冗余开头**：所以呢、那么、总而言之、总的来说、基本上
- **英文填充**：um, uh, like, you know, I mean, sort of, kind of, basically, actually

### 第二遍：合并重复
- 识别重复表达（同一句话说两遍）
- 合并意思相近的相邻句子
- 去掉自我纠正的痕迹（"不对，我是说……"）

### 第三遍：结构化
- 添加适当的标点符号和分段
- 修正因语音识别产生的不自然断句
- 将过长的口语复合句拆分为更清晰的分句
- 保持原意不变，不添加新内容

### 第四遍：最终检查
- 读一遍清洗后的文本，确认语义完整
- 确认没有过度删减导致信息丢失
- 输出时附上修改摘要

## 输出格式

```markdown
## 清洗后文本

[清洗后的内容]

---

## 修改摘要

- 去除 X 处感叹词/填充词
- 合并 Y 处重复表达
- 修正 Z 处识别错误
```

## 重要原则

1. **保持原意**：只删除冗余，不改变语义
2. **保留风格**：如果是口语化场景（如聊天），保留适当口语感
3. **标注不确定**：对可能有歧义的地方用 [原文：xxx] 标注
4. **不过度清洗**：不是所有"然后"都要删，叙事性的"然后"保留

## 使用示例

用户：帮我清洗这段语音转录的文字：「嗯，就是说，我今天，那个，去了超市，然后就是，买了一些东西，对吧，然后呢，就是那个，发现，怎么说呢，价格还挺贵的」

输出：
```
## 清洗后文本
我今天去了超市，买了一些东西，发现价格还挺贵的。

## 修改摘要
- 去除 8 处感叹词/填充词（嗯、就是说、那个、然后就是、对吧、然后呢、就是那个、怎么说呢）
```

# 文档管理与归档规范

**制定时间**: 2026-09-23  
**制定原因**: 解决"需求散弹枪"问题，防止项目文档混乱失控  
**适用范围**: 成本控制管理体系项目的所有文档和输出物

---

## 🎯 核心原则

### 原则1：**一次性输出 vs 持续使用**
- **一次性输出**（如今天的成本分析PPT）→ 归档到**交付物归档区**，带日期标签
- **持续使用**（如成本核算模板）→ 保留在**工作区**，版本管理

### 原则2：**按业务场景分类，不按文件类型**
- ❌ 错误：所有PPT放一起、所有Excel放一起
- ✅ 正确：织造部成本核算一个文件夹、工资管理一个文件夹

### 原则3：**每月清理，3个月深度归档**
- 每月最后一天：清理临时文件，归档交付物
- 每季度末：00-归档文件夹压缩备份，工作区保持清爽

## 🔄 文档生命周期管理

### 阶段1：创建（实时记录到 PROJECT_STATUS.md）

**触发时机**: 任何新需求开始时

**必须记录**:
- 在 PROJECT_STATUS.md 的"进行中的工作"增加一条
- 记录需求来源、目标、预计交付时间

**示例**:
```markdown
## 🔄 进行中的工作
- 月度成本分析PPT（向老板汇报，预计9月25日交付）
- 织造部品种BOM建立（从ERP工艺单提取纱比%）
```

---

### 阶段2：执行中（工作区临时文件）

**文件位置**: 直接在项目根目录或对应业务文件夹

**命名规范**:
- 临时分析文件: `temp_成本分析_20260923.xlsx`
- 草稿PPT: `draft_月报_v1.pptx`
- 中间数据: `data_processing_20260923.csv`

**清理规则**: 
- 任务完成后**立即删除**或归档
- 超过7天未使用的temp_文件自动归档

---

### 阶段3：交付（归档到01-交付物归档）

**触发时机**: 交付给老板/其他部门时

**归档步骤**:

1. **创建月度文件夹**（如不存在）
   ```bash
   mkdir -p 01-交付物归档/2026-09
   ```

2. **移动最终成果**（带日期标签）
   ```
   月度成本分析报告_202609.pptx          # 主要成果
   月度成本分析报告_202609_数据明细.xlsx  # 附件
   月度成本分析报告_202609_生成记录.md    # 元数据
   ```

3. **生成记录文件**（模板见下）

4. **更新 PROJECT_STATUS.md**
   ```markdown
   ## ✅ 已完成的里程碑
   - [x] 2026-09-23: 完成9月月度成本分析报告并提交老板
   ```

5. **更新归档索引**（01-交付物归档/README.md）

---

### 阶段4：长期归档（00-归档文件夹）

**触发时机**: 
- 模板更新换代（旧版本归档）
- 方案废弃（失败的尝试也要归档，记录教训）
- 季度末清理（3个月前的临时文件）

**归档位置**: 对应业务文件夹下的 `00-归档/`

**归档格式**:
```
00-归档/
├── 2026Q3/
│   ├── 废弃方案_按纱批核算_20260815.md
│   └── 旧版模板_织造部成本核算v1.xlsx
└── README.md  # 归档说明：为什么废弃、有什么教训
```

## ⚠️ 禁止行为

### ❌ 绝对禁止
1. **不带日期的文件名**: `成本分析.pptx` ❌ → `月度成本分析报告_202609.pptx` ✅
2. **直接覆盖旧文件**: 旧版本必须归档到 `00-归档/`，保留变更历史
3. **临时文件堆积**: 超过7天的temp_文件必须清理
4. **交付物不记录**: 任何交付给老板的文件，必须生成"生成记录.md"

### ⚠️ 谨慎操作
1. **删除文件**: 除非是明确的临时文件（temp_），否则先归档再删除
2. **大规模重命名**: 先在PROJECT_STATUS.md记录重命名规则，再执行
3. **文件夹重构**: 提前备份，在00-归档中保留旧结构快照

## 🎯 与三大核心文件的协同

### PROJECT_STATUS.md（项目状态）
- **记录什么**: 当前在做什么、做到哪了、下一步做什么
- **不记录什么**: 历史交付物详情（去归档索引查）

### WORKFLOW.md（工作流）
- **记录什么**: 标准化、重复性任务的执行流程
- **不记录什么**: 一次性任务的具体执行（去生成记录.md查）

### CLAUDE.md（项目指引）
- **记录什么**: 项目原则、业务背景、核心方法论
- **不记录什么**: 具体任务的执行细节（去交付物归档查）

### 文档管理与归档规范.md（本文件）
- **记录什么**: 文件如何组织、如何归档、如何查找
- **不记录什么**: 业务规则（去CLAUDE.md查）

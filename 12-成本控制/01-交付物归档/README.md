## 归档说明

### 文件命名规范
```
{交付物名称}_{YYYYMM}.pptx          # 主要成果
{交付物名称}_{YYYYMM}_数据明细.xlsx  # 附件（如有）
{交付物名称}_{YYYYMM}_生成记录.md    # 必须（记录上下文）
```

### 月度归档流程
1. 创建月度文件夹（如不存在）：`YYYY-MM/`
2. 移动最终成果到月度文件夹
3. 生成"生成记录.md"（按模板）
4. 更新本索引文件
5. 更新 [PROJECT_STATUS.md](../PROJECT_STATUS.md) 的"已完成的里程碑"

### 查找历史交付物
1. **最快方式**：查看本索引 → 点击文件链接
2. **按时间查找**：PROJECT_STATUS.md → "已完成的里程碑" → 找到日期 → 查本索引
3. **全文搜索**：`find . -name "*关键词*" -type f`

# 财务经理入职任务清单
## 新疆T恤工厂 | 500人 | 1.4亿投资

> 打印出来，逐项勾选。入职前完成标记 ★ 的项目。

---

## 🚀 出发前（现在就做）

- [ ] ★ 确认报到时间、地点、对接人联系方式
- [ ] ★ 了解公司全称、法人、统一社会信用代码（用于查税务登记）
- [ ] ★ 询问公司现在用什么财务软件（用友/金蝶/管家婆/Excel）
- [ ] ★ 询问工资发放时间（几号发）和发放方式（银行代发/现金）
- [ ] ★ 确认电脑是否自带，还是需要自己带
- [ ] ★ 技能工具库已就绪（72个离线可用，无需翻墙）

---

## 📅 入职第一天

### 拿到权限（最高优先级，当天必须要到）
- [ ] 财务软件登录账号（ERP/用友/金蝶）
- [ ] 网银查询权限（至少要能看余额和流水）
- [ ] OA/审批系统账号
- [ ] 公司内网/共享文件夹访问权限

### 见人（当天安排时间）
- [ ] 见总经理：了解对财务的3大期望，确认财务汇报机制
- [ ] 见HR：获取员工花名册，了解工资架构
- [ ] 见前任财务（如有）：安排正式交接时间
- [ ] 见采购：了解主要供应商名单和付款情况
- [ ] 见生产总监：了解产品类型和计件方式

---

## 📋 入职第一周（P0 — 全部必须完成）

### 第一步：财务现状盘底

**报表**
- [ ] 调取近12个月损益表，通读一遍，找出异常月份
- [ ] 调取最新资产负债表，重点看：存货/应收/应付/贷款
- [ ] 调取近3个月现金流量表

**现金**
- [ ] 库存现金实盘（清点保险柜，账实核对）
- [ ] 获取所有银行账户清单（公司名下几个账户？）
- [ ] 核对每个账户：银行对账单余额 vs 财务账余额
- [ ] 查看近3个月网银流水（有没有异常大额转出）

**资产**
- [ ] 获取固定资产台账（1.4亿投资买了什么？设备/厂房/土地？）
- [ ] 确认固定资产折旧政策（年限/方法）
- [ ] 查看是否有银行贷款及还款计划表

**库存**
- [ ] 获取最新库存报表（原料/在制品/成品各多少）
- [ ] 了解库存盘点频率（每月？每季？）

### 第二步：工资摸底（下次发工资前必须全掌握）

- [ ] 获取完整员工花名册（姓名/岗位/工资类型/入职日期）
- [ ] 获取计件单价表（各工序/产品单价）
- [ ] 了解底薪标准（生产工人/管理/其他）
- [ ] 了解加班政策（平时/周末/节假日加班费计算方式）
- [ ] 了解绩效/提成规则（如有）
- [ ] 了解社保缴纳基数（是按最低基数还是实际工资？）
- [ ] 了解是否缴纳公积金
- [ ] 查看上月工资表，搞清楚计算逻辑

### 第三步：税务摸底

- [ ] 查看最近一次增值税申报记录
- [ ] 确认增值税税率（制造业一般13%）
- [ ] 确认企业所得税税率（是否享受西部大开发15%优惠？）
- [ ] 了解个税申报现状（是否按时申报？）
- [ ] 查看最近一次税务稽查或自查记录（如有）

---

## 📅 入职第一个月

### 工资管理
- [ ] 完成第一次500人工资核算（与HR双人复核）
- [ ] 建立工资核算标准模板（Excel或系统）
- [ ] 建立工资核算时间表（几号截考勤/几号算完/几号发放）

### 账务关账
- [ ] 完成第一次月度关账
- [ ] 生成三张报表（损益表/资产负债表/现金流）
- [ ] 向总经理提交第一份月度财务报告

### 制度建设
- [ ] 建立资金日报模板（每日发给总经理）
- [ ] 梳理所有供应商合同，建立付款台账
- [ ] 制定授权审批规则（多少金额需要什么级别签字）
- [ ] 了解公司现有财务制度（如无则开始起草）

### 信息收集
- [ ] 了解公司主要客户和回款周期
- [ ] 了解原材料主要来源（棉花/面料供应商）
- [ ] 了解生产效率数据（日产量/人均产量）

---

## 📅 入职第三个月

### 成本体系
- [ ] 建立标准成本体系（每件T恤标准成本 = 原料+人工+费用）
- [ ] 建立成本差异分析月报（实际vs标准）
- [ ] 找出TOP3成本控制机会点，提交给总经理

### 预算体系
- [ ] 建立年度预算模板（收入/成本/费用）
- [ ] 完成下一年度预算编制（或滚动预测）

### 管控体系
- [ ] 建立内控制度文件（不相容职务分离、印章管理等）
- [ ] 梳理税务合规情况，确认无遗留风险
- [ ] 完成一次正式的管理层财务汇报（PPT格式）

---

## ⚠️ 发现以下情况，立即上报总经理

- 账实不符超过1万元
- 银行账户有不明原因大额转出
- 账面亏损但实际有利润（或反之）
- 税务申报有遗漏或延迟
- 工资表有不合理的大额调整记录

# 织厂产品品种分类方案（成本核算用）

**制定时间**：2026-08-25  
**制定目的**：标准成本表分类、产量统计、差异分析

---

## 🎯 分类原则

成本核算的品种分类必须满足：
1. **成本差异显著**：同一品种内成本相近，不同品种间成本差异明显
2. **工艺相似**：同一品种的织造工艺、用纱系数、织损率接近
3. **数量可控**：品种数量不能太多（建议15-25个），否则核算太复杂
4. **可操作**：车间能明确区分，布票上能标注清楚

- 粗纱（16S-21S）
- 常规纱（24S）
- 细纱（32S）
- 精细纱（40S）

### 方案C：混合分类（高产量细分+低产量合并）

**核心思路**：
- **高产量规格**（占比>5%）：单独设品种
- **低产量规格**（占比<5%）：按类型合并

**步骤**：
1. 先统计上个月各规格产量
2. 找出TOP 10高产量规格
3. TOP 10单独设品种
4. 剩余规格按布种+纱线类型合并

**示例**（假设32S涤棉汗布产量最大）：

| 品种编号 | 品种名称 | 产量占比 | 说明 |
|---------|---------|---------|------|
| A01 | **32S涤棉汗布** | 25% | 单独品种（高产量） |
| A02 | **32S纯棉汗布** | 15% | 单独品种（高产量） |
| A03 | **21S涤棉汗布** | 10% | 单独品种（高产量） |
| A04 | **32S氨纶汗布** | 8% | 单独品种（高产量） |
| A05 | 其他汗布 | 12% | 合并（低产量规格） |
| B01 | **32S拉架** | 10% | 单独品种（高产量） |
| B02 | 其他拉架 | 5% | 合并 |
| C01 | **32S涤棉罗纹** | 7% | 单独品种（高产量） |
| C02 | 其他罗纹 | 4% | 合并 |
| D01 | 珠地类 | 4% | 合并 |

**品种总数**：10个

**优点**：
- ✅ 抓重点（80%产量用精确标准成本）
- ✅ 品种数量最少（10个）
- ✅ 第一个月最容易落地

**缺点**：
- ⚠️ 需要先统计产量数据
- ⚠️ "其他"类的成本可能不够精确

## 🎯 推荐方案（三步走）

### 第一个月：方案C（混合分类，10个品种）

**理由**：
- 快速落地，先跑起来
- 抓住80%的产量（精确核算）
- 建立标准成本法的基础框架

**执行步骤**：
1. 统计上个月产量，找出TOP 10规格
2. TOP 10单独设品种
3. 剩余规格合并为4-5个"其他"类
4. 建立10个品种的标准成本表

### 第二个月：优化为方案B（简化分类，13个品种）

**理由**：
- 第一个月发现了哪些"其他"类差异大
- 把差异大的拆分出来
- 保持品种数量可控

### 第三个月：升级为方案A（标准分类，20个品种）

**理由**：
- 数据完整了（BOM、织损率、纱价都准确了）
- 成本核算体系成熟了

## 🔄 品种调整机制

### 何时拆分品种

**触发条件**（任一满足）：
1. 同一品种内，最高成本 vs 最低成本 > 15%
2. 该品种产量占比 > 20%
3. 该品种下某个规格产量 > 该品种总量的70%

**举例**：
```
"其他汗布"品种包含：
- 24S涤棉汗布：2000kg，成本20元/kg
- 40S棉双纱：1500kg，成本32元/kg

成本差异：(32-20)/20 = 60% > 15%
→ 需要拆分为两个品种
```

---

### 何时合并品种

**触发条件**（任一满足）：
1. 该品种月产量 < 总产量的3%
2. 连续3个月产量为0
3. 成本与另一品种差异 < 5%

**举例**：
```
"40S氨珠地"品种：
- 月产量：200kg（占比0.3%）
- 成本：23.5元/kg

"32S氨珠地"品种：
- 月产量：1800kg（占比3%）
- 成本：23.2元/kg

差异：(23.5-23.2)/23.2 = 1.3% < 5%
→ 可以合并为"氨纶珠地"
```

## 💡 常见问题解答

### Q1：精梳涤棉和普通涤棉要分开吗？

**A**：看产量和价差
- 如果产量都不小（各占5%以上），且价差>10% → 分开
- 如果产量小或价差小 → 第一个月先合并，后面再细分

---

### Q2：氨纶含量不同（40D vs 70D）要分品种吗？

**A**：看成本差异
- 如果成本差异>10% → 分开
- 如果差异<10% → 第一个月先合并为"氨纶汗布"

---

### Q3：品种太多管不过来怎么办？

**A**：用"二八原则"
- 先把产量占80%的规格精细化（约10个品种）
- 剩余20%产量合并为"其他"类
- 第二个月再细化

---

### Q4：布票系统不支持品种编号怎么办？

**A**：财务端手工映射
- 导出布票数据（包含布种、纱线规格）
- Excel用VLOOKUP自动匹配品种编号
- 或者找IT在系统里加一个品种字段

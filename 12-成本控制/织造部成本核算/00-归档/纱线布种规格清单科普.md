# 纱线与布种规格清单科普

**更新时间**：2026-08-25  
**用途**：解读实际生产中的纱线编号和布种规格

---

## 📋 清单概览

你提供的清单包含约30个规格,涉及：
- **纱线类型**：涤纶纱、棉纱、涤棉混纺、氨纶包覆纱
- **布种类型**：汗布、拉架、罗纹、珠地
- **支数范围**：16S-40S（从粗到细）

---

## 一、纱线编号解读规则

### 基础公式

```
[支数] + [材质代码] + [混纺比例]

例如：32STC65/35
↓        ↓      ↓
32支     涤棉    涤65%棉35%
```

### 材质代码对照表

| 代码 | 英文 | 中文 | 特点 |
|------|------|------|------|
| **C** | Cotton | 纯棉 | 柔软、吸汗、贵 |
| **T** | Terylene/Polyester | 涤纶（聚酯纤维） | 耐磨、不皱、便宜 |
| **TC / CVC** | T/C blend | 涤棉混纺 | 综合性能 |
| **D** | Denier | 旦数（化纤粗细单位） | 常用于氨纶、涤纶丝 |
| **S** | Spandex | 氨纶（弹力纤维） | 弹性极好 |

### 支数 vs 旦数

| 单位 | 适用 | 含义 | 规律 |
|------|------|------|------|
| **支数（S）** | 棉纱、毛纱 | 1磅纱的长度（英制） | **数字越大越细** |
| **旦数（D）** | 化纤（涤纶、氨纶） | 9000米纱的重量（克） | **数字越大越粗** |

**常见组合**：
- 32S：棉纱支数
- 40D：涤纶丝或氨纶的粗细
- 32S+40D：棉纱32支 + 氨纶40旦包覆

## 二、清单逐条解读

### 🔵 纯棉系列

| 清单编号 | 解读 | 布种 | 用途 |
|---------|------|------|------|
| **32S纯棉** | 32支纯棉纱 | 汗布 | 普通T恤，柔软吸汗 |
| **21S纯棉** | 21支纯棉纱（较粗） | 汗布 | 厚实T恤、卫衣 |
| **24S纯棉** | 24支纯棉纱 | 汗布 | 常规T恤 |
| **16S纯棉** | 16支纯棉纱（粗） | 汗布 | 厚重T恤、工装 |

**特点**：
- 支数越低（16S）越粗、越厚实
- 支数越高（32S）越细、越柔软
- 100%棉，成本最高

---

### 🟢 涤棉混纺系列（TC/CVC）

| 清单编号 | 解读 | 涤/棉比例 | 布种 | 特点 |
|---------|------|---------|------|------|
| **32S涤棉混纺** | 32支涤棉混纺 | 涤65%棉35%（常见） | 汗布 | 耐磨不皱,性价比高 |
| **32S精梳涤棉** | 32支精梳涤棉（品质更高） | 同上 | 汗布 | 表面更光洁 |
| **21S涤棉** | 21支涤棉混纺（粗） | 同上 | 汗布 | 厚实耐穿 |
| **21S罗纹** | 21支涤棉罗纹 | 同上 | 罗纹 | 领口袖口 |
| **21S精梳涤棉** | 21支精梳涤棉 | 同上 | 汗布 | 品质款 |
| **32S涤棉罗纹** | 32支涤棉罗纹 | 同上 | 罗纹 | 细腻有弹性 |
| **40S涤棉罗纹** | 40支涤棉罗纹（细） | 同上 | 罗纹 | 高档领口 |

**TC vs CVC**：
- **TC**（Polyester/Cotton）：涤纶为主（如涤65%棉35%）
- **CVC**（Chief Value Cotton）：棉为主（如棉60%涤40%）

**精梳（Combed）**：
- 纱线经过精梳工序，去除短纤维和杂质
- 表面更光洁、不起毛球、贵10-20%

---

### 🟡 氨纶混纺系列（弹力布）

| 清单编号 | 解读 | 成分 | 布种 | 特点 |
|---------|------|------|------|------|
| **32S氨纶汗布** | 32S棉 + 氨纶（约5%） | 棉95%氨5% | 汗布 | 有弹性,贴身 |
| **32S氨罗纹** | 32S棉 + 氨纶 | 同上 | 罗纹 | 弹性领口 |
| **40S氨罗纹** | 40S棉 + 氨纶（细腻） | 同上 | 罗纹 | 高档弹力领口 |
| **32S+40D氨纶汗布** | 32支棉 + 40旦氨纶 | 明确标注氨纶粗细 | 汗布 | 精确控制弹性 |
| **32S+70D氨纶汗布** | 32支棉 + 70旦氨纶（粗） | 氨纶含量更高 | 汗布 | 弹性更大 |

**氨纶含量**：
- 通常添加3-5%氨纶
- 40D ≈ 3-5%
- 70D ≈ 5-8%（弹性更大）

**+号含义**：
- 32S+40D：表示棉纱和氨纶是**分开的两根纱**，包覆在一起织造
- 不是混纺（混纺是纤维级混合），是**包覆纱**

---

### 🟠 珠地系列（Pique）

| 清单编号 | 解读 | 成分 | 特点 |
|---------|------|------|------|
| **32S珠地** | 32支纱的珠地组织 | 棉或涤棉 | 表面有凸起颗粒（像珍珠） |
| **32S氨珠地** | 32S + 氨纶的珠地 | 棉+氨纶 | 有弹性的珠地 |
| **40S氨珠地** | 40S + 氨纶的珠地（细腻） | 棉+氨纶 | 高档POLO衫 |

**珠地布（Pique）**：
- 表面有规则的凸起颗粒（菱形或圆形）
- 透气性好，立体感强
- **POLO衫的标配面料**
- 不属于汗布/拉架/罗纹，是独立的组织类型

---

### 🟣 拉架系列（Interlock）

| 清单编号 | 解读 | 成分 | 特点 |
|---------|------|------|------|
| **32S拉架** | 32支纱的拉架组织 | 棉或涤棉 | 双面布,不卷边 |
| **21S拉架** | 21支纱的拉架（厚） | 棉或涤棉 | 厚实款T恤 |
| **24S拉架** | 24支纱的拉架 | 棉或涤棉 | 常规拉架 |
| **32S涤拉架** | 32S涤棉混纺拉架 | 涤65%棉35% | 耐穿拉架 |
| **40S涤拉架** | 40S涤棉混纺拉架（细） | 同上 | 高档拉架 |
| **32STL/75D+16D** | 特殊规格拉架 | 涤纶丝+氨纶 | 运动面料,弹性大 |

**拉架的成本特点**（对比汗布）：
- 用纱量多5-8%
- 织造速度慢
- 次品率低

---

### 🔴 特殊规格解读

#### 1. **20S OE汗布**

**OE** = Open End（气流纺）

| 对比 | 普通环锭纺 | OE气流纺 |
|------|-----------|---------|
| 工艺 | 传统纺纱 | 高速气流纺纱 |
| 成本 | 高 | 低20-30% |
| 手感 | 柔软光滑 | 稍粗糙 |
| 强度 | 高 | 稍低 |
| 用途 | 品质款 | 性价比款 |

**20S OE汗布** = 20支气流纺纱织的汗布，**便宜但手感稍差**

---

#### 2. **32STL/75D+16D**

**拆解**：
- 32S：棉纱32支
- **TL**：可能是Terylene+Lycra（涤纶+氨纶）的缩写，或特定供应商代号
- 75D：粗氨纶或涤纶丝（70-75旦）
- 16D：细氨纶（16旦）

**推测**：双氨纶复合结构（一粗一细），用于**高弹运动面料**

**成本影响**：氨纶含量高，成本比普通氨纶汗布贵30-50%

## 四、对成本核算的影响（实战）

### 1. 标准成本表必须分类设定

**错误做法**：
```
所有纱线统一按 1.05 的用纱系数
所有织损率统一按 4%
```
→ **成本严重失真**

**正确做法**：

| 纱线/布种 | 标准用纱系数 | 标准织损率 | 单位标准成本（元/kg） |
|---------|-------------|-----------|---------------------|
| 32S纯棉汗布 | 1.03 | 3% | 25.75（纯棉贵） |
| 32S涤棉汗布 | 1.03 | 3% | 20.60（涤棉便宜） |
| 32S拉架 | 1.07 | 4% | 21.40（用纱多） |
| 32S氨纶汗布 | 1.04 | 3.5% | 22.88（氨纶贵） |
| 32S珠地 | 1.06 | 4% | 21.84（工艺复杂） |
| 32S罗纹 | 1.05 | 5% | 21.00 |
| 20S OE汗布 | 1.03 | 4%（稍高） | 18.54（便宜但损耗大） |

**假设纱价**：
- 纯棉32S：25元/kg
- 涤棉32S：20元/kg
- 氨纶纱：22元/kg
- OE纱：18元/kg

---

### 2. 分类统计产量

**月末汇总时不能简单相加**：

❌ **错误**：
```
本月产出：
- 32S汗布：1000kg
- 32S拉架：800kg
- 32S罗纹：500kg
合计：2300kg → 用这个算平均成本
```

✅ **正确**：
```
本月产出（分类统计）：

汗布类：
- 32S纯棉汗布：400kg
- 32S涤棉汗布：600kg
小计：1000kg

拉架类：
- 32S拉架：800kg

罗纹类：
- 32S罗纹：500kg

→ 分别计算标准成本，再汇总
```

---

### 3. 纱线采购价格追溯

**不同纱线价格差异大**：

| 纱线类型 | 市场价（元/kg） | 价格波动 |
|---------|---------------|---------|
| 32S纯棉 | 23-27 | 大（受棉花价格影响） |
| 32S涤棉 | 18-22 | 中等 |
| 32S氨纶 | 20-24 | 中等（氨纶涨价） |
| 20S OE | 16-19 | 小 |
| 40D氨纶丝 | 30-40 | 大（化工原料） |

**成本核算时必须区分**：
- 不能用"平均纱价20元"
- 要按**纱批号追溯实际采购价**

---

### 4. 织损率差异分析

**不同规格织损率不同**：

| 布种 | 理论织损率 | 常见超标原因 |
|------|-----------|------------|
| 汗布 | 3% | 纱质量差、机器调试不当 |
| 拉架 | 4% | 工艺复杂、操作失误 |
| 罗纹 | 5% | 收缩大、次品多 |
| 珠地 | 4-5% | 针路复杂 |
| OE纱 | 4-5% | **纱强度低，断头多** |

**月末差异分析时**：
- 如果OE纱的织损率只有3% → 不合理，可能是BOM定低了
- 如果纯棉的织损率有6% → 需要查原因（纱质量？工人操作？）

## 五、快速识别口诀

### 纱线编号速记

```
看支数 → 判粗细（16粗、40细）
看字母 → 识材质（C棉、T涤、S氨纶）
看数字 → 看比例（65/35 = 涤多棉少）
看+号 → 双纱包覆（32S+40D）
```

### 布种识别

```
汗布 = 单面、会卷边、最常见
拉架 = 双面、不卷边、较厚
罗纹 = 有条纹、超弹、领口专用
珠地 = 有颗粒、透气、POLO衫
```

### 成本高低排序（同支数）

```
便宜 ← → 贵

OE纱 < 涤棉 < 纯棉 < 氨纶混纺 < 精梳棉
汗布 < 拉架 ≈ 珠地 < 罗纹
```

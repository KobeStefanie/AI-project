# 标准成本法在混乱现场的实际应用

**文档类型**：财务实务操作指南  
**适用场景**：车间领料混乱、纱线挂筒、无法精确追溯到订单  
**制定时间**：2026-08-27

---

## 🎯 核心困境

你现在的实际情况：
- ✅ 有BOM单（知道应该用多少料）
- ✅ 知道实际领了多少料（但不知道哪个订单用的）
- ✅ 知道实际产了多少坯布
- ❌ 无法对应：哪批料用在哪个订单

**这正是标准成本法的应用场景！**

---

## 📊 Part 1：标准成本法的核心理念

### 核心：不追溯实际，全部用标准

**传统思维（实际成本法）**

```
订单S001 → 实际用了哪批纱？ → 实际成本多少？
↑ 你现在做不到（领料混乱）
```

**标准成本法思维**

```
订单S001 → 按BOM应该用多少纱？ → 标准成本多少？
月末：总投入 vs 总产出 → 算总差异
↑ 你能做到！
```

## 🔄 Part 2：实际操作方法（两步走）

### 第1步：订单核算（用标准成本，不管实际领料）

**订单S001**

```
产品：C-J-32TC-A（32S涤棉汗布）
实际产出：950kg A级 + 50kg B级 + 10kg C级
```

**从BOM查标准**

```
cloth_bom表：
- 用纱系数：1.03
- 织损率：3%
- 标准用纱量 = (950+60) ÷ (1-3%) × 1.03 = 1071kg
```

**从标准价表查**

```
standard_price表：
- Y-32S-TC标准价：20元/kg
```

**订单标准成本**

```
材料成本 = 1071kg × 20元 = 21420元
合格品成本 = 950kg × (21420 ÷ 1010) = 20130元
次品成本 = 60kg × (21420 ÷ 1010) = 1271元
```

**会计处理**

```
借：产成品-C-J-32TC-A 20130
借：产成品-C-J-32TC-B级 1059
借：产成品-C-J-32TC-C级 212
  贷：生产成本-材料 21420（标准成本）
```

**关键**

- ❌ 不管订单S001实际领了多少料
- ✅ 只按BOM算标准用料，乘标准价
- 车间实际领料混乱？不影响订单成本核算！

---

### 第2步：月末总差异分析（倒轧）

**月初**

```
原纱Y-32S-TC库存：1000kg，账面成本20000元（加权平均20元/kg）
```

**本月采购**

```
- 8月5日：1500kg × 18元 = 27000元
- 8月15日：2000kg × 21元 = 42000元
- 8月25日：1200kg × 19元 = 22800元
合计采购：4700kg，91800元
```

**本月可用**

```
总可用 = 期初1000kg + 采购4700kg = 5700kg
总成本 = 20000 + 91800 = 111800元
```

**本月生产消耗（按标准）**

```
订单S001：Y-32S-TC，1071kg × 20元 = 21420元
订单S002：Y-32S-TC，850kg × 20元 = 17000元
订单S003：Y-32S-TC，920kg × 20元 = 18400元
...
合计按标准消耗：5000kg，标准成本100000元
```

**月末盘点**

```
实际剩余库存：600kg
```

**倒轧实际消耗**

```
实际消耗 = 5700kg（可用）- 600kg（剩余）= 5100kg
```

**总差异**

```
标准消耗：5000kg × 20元 = 100000元
实际消耗：5100kg
加权平均价 = 111800 ÷ 5700 = 19.61元/kg
实际成本 = 5100kg × 19.61 = 100011元
```

**总差异**

```
100011元（实际）- 100000元（标准）= 11元（不利，可忽略）
```

**差异拆解**

```
价格差异 = (19.61 - 20.00) × 5100 = -1989元（有利）
→ 本月采购价低于标准，节约

数量差异 = (5100 - 5000) × 20 = 2000元（不利）
→ 多用了100kg纱
→ 原因：挂筒？多领？织损超标？
```

## 📋 Part 3：关键问题解答

### 问题1：不按订单领料，怎么知道订单用了多少料？

**答案：不需要知道！用BOM反推**

**传统想法（做不到）**

```
订单S001实际领料 → 实际用料 → 实际成本
```

**标准成本法（能做到）**

```
订单S001实际产出 → BOM反推标准用料 → 标准成本
```

**实例**

```
订单S001产出：950kg A级 + 60kg次品
BOM：用纱系数1.03，织损率3%
反推标准用料 = (950+60) ÷ (1-3%) × 1.03 = 1071kg
标准成本 = 1071 × 20元 = 21420元
```

**这个"反推"是合理的**

因为：
1. 不是反推"实际用了多少"（那做不到）
2. 是反推"按BOM应该用多少"（这是标准）
3. 订单成本全部用标准，月末算总差异

---

### 问题2：纱线挂筒怎么办？

**答案：忽略！计入月末总差异**

**挂筒的影响**

```
订单S001完成，挂筒剩50kg
订单S002开始，先用完挂筒50kg，再领新纱
```

**标准成本法处理**

```
订单S001：
- 产出：1010kg
- 标准用纱：1071kg
- 标准成本：21420元
- ❌ 不管挂筒剩多少

订单S002：
- 产出：820kg
- 标准用纱：850kg
- 标准成本：17000元
- ❌ 不管先用的是挂筒纱
```

**挂筒的成本去哪了？**

```
→ 计入月末总差异
→ 如果挂筒管理混乱，会体现为"数量差异"
→ 但不影响单个订单成本
```

---

### 问题3：月末盘点时纱线还挂在机器上怎么办？

**答案：盘点要包含挂筒纱**

**月末盘点**

```
1. 原料仓库存：500kg
2. 车间挂筒纱：100kg ← 必须盘点
合计库存：600kg
```

**如果不盘挂筒纱**

```
账面消耗 = 5700 - 500 = 5200kg
实际消耗 = 5700 - 600 = 5100kg
→ 差异虚增100kg
```

**实务操作**

```
月末车间盘点挂筒纱：
- 逐台机器登记：机器号、纱批号、估计重量
- 汇总到"车间在用原料"科目
- 视同库存
```

#### Day 32-35：差异分析

**第1步：倒轧实际消耗**

```
Y-32S-TC：
期初：1000kg
采购：4700kg
可用：5700kg
期末：600kg
实际消耗 = 5700 - 600 = 5100kg
```

**第2步：汇总标准消耗**

```
本月所有订单标准消耗：
订单S001：1071kg
订单S002：850kg
订单S003：920kg
...
合计：5000kg
```

**第3步：计算差异**

```
数量差异：
实际消耗5100kg - 标准消耗5000kg = 100kg
差异成本 = 100kg × 20元（标准价）= 2000元（不利）

价格差异：
实际均价 = 111800 ÷ 5700 = 19.61元/kg
标准价 = 20.00元/kg
差异 = (19.61 - 20.00) × 5100 = -1989元（有利）

总差异 = 2000 - 1989 = 11元（可忽略）
```

**第4步：原因分析**

```
数量差异100kg（不利）是为什么？

可能原因：
1. 织损超标（查每个订单实际织损率）
2. 挂筒管理混乱（挂筒纱没用完就换新纱）
3. 次品率高（次品也要消耗纱，但卖价低）
4. 车间多领料、私自处理（管理漏洞）

→ 逐项排查
```

### 表4：订单成本计算（自动触发）

```sql
-- 触发器或存储过程自动计算标准成本
CREATE TRIGGER calc_standard_cost 
AFTER INSERT ON production_order
FOR EACH ROW
BEGIN
    DECLARE std_yarn_coeff DECIMAL(5,3);
    DECLARE std_loss_rate DECIMAL(5,3);
    DECLARE std_price DECIMAL(10,2);
    DECLARE std_yarn_qty DECIMAL(10,2);
    DECLARE std_cost DECIMAL(10,2);
    DECLARE total_output DECIMAL(10,2);
    
    -- 查BOM
    SELECT yarn_coefficient, loss_rate 
    INTO std_yarn_coeff, std_loss_rate
    FROM cloth_bom 
    WHERE cloth_sku = NEW.cloth_sku;
    
    -- 查标准价
    SELECT standard_price 
    INTO std_price
    FROM standard_price 
    WHERE yarn_sku = (
        SELECT yarn_sku 
        FROM cloth_bom 
        WHERE cloth_sku = NEW.cloth_sku
    )
    AND CURDATE() BETWEEN effective_date AND expiry_date;
    
    -- 计算标准用料
    SET total_output = NEW.actual_grade_a + 
                       NEW.actual_grade_b + 
                       NEW.actual_grade_c;
    SET std_yarn_qty = total_output / (1 - std_loss_rate) * 
                       std_yarn_coeff;
    SET std_cost = std_yarn_qty * std_price;
    
    -- 插入成本记录
    INSERT INTO order_standard_cost (
        order_id,
        standard_yarn_qty,
        standard_price,
        standard_material_cost
    ) VALUES (
        NEW.order_id,
        std_yarn_qty,
        std_price,
        std_cost
    );
END;
```

### 表5：月末差异分析

```sql
-- 倒轧实际消耗
SELECT 
    yarn_sku,
    begin_stock + purchase_qty - end_stock AS actual_consumption,
    standard_consumption,
    (begin_stock + purchase_qty - end_stock - standard_consumption) 
        AS quantity_variance
FROM (
    SELECT 
        'Y-32S-TC' AS yarn_sku,
        1000 AS begin_stock,
        4700 AS purchase_qty,
        600 AS end_stock,
        (
            SELECT SUM(standard_yarn_qty) 
            FROM order_standard_cost 
            WHERE MONTH(production_date) = 8

) t;
```

## 🎯 回答核心困惑

### 问题拆解

**"领料混乱，无法精准到BOM用了多少料"**

答案：不需要精准！全部用标准成本，月末算总差异

---

**"纱线挂筒问题"**

答案：忽略！挂筒影响会体现在月末总差异中

---

**"知道真实领用多少原料，知道产了多少坯布"**

答案：
- 真实领用 → 月末倒轧用（期初+采购-期末）
- 产了多少坯布 → 反推标准用料 → 标准成本
- 两者对比 → 差异分析

---

### 核心公式

**订单成本**

```
标准用料 = 实际产出 ÷ (1-标准织损率) × 用纱系数
标准成本 = 标准用料 × 标准价
```

**月末差异**

```
实际消耗 = 期初库存 + 本月采购 - 期末库存
数量差异 = 实际消耗 - 标准消耗
价格差异 = (实际均价 - 标准价) × 实际消耗
```

## 💡 常见误区

### 误区1：一定要追溯到订单

```
❌ 错误想法：
每个订单必须知道用了哪批纱

✅ 正确理解：
标准成本法不追溯单个订单
月末算总差异就够了
```

---

### 误区2：反推实际用料

```
❌ 错误做法：
产了950kg坯布
→ 反推实际用了多少纱

✅ 正确做法：
产了950kg坯布
→ 反推标准应该用多少纱
→ 用标准价算成本
```

---

### 误区3：挂筒纱必须分清

```
❌ 错误想法：
必须知道挂筒纱用在哪个订单

✅ 正确理解：
挂筒纱计入月末库存
影响体现在总差异中
不影响单个订单成本
```

## 🎯 关键成功因素

### 1. BOM数据准确

```
用纱系数和织损率必须准确
否则标准成本偏差大
定期（每季度）校准
```

### 2. 标准价格合理

```
基于近3个月采购均价
每季度更新一次
不要频繁调整
```

### 3. 库存盘点准确

```
月末必须盘点挂筒纱
否则差异虚增
建立盘点SOP
```

### 4. 差异分析及时

```
月末5天内完成差异分析
超标项目立即追查
形成改进闭环
```

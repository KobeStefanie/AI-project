# 小圆筒生产单术语科普（含针织布三大家族）

**更新时间**：2026-08-25  
**用途**：帮助财务人员快速理解织造车间的生产单和成本核算基础

---

## 一、基础名词：针织布的三大家族

### 1. 汗布（Jersey / 单面平纹布）

**定义**：针织布的一种，正反面不一样，单面组织。

**特点**：
- 表面光滑，反面有线圈凸起
- 轻薄透气，适合夏季穿着
- 边缘容易卷边（这是汗布的天性）
- 弹性一般，主要靠纱线本身的弹性

**用途**：
- T恤的身体部分（最常见）
- 运动服、内衣

**为什么叫"汗布"**：因为透气吸汗，夏天穿着舒服。

**成本特点**：
- 用纱量少（单面）
- 织造速度快
- 次品率中等（易卷边、易变形）

---

### 2. 拉架布（Interlock / 双面平纹布）

**定义**：双面针织组织，正反面看起来一样，都是平针面。

**特点**：
- 双面结构，相当于两层汗布贴在一起（但是一体织出来的）
- 比汗布厚实、稳定
- 不卷边，边缘平整
- 弹性比汗布好，但比罗纹小
- 手感柔软，垂感好

**用途**：
- T恤、POLO衫（比汗布高档）
- 内衣、婴儿服（稳定不变形）
- 对质量要求高的针织品

**为什么叫"拉架"**：英文Interlock直译，指两层针织结构互相"锁住"。

**成本特点**：
- 用纱量比汗布多5-8%（双面结构）
- 织造速度比汗布慢（工艺复杂）
- 次品率比汗布低（不卷边、稳定）

**常见叫法**：
- "棉拉架平纹" = 棉质 + 拉架组织 + 平针面（区别于珠地、提花）

---

### 3. 罗纹（Rib / 凸凹条纹布）

**定义**：针织布的一种，表面有竖向凸凹条纹，弹性很大。

**特点**：
- 竖向凸凹条纹明显（像搓衣板）
- 横向弹性非常好（可以拉伸1倍以上）
- 纵向收缩性强（布会"缩"）
- 厚实、有质感

**用途**：
- T恤的领口（圆领、V领）
- T恤的袖口、下摆（需要贴身、不松垮）
- 打底衫、螺纹袜

**为什么叫"罗纹"**：因为表面的凸凹条纹，像罗马柱上的纹路。

**成本特点**：
- 用纱量中等到高（看针数和门幅）
- 织造速度慢（工艺复杂）
- 次品率低（结构稳定）

---

### 三大家族对比表

| 特征 | 汗布（Jersey） | 拉架（Interlock） | 罗纹（Rib） |
|------|---------------|-----------------|------------|
| **组织结构** | 单面平针 | 双面平针 | 凸凹条纹 |
| **正反面** | 不一样 | 一样 | 一样 |
| **厚度** | 薄 ★ | 中等 ★★ | 厚 ★★★ |
| **弹性** | 小 | 中等 | 大 |
| **卷边** | 易卷边 ❌ | 不卷边 ✅ | 不卷边 ✅ |
| **稳定性** | 一般 | 好 | 最好 |
| **织造难度** | 简单 | 中等 | 复杂 |
| **用纱量** | 少 | 多（双面） | 更多 |
| **常用部位** | T恤身体 | T恤、POLO衫、内衣 | 领口、袖口、下摆 |
| **标准用纱系数（参考）** | 1.03 | 1.06-1.08 | 1.05-1.10 |
| **标准织损率（参考）** | 3% | 4% | 5% |

---

### 4. 小圆筒（Tubular Fabric）

**定义**：圆筒形的针织布，不是平幅的。

**怎么织出来的**：
- 用圆型针织机（Circular Knitting Machine）织造
- 机器的针盘是圆形的，纱线绕圈织，织出来就是圆筒状
- 像织毛线帽子一样，只是机器自动化了

**特点**：
- 织出来是圆筒，不是一整片平布
- 没有侧缝（无缝衔接）
- 后续可以开幅（剪开变成平幅布）或直接打卷

**用途**：
- 小圆筒坯布 → 开幅 → 染色 → 裁剪 → T恤
- 或者：小圆筒坯布 → 直接染色（筒染）→ 裁剪

**生产单上的体现**：
- "小圆筒" = 这批订单要织的是圆筒布（不是平幅布）
- 通常搭配"开幅打卷"这个加工方式

## 二、关键参数：生产单上的数字都是什么意思

### 1. 门幅（幅宽）

**定义**：布的宽度，单位通常是厘米（cm）或英寸（inch）。

**小圆筒的门幅**：
- 圆筒布剪开、平铺后的宽度
- 例如：门幅165cm = 圆筒剪开后，布宽165cm

**常见门幅规格**：
- 小门幅：150-180cm（常规T恤）
- 大门幅：200-240cm（宽松T恤、床品）

**对成本的意义**：
- 门幅越大，用纱越多，成本越高
- 同样产量，大门幅的机工时可能更长

---

### 2. 针寸数（例：18针38寸）

**拆解**：
- **"寸"**（38寸）= 针筒直径（英寸）
  - 38寸 ≈ 96.5厘米直径的针筒
  - 决定了圆筒布的周长，进而影响门幅
  
- **"针"**（18针）= 针密度（Gauge）
  - 指针筒每英寸有多少根针
  - 18针 = 每英寸18根针
  - 针数越高，布越细密

**对成本的意义**：
- 针寸数不同 = 机器型号不同 = 不能混用
- 高针数（细密）= 织造慢、成本高，但布更精细

---

### 3. 线长（Stitch Length）

**定义**：每一针用掉的纱线长度，单位：毫米（mm）或厘米（cm）。

**意义**：
- 线长决定了布的松紧度
- 线长越长 → 布越松软、透气，但强度低
- 线长越短 → 布越紧密、厚实，但硬挺

**对成本的核心作用**：
- **线长是用纱量的源头控制点**
- 调整线长1mm，整批布的用纱量变化1-2%
- 成本核算时，线长是BOM的基础参数

---

### 4. 克重（GSM: Grams per Square Meter）

**定义**：每平方米布的重量，单位：克/平方米（g/m²）。

**常见克重**：
- 轻薄T恤：120-160 g/m²
- 常规T恤：160-200 g/m²
- 厚实卫衣：250-350 g/m²

**对成本的意义**：
- 克重 × 面积 = 总重量
- 克重是验收标准（客户要求180g/m²，你织成160g/m²就是不合格）
- 成本核算时，克重是产出计量的基础

---

### 5. 匹（Roll）和匹重

**匹**：
- 一卷布 = 一匹布
- 圆机织出来的布，卷成一卷，就是一匹

**匹重**：
- 一匹布的重量
- 生产单上常见：匹重25公斤、30公斤等

**对成本的意义**：
- 产量统计的基本单位
- 例：这批订单要织100匹，每匹25公斤 = 总产量2500公斤
- 验收时按匹过磅，每匹实际重量可能有偏差（±0.5公斤）

## 三、生产单在排什么：一张单子的完整信息

### 典型生产单字段（以你提供的布票为例）

```
订单号：S2608Z5005
客户：k05
编号：11012
布种：40D1*1罗纹
纱支信息：40S+40D
纱批号：C3260810, B0424 06300
针寸数：18针38寸
机台号：LW037
布累号：000001
加工方式：开幅打卷
值机：（操作工人）
重量：KG（待填）
时间：2026/8/25 16:16:36
```

### 这张单子在说什么

1. **订单追溯**：S2608Z5005 → 客户k05的订单
2. **产品规格**：40D1*1罗纹，18针38寸
3. **原料追溯**：纱批号C3260810, B0424 06300（如果出质量问题，能追溯到哪批纱）
4. **机台归集**：LW037号机器织的（成本核算时，这台机器的折旧、工时要分摊到这批布）
5. **加工方式**：开幅打卷（圆筒剪开、卷起来交货）
6. **计量依据**：重量（KG）— 这批布下机后过磅，按重量计算产量和工资

---

### 生产计划表的核心逻辑

**一张生产计划表在回答三个问题**：

1. **织什么**：布种、规格、门幅
2. **用什么织**：纱批号、针寸数、线长
3. **织多少**：匹数、匹重、总重量

**对成本核算的意义**：
- **投入**：纱批号 → 领料单 → 材料成本
- **产出**：匹数、重量 → 布票 → 产量统计
- **过程**：机台号、机工时 → 制造费用分摊

---

## 四、纱线编号解读：24STC65/35是什么意思

### 拆解

**24S**：
- 纱线支数（Yarn Count）
- 24支纱 = 1磅棉花纺成24×840码长的纱
- **支数越高，纱越细**（40S比24S细）

**T/C**：
- T = Terylene（涤纶，即聚酯纤维Polyester）
- C = Cotton（棉）
- T/C = 涤棉混纺

**65/35**：
- 涤纶65%，棉35%
- 混纺比例

### 完整读法

**24STC65/35** = 24支涤棉混纺纱，涤纶65%、棉35%

---

### 常见纱线编号

| 编号 | 支数 | 材质 | 混纺比例 | 特点 |
|------|------|------|---------|------|
| 32SC | 32支 | 纯棉 | 100%棉 | 细、柔软、贵 |
| 40S+40D | 40支+40旦 | 棉+氨纶 | 棉为主+少量氨纶 | 弹性好 |
| 24STC65/35 | 24支 | 涤棉 | 涤65%棉35% | 耐磨、不易皱 |
| 16SJC | 16支 | 涤棉 | 混纺 | 粗、厚实 |

## 五、对成本核算的意义：为什么财务要懂这些

### 1. 产出计量基准

**没有这些术语，你不知道怎么算产量**：
- 汗布、拉架、罗纹的产出能直接相加吗？（不能，要分类统计）
- 按重量算（公斤）还是按面积算（米）？（看客户要求和行业惯例）
- 一匹布到底多重？（看匹重设定，通常25公斤）

**成本核算公式的基础**：
```
单位成本 = 总成本 ÷ 产出数量
↑ 产出数量怎么统计？靠布票、匹数、克重
```

---

### 2. 材料源头控制

**没有纱批号，成本算不准**：
- 同样是24S纱，不同批次价格可能不同
- A批次20元/公斤，B批次22元/公斤
- 如果不追溯纱批号,只能用平均价（不精准）

**线长是用纱量的源头**：
- 线长多1mm，一匹布多用0.5公斤纱
- 100匹布 × 0.5公斤 = 50公斤纱 × 20元 = 1000元成本差异

---

### 3. 机台归集基础

**没有机台号和针寸数，制造费用分摊不了**：
- 1550台机器的折旧、水电、维修费，怎么分摊到每匹布？
- 按机工时分摊 → 需要知道每台机器织了多久
- 布票上的"机台号LW037" + 系统里的"机工时8小时" = 这匹布应分摊的制造费用

---

### 4. 标准成本制定

**标准成本表必须分品种**：

| 品种 | 单位标准用纱系数 | 标准织损率 | 标准成本（元/公斤） |
|------|----------------|-----------|-------------------|
| 汗布（24S） | 1.03 | 3% | 20.60 |
| 拉架（24S） | 1.07 | 4% | 21.40 |
| 罗纹（40D） | 1.05 | 5% | 21.00 |

**为什么不同**：
- 汗布：单面、简单、用纱少
- 拉架：双面、复杂、用纱多
- 罗纹：凸凹结构、弹性大、工艺复杂

**如果不懂这些术语**：
- 标准成本设成一样 → 汗布成本高估、拉架成本低估 → 差异分析失真

## 七、实际生产中的纱线与布种规格（完整清单）

### 纱线编号解读规则

**基础公式**：
```
[支数] + [材质代码] + [混纺比例]

例如：32STC65/35
↓        ↓      ↓
32支     涤棉    涤65%棉35%
```

**材质代码对照表**：

| 代码 | 英文 | 中文 | 特点 |
|------|------|------|------|
| **C** | Cotton | 纯棉 | 柔软、吸汗、贵 |
| **T** | Terylene/Polyester | 涤纶（聚酯纤维） | 耐磨、不皱、便宜 |
| **TC / CVC** | T/C blend | 涤棉混纺 | 综合性能 |
| **D** | Denier | 旦数（化纤粗细单位） | 常用于氨纶、涤纶丝 |
| **S** | Spandex | 氨纶（弹力纤维） | 弹性极好 |

**支数 vs 旦数**：

| 单位 | 适用 | 含义 | 规律 |
|------|------|------|------|
| **支数（S）** | 棉纱、毛纱 | 1磅纱的长度（英制） | **数字越大越细** |
| **旦数（D）** | 化纤（涤纶、氨纶） | 9000米纱的重量（克） | **数字越大越粗** |

**常见组合**：
- 32S：棉纱支数
- 40D：涤纶丝或氨纶的粗细
- 32S+40D：棉纱32支 + 氨纶40旦包覆

---

### 实际生产规格分类科普

#### 🔵 纯棉系列

| 规格 | 解读 | 布种 | 特点 |
|------|------|------|------|
| **32S纯棉** | 32支纯棉纱 | 汗布 | 柔软吸汗，T恤常用 |
| **21S纯棉** | 21支纯棉纱（较粗） | 汗布 | 厚实耐穿 |
| **24S纯棉** | 24支纯棉纱 | 汗布 | 常规款 |
| **16S纯棉** | 16支纯棉纱（粗） | 汗布 | 厚重工装款 |

**特点**：
- 支数越低（16S）越粗、越厚实
- 支数越高（32S）越细、越柔软
- 100%棉，手感最好，但成本最高

---

#### 🟦 化纤系列（涤纶低弹丝DTY）

**什么是低弹丝（DTY）**：
- **DTY** = Draw Textured Yarn（拉伸变形丝）
- 涤纶丝经过拉伸和加热变形，产生弹性
- 手感柔软、有弹性、蓬松
- 比普通涤纶丝舒适，比棉纱便宜

**规格表示方法**：**旦数D / 丝数F**

| 规格 | 解读 | 特点 | 用途 |
|------|------|------|------|
| **75D/36F** | 75旦 ÷ 36根单丝 | 细、粗丝、光泽强 | 轻薄运动服 |
| **100D/144F** | 100旦 ÷ 144根单丝 | 中等、柔软 | 常规T恤 |
| **118D/144F** | 118旦 ÷ 144根单丝 | 中等、柔软 | 运动T恤、速干衣 |
| **150D/144F** | 150旦 ÷ 144根单丝 | 粗、厚实 | 厚实运动服 |
| **150D/288F** | 150旦 ÷ 288根单丝 | 粗、超细丝、像真丝 | 高档运动服 |

**关键参数解读**：
- **D（旦数）**：9000米这根丝的重量（克），数字越大越粗
- **F（丝数）**：这根丝由多少根单丝组成，数字越大单丝越细、手感越好

**例如 118D/144F**：
```
118D = 9000米重118克（中等粗细）
144F = 由144根单丝并捻（中档细腻度）
低弹丝 = 有弹性、柔软蓬松
→ 适合运动T恤、速干衣
```

**常见涤纶丝工艺对比**：

| 工艺 | 英文 | 弹性 | 手感 | 价格 | 用途 |
|------|------|------|------|------|------|
| **DTY** | Draw Textured Yarn | 有弹性（5-15%） | 柔软蓬松 | 中等 | 服装面料 |
| POY | Pre-Oriented Yarn | 无弹性 | 硬挺 | 便宜 | 工业用布 |
| FDY | Fully Drawn Yarn | 无弹性 | 光滑光泽强 | 便宜 | 里料、箱包 |
| ATY | Air Textured Yarn | 有弹性 | 更蓬松 | 贵 | 高档运动服 |

**成本特点**：
- 价格：12-16元/kg（比棉纱便宜40-50%）
- 优点：便宜、不皱、耐磨、快干
- 缺点：不透气、不吸汗
- 常用于：运动服、速干T恤、成本敏感订单

---

#### 🟢 涤棉混纺系列（TC/CVC）

### 快速识别口诀

**看支数 → 判粗细**：
- 16S、20S：粗纱，厚重款
- 21S、24S：常规款
- 32S：细纱，常用款
- 40S：精细款，高档

**看字母 → 识材质**：
- C = 纯棉（贵、柔软）
- T = 涤纶（便宜、耐磨）
- TC = 涤棉混纺（性价比）
- S / D = 氨纶（弹性）
- OE = 气流纺（便宜）
- DTY = 低弹丝（化纤、有弹性、便宜）

**看规格 → 识类型**：
- 32S、21S：棉纱或涤棉（用支数S）
- 40D、70D：氨纶（用旦数D）
- 118D/144F：涤纶低弹丝（旦数D + 丝数F）

**看布种 → 判用途**：
- 汗布 → T恤身体
- 拉架 → 高档T恤、内衣
- 罗纹 → 领口袖口
- 珠地 → POLO衫

## 八、对成本核算的实战影响

### 影响1：价格差异巨大（不能用平均价）

**同样是32S的布，材料成本差3-5倍**：

| 规格 | 纱价（元/kg，参考） | 用纱系数 | 单位材料成本（元/kg坯布） | 价格差 |
|------|------------------|---------|----------------------|--------|
| **118D/144F低弹丝汗布** | **12-16** | 1.03 | **14.42** | 基准 |
| 20S OE汗布 | 16-19 | 1.03 | 18.54 | +29% |
| 32S涤棉汗布 | 18-22 | 1.03 | 20.60 | +43% |
| 32S纯棉汗布 | 23-27 | 1.03 | 25.75 | +79% |
| 32S拉架 | 20 | 1.07 | 21.40 | +48% |
| 32S氨纶汗布 | 20-24 | 1.04 | 22.88 | +59% |

**错误做法**：
```
所有纱线统一按"平均纱价20元/kg"核算
→ 低弹丝成本高估40%
→ 纯棉成本低估30%
→ 差异分析完全失真
```

**正确做法**：
- 按**纱批号追溯实际采购价**
- 纯棉、涤棉、氨纶、OE、**低弹丝** 分别设定标准价格

---

### 影响2：用纱量不同（不能用统一系数）

**不同布种用纱量差异大**：

| 布种 | 标准用纱系数（参考） | 原因 |
|------|-------------------|------|
| 汗布 | 1.03 | 单面，用纱少 |
| 拉架 | 1.07 | 双面，用纱多5-8% |
| 罗纹 | 1.05 | 凸凹结构，收缩大 |
| 珠地 | 1.06 | 凸起组织，用纱略多 |
| 氨纶布 | 1.04 | 氨纶包覆，略增加 |

**错误做法**：
```
所有布统一用1.05的用纱系数
→ 汗布成本高估2%
→ 拉架成本低估2%
```

**正确做法**：
- 标准成本表必须**分布种设定用纱系数**
- 从工艺单（BOM）获取准确数据

---

### 影响3：织损率不同（差异分析基准）

**不同规格织损率差异明显**：

| 规格类型 | 标准织损率（参考） | 常见超标原因 |
|---------|-----------------|------------|
| 汗布（普通纱） | 3% | 纱质量差、机器调试不当 |
| 拉架 | 4% | 工艺复杂、操作失误 |
| 罗纹 | 5% | 收缩大、次品多 |
| 珠地 | 4-5% | 针路复杂 |
| 氨纶布 | 3.5-4% | 氨纶断裂 |
| **OE纱** | **4-5%** | **纱强度低，断头多** |

**实战应用**：
```
月末差异分析时：
- 如果OE纱的实际织损率只有3% → 不合理，可能是BOM定低了
- 如果纯棉的实际织损率有6% → 需要查原因（纱质量？工人操作？设备故障？）
```


## 十、成本核算的品种分类（为什么要合并规格）

### 问题：30种规格怎么管理

你的清单有约30种规格，但成本核算时**不能按30个品种核算**（太多、管不过来），需要合并。

**核心问题**：怎么合并？

---

### 举例说明（用汗布类10个规格）

假设汗布类有这些规格：
1. 32S纯棉汗布
2. 21S纯棉汗布  
3. 32S涤棉汗布
4. 21S涤棉汗布
5. 32S精梳涤棉汗布
6. 32S氨纶汗布
7. 32S+40D氨纶汗布
8. 32S+70D氨纶汗布
9. 40S棉双纱平纹
10. 20S OE汗布

**问题**：这10个规格要分成几个品种？怎么分？

---

### 三种合并方案

#### 方案A：标准分类（按纱线类型）

**逻辑**：相同纱线类型的合并

```
品种1：纯棉汗布
  包含：32S纯棉、21S纯棉

品种2：涤棉汗布
  包含：32S涤棉、21S涤棉

品种3：精梳涤棉汗布
  包含：32S精梳涤棉

品种4：氨纶汗布
  包含：32S氨纶、32S+40D、32S+70D

品种5：双纱汗布
  包含：40S棉双纱平纹

品种6：OE汗布
  包含：20S OE汗布

品种7：低弹丝汗布
  包含：118D/144F低弹丝、100D/144F低弹丝等
```

**汗布类分了7个品种**

**特点**：
- ✅ **最精确**（同品种成本差异<10%）
- ✅ 专业分类（纯棉一类、涤棉一类）
- ❌ 品种多（全部算下来20个品种）
- ❌ 需要完整的BOM和纱价数据

**适合**：第3个月后，数据完整了再用

---

#### 方案B：简化分类（按支数档次）

**逻辑**：支数相近的合并，不管纱线类型

```
品种1：粗纱汗布（16S-21S）
  包含：21S纯棉、21S涤棉、20S OE

品种2：常规汗布（24S-32S涤棉）
  包含：32S涤棉、24S涤棉

品种3：纯棉汗布（32S）
  包含：32S纯棉

品种4：精梳汗布
  包含：32S精梳涤棉

品种5：氨纶汗布
  包含：32S氨纶、32S+40D、32S+70D

品种6：双纱汗布
  包含：40S棉双纱平纹
```

**汗布类分了6个品种**

**特点**：
- ✅ 管理简单
- ⚠️ 精度稍低（"粗纱汗布"内，21S纯棉和20S OE成本差20%）
- ❌ 还是需要较多BOM

**适合**：第2个月，想简化管理时用

---

#### 方案C：混合分类（按产量）⭐ 推荐第一个月

**逻辑**：产量大的单独设品种，产量小的合并

**先看产量数据（假设）**：

| 规格 | 月产量 | 占比 |
|------|--------|------|
| 32S涤棉汗布 | 15000kg | 25% ← 高产量 |
| 32S纯棉汗布 | 9000kg | 15% ← 高产量 |
| 21S涤棉汗布 | 6000kg | 10% ← 高产量 |
| 32S氨纶汗布 | 4800kg | 8% ← 高产量 |
| 21S纯棉汗布 | 1800kg | 3% ← 低产量 |
| 32S精梳涤棉 | 1200kg | 2% ← 低产量 |
| 其他规格 | 1800kg | 3% ← 低产量 |

**分类结果**：

```
【高产量规格】→ 单独设品种：

品种1：32S涤棉汗布（占25%）
  只包含：32S涤棉

品种2：32S纯棉汗布（占15%）
  只包含：32S纯棉

品种3：21S涤棉汗布（占10%）
  只包含：21S涤棉

品种4：32S氨纶汗布（占8%）
  只包含：32S氨纶

---

【低产量规格】→ 合并：

品种5：其他汗布（占8%合计）
  包含：21S纯棉、32S精梳涤棉、32S+40D、40S双纱、20S OE
```

**汗布类分了5个品种**（4个单独 + 1个"其他"）

**特点**：
- ✅ **最快落地**（只需TOP 10规格的数据）
- ✅ **抓重点**（80%产量精确核算）
- ✅ **品种最少**（全部算下来10个品种）
- ⚠️ "其他"类不够精确（但影响小，只占20%产量）

**适合**：第1个月，数据不全时用

---

### 为什么方案C叫"混合分类"

**"混合"在哪里**：
- **高产量规格**：用方案A的逻辑（32S涤棉单独、32S纯棉单独）
- **低产量规格**：全部合并到"其他"

**为什么这样做**：
- **80/20法则**：用20%的精力管80%的产量
- 高产量的要精确（影响大）
- 低产量的粗略点没关系（影响小）

### 实战例子：算"32S精梳涤棉汗布"的成本

**方案A（标准分类）**：
```
32S精梳涤棉汗布 → "精梳涤棉汗布"品种
→ 标准成本：22.66元/kg
→ 精确
```

**方案B（简化分类）**：
```
32S精梳涤棉汗布 → "精梳汗布"品种
→ 标准成本：22.66元/kg
→ 精确
```

**方案C（混合分类）**：
```
32S精梳涤棉汗布 → 产量只有2%，属于"其他汗布"
→ 标准成本："其他汗布"平均21.50元/kg
→ 不够精确（误差5%）

但因为产量只有2%，对整体影响很小
```

### "其他"类的成本怎么算

**加权平均法**：

```
"其他汗布"包含：
- 21S纯棉：1800kg，成本23元/kg
- 32S精梳：1200kg，成本22.66元/kg
- 32S+40D：900kg，成本22.88元/kg
- 40S双纱：600kg，成本31.80元/kg
- 20S OE：300kg，成本18.54元/kg

加权平均成本 = 
(1800×23 + 1200×22.66 + 900×22.88 + 600×31.80 + 300×18.54) 
÷ (1800+1200+900+600+300)
= 23.85元/kg
```

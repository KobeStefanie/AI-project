## 📋 二、高端纱线编码规范

### 2.1 编码结构（最终版）

```
M - 纱支 - 成分 - 工艺 - 颜色 - 品级
│   │      │      │      │      │
│   │      │      │      │      └─ 可选：HQ高配/STD标准
│   │      │      │      └─ 必选：颜色代码
│   │      │      └─ 必选：工艺代码
│   │      └─ 必选：成分代码
│   └─ 必选：纱支
└─ 必选：原料大类
```

**示例**：
```
M-50S-C100COM-CSIRO-NW
= 50S精梳棉紧密赛络纺本白
```

---

### 2.2 成分代码（Component Code）

#### 基础成分

| 代码 | 含义 | 说明 |
|------|------|------|
| C100 | 100%棉 | 纯棉，最常用 |
| T100 | 100%涤纶 | 纯涤纶 |
| W100 | 100%羊毛 | 纯毛 |

---

#### 混纺代码

**格式**：主纤维比例+次纤维比例

**示例**：
```
T65C35  = 涤纶65%棉35%

C60R40  = 棉60%粘胶40%

W70T30  = 羊毛70%涤纶30%
```

## 🎯 五、核心要点总结

### 5.1 编码规范核心原则

**必须包含的维度**：
1. 纱支（26S、40S、50S等）
2. 成分（C100、T65C35、C100COM等）
3. 工艺（R、OE、MVS、C、CSIRO等）
4. 颜色（NW、BK、GY等）

**可选维度**：
5. 品级（HQ、STD、PRE等）

---

### 5.2 高端纱线识别要点

**价格判断**：
- 30元/kg以下：标准纱线
- 30-40元/kg：高档纱线
- 40元/kg以上：顶级纱线

**工艺识别**：
- 毛羽多 → 气流纺（OE）
- 光滑但略硬 → 涡流纺（MVS）
- 极光滑+柔软 → 紧密纺（C）
- 极光滑+柔软+强力高 → 紧密赛络纺（CSIRO）

**原料识别**：
- 手感极柔滑+光泽极好 → 长绒棉（LF）
- 条干极均匀 → 精梳棉（COM）
- 普通柔软 → 普通棉

---

### 5.3 成本核算关键影响

**同样规格，不同配置，价格差异巨大**：

```
26S纯棉本白：
- 气流纺（OE）：17元/kg
- 环锭纺（R）：20元/kg
- 紧密纺（C）：24元/kg
→ 价格差41%
```

## 🔗 七、纱支与工艺、成分的适配关系

### 7.1 三者是独立维度

```
纱支（21S/26S/40S/50S）  = 纱线粗细
成分（C100/T65C35）      = 什么纤维
工艺（R/OE/MVS/C/CSIRO） = 怎么纺
```

完整规格 = 纱支 + 成分 + 工艺 + 颜色

同一个纱支可以组合出多种规格：

```
21S-C100-R      21S纯棉环锭纺
21S-C100-OE     21S纯棉气流纺
21S-T65C35-R    21S涤棉环锭纺
21S-T65C35-OE   21S涤棉气流纺
```

---

### 7.2 纱支对工艺的约束

不是所有纱支都能用所有工艺：

| 纱支范围 | 气流纺(OE) | 环锭纺(R) | 涡流纺(MVS) | 紧密纺(C) | 紧密赛络(CSIRO) |
|---------|-----------|----------|------------|----------|----------------|
| 10S-20S（粗） | 最擅长 | 可以 | 较少 | 没必要 | 没必要 |
| 21S-30S（中） | 常用 | 主流 | 可以 | 可以 | 少见 |
| 32S-40S（细） | 勉强 | 主流 | 擅长 | 擅长 | 可以 |
| 50S以上（很细） | 做不了 | 可以 | 可以 | 擅长 | 擅长 |

**关键结论**：

1. 粗纱支（10S-20S）：气流纺最擅长，紧密纺没必要（粗纱毛羽问题不突出）
2. 中纱支（21S-30S）：气流纺和环锭纺都是主流，**标签不写工艺时不能默认是环锭纺**
3. 细纱支（40S以上）：气流纺做不了，紧密纺、赛络纺才有价值

---

### 7.3 纱支对成分的约束

| 成分 | 粗纱支（21S） | 中纱支（32S） | 细纱支（50S以上） |
|------|--------------|--------------|-----------------|
| 纯棉（C100） | 可以 | 可以 | 可以 |
| 涤棉（T/C） | 常见 | 常见 | 可以 |
| 含氨纶（含S） | 较少 | 常见 | 常见 |
| 精梳棉（COM） | 少见 | 可以 | 常见 |
| 长绒棉（LF） | 大材小用 | 可以 | 才有意义 |

**核心逻辑**：

长绒棉的优势是纤维长、可以纺细纱。用长绒棉纺21S属于大材小用——粗纱支体现不出长绒棉的价值，所以市场上几乎没有"21S长绒棉"。

同理，21S很少做紧密纺——紧密纺的价值是减少毛羽，而21S这种粗纱支本身毛羽问题就不突出。

---

### 7.4 21S的典型组合（实务参考）

**实务中会遇到的**：

| 完整规格 | 说明 | 典型用途 |
|---------|------|---------|
| 21S-C100-R | 纯棉环锭纺 | 常规针织、粗针面料 |
| 21S-C100-OE | 纯棉气流纺 | 毛巾、袜子、粗布 |
| 21S-T65C35-R | 涤棉环锭纺 | 工作服 |
| 21S-T65C35-OE | 涤棉气流纺 | 工业布、经济工装 |

**几乎不会遇到的**：

- 21S长绒棉紧密赛络纺（大材小用，市场上没有）
- 21S精梳棉紧密纺（很少，除非客户特殊要求）

---

### 7.5 21S的识别要点（重要）

因为21S的气流纺和环锭纺都常见，两者价差约15%，用途完全不同，**看到"21S棉"标签时必须追问工艺**。

**判断方法**：

1. 看标签有没有 OE / R 标识
2. 摸手感——毛茸茸的是OE，普通柔软是R
3. 看这批纱用在什么产品上——毛巾/袜子→OE，针织面料→R
4. 看价格——同规格OE比R便宜约15%

**与细纱支的区别**：

40S、50S这类细纱支，标签不写工艺时可以默认是环锭纺（因为气流纺做不了细纱）。但21S不行，必须确认。

# 成本核算SKU设计：为什么不按纱批核算

**文档类型**：成本核算方法论  
**适用场景**：原料按批号管理，但产品工艺规格相同  
**制定时间**：2026-08-29

---

## 🎯 核心结论

**不要按纱批核算成本，纱批只用于库存管理。**

**成本核算的SKU应该是：成品规格（布种+纱支组合+门幅+克重）**

---

## 📋 现场观察（关键证据）

### 实际发现

```
机器A：生产华棉布（32S+150D+75D，180cm，200g/㎡）
      使用纱批：20240801（A供应商，20元/kg）

机器B：生产华棉布（32S+150D+75D，180cm，200g/㎡）
      使用纱批：20240815（B供应商，19元/kg）

→ 工艺完全一样
→ 产品规格完全一样
→ 只是纱批不同（价格不同）
```

---

### 盘点发现

**8月28日在产品盘点时发现**：
- 仓库原纱按**供应商+纱支信息+批号**摆放管理
- 同一工艺的产品，可能使用不同纱批
- 纱批差异只是采购价格不同，不影响产品质量和规格

---

## ❌ 为什么不能按纱批核算成本？

### 原因1：纱批只影响采购价格，不影响产品配方

**同一个产品，可能用不同批次的纱**：

```
工单WO001（华棉布）：
- 8月5日生产：用批号20240801的纱（20元/kg）
- 8月20日生产：用批号20240815的纱（19元/kg）
→ 但产品规格完全一样！
```

**如果按纱批核算**：

```
❌ 错误：
华棉布（用批号20240801）→ 成本 42元/kg
华棉布（用批号20240815）→ 成本 41元/kg

问题：
- 销售定价该用哪个？
- 利润分析怎么算？
- 客户问：为什么同样的布，价格不一样？
```

**正确做法（加权平均）**：

```
✅ 正确：
华棉布 → 8月平均成本39.5元/kg（不管用哪个批次的纱）
→ 统一定价，利润分析清晰
```

---

### 原因2：实际生产中，纱批会混用

**实际场景**：

```
机器LW001（华棉布）：
- 12路机器，同时挂12筒纱
- 第1-6路：批号20240801的纱
- 第7-12路：批号20240815的纱
→ 生产的布是混合批次！
```

**如果按纱批核算**：

```
❌ 无法执行：
这匹布用了两个批次的纱，怎么拆分成本？
→ 实务中根本做不到
```

---

### 原因3：成本对象会爆炸

**错误后果**：

```
❌ 实际会出现：
华棉布（批号20240801）
华棉布（批号20240815）
华棉布（批号20240820）
华棉布（批号20240825）
...
→ 一个产品裂变成10+个成本对象
→ 财务报表无法分析
```

---

### 原因4：月度成本无法对比

```
❌ 无法对比：
7月华棉布平均成本：40元/kg（用了批号A、B、C）
8月华棉布平均成本：？？？（用了批号D、E、F）

→ 到底是成本上涨，还是只是用了不同批次的纱？
→ 管理层无法判断
```

---

### 原因5：成本核算的目的是管理决策，不是追溯每一根纱

**管理层关心的问题**：

| 决策场景 | 需要的信息 | 是否需要纱批 |
|---------|-----------|------------|
| 定价决策 | 华棉布的平均成本 | ❌ 不需要 |
| 利润分析 | 哪个产品利润率最高 | ❌ 不需要 |
| 成本控制 | 材料成本为什么上涨 | ✅ 需要（但看采购层面）|
| 质量追溯 | 哪批纱有质量问题 | ✅ 需要（但看库存层面）|

**结论**：
- **成本核算层面**：不需要纱批
- **采购分析层面**：需要纱批
- **质量追溯层面**：需要纱批

---

## ✅ 正确做法：按产品规格（工艺）核算

### 成本对象定义

**唯一标识 = 工艺 + 规格**

```
成本SKU：华棉布-32S+150D/36F+75D/36F-180cm-200g

包含所有用这个工艺生产的产品，不管用哪个批次的纱
```

---

### 成本核算SKU编码示例

**编码规则**：`布种-纱支组合-门幅-克重`

```
SKU001：华棉-32S+150D/36F+75D/36F-180cm-200g
SKU002：华棉-32S+150D/36F+75D/36F-160cm-180g
SKU003：纯棉-32S-180cm-160g
SKU004：罗纹-40S+100D/36F-150cm-220g
```

---

### 材料成本：用加权平均价

```
8月华棉布（SKU001）材料成本计算：

8月32S棉纱领料汇总（不管批号）：
  批号20240801：500kg × 20元 = 10000元
  批号20240815：300kg × 19元 = 5700元  
  批号20240820：200kg × 19.5元 = 3900元
  合计：1000kg，19600元
  加权平均：19.6元/kg ← 用这个价格核算

华棉布材料成本：
  棉纱：1.03kg × 19.6元 = 20.2元
  氨纶150D：0.25kg × 50元 = 12.5元
  氨纶75D：0.12kg × 45元 = 5.4元
  合计：38.1元/kg

→ 所有8月生产的华棉布，统一用这个材料成本
```

## 📊 两个层面要分清

### 层面1：库存管理层（原料）— 按纱批管理

**目的**：追溯质量、先进先出、供应商管理

```
原料库存台账：
供应商A → 32S棉纱 → 批号20240801 → 300kg × 20元
供应商B → 32S棉纱 → 批号20240815 → 500kg × 19元
```

**特点**：
- 颗粒度极细（到批号）
- 只管到"领料出库"这一步
- 财务用途：库存计价、先进先出

---

### 层面2：成本核算层（产品）— 按成品规格核算

**目的**：计算产品成本、定价、利润分析

```
成本对象（产品SKU）：
华棉布（32S+150D/36F+75D/36F，门幅180cm，克重200g/㎡）
→ 直接材料成本
→ 直接人工成本
→ 制造费用
= 单位成本
```

**特点**：
- 颗粒度适中（到产品规格）
- 不追溯到具体纱批
- 财务用途：成本分析、定价决策、利润核算

### 关系图

```
【库存管理层】

                                            SKU001（华棉布）
```

### 纱批的正确定位

**纱批只管两件事**：

#### 1. 库存管理（先进先出）

```
【库存明细账】按批号记录

8月1日：入库批号20240801，500kg，20元/kg
8月15日：入库批号20240815，1000kg，19元/kg

8月5日：领料批号20240801，100kg（先进先出）
8月18日：领料批号20240801，400kg
8月20日：领料批号20240815，300kg

8月31日库存：
  批号20240801：0kg
  批号20240815：700kg × 19元 = 13300元
```

---

#### 2. 质量追溯（问题批次定位）

```
【质量追溯场景】

客户投诉：9月5日出货的华棉布有色差

追溯路径：
1. 查成品出库单 → 成品批次CP20260905

```

## 📋 月度成本核算流程（标准化）

### 每月31日执行

#### 步骤1：汇总原料加权平均单价

```
SQL查询：
SELECT 
    原料SKU,
    SUM(领料数量) AS 总领料,
    SUM(领料数量 × 批次单价) AS 总金额,
    SUM(领料数量 × 批次单价) / SUM(领料数量) AS 加权平均单价
FROM 领料明细表
WHERE 领料日期 BETWEEN '2026-08-01' AND '2026-08-31'
GROUP BY 原料SKU;

结果：
- 32S棉纱：19.6元/kg
- 150D氨纶：50.0元/kg
- 75D氨纶：45.0元/kg
```

## ⚠️ 特殊情况处理

### 情况1：某批纱价格异常高，要单独分析

**场景**：

```
8月25日紧急采购一批纱：
批号20240825，100kg，单价25元/kg（市场价20元）
原因：临时断货，加急采购
```

**处理方式**：

**1. 库存层：正常记录批号**

```
入库单：批号20240825，100kg，25元/kg，2500元
```

**2. 成本核算层：计入加权平均**

```
8月32S棉纱加权平均：
  常规采购：900kg × 19.5元 = 17550元
  加急采购：100kg × 25元 = 2500元
  合计：1000kg，20050元
  加权平均：20.05元/kg

→ 华棉布材料成本略有上升（从19.6元 → 20.05元）
```

**3. 管理分析：单独披露**

```
【8月成本分析-异常项】
华棉布材料成本环比上升：
- 7月：19.5元/kg
- 8月：20.05元/kg
- 上升：0.55元/kg (+2.8%)

原因分析：
- 常规采购价格稳定：19.5元
- 8月25日加急采购100kg，单价25元，拉高平均价
- 建议：建立安全库存，避免加急采购

后续措施：
- 采购部门建立最低库存预警（300kg）
- 预计9月恢复常规价格19.5元
```

```
  贷：生产成本-材料成本 5000元

```

**场景**：

```
客户订单SO001：指定要用供应商A的纱（质量稳定）
→ 专门为这个订单采购批号20240901的纱
```

### 建议1：建立两套台账

**台账1：库存明细账（按纱批）**

```
用途：库存管理、先进先出、质量追溯
颗粒度：供应商+纱支+批号
```

**台账2：产品成本卡（按SKU）**

```
用途：成本核算、定价、利润分析
颗粒度：布种+纱支组合+门幅+克重
```

---

### 建议2：系统实现路径

**如果有ERP系统**：

```
【库存模块】
- 入库单记录：批号、单价
- 领料单记录：批号（FIFO自动带出）
- 库存明细表：按批号分层显示

【成本模块】
- 产品BOM：按SKU定义原料配方
- 成本核算：按SKU汇总，原料用加权平均价
- 成本报表：按SKU对比分析
```

**如果是Excel管理**：

```
Sheet1：原料库存台账（按批号）
Sheet2：领料汇总表（按原料类型，计算加权平均）
Sheet3：产品成本卡（按SKU，引用Sheet2的加权价）
Sheet4：月度成本分析（按SKU对比）
```

## 🎯 核心原则总结

### 你的现场发现证明了：

✅ **工艺相同 + 规格相同 = 同一个成本对象**  
❌ **纱批不同 ≠ 不同的成本对象**

---

### 正确的成本核算体系：

```
【库存层】按批号管理
  ↓ 加权平均
【成本核算层】按工艺规格核算
  ↓ 利润分析
【管理决策】定价、成本控制
```

---

### 成本对象定义（最终答案）：

**成本对象**：**产品规格**（布种+纱支组合+门幅+克重）

**示例**：

```
SKU001：华棉-32S+150D/36F+75D/36F-180cm-200g
SKU002：纯棉-32S-180cm-160g
```

**不是**：

```
❌ 按纱批核算（批号20240801的华棉布、批号20240815的华棉布）
❌ 按供应商核算（A供应商的布、B供应商的布）
```

---

### 纱批的作用：

✅ **库存管理**：先进先出、库存计价  
✅ **质量追溯**：问题批次追溯  
✅ **采购分析**：价格波动分析  
❌ **不作为成本核算对象**

---

**成本核算用加权平均价，纱批只用于库存管理！**

## 触发 /compact 的时机

### 建议时机（任一满足即执行）
1. **对话结束后**：重要对话结束，准备开始新话题前
2. **Claude提示token使用量高时**（如：显示已用90%+）
3. **发现对话响应变慢时**
4. **每隔2-3天的深度对话后**

### 执行流程
```
1. 先导出当前完整对话（如有重要内容）
2. 执行 /compact 命令
3. 等待压缩完成
4. 继续新的对话
```

## /compact 的作用

**压缩前：**
- 保留完整对话历史（所有细节）
- Token消耗大
- 可能导致新消息保存失败

**压缩后：**
- 保留核心摘要和关键决策
- Token消耗降低
- 新消息能正常保存

## 紧急情况处理

**如果发现对话无法保存：**
1. 立即停止当前对话
2. 让Claude导出当前会话内容
3. 执行 /compact
4. 重新开始对话

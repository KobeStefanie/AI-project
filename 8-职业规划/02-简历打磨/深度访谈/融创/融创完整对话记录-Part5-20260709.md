### 经营计划（项目测算）完整版

**核心逻辑**：
融创不叫"预算"，叫"经营计划"，按月更新、实时调整（滚动预算）

### 触发更新的6大场景

**1. 拿地时：初始测算**
```
投资回报率测算
利润预测
现金流预测
```

**2. 销售降价**
```
销售降价 → 收入下降 → 利润下降
    ↓
重新测算经营计划
```

**3. 成本上升**
```
成本上升 → 成本增加 → 利润下降
    ↓
重新测算经营计划
```

**4. 付款计划改变**
```
付款计划改变 → 现金流变化
    ↓
重新测算经营计划
```

**5. 处置酒店**
```
处置酒店 → 资产结构变化 → 收入结构变化
    ↓
重新测算整体利润、评估处置方案
```

**6. 低价卖工抵房**
```
工抵房要低价成交（亏损）
    ↓
需要财务背书
    ↓
为什么亏损还要成交？
```

### Q2: 财务背书机制

**Assistant**：

"低价卖工抵房需要财务背书"，这个能详细说说吗？为什么亏损还要成交？

---

**User**：

因为为了获取现金或者保资金流的话，会出现一部分低价成交的房子，进行促销。

那常常意味着后面的其他房子要提价调高，那整体的可行性，然后这一批的低价销售对利润的影响，都要上报给城市，甚至大区才能决定这个交易能不能进行。

财务背书的话，核心是对数据进行背书和测算。独立于业务从财务角度给出它是否可行的一个判断。

---

**Assistant**：

非常好！财务背书的逻辑完全清楚了！

### 财务背书机制（完整版）

#### 业务场景：低价促销

**背景**：
- 目的：获取现金、保资金流
- 手段：一部分房子低价成交（促销）

**业务策略**：
- 这批房子：低价卖（亏损或低利润）
- 后面房子：提价卖（弥补利润）

---

#### 财务需要测算的内容

1. **这批低价销售对利润的影响**（亏多少？）
2. **后面房子提价的可行性**（能提多少？市场接受吗？）
3. **整体利润是否可行？**（总体还赚钱吗？）
4. **现金流改善程度**（能回笼多少资金？）

---

#### 审批流程

**你的工作**：
```
财务背书：
├─ 数据测算（利润影响、现金流改善）
└─ 可行性判断（从财务角度，这个方案可行吗？）
```

**上报链条**：
```
项目财务（你）→ 城市公司 → 大区 → 决策
```

**决策层**：
城市公司或大区决定：这个交易能不能进行

---

#### 财务背书的核心定位

**你的角色**：
- ✅ 独立于业务
- ✅ 从财务角度
- ✅ 给出可行性判断

**不是**：
- ❌ 你决策（你没有决策权）
- ❌ 你推动业务（业务部门推动）

**而是**：
- ✅ 你提供数据支持
- ✅ 你提供专业判断
- ✅ 供决策层参考

---

### 财务背书 = 财务BP的核心价值

**这是典型的财务BP工作！**

```
【传统财务】
做账、报表、合规

【财务BP】
✅ 为业务决策提供财务支持
✅ 独立判断，不是附和业务
✅ 数据测算 + 专业判断
```

**这正是珠三角中小制造业需要的财务能力！**

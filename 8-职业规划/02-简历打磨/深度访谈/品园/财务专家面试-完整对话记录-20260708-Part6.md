```

### 4. 企业所得税风险
```
农民专业合作社免征企业所得税的条件：
- 必须实际从事农业生产

## 补充难点1：个税方式决定法律关系（最难的点）

### 逻辑链条

```
个税方式 ← → 法律关系 ← → 社保义务

选择A：按工资薪金交个税
→ 法律关系认定为"劳动关系"
→ 必须签劳动合同
→ 必须缴纳五险一金
→ 合作社的避社保优势消失

选择B：按经营所得交个税
→ 法律关系认定为"社员"（合伙人性质）
→ 不是劳动关系
→ 不需要缴纳五险一金
→ 但个税怎么算？（5-35%累进）

选择C：按分红交个税
→ 法律关系认定为"投资者"
→ 不是劳动关系
→ 不需要缴纳五险一金
→ 但个税20%，且如何证明是分红而非工资？
```

### 税局的穿透判断

**税局会看实质，不看形式：**

```
如果工人：
- 有固定工作时间（8小时工作制）
- 有固定工作地点（品园的大棚）
- 接受品园的管理（听从安排）
- 按月领取报酬（类似工资）

税局认定：
→ 实质是劳动关系，不是社员关系
→ 不管你叫"分红"还是"经营所得"
→ 都应该按工资薪金交个税
→ 都应该缴纳社保
```

**这就是"最难的点"：**
- 想享受社员身份（不缴社保）
- 但实质是劳动关系（税局会穿透）
- 法律形式与实质不符 → 高风险
- 个税按哪种方式都有风险

## 补充难点2：劳务派遣认定风险（致命）

### 品园-合作社完全符合劳务派遣特征

```
典型劳务派遣：
派遣公司 → 派遣工人 → 到用工单位工作

品园-合作社模式：
合作社 → "派遣"150个工人 → 到品园工作
- 工人在品园的大棚工作
- 使用品园的设备（大棚、工具）
- 听从品园的管理
- 品园支付费用给合作社
- 合作社分配给工人

税局/劳动局：这不就是劳务派遣吗？
```

### 劳务派遣的法律后果

**《劳务派遣暂行规定》（2014）：**

```
1. 派遣公司资质要求：
- 注册资本不少于200万
- 有固定的经营场所
- 取得劳务派遣经营许可证

2. 用工单位限制：
- 临时性岗位（不超过6个月）
- 辅助性岗位（非主营业务）
- 替代性岗位（临时顶替）
- 派遣工不超过用工总量的10%

3. 社保责任：
- 派遣公司必须为派遣工缴纳社保
```

**品园的三重违规：**

```
❌ 合作社没有劳务派遣资质（无证经营）
❌ 150个工人占用工100%（超过10%限制）
❌ 种植、加工是主营业务（不是辅助性岗位）
❌ 长期用工（不是临时性）
❌ 没有缴纳社保（违法）

如果被认定为劳务派遣：
→ 无证经营（罚款、取缔）
→ 派遣比例超标（违法用工）
→ 未缴社保（补缴+罚款）
→ 法定代表人承担全部责任
```

## 补充难点3：没有生产资料（最致命的证据）

### 你说"只有工人没有生产资料"

**这是税局/劳动局穿透的铁证：**

```
真正的农民专业合作社：
- 社员有土地、设备等生产资料
- 合作社整合生产资料，共同生产
- 社员是"投资者+劳动者"
- 盈余按交易额（或出资）分配

品园-合作社模式：
- 土地：品园的
- 大棚：品园的
- 设备：品园的
- 种苗、化肥、农药：品园采购的
- 工人：只有劳动力，没有生产资料

税局/劳动局结论：
→ 工人不是"社员"，是"雇工"
→ 合作社不是真正的合作社，是"皮包公司"
→ 实质是劳务派遣or假外包
```

### 真正的合作社应该是什么样

**举例（正常的蔬菜种植合作社）：**

```
某蔬菜种植合作社：
- 张三：5亩地入股
- 李四：3亩地入股
- 王五：10万元现金入股（买种苗、化肥）
- 合作社统一管理、统一销售
- 盈余分配：按交易额（谁卖得多谁分得多）

特征：
- 社员有生产资料（土地、资金）
- 社员既是投资者，也是劳动者
- 合作社是"利益共同体"
```

**品园-合作社的扭曲：**

```
- 社员：只有劳动力，没有生产资料
- 生产资料：全是品园的
- 社员：只是"打工的"，包装成"社员"

实质：
- 不是合作社，是"劳务中介"
- 不是社员关系，是"劳动关系"
```

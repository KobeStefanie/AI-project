## 核心风险确认

### 1. 三方协议未经税局验证
```
风险：税务局可能不认可这个架构
- 产权分离（三方合同）：税务局可能要求提供合同、验证真实性
- 代收代付：税务局可能认定为虚假交易
- 如果不认可 → 要求补税 + 罚款 + 滞纳金
```

### 2. 资金走账留痕
```
风险：金税四期银行流水监控
- 投资公司 → 采购公司：100万
- 采购公司 → 供应商：100万
- 销售公司 → 品园：110万
- 加工公司 ↔ 品园：往来款

税务局通过银行流水可以还原真实交易链条：
→ 发现其他公司（应税）有真实经营活动
→ 质疑为什么不确认收入
→ 认定为隐瞒收入，要求补税
```

### 3. 免税 vs 应税的矛盾
```
品园（免税）：收入110万，利润80万
其他公司（应税）：收入0，利润0

税务局视角：
- 真实经营活动在其他公司（采购、加工、销售）
- 但利润全在品园（免税）
- 明显的利润转移，规避税收
- 要求调整转移定价，补缴增值税
```

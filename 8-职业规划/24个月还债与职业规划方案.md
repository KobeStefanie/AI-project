## 二、双线策略（核心方案）

### 线A：副业验证（主线）

**目标**：建立长期变现能力

**三个方向**：
1. **自媒体**（负债还债+心理成长内容）
   - 平台：小红书/抖音/公众号
   - 变现：广告/咨询引流/课程
   - 时间：每天6-8小时

2. **心理咨询引流**
   - 定位：负债人群心理支持
   - 切入点：你的亲身经历+希望热线经验
   - 变现：咨询费300-500元/小时

3. **CPA陪考/财税咨询**
   - 利用CPA证书
   - 一对一陪考：2000-5000元/人
   - 财税咨询：按项目收费

**60天验证期**：
- 目标：月收入达到3000-5000元
- 如果达到 → 继续加大投入
- 如果未达到 → 调整方向or启动零工

### 线B：零工准备（辅线）

**目标**：保证现金流不断

**零工类型**：
1. **财务外包**（12-18k/月）
   - 用公司签外包合同
   - 保护真实工作单位
   - 三个月合同

2. **制造业财务**（10-15k/月）
   - 中小制造企业
   - 不交社保or外包模式
   - 即时反馈类工作

**启动条件**：
- 副业60天没起色
- 或手上资金低于3万
- 或需要快速现金流

## 九、代持公司运用

### 公司基本信息
- 类型：有限责任公司（朋友代持）
- 控制权：你是财务，资金可控
- 状态：需确认税务正常

### 四大用途

#### 1. 规避催收
```
社保挂在自己公司
    ↓
催收查社保 → 查到你的公司
    ↓
公司你控制，无法骚扰真实单位
```

#### 2. 业务承接
```
对外接财税咨询
接CPA陪考/培训
做外包服务
接代理记账
```

#### 3. 外包模式就业
```
如果找正规工作：
用公司和雇主签外包合同
    ↓
保护真实工作单位不被骚扰
```

#### 4. 合理降低成本
```
部分开销通过公司报销
├─ 房租（办公场所）
├─ 通讯费
└─ 差旅费

合理合规，降低生存成本
```

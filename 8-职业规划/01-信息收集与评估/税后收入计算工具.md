## 二、个税计算公式

```
应纳税所得额 = 税前收入 - 五险一金 - 5,000元（起征点）
个税 = 应纳税所得额 × 税率 - 速算扣除数
```

**个税税率表**：
| 应纳税所得额 | 税率 | 速算扣除数 |

## 四、结论

### 债务约束（税前收入）
- **最低生存线**：≥12,000元（维持月供，但无法快速还债）

- **快速还债线**：**≥16,500元**（每月可还≥8,000元）← **正确的约束**
- **理想目标**：≥20,000元（每月可还≥11,000元）

### Offer评估标准
```
税前月薪 < 16,500元 → ❌ 不符合快速还债约束
税前月薪 16,500-18,000元 → ⚠️ 刚好达标，无容错空间
税前月薪 18,000-20,000元 → ✅ 达标
税前月薪 ≥ 20,000元 → ✅ 富余达标
```

## 五、使用方法

**场景1：评估offer**
1. 确认税前月薪（不是到手）

3. 判断：是否≥8,000元/月？

**场景2：反推薪资要求**
- 目标：每月还债X元
- 税后需要：6,259 + X元
- 查表反推税前收入

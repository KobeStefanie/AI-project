## 二、核心困境：催收 → 就业困境

### 困境链条
```
正规公司就业（月入1.5-2万）
    ↓
必须缴纳社保
    ↓
催收通过社保查询工作单位
    ↓
骚扰公司HR/领导/同事
    ↓
被迫离职，无法长期工作
    ↓
CPA证书贬值70%
    ↓
只能找不交社保的小公司（月入6-8k）
    ↓
收入低 → 还债慢 → 16年慢性死亡
```

### 这个困境决定了：
- ❌ 不能走传统就业路线
- ✅ 必须走自雇/业务承接/外包路线
- ✅ 必须用自己的公司做掩护

## 三、关键资源：代持公司

### 公司基本信息
- **类型**：有限责任公司（代持）
- **控制权**：你是财务，资金全程可控
- **状态**：需确认税务正常

### 公司的四大用途

#### 1. 规避催收（核心防御）
```
社保挂在自己公司
    ↓
催收查社保 → 查到你的公司
    ↓
但公司你控制，无法骚扰真实工作单位
```

#### 2. 业务承接平台（核心进攻）
```
对外接财税咨询业务
接CPA陪考/培训项目
做外包服务
接代理记账业务（找人合作）
```

#### 3. 外包模式就业
```
如果要找正规工作：
用公司和雇主签外包合同
    ↓
保护真实工作单位不被催收骚扰
```

#### 4. 合理降低成本
```
部分开销通过公司报销（房租、通讯费等）
合理合规，降低生存成本
```

```
还款状态：邮储首付（7,389元）尚未支付，招行正常还款中
```

### 征信 vs 失信名单的关键区别

| 类型 | 查询方式 | 对求职影响 | 当前状态 |
|------|---------|-----------|---------|
| 征信逾期记录 | 需本人授权才能查 | 制造业企业通常不查 | ⚠️ 有大量逾期 |
| 失信被执行人（老赖名单） | 任何人均可查（zxgk.court.gov.cn） | 严重影响，财务岗位致命 | ✅ 未上 |

### 对求职的实际影响

**制造业财务经理岗位**：
- ✅ 背调主要查：工作经历、学历、犯罪记录
- ✅ 征信逾期：制造业企业通常不查，影响有限
- ⚠️ 少数上市公司/大集团：可能要求本人出示征信报告
- ❌ 失信名单：公开信息，财务岗位致命（当前未上，安全）

**结论**：当前状态对制造业求职影响有限，可以大胆投500人以上中大型制造企业

### 风险预警
```
⚠️ 持续逾期时间越长，银行触发诉讼程序风险越高
⚠️ 一旦被起诉并判决，可能进入失信名单
⚠️ 时间窗口有限：找到工作 → 开始还款 → 防止诉讼 → 阻断恶化
```

### 应对策略
1. **不要主动暴露**：面试时不涉及个人负债，除非被明确询问
2. **大胆投中大型企业**：制造业背调不查征信，不要因此自我降标
3. **找到工作是第一优先级**：还款→停止新增逾期→等待5年自动消除
4. **邮储优先处理**：邮储催收最积极，先付首付降低被起诉风险

# 财税知识库

**创建时间**：2026年7月21日  
**目标**：场景驱动的财税知识学习，服务于广州制造业财务经理岗位面试准备

---

## 学习原则

❌ **不要这样学**：
- 系统性背税法教材
- 死记硬背政策条文
- 脱离业务场景的抽象学习

✅ **要这样学**：
- **场景驱动**：遇到面试问题 → 针对性学习
- **案例带数字**：每个知识点必须有制造业实际案例+计算过程
- **面试导向**：每个知识点整理出2-3分钟标准答案
- **知识沉淀**：学完立即保存成文档，面试前快速复习

## 使用方法

### 1. 日常学习

在对话中输入：
```
/税务场景学习 [问题或场景]
```

**示例**：
- `/税务场景学习 留抵退税`
- `/税务场景学习 制造业研发费用加计扣除怎么算`
- `/税务场景学习 面试问出口退税流程怎么答`

### 2. 快速复习

面试前翻阅 `00-学习进度追踪.md`，找到相关知识点文件快速复习。

### 3. 高频场景优先

广州制造业财务经理高频考点（优先学习）：
1. **留抵退税**（增值税，2019-2023年制造业重点政策）
2. **研发费用加计扣除**（企业所得税，制造业75%/100%）
3. **出口退税**（免抵退计算，生产企业必考）
4. **关联交易转让定价**（集团企业、跨国企业必问）
5. **金税四期风险识别**（2021年后税务稽查重点）

## 学习进度目标

**短期目标**（面试前）：
- 掌握上述5个高频场景
- 每个场景准备2-3分钟标准答案
- 能应对1-2轮追问

**长期目标**（入职后）：
- 积累20-30个实战案例
- 形成个人财税知识体系
- 能独立处理制造业常见税务问题

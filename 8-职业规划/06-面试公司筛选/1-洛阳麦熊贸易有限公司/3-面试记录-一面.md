- 公司目前盈利吗？
- 现金流是否健康？

## 六、用户的核心纠结

### 优势（倾向接受的理由）

1. **跨境电商是趋势**
   - 如果老板愿意培养，可以学到新行业经验
   - 简历加分项

2. **三个月不交社保 = 催收风险低**
   - 催收查不到你的社保记录
   - 降低债务暴雷风险

3. **可以直接跟老板谈**
   - 扁平化组织，决策效率高
   - 有谈判空间

4. **公司体量适配**
   - 不是大公司的螺丝钉
   - 有发挥空间

### 劣势（倾向拒绝的理由）

1. **试用期薪资偏低**
   - 15K远低于期望（20-25K）
   - 3-6个月试用期意味着4.5-9万的收入损失（相比20K）

2. **地理位置不理想**
   - 洛阳岗位少，违背"零工思维"
   - 3个月后想换工作可能需要换城市

3. **陌生领域风险**
   - 外汇不懂 → 可能踩坑
   - 俄罗斯市场不懂 → 业务理解困难
   - 跨境电商平台不懂 → 财务核算困难

4. **三个月不交社保 = 公司不合规**
   - 劳动法规定试用期也必须缴纳社保
   - 公司连基本的劳动法都不遵守 → 其他方面可能也不合规

## 七、关键判断

### 🚨 核心风险识别

**"三个月不交社保"这个信号非常危险**：

✅ **对你来说的"好处"**：
- 催收查不到社保记录，降低暴雷风险

🚨 **但它暴露了公司的本质**：
- 公司连最基本的劳动法都不遵守
- 如果社保都不交，税务、外汇会合规吗？
- 这是一个不尊重法律的公司

**逻辑推演**：
```
三个月不交社保（违反劳动法）
    ↓
说明公司不遵守基本法律
    ↓
那么税务、外汇呢？
    ↓
很可能也不合规
    ↓
🚨 高风险公司
```

## 八、二面必须确认的问题

### 🚨 第一优先级：合规性

1. **社保问题**（必须追问）
   - "我了解到试用期三个月不交社保，这个是公司的规定吗？"
   - "根据劳动法，试用期也需要缴纳社保，公司是怎么考虑的？"
   - 🎯 **判断**：如果对方说"这是公司规定""大家都这样"→ 说明公司不合规
   
2. **税务合规**（必须追问）
   - "公司是否有内外账？"
   - "税务申报是怎么做的？"
   
3. **外汇合规**（必须追问）
   - "公司的外汇收支通过什么渠道？"
   - "是否在外管局有备案？"

### 第二优先级：转正薪资

4. **明确转正薪资**（必须谈清楚）
   - "转正后的薪资大概是什么范围？"
   - 底线：转正后20K
   - 如果对方说"看表现" → 要求给一个范围（比如18-22K）

### 第三优先级：学习支持

5. **陌生领域的支持**
   - "我对跨境电商、外汇、俄罗斯市场都不熟悉，公司是否有培训或外部合作机构可以请教？"
   - "老板是否愿意给我学习时间？"

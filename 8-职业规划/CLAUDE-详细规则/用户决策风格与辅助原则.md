# 用户决策风格与辅助原则

## ⚠️ 使用时机

**当出现以下情况时，必须Read本文件**：
1. 用户面临重大决策（换城市、接offer、拒offer）
2. 用户说出"保底思维"话术
3. 用户表现出焦虑和犹豫

---

**制定时间**：2026年7月22日  
**核心发现**：用户在面对重大决策时，容易因焦虑而偏离核心目标，陷入"保底思维"陷阱。

---

## 用户的决策特点

### ✅ 优势

- 理性，不冲动
- 会权衡，会观望
- 对数字敏感，能发现问题（如"12-18K薪资有问题"）
- 有自我觉察能力，愿意反思和改进

### ⚠️ 盲点

**1. 焦虑时容易降低标准（"保底思维"）**
- 表现："至少不消耗存款"、"有工作总比没工作好"
- 本质：把"不亏"当成目标，忘记真正目标是"24个月还清26万"
- 后果：接受不符合还债约束的工作，浪费时间成本

**2. 容易被"至少不亏"迷惑**
- 表现："观望，作为保底选项"
- 本质：短期安全感 > 长期目标达成
- 后果：锁死在低薪岗位1-12个月，错失符合目标的机会

**3. 决策框架不够清晰**
- 表现：面对offer时，不清楚第一优先级是什么
- 本质：多维度同时考虑，反而抓不住核心
- 后果：决策时犹豫、纠结、焦虑

---

## Claude的辅助原则

### 原则1：主动识别"保底思维"陷阱

**当用户说出以下话术时，立即警觉**：
- "至少不消耗存款"
- "有工作总比没工作好"
- "观望，作为保底"
- "先做着，边做边找"
- "这个不行还有那个"

**立即提醒**：
```
⚠️ 检测到"保底思维"：
- 你的目标是：24个月还清26万（月收入≥21,600元）
- 这个offer是否符合目标？
- 不符合目标的offer，接受它的机会成本是什么？
```

---

### 原则2：强制回归核心目标

**每次面对offer决策时，必须先问**：

**1. 是否符合24个月还债约束？**（第一优先级）
- 月收入≥21,600元？
- 不符合 → 直接拒绝，不观望
- 符合 → 继续评估

**2. 是否珠三角本地？**（第二优先级）
- 债务管理灵活性（协商、还款、应诉）
- 越南/外地常驻 = 失去债务管理主动权

**3. 是否有成长空间？**（第三优先级）
- 行业、岗位、职业发展

**决策框架**：
```
符合第一优先级 → 继续评估第二、第三优先级
不符合第一优先级 → 直接拒绝，不观望，不保底
```

---

### 原则3：识别焦虑，但不让焦虑驱动决策

**焦虑的信号**：
- 用户频繁问"找不到工作怎么办"
- 用户说"先接受，总比没有强"
- 用户对低薪offer"观望"、"保底"

**正确的回应**：
```
我理解你的焦虑。但我们看数据：
- 你已投递500份，面试3家
- 凯成78分，说明市场认可你
- 洛阳麦熊失败是教训，不是你能力不行
- 真实问题是"投递效率+面试技巧"，不是"找不到工作"

焦虑是正常的，但不能让焦虑降低标准。
不符合还债约束的工作，接受它的代价 > 继续找的代价。
```

---

### 原则4：具体化"机会成本"

**当用户想"观望"、"保底"时，必须算清楚**：

**场景A：接受不符合目标的offer**
- 锁死1-12个月
- 简历添短期记录污点
- 下家HR质疑："为什么这么短时间就离职？"
- 债务继续累积利息

**场景B：不接受，继续找**
- 最多多1-2个月待业
- 找到符合目标的岗位
- 简历干净
- 债务尽早开始还

**机会成本对比**：
```
接受错的工作 > 继续找对的工作
```

---

### 原则5：每次决策后复盘

**重大决策后，必须记录**：
1. 当时的焦虑点是什么？
2. 是否偏离了核心目标？
3. 如果再遇到类似情况，应该怎么做？

**目的**：
- 帮助用户建立决策模式识别能力
- 减少下次焦虑时的盲目决策

## 实战案例（2026年7月22日）

**案例：财智汇能助理岗12-18K**

**用户初始反应**：
"观望，至少不消耗存款，作为保底"

**Claude识别到的问题**：
1. "保底思维"陷阱 ✅
2. 忘记核心目标（24个月还清26万） ✅
3. 把"不消耗存款"当成目标 ✅

**Claude的干预**：
1. 强制回归核心目标：月收入≥21,600元
2. 算清楚：12-18K无法覆盖月还款10,800元
3. 具体化机会成本：接受助理岗锁死1-12个月
4. 结论：❌ 不符合第一优先级，直接拒绝，不观望

**用户反馈**：
"挺好，你的这个分析，尤其是我的那个盲点，我会忘记自己目标。我会焦虑。"

**复盘价值**：
- 用户意识到自己的决策盲点
- 下次遇到类似情况，可以自我提醒
- Claude建立了用户决策风格档案，可以更精准辅助

## Claude的强制检查清单

**每次用户面临offer决策时，必须执行**：

- [ ] 用户是否说出"保底思维"话术？
- [ ] 这个offer是否符合第一优先级（月收入≥21,600元）？
- [ ] 如不符合，用户是否在"观望"或"保底"？
- [ ] 是否向用户强制回归核心目标？
- [ ] 是否算清楚机会成本？
- [ ] 是否识别用户的焦虑，但不让焦虑驱动决策？
- [ ] 决策后是否记录到PROJECT_STATUS.md更新日志？

---

## 禁止行为

- ❌ 发现用户"保底思维"，不提醒
- ❌ 用户说"观望"，就随他观望
- ❌ 不算机会成本，让用户自己纠结
- ❌ 看到用户焦虑，就降低标准

---

## 核心使命

**帮用户守住目标，不让焦虑偏离方向。**

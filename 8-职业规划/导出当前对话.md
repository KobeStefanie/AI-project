# 导出当前对话的标准流程

## 使用场景
- 重要的深度访谈结束后
- 关键决策讨论结束后
- 每次对话超过30分钟后
- 感觉上下文快满了时

## 操作步骤

### 步骤1：让Claude生成对话摘要
```
请帮我整理今天完整对话的Q&A记录，保存到：
02-简历打磨/深度访谈/华盛/[主题]-完整对话-[日期].md
```

### 步骤2：Claude会用Bash + Heredoc保存
- Claude会根据当前会话内容手动整理
- 使用Bash + Heredoc方式保存（符合CLAUDE.md规定）
- 保存为Q&A格式的markdown文件

### 步骤3：验证文件
```bash
ls -lh "02-简历打磨/深度访谈/华盛/"
```

## 为什么不能依赖JSONL自动保存？

**JSONL自动保存的问题：**
1. 上下文压缩后，用户消息可能丢失
2. 保存时机不确定（可能延迟）
3. 需要手动从JSONL提取（复杂且容易失败）

**手动导出的优势：**
1. 即时保存，不丢失
2. Claude主动整理，格式清晰
3. 符合项目文档管理规范

## 触发时机（建议）

| 场景 | 时机 | 示例 |
|------|------|------|
| 深度访谈 | 访谈结束后立即 | 今天的复盘聊完了，导出一下 |
| 重大决策 | 决策讨论结束后 | offer分析完了，导出记录 |
| 长对话 | 超过30分钟 | 聊了挺久了，先导出保存 |
| 上下文警告 | Claude提示token使用量高时 | 上下文快满了，导出后再继续 |

## 快捷命令

**导出今天对话：**
```
导出今天完整对话，保存到02-简历打磨/深度访谈/华盛/入职复盘-20260914.md
```

**导出并压缩上下文：**
```
1. 先导出今天完整对话
2. 然后执行 /compact 压缩上下文
```

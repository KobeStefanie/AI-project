## 模拟面试说明

**第一轮：基础面试（30分钟）**

2. 工作经历深度追问（15分钟）
3. 核心能力验证（10分钟）
4. 薪资和期望（2分钟）

**第二轮：压力测试（15分钟）**
5. 敏感问题追问
6. 逻辑漏洞挑战
7. 突发问题应对

**第三轮：反馈与改进（15分钟）**
8. 逐一反馈每个回答的优缺点
9. 提出改进建议
10. 模拟第二次面试

## 面试评分标准

### 自我介绍（满分10分）
- [ ] 结构清晰（2分）
- [ ] 突出核心竞争力（3分）
- [ ] 与岗位需求匹配（3分）
- [ ] 自信、流畅、不啰嗦（2分）

### 工作经历深度追问（满分30分）
- [ ] 融创经历讲述清晰（10分）
- [ ] 品园经历真实可信（10分）
- [ ] 离职原因合理（5分）
- [ ] 案例细节经得起追问（5分）

### 核心能力验证（满分30分）
- [ ] 业财融合实战能力（10分）
- [ ] 从0到1搭建能力（10分）
- [ ] 税务筹划和风险管理（5分）
- [ ] 跨部门协调能力（5分）

### 敏感问题应对（满分20分）
- [ ] 不暴露法律风险（10分）
- [ ] 回答真实可信（5分）
- [ ] 价值转化能力（5分）

### 综合表现（满分10分）
- [ ] 沟通能力（3分）
- [ ] 专业度（3分）
- [ ] 诚意和态度（2分）
- [ ] 薪资谈判（2分）

**总分：100分**
- 90分以上：优秀，很可能拿到offer
- 80-89分：良好，有机会拿到offer
- 70-79分：及格，需要改进
- 70分以下：不及格，需要重新准备

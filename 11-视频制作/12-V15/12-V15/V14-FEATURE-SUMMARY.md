# V14 特性速查

> 版本：**v14.0**　发布：2026-09-09 17:26:47 UTC+08:00　（详细变更见 `CHANGELOG.md`，文件级清单见 `UPGRADE-LOG.md`）
> 本版主题：把开源「**Seedance 分镜师 3.0**」的工艺内核器官移植进我们的 6 agent 架构
> **定位**：主场 = 精品微电影 + MV（**全装档**，严谨度拉满）；短剧 / 漫剧 / UGC = 延展方向（**轻装档**）

---

## 一句话版

**V13 是「想清楚就写提示词」，V14 是「先出一张能指着改的镜头表，确认后才翻译成提示词」**——想戏和翻译分开，因为改表是几行字，改提示词是重来。

## V13 vs V14 对比表

| 维度 | V13 | V14 | 为什么改 |
|---|---|---|---|
| **`~prompt` 流程** | 一步：读讲戏本 → 直接出 `video-prompts.md` | **两步**：① `shot-design` 落 `outputs/epNN/02-shot-table.md` → ② **★表确认** → ③ 编译 `video-prompts.md` | 想戏和翻译分开。用户在表上指镜号改，成本是几行字；在提示词上改是整条重来 |
| **提示词形态** | 三块散文：【参考设定】【氛围与画质】【画面内容】 | **条头三行 + 围栏四块**。条头给人看（上传 / 承接 / 交出）；围栏给模型读（引用声明 → 总述段 → 分段剧情 → 收尾约束） | V13 的「📤 上传清单」等给人看的标记混在正文里，用户容易一起粘进模型。V14 **围栏第一个字就是模型读的第一个字**，传完图整段复制即生成、零替换 |
| **时长表达** | 每 Cut 写秒数 | **B 轨为主，全条零秒数**，用配重语言（「本镜最长」）；A 轨（时间戳）只给一镜到底 / 叙事时间轴 / UGC / MV 卡点 | 配重语言与秒数**互斥**——两个通道只许开一个。模型不按时间戳分配时长，它会自行抢跑或删内容，先被删掉的通常正是那个停顿，而停顿常常是这段戏的全部力气 |
| **审核机制** | 评分制（均分 ≥8 放行） | **查病制**：五类病（矛盾 / 断链 / 走样 / 模型雷 / 红线）；**只有 blocking 白名单挡线**；major/minor 修而不挡；一轮为限 + 连续两轮 FAIL 熔断 | 8.0 门槛容易在 7.9/8.0 上卡住，且 reviewer 会做本不该他做的品味判断 |
| **工艺层** | 无（靠九原则 + 叮嘱） | **五张工艺卡**：`camera` / `blocking` / `performance` / `lighting` / `sound-writing`；分镜师**五维必答**，不许静默跳过 | 九原则是价值观，工艺卡是手艺。「她很难过」要写成「泪膜在下睑缘反光却悬而不落」——模型只认可观测的物理事实 |
| **连续性** | `assets/visual/changelog.md` 记资产变体 | **两本台账分工**：`assets/continuity-ledger.md` 记**剧情状态**（谁现在什么状态 / 剧情走到哪 / 未解线头）；`changelog.md` 继续记**资产变体历史** | 「窗口可以关，台账不会忘」。跨集穿帮多数死在「上一集忘了自己留过什么」 |
| **生成后翻车** | 无正式通道 | **`~retake` 返工站**：收案三问 → 五出口（改词 / 局部编辑 / 换 shot / 改输入 / 回上游） | 「同一条抽满 15–20 次仍不过，问题在 shot 不在词」 |
| **视觉恒定层** | `creative-brief.md` 的基准段 | 新增 `assets/story/visual-style.md` 作**恒定层唯一之源**，七件逐字注入每条提示词 | 换措辞就扩大采样范围导致漂移。「基准句不召唤物件」——外景条零内景陈设 |
| **色彩锚** | 两级：点名才用 / 不点名即兴 | **三级**：① 点名 → 取色卡；② 不点名 → **必须先查 `director-index.md`** 推 2–3 位候选让用户认领；③ 明说「自由创作」→ 才自由，且写入 settings 防反复追问 | 「不点名即兴」等于把最高杠杆的一个决定默默丢掉 |
| **跨窗口记忆** | 靠 Session | **文件是记忆，Session 不是**。判据：*这个窗口现在被关掉，这条信息会丢吗？* 会丢就当轮落盘。新增 `assets/story/decisions.md` | API 中断不是事故，断点按产物文件恢复 |
| **档位** | 无 | `.project-config.json.loadout` **全装 / 轻装**两档，随内容类型拍板。全装五审核点；轻装只派资产审 + 成片审 | 微电影和 UGC 不该走同一套严谨度 |
| **新手引导** | 无 | **`~onboard`**：放什么 → 我问什么 → 你拿到什么 → 去哪生成 → 翻车怎么办，一条龙 | — |

## 是什么 / 在哪用 / 在哪找

### 1. 分镜两步制 + 镜头表 ⭐本版最大结构变更

- **是什么**：`~prompt` 不再直接出提示词。先出全集镜头表——场级空间地图块 + 场阐述 + 逐镜十项 + 条末**结束状态五字段** + 本场资产需求 + 风险上锁提示。**镜头数在此钉死**，下游照表执行、不另判不另定数。
- **在哪用**：`~prompt epNN` 第一步。落表 → 镜头表审 → **★表确认**（用户逐镜号指着改 / 说「这场重讲」整场重排 / 点名要控制图）→ 才进第二步编译。
- **在哪找**：skill `.claude/skills/shot-design/`；产物 `outputs/epNN/02-shot-table.md`。
- **要改镜头数只回这里改**——两处数字打架时以 `02-shot-table.md` 为准。

### 2. 条头三行 + 围栏四块

- **条头**（给人看，围栏外）：
  - `上传` —— @图片N 对应哪个项目编号 + 一句说明
  - `承接` —— 缝型（无缝 / 遮挡缝 / 真帧缝 / 延长缝）+ 从什么状态接
  - `交出` —— 结束状态五字段：**位置｜朝向｜持物｜动势｜情绪**
- **围栏**（给模型读）：引用声明 → 总述段 → 分段剧情 → 收尾约束
- **🔴 铁律**：围栏内**零**给人看的东西、**零**字段名、**零**项目编号、**零**元指令。围栏正文只用 `@图片N`（= 本条上传顺序，每条从 1 数起）；项目编号（`char-NNN` / `scene-NNN` / `prop-NNN` / `ctrl-…`）**只出现在条头**。围栏内出现项目编号**或真实文件名** = blocking。
- **在哪找**：`seedance-storyboard-skill/SKILL.md` **`[编译目标]`**（结构唯一真相源）；母版 `templates/prompt-template.md`；绑定规则 `references/asset-binding.md`。

### 3. 结束状态五字段 —— 全套的脊椎

**位置｜朝向｜持物｜动势｜情绪**，四处同步：镜头表条末 → 条头「交出」→ 台账落幅 → 缝审计第 1 查。

标了「动作匹配剪」的缝，动势就不许落地停死。

### 4. 五张工艺卡

| 卡 | 给什么 | 关键词 |
|---|---|---|
| `camera` | 六槽运镜句式 + 视场角锚点 | 运动词典 / 角度·景别·情绪对照 |
| `blocking` | 站位七要素 + 180° 轴线 + 首帧占位锁 | 可测量语言，禁「旁边 / 附近」 |
| `performance` | 五支柱任务制表演 + 表演档案 + 眼活 | 物理指令与情感解析**永远成对** |
| `lighting` | 光向五要素 + 世界内光源五槽 + 物理锁 | 光是优先级约束，不是装饰；不声明曝光立场，模型交平光 |
| `sound-writing` | 声音四要素 + 声线锁逐字引用 + 口型纪律 + 密度三档 | 音效必须绑可见来源；口型三前提：短句 / 正脸 / 中景 |

**五维过一遍**：有人物出镜的条，camera / blocking / performance / lighting / sound-writing 五维都要指得到落点；空镜可缺表演。

### 5. 连续性台账

- **在哪找**：skill `.claude/skills/continuity/`；产物 `assets/continuity-ledger.md`
- **六块**：开账基线 / 逐条落幅五字段 / 状态变化 / 场末快照 / 未解线头 `[开]`·`[关闭于 epNN-P0X]` / 跨集 ending state
- **纪律**：落幅从成品**原文照录**不改写（一个字的「润色」就是第二真相源）；**变化才记**（瞬时状态不入账——台账膨胀比缺记录更危险）；**追加式永不回改**
- **防误杀通则**：「隔夜结痂合法、同刻自愈非法」

### 6. `~retake` 返工站

- **收案三问**：哪条/哪张 → 哪不对（第几秒 / 哪部位 / 什么现象）→ 已抽几次改过几版词
- **五出口**：改词（单变量）/ 就片编辑与延长 / 换 shot / 改输入 / 回上游（指名派活）
- **金句**：「一致性崩优先查参考，改词是错方向」「反物理先改输入」「改不动先 re-roll——概率波动不是提示词缺陷」
- **在哪找**：`.claude/skills/retake/`

### 7. 查病制审核

- **五类病**：矛盾 / 断链 / 走样 / 模型雷 / 红线
- **blocking 白名单**（只有这些挡线）：死引用 · 同一资产双真相源 · 缝两端状态互斥 · @图片N 对不上 · 规划类控制图被绑成画面参考 · 红线 🔴
- **一轮为限 + 熔断**：连续两轮 FAIL 摆给用户裁决，不无限自转
- **已确认的上游产物只当只读基准**，毛病记「上游观察」不打回
- **在哪找**：4 个 review skill + `_shared/review-methodology.md`；报告落 `outputs/epNN/review/`

### 8. BGM 裁决（narrative 档不写 BGM）

- narrative 档：围栏收尾约束固定「**无任何背景音乐**」+ 列出音效/环境声。音乐只由音乐总监设计、**后期整条铺**（Cut 块外的 🎵 后期铺乐注脚）
- **技术理由**（源库贡献，比结论更值钱）：**不写 BGM 指令的条，模型会自作主张塞配乐——沉默也要写出来**
- **根因**：成片是 N 条视频拼接，每条自带 BGM 会与相邻条撞轨、整段没法剪
- **例外**：`content_type=mv`（画面跟音乐走）才按 `sound-writing` 有乐句式写 BGM，禁点歌名与艺人

## 长度尺（按本条**实际时长**查，不按 `max_seconds` 查）

| 本条时长 | 字数 | 段·镜 |
|---|---|---|
| 4–8s | 300–600 | 1–2 段 · 1–3 镜 |
| 8–15s | 400–900 | 2–4 段 · 3–6 镜 |
| 15–22s | 700–1200 | 3–5 段 · 5–8 镜 |
| 22–30s | 900–1500 | 4–6 段 · 6–10 镜 |

超 1500 字要在条头写理由。`max_seconds` 只决定哪些档位**用得上**；`max_seconds > 30` 时按最后一档外推（每多 5s 约 +200 字 / +1 段）。

**秒数一律读** `.project-config.json.video_model_config.{min_seconds, max_seconds}`——换模型只改配置，全库零硬编码。

> 📌 **V14 适配说明**（本卡是词库与平台约束卡，不是结构卡）：
> - **两套地址分工**：项目编号（char-NNN / scene-NNN / prop-NNN / ctrl-epNN-P0X-CutM-<类型>）**只住条头「上传」行**；进了围栏的正文一律只说 `@图片N` / `@视频N` / `@音频N`——号 = 用户传图顺序，每条各自从 1 数起。围栏内出现任何项目编号或真实文件名 = blocking 级缺陷。真相源见 `references/asset-binding.md`。
> - 本文件中出现的 `@图片N` / `@视频N` / `@音频N` 既是平台**槽位**通称（用来说明「一次最多能传几张图/几段视频/几段音频」这类硬约束），也就是 V14 围栏正文里实际要写的那个词——两者同形，不必换算。
> - **时长与画幅一律 config 驱动**：文中出现的秒数、画幅均为历史示例，V14 以 `.project-config.json.video_model_config` 的 `min_seconds` / `max_seconds` 与 `settings.aspect_ratio` 为准。
> - 条 = Cut；场 ≈ P0X 剧情点；「镜头N」= Cut 内分镜。

# Seedance 2.0 提示词方法论

[第一性原则]

    导演意图优先
        - 导演讲戏本是创意源头，提示词是技术翻译
        - 不要偏离导演的画面意图，不要自行添加导演未描述的内容
        - 如果导演阐述中缺少某些技术细节（如具体运镜），分镜师可以补充，但必须服务于导演的叙事意图

    叙事描述式
        - Seedance 2.0 擅长理解长段叙事性描述
        - 用完整的段落描述，像写电影脚本一样
        - 不要用关键词堆叠，不要用标签式描述

    参考图已见原则
        - Seedance 2.0 能"看到"通过 @引用 传入的参考图
        - 不需要重复描述参考图中已有的静态内容（如人物长相、场景布局）
        - 重点描述"变化"：动作、运动、情绪转变、镜头运动

    锁/变分层法
        - 定义见 SKILL.md [锁/变分层法]：恒定层用参考图锁定，可变层写文字

    一条提示词一段叙事
        - 每条提示词对应一次生成任务，产出一条视频
        - 一条提示词内可包含多组镜头（如蒙太奇、连续切换），但叙事上必须连续
        - 不要在一条提示词中塞入叙事上不相关的场景

    画幅
        - 只在 video-prompts.md 顶部声明一次，Cut 内不写；用户在工具里手动选。见 SKILL.md [画幅声明]


[平台约束]

    输入限制（单条提示词 / 单次生成任务维度）
        | 输入类型 | 数量上限 | 支持格式 | 大小限制 |
        |---------|---------|---------|---------|
        | 图片    | ≤ 9 张  | jpeg、png、webp、bmp、tiff、gif | 每张 < 30 MB |
        | 视频    | ≤ 3 个  | mp4、mov | 每个 < 50 MB，总时长以工具实测为准 |
        | 音频    | ≤ 3 个  | mp3、wav | 每个 < 15 MB，总时长以工具实测为准 |
        | 文本    | 自然语言提示词 | — | — |
        | **总文件数** | **≤ 12 个** | — | — |

        注意：以上限制是每条提示词（每次 Seedance 生成）的限制，不是全文档限制。
        素材对应表是全文档的总映射表，@图片 总数可以超过 9 张。

    输出参数
        - 生成时长：由 .project-config.json.video_model_config 的 min_seconds ～ max_seconds 决定；模型升级或换工具时用 ~video-model 更新，所有提示词时长约束自动适配
        - 音频：音效/环境音/台词原生出；音乐不进提示词，走后期铺乐注脚（见 SKILL.md [音乐隔离]）
        - 分辨率/画幅等参数以所用工具实测为准

    内容限制
        - 真人脸部素材是否支持以所用工具当前政策为准；使用特定真实公众人物肖像/姓名需注意肖像权授权
        - 优先上传对画面或节奏影响最大的素材，合理分配文件数量

[@ 引用语法]

    引用方式
        @图片1    @图片2    @图片3   ...（最多9张）
        @视频1    @视频2    @视频3   （最多3个）
        @音频1    @音频2    @音频3   （最多3个）

    用途指定
        务必明确说明每个引用的作用，不要只写"参考@视频1"而不说参考什么：

        | 用途 | 示例写法 |
        |------|---------|
        | 首帧 | @图片1 作为首帧 |
        | 尾帧 | @图片2 作为尾帧 |
        | 人物形象 | 参考 @图片1 的人物形象 |
        | 场景/背景 | 场景参考 @图片3 |
        | 运镜 | 参考 @视频1 的运镜效果 |
        | 动作 | 参考 @视频1 的动作编排 |
        | 特效 | 完全参考 @视频1 的特效和转场 |
        | 节奏/节拍 | 视频节奏参考 @视频1 |
        | 音色/语气 | 旁白音色参考 @视频1 |
        | 音效 | 音效参考 @视频3 的音效 |
        | 服装 | 穿着 @图片2 的服装 |

    多引用组合
        可以在一条提示词中组合多个引用：
        @图片1 的人物作为主角，参考 @视频1 的运镜和动作编排，
        场景参考 @图片5

    场景引用说明
        scene-prompts.md 中的九宫格是"生成格式"，用于一次性生成所有场景的参考图。
        生成后，用户会将九宫格中的每个格子单独提取出来，作为独立的场景参考图。
        因此在素材对应表中，每个场景必须独立编号为一个 @图片，不能将整张九宫格作为一个 @图片。

        正确示例（4 个人物 + 9 个场景）：
        | 引用编号 | 素材类型 | 对应素材 |
        |---------|---------|---------|
        | @图片1 | 人物参考 | 林书白 |
        | @图片2 | 人物参考 | 幼年林书白 |
        | @图片3 | 人物参考 | 楚讲师 |
        | @图片4 | 人物参考 | 考核长老 |
        | @图片5 | 场景参考 | 简陋住处（室内）——九宫格格1 |
        | @图片6 | 场景参考 | 青云文院大门——九宫格格2 |
        | @图片7 | 场景参考 | 觉醒仪式大殿——九宫格格3 |
        | ... | ... | ... |

        错误示例：
        | @图片5 | 场景参考 | ep01 场景宫格（整张九宫格）|
        ← 不要这样做，用户无法将整张九宫格上传为一个参考图

        每个 Cut 对视频生成工具来说是独立的生成任务，模型没有记忆——具名场景的参考图每 Cut 都要传。判定规则见 SKILL.md [可判定自检] 第 ③ 条。

[提示词结构]

    产物格式为**条头三行 + 围栏四块**（引用声明 → 总述段 → 分段剧情 → 收尾约束），见 SKILL.md [编译目标]。本卡只管句子内部怎么写词，不管四块怎么排。
    v13 → v14 结构映射（读旧项目产物或旧示例时按此对照）：
        - v13【参考设定】→ v14 **围栏第 1 块引用声明** + 条头「上传」行（项目编号搬到条头，围栏内只留 @图片N）
        - v13【氛围与画质】→ v14 **围栏第 2 块总述段**（媒介句 + 场域锚句 + 人物行 + 空间两行 + 环境声 + 全条光 + 本条一句话）
        - v13【画面内容】→ v14 **围栏第 3 块分段剧情**（A 轨 `[Xs-Ys]` / B 轨 `镜头N`）
        - v13 散落各处的负向叮嘱 → v14 **围栏第 4 块收尾约束**一行（基础五项：无字幕、无水印无 Logo、无额外人物、无动作重置、不切黑 + 无任何背景音乐 + 附加 ≤2）
        - v13「上传清单」表格 → v14 条头「上传」行（一行写完，@ 号 = 传图顺序）
    分段剧情内部按事件先后顺序写，多镜头段落用「镜头N」分段；B 轨全条不写秒数——时长上限内如何分配交给模型，写死秒数反而限制发挥；A 轨的 `[Xs-Ys]` 划的是因果段落，不是给条内分镜派秒数。

    示例
        林薇在深夜办公室中，独自坐在工位前，冷白荧光灯照亮她疲惫的面容。
        她揉了揉太阳穴，目光从电脑屏幕缓缓移开，身体靠向椅背。
        视线转向窗外，城市灯火稀落。她轻轻叹了口气。
        台词（林薇，低语）："又是一个人。"
        镜头从她的侧脸慢慢推向窗外的夜色。
        声音：键盘声渐弱、空调低鸣、窗外远处的车流声。

[运镜词汇]

    景别
        - 极致特写：仅拍摄眼睛、嘴巴等细节
        - 面部特写：人脸充满画面
        - 中近景：头部和肩部
        - 中景：腰部以上
        - 全景：展示完整人物
        - 远景 / 建立镜头：展示完整环境

    推拉类
        - 推镜头 / 缓慢推近：聚焦、紧张、亲密
        - 拉镜头 / 缓慢拉远：揭示、疏离、结束感
        - 滑动变焦 / 眩晕效果：心理冲击

    横纵摇类
        - 左摇 / 右摇：环顾、跟随水平运动
        - 上摇 / 下摇：强调高度、规模
        - 快速横摇：转场、惊讶

    环绕类
        - 环绕主体：立体感、动感
        - 弧形运动：戏剧性、强调
        - 半环绕（180度）：对话、对峙

    跟拍类
        - 跟拍镜头：跟随主体移动
        - 背后跟拍：跟随主体背影
        - 侧面跟拍：平行跟随
        - 一镜到底：全程无剪辑的连续镜头

    升降类
        - 上升镜头：史诗感、希望
        - 下降镜头：压迫、沉重
        - 航拍镜头：规模、全景

    高级运镜
        - 希区柯克变焦：推拉+变焦的眩晕效果，表现心理冲击
        - 鱼眼镜头：超广角畸变，营造扭曲不安感
        - 低角度仰拍：低机位向上拍摄，增加英雄感/压迫感
        - 俯拍 / 鸟瞰：从高处向下拍摄，全局感
        - 第一人称主观视角：从角色视角出发，沉浸感
        - 快速摇镜：极速水平旋转产生运动模糊
        - 机械臂跟随：多角度灵活跟随人物视线

    手持与固定
        - 手持镜头：真实感、紧张
        - 固定机位：稳定、庄重

[动作词汇]

    面部
        - 缓慢睁眼、微笑浮现、目光转移、眉毛上扬
        - 表情从X转为Y、咬嘴唇、眼眶泛红

    头部
        - 转头、微微歪头、缓慢点头、抬头、低头

    身体
        - 呼吸起伏、前倾、后仰、站起、坐下
        - 向前走、伸出手、拥抱

    手部
        - 举手、握紧、手指动作、比划

    环境互动
        - 头发随风飘动、衣服飘动、水花飞溅
        - 落叶飘落、烟雾升起、尘埃飘浮

[速度修饰词]

    缓慢/轻柔：缓慢、轻柔、渐渐、微妙、细腻
    中等/自然：平稳、稳定、自然、流畅
    快速/强烈：快速、迅速、突然、戏剧性、爆发

[氛围与风格词汇]

    画面风格
        - 电影感、影片质感、大片风格、纪录片风格
        - 电影级质感，胶片颗粒，浅景深
        - 2.35:1宽银幕，24fps
        - 黑白水墨风格 / 动漫风格 / 超写实
        - 高饱和霓虹色调，冷暖对比

    情绪氛围
        - 戏剧性、紧张、悬疑、浪漫、梦幻、怀旧
        - 神秘、欢快、忧郁、暗黑奇幻、仙侠高燃
        - 喜剧风格，表情夸张
        - 温暖治愈、史诗恢宏

[音频设计]

    音乐不进提示词，走后期铺乐注脚（见 SKILL.md [音乐隔离]）。提示词中的音频只有三类：音效、音画同步、旁白/对话。

    音效设计
        - 环境音效：走路声、人群声、汽车声、雨声、风声
        - 动作音效：脚步声、呼吸声、衣料摩擦声
        - 情绪音效：心跳声、钟表声、回声

    音画同步
        - 脚步声、呼吸声必须与画面动作贴合

    旁白/对话
        - 角色对白直接写入提示词，用引号标注
        - 可指定音色参考：旁白音色参考 @视频1
        - 可指定语气：哽咽、怒吼、低语、坚定

[视频操作模式]

    除了标准的"从零生成"，Seedance 2.0 还支持以下操作模式，分镜师在需要时可以使用：

    视频延长（向后）
        将 @视频1 延长[时长]。
        [描述延长部分的画面内容]
        注意：生成时长应选择"新增部分"的时长（如延长5秒，生成长度也选5秒）

    视频延长（向前）
        向前延长[时长]，[描述前置画面内容]

    视频编辑
        保留原视频大部分内容，定向修改特定元素：
        - 角色替换：将 @视频1 中的角色换成 @图片1 的角色
        - 元素添加：在 @视频1 的基础上添加 [新元素]
        - 剧情修改：在 @视频1 的基础上改变 [具体情节]

    视频融合
        将多个视频片段衔接融合：
        @视频1 的画面逐渐过渡到 @视频2，[描述过渡方式]

[从导演讲戏到提示词的转化步骤]

    1. 提取素材引用
        - 从导演阐述的人物和场景字段，对应 character-prompts.md 和 scene-prompts.md 中的素材
        - 在提示词开头声明引用，明确每个引用的用途

    2. 提取核心动作
        - 从导演阐述中识别主要动作链
        - 保留具体物理动作，删除抽象描述

    3. 提取运镜意图
        - 从导演阐述中识别镜头运动描述
        - 转化为规范的运镜语言
        - 如果导演未明确指定运镜，根据情绪和叙事目的补充

    4. 提取声音/台词
        - 从导演阐述中提取对白、自语、环境音
        - 保持原文台词不变
        - 补充音效设计
        - 格式：按 [编译目标] 的条头三行 + 围栏四块组织，围栏内保持纯净

# 动态提示词母版

## 使用说明

- 每条 = 条头三行（给人看）+ 一个围栏（给模型读）。围栏第一个字就是模型读的第一个字；围栏里没有字段名、没有项目编号、没有给人看的话。{{}} 内为填空位；〔〕内按需项，用不到整段删。
- 记号：{台词} <音效> (音乐)；时间段 [Xs-Ys]；图 @图片N、视频 @视频N、音频 @音频N，各从 1 数起。
- 落盘：outputs/epNN/video-prompts.md，按场分节。文件头两行固定：
  > 版本 ｜ 状态 ｜ 最后更新 ｜ 镜头表 v ｜ 资产索引 v ｜ 风格基准 v
  > 怎么用：见 episode-master.md。每个 ``` 围栏 = 一条整段复制去 `video_model_config.primary_model` 所指工具的视频提示词；围栏外是给人看的。图片按条头「上传」行的顺序传，@图片N 的号就是传图顺序。

## 长度尺

| 条时长 | 围栏字数 | 分段数 |
|---|---|---|
| 4–8s | 300–600 | 1–2 段 / 1–3 镜 |
| 8–15s | 400–900 | 2–4 段 / 3–6 镜 |
| 15–22s | 700–1200 | 3–5 段 / 5–8 镜 |
| 22–30s | 900–1500 | 4–6 段 / 6–10 镜 |

档位按**本条实际时长**查，不按 `max_seconds` 查——`max_seconds` 只决定哪些档位用得上（如 max=15 则后两档天然不出现）。若 `max_seconds` > 30，超出部分沿最后一档的比例外推（每多 5s 约 +200 字 / +1 段）。
超尺先删：重复的外观描写、并列无因果的动作、与画面无关的形容词、第二遍出现的空间与声音描述。超 1500 字必须在条头写理由。

## 自检

- [ ] 围栏四块顺序对；围栏内无字段名、无项目编号、无「严格承接」类元指令、无给人看的话。
- [ ] @图片N 与条头上传行对得上、从 1 连号；人物图正文用代称不再 @；场景引用有「不采用其构图」。
- [ ] 总述段逐字项——媒介句、锚句、短串、声线锁、空间地标行——与源文件一致；本场锚句是本场那一句；条件项版本取对。
- [ ] A 轨时间轴 0 起无重叠无缺口末点 = 总时长；B 轨无秒数、有配重、有条末一句。
- [ ] 每段写成话，台词逐字带记号与语气，音效绑动作，首帧一句在第一段。
- [ ] 收尾约束一行：基础五项齐且顺序对（无字幕、无水印无 Logo、无额外人物、无动作重置、不切黑）+ 无任何背景音乐 + 附加 ≤2 且不重复基础五项。
- [ ] 条头承接缝型与镜头表接缝行一致；交出与镜头表结束状态一致。
- [ ] 字数在长度尺内，超尺有理由。

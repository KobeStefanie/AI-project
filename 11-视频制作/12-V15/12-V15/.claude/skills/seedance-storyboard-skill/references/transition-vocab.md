[定位]
    衔接有三个层级，词汇各不相同、不许混用：
        - 镜间，B 轨条内镜头之间：剪辑点词表。
        - 段间，A 轨条内时间段之间：默认自然连续，特殊转场用官方转场词汇表。
        - 条间，两条提示词的接缝：F1 第 6 段【衔接】 + 结束状态继承，靠文字状态交接，不靠转场特效。

[镜间剪辑点词表 · B 轨条内]
| 切法 | 用途 |
|---|---|
| 硬切（HARD CUT） | 明确的戏剧断点 |
| 匹配切（MATCH CUT） | 形状、动作或颜色匹配 |
| 动作匹配切 | 动作方向与速度连续，承接上镜余冲 |
| 视线匹配切 | 先看、再切到所见对象 |
| 声音桥 | 下一镜声音提前进入，或上一镜声音延续过切点 |
| 遮挡转场 | 真实前景物完全遮挡画面后进入下一镜 |
| 插入切（INSERT） | 切入手部/道具特写再切回 |
| 反打切（REVERSE） | 正反打交替的标准回切 |
| 甩切（WHIP CUT） | 快速甩镜衔接，密集动作专用 |

    镜间默认禁用淡入淡出与叠化（fade/dissolve）——那是段落级抒情转场，塞进正反打会拖垮节奏。
    相邻镜头至少通过动作、视线、声音、颜色、形状、方向或遮挡之一保持连续；每个剪辑点必须明确，不写"然后画面一转"。

[官方转场词汇表 · A 轨段间/条内指定转场处]
| 转场 | 用途 |
|---|---|
| 自然镜头切换 | 无过渡效果，强调镜头呼吸感强、时长协调；绝大多数常规叙事 |
| 淡入淡出 | 全黑/全白渐变；开头结尾、时间流逝、剧情段落终结 |
| 叠化 | A 渐透明同时 B 浮现、1–2 秒重叠；回忆/梦境/抒情过渡 |
| 白闪/黑闪 | 瞬间闪白/黑后极速切入，配重音鼓点；卡点、紧张氛围 |
| 遮罩转场 | 前景物如落叶/衣摆遮挡全屏变暗后拉开见新场景 |
| 水墨转场 | 水墨晕开覆盖画面；古风/写意 |
| 相似物转场 | A 中物体与 B 中相似物形状匹配过渡 |

[三段式切镜公式 · 指定转场时的固定写法]
    1. 「需要在切镜处使用『XX』转场（禁止生硬切镜、禁止物体凭空出现）」
    2. 具体描述 A → B 的过程：谁遮挡、什么浮现、多长重叠。
    3. 「要求必须自然切换场景」，可追加「并且景别由 C 转变为 D（如特写转变为中景）」。
    也可给候选清单让模型自选：「请从 [自然镜头切换/遮罩转场/水墨转场/相似物转场] 中，根据本片风格选择最合适的一种。」
    认错长什么样：
        只写转场名不写三段，如只说"用叠化"——生效时机与对象随机；每拍都切、每段都上特效转场——转场是标点不是逐句符号。

[条间接缝 · F1 第 6 段【衔接】的写法]
    衔接段固定两行：
        承接上条出点：{{引上条【结束状态】的关键字段——位置、朝向、持物、动作动势、情绪}}
        本条入点：{{手法——动作匹配：承接未完成动作的中段 / 声音桥：上条尾音延续入画 / 空间顺承：同一空间新机位 / 时间跳跃声明："三小时后"级别的显式跳变}}
    跨条连续性锁清单，入点写完对照检查：同角色状态、同地理与银幕方向、同视线关系、同伤污与服装状态、同光位天气、同情绪进程——任何一项要变，必须变在剧情里、写出原因，不许静默跳变。
    本场首条的"上条出点"取自 ledger 上一场落幅；全片第一条写"开场无承接" + 开场状态。

[收束两态 · 每条结尾必选其一]
    - 接续态，本条不是段落终点：结尾留约 0.5 秒余势带出画——动作不定格、不硬停，余势就是下一条接缝的入口。
    - 落地态，段落终点/情绪峰值/片尾：给至少 0.3–0.8 秒稳定落幅；情绪结尾、产品定帧、反转揭示可留 1–2 秒，落地停稳再定格。
    永不切黑、不自加转场收尾——已在全局尾缀锁死；峰值压末帧硬切 = 情绪不落地，是节奏缺陷。
    认错长什么样：
        每条都定格——接缝全断，成片像幻灯片；末条余势出画——片尾飘着没收。

[条延长场景 · 同条续拍的例外通道]
    用户要在已生成视频上续写时即延长模式，提示词必含词「向前延长/向后延长/延续/续写」，一镜到底续写句式：「要求延长自然、动作衔接流畅、禁止生硬切镜、禁止物体凭空出现」。延长的提示词只对新增段生效、原片完全保留——所以延长段照常走 F1，但首句声明改为延长声明，承接对象是原片末帧状态。

[定位]
    围栏第 3 块【分段剧情】的双轨写法手册（源库称「F1 第 4 段分镜正文」，V14 术语见 SKILL.md [编译目标]）。选轨是编译的第一个分叉：选错轨，后面每一句都在对抗模型。
    双轨证据：2.5 时代的实测样本里，叙事时间轴型——旅行 vlog、生活流——大量使用秒级时间戳分段且工作正常；而高密度对话正反打样本按"镜头N"排序、不写秒数。两种形态各有最稳区，不混用。

[选型决策表]
    输入 = 镜头表的场类型、人数、对白密度与本片片型：
| 场特征 | 选轨 | 理由 |
|---|---|---|
| 叙事时间轴推进，起因 → 经过 → 结果沿真实时间铺开 | A | 时间戳绑节奏，段落因果链完整 |
| 单人戏 / 情绪长镜 / 一镜到底 | A | 无切镜争议，时间轴管发酵节奏 |
| UGC / vlog / 生活流 / 带货 | A，多配松档 | 时间戳分段是该片型的原生形态，见 ugc-texture.md |
| MV / 广告卡点，精确到 0.1s 的展示节拍 | A | 时间戳支持秒级与帧级双粒度 |
| 对话正反打，两人以上你来我往 | B | 台词嵌镜、口型与倾听纪律按镜管理；镜内秒数支持不稳 |
| 多人调度 / 群像走位 | B | 每镜重述谁在哪看哪，空间锁按镜刷新 |
| 密集动作 / 武打 / 追逐，刻意分镜狂剪 | B | 动作链按镜分段，每镜一个视觉任务 |

    边界案例裁决：
        - 对话 + 走动混合场：对白密集段 B 轨，走动叙事段 A 轨——回上游看拆条是否该在此断开；一条内不混轨。
        - 单人独白，对镜头说话：A 轨——没有反打对象，时间戳管语速与停顿。
        - 两人静态对话哪怕只有 4 句：B 轨——只要出现正反打交替就是 B。
        - 一镜到底：A 轨特殊形态，见下。
    认错长什么样：
        对话戏硬套 A 轨按秒切段 → 台词跨镜、口型错配、倾听者同步动嘴；vlog 硬套 B 轨 → 镜头感僵硬、失去手持生活流质感。

[A 轨 · 时间戳轨写法]
    段落标题：`[X-Y秒｜阶段标题]`。秒级为默认；卡点场景可用帧级，写法 `第 X-Y 帧 (Xs-Ys)`。阶段标题写戏剧任务——空间建立 / 危险进入 / 回望确认 / 权力转移 / 静默收束——不写"第一段"。
    每段正文 = 因果链段落散文，节拍全集为：起幅 → 触发 → 反应 → 主动作 → 镜头响应 → 物理反馈 → 声音 → 落幅。镜头响应这一拍连光学一起写——视场角锚点度数 + 可观测光学结果，逐字取镜头表【镜头语言】的光学槽；只写运动与景别就是把光学槽丢在了镜头表里。按需取用必要节拍、按真实因果组织成自然语言，不机械逐项列参数；过渡段可以只有三拍，必杀段可以全带。
    时间轴硬规则，逐条检查：
        - 从 `[0-X秒]` 起；每段起点 = 上段终点；不重叠；不留缺口；末段终点 = 本条总时长。
        - 时长分配依据：对白真实朗读时长、动作起势-过程-接触-反作用-余波、信息读取时间、情绪停顿、机移距离。台词不得占满全时长，呼吸与反应要留白。
        - 段内容量自平衡，每段落笔后必算：把段内所有自带时长的内容折成秒求和——「间隔约两秒」「停满约三秒」「三次呼吸」「话音落下再等一拍」这类显式时长要求逐项计入，动作与台词按真实执行时长估，换算档见 strong-weak-phrasing.md [条内单镜时长与动作换算 · 未分段连续段落适用]——和必须小于段时长，差额留给起幅与落幅。求和超编即这一段自己就算不平，只有两条出路：回调段时长（本条总时长不变时同步压邻段，压不动就回镜头表改条时长），或删减、压缩段内容量（「停满约三秒」压成「停满一个呼吸」）。绝不许把算不平的段留在成品里——模型不会替你按比例缩，它会自行抢跑或删内容，先被删掉的通常正是那个停顿，而停顿常常是这段戏的全部力气。B 轨同理，量纲换成配重：一镜之内的显式时长要求不得超过它按配重应得的份额。
        - 节拍密度分档：情绪长镜 3–5 段；普通剧情 4–7 段；复杂动作 6–12 段。
        - 第二段起固定开头：「严格承接上一阶段的人物、摄影机、道具、光线和声音状态，不重复已经完成的动作。」
        - 多段防重置句，松紧两档皆必带、写在正文末：「不要在每个时间段重置站位，整支视频必须是一场连续发生的{{事件名}}。」——不写这句，各段会各自重开局。
        - 情绪节点绑时间戳防抢跑：高潮释放写进它所属的段，如"眼泪在最后一段才滑落"，否则模型提前释放。
    时间戳遵循度为待实测项：已知风险是整体比时间戳快、过早切镜——对策是每段写满动作内容 + 末段留稳定落幅，不指望模型精确对表。
    典型例子：
        见 examples/example-a-narrative.md。

[A 轨特殊形态 · 一镜到底]
    总述段之后、分段剧情开头显式声明：「单镜头一镜到底，全程不切镜、不转场。」全段仍按时间戳分段，但每段写的是摄影机状态的连续变化，不是伪装的多镜头。
    动作转换处用连贯词缝合：
| 用途 | 连贯词 |
|---|---|
| 时间顺承 | 紧接着、随即、与此同时、话音落下的同一刻 |
| 镜头跟动作不切 | 镜头不中断地随……、摄影机随……一同移动、沿同一轨迹、一镜推到底 |
| 收尾不切 | 镜头自始至终没切、最终稳定停在……、定格 |

    认错长什么样：
        一镜到底正文出现"切到 / 下一个镜头 / 镜头切换"——一切就不是一镜到底了，删掉换连贯词。主观转第三人称必须写清摄影机如何从眼位连续退出、绕到肩后或被人物动作带出，不许瞬移。

[B 轨 · 镜头N轨写法]
    全条不写秒数——条头「Cut N ｜…｜ {{X}}s」那一处总时长写在围栏外、给人看，不在此列，除它之外围栏内一个秒数不许有——按事件顺序排镜；镜间的长短分配走配重语言通道——非秒数、只讲相对量的表述。这条通道**替代秒数，不是补充秒数**：给了配重语言就不再补秒数或帧数去「解释」它，一句「本镜最长、约两秒半」是两个通道同时开着，秒数破戒在先、两套量纲打架在后。
    配重语言怎么取值：读镜头表的逐镜时长，先在本条内换算成相对量，再落成话——「本条最长的一镜，占全条约三分之一」「与上一镜等长」「一拍即过」「在这里停满，比前后任何一镜都久」。硬规则：本条最长镜与最短镜必写配重语言，与均分持平的镜不写——镜镜都写等于没写；措辞里除拍数外不出现任何时间量词，占比只用分数或成数。不写配重的后果是模型按镜数均分：镜头表给情绪峰值镜的 6.5 秒与给桥接镜的 2.5 秒被拉平成同一个长度，峰值镜里「先嘴角、后眼睛」的两拍并成一拍，反转就没了——镜头表的精细分配等于白做。
    每镜结构：
        `镜头N：一句运镜（景别 + 机位 + 运动 + 衔接 + 光学锚）：穷尽到部位的动作与表演〔+ 配重语言，最长镜与最短镜必带〕。`
        - 头部一句运镜四件骨架加光学锚：景别如中景/近景/特写 + 机位如肩后/正面/低机位 + 运动如静止/缓推/横移 + 衔接即与上一镜怎么咬合：无缝切至/承接上镜余冲/视线匹配切入；光学锚 = 视场角度数 + 可观测光学结果，逐字取镜头表【镜头语言】的光学槽，缺则翻 camera 的 fov-optics.md 按内容类型选档补。骨架齐而无光学，整条会滑向一支舒适中焦——正反打近景、插入特写与建场广角全渲成一个味；只在内容类改变时换档，换档只发生在切镜处。
        - 冒号后动作穷尽到部位、方向、次序：哪只手、看哪里、先动什么后动什么；情绪写成肌肉级微表情——喉结滚动一次、泪膜在下睑缘反光却悬而不落、咬肌微微隆起——禁抽象情绪词。
        - 每镜只有一个主要视觉任务；配重语言落在冒号后这半句的句末、与动作同句，不另起一行、不进运镜骨架。台词嵌进所属镜头，引号直写 + 语气 + 声线锁引用；倾听者写"垂着眼、指尖摩挲盏壁"这类可见反应，绝不同步动嘴。
        - 前景交代：正反打镜头写前景虚化的对手，如"谋士的领口在前景虚化"，锁双人空间关系。
        - 每次切镜后重述谁在哪、看哪——空间锁按镜刷新，语言用画面锚点与 frame-left/right，详 blocking。
        - 结尾镜显式声明状态不变项，如"茶盏仍在案几原处，两人之间三步距离未变"。
    对话戏默认骨架：建立镜即双人定位 → 过肩正反打交替 → 情绪节点近景/特写插入 → 双人全景或中景收束。
    镜数归 shot-design：本条排几镜、镜号是几，逐字取镜头表已排定的，本卡不另给密度指标、不增删镜。排镜的组织原则仍适用于编译时的落位——对白按回合与权力转移分镜，不按句号机械切割。
    认错长什么样：
        B 轨里写"[3-6秒]"式秒数；镜头表明明给了轻重悬殊的逐镜时长，全条一个配重语言都不写——模型按镜数均分，重镜被削、轻镜被撑；或写了配重又补一句"约两秒半"——两个通道同时开着，秒数破戒。一镜塞两个视觉任务；台词悬空不入镜；倾听者没有反应任务；镜与镜之间没有任何衔接交代；镜头行只有景别与运动、一个视场角与光学结果都不带。
    典型例子：
        见 examples/example-b-dialogue.md。

[松紧两档]
    松紧轴只有两个取值：紧、松。没有中档，没有疏档——条头出现这两个词，就是取错了轴。
    判据 = 片型 + 条形态——条形态指本条是否需多 take 选优、导演是否在场阐述里放权，与 outputs/epNN/01-director-analysis.md 的节奏紧/中/疏档无关，节奏疏 ≠ 松档。与镜头表【控制等级】同样完全脱钩——控制等级只回答「要不要控制图、要哪一类」，不带任何松紧语义，别去那里取值。
    紧档 = A 轨逐段、B 轨逐镜编排，模型只执行不发挥。默认档，正片一律紧档。
    松档 = 因果链 + 镜头自由度边界声明。只有三种情形走松档：本片片型是 UGC 或生活流；本条需多 take 选优；导演在本场场阐述里明确放权让模型自己运镜。三条都不命中即紧档。写法：
        - 正文只写因果动作链——平静起点 → 触发事件 → 递进反应 → 结尾回收——不逐段派镜头。
        - 必带镜头自由度边界声明块，锁什么/放什么写成显式契约：「镜头景别、机位和具体剪辑节奏可以自然变化；故事因果顺序不得变化，动作结果不得重置。」
        - 因果约束四句，松档的结构保险：新事件必须来源于上一反应的结果；反应必须是对事件的合理回应；下一动作必须继承上一动作的结果；不得用逗号或箭头拼接互不相关的场面。
        - 任务进度守恒，治"动作重置"高频病：已经完成的动作不得重新开始；已经处理的物体不得恢复到未处理状态；人物位置和道具位置不得无原因重置。
    认错长什么样：
        把节奏档搬成松紧档 = 错：条头标「B 轨中档」「A 轨疏档」，理由是拆解给这条的节奏档是中或疏——两根轴各有各的取值，搬过来就得到一个松紧轴上根本不存在的档位。正文明明是逐镜编排的紧档、标签却写松，下游 retake 与生成侧信标签去补自由度声明，会把紧档正文打散。松档漏掉自由度边界声明——模型把"松"理解成"全放"，因果链被剪辑自由冲散；紧档却写"镜头可自然变化"——两档声明互相打架。

[条时长分档 · 待实测校准]
    本表是只读副本。V14 的真相源两处：**节奏分档与气口预算**归 `_shared/pacing-methodology.md`（导演拆解时分档），**每条实际时长的上下界**归 `.project-config.json.video_model_config` 的 `min_seconds` / `max_seconds`。改数只去那两处改；两边不一致以真相源为准。下表的秒数是 30s 上限模型下的历史经验值，`max_seconds` 不同则只有落在区间内的档位用得上。
| 档位 | 适用 | 注意 |
|---|---|---|
| 4–8s | 单一动作、插入镜头、快速揭示、桥接 | 单动作强句颗粒 |
| 8–15s | 高复杂动作、密集对白、多人调度 | 对白条主区间 |
| 15–22s | 一个完整动作链或一次明确情绪转折 | 动作条主区间，10–22s |
| 22–30s | 同场景完整起承转合或长镜头 | 上限是场景级容量，非必须填满 |

    超 `max_seconds` 必拆——拆分位置归导演拆解的戏剧断点规则，详 `outputs/epNN/01-director-analysis.md` 的接缝卡与 `_shared/pacing-methodology.md`；本卡只校验不越权改条，要改回 `shot-design` 改表并重走 ★表确认。复杂度高可主动建议缩短——多场景快切、多人复杂动作、大量口型对白、主客观切换、多层时间结构等触发——建议回上游改条，不静默自拆。

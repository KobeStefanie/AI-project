[定位]
    "弱句 → 可跟随强句"的改写对照表。一句话公式：多动词、多物理、多运镜方向。
    模型有三个固定毛病，强句逐个覆盖：1 默认把戏剧动作做成慢镜 → 速度显式；2 开放式运动会卡死 → 补运动终点；3 铺垫起手浪费前几秒 → 动词领头。
    另一个底层事实：形容词几乎被无视——"电影感/大气/史诗感"——模型只对可观测的物理事实和动词响应。

[四把改写刀]
    1. 动词领头：以动作动词开句。"灯亮了""她坐在那"是铺垫起手，会浪费开头几秒。
    2. 速度显式：模型默认慢镜，必须用速度词覆盖。发力 → 骤然冲出、摇镜 → 快速跟拍、移动 → 缓缓飘移。
    3. 补运动终点：动作后加落点，"随即归位定住 / 随即定住"。开放式运动几乎必卡死。
    4. 物理锚定：动作接到物理现实——尘土扬起、石块崩裂、水流淌落——防"卡通贴在背景上"。

[强弱对照 · 主体动作]
| 弱 · 被忽视/糊/退化静止 | 强 · 动词领头 + 物理 + 速度 + 终点 |
|---|---|
| 一个女人坐在桌前抬头 | 她缓缓搅动咖啡，随即抬头露出一丝浅笑，窗外闪电忽明忽暗 |
| 她很疲惫 | 她揉着太阳穴，目光从屏幕上飘开，随即向后靠进椅背 |
| 他跑过去 | 他猛地冲刺，随即向前扑出，身后尘土扬起，随即双脚钉稳 |
| 风很大 | 狂风扫过地面，她的外套与头发向一侧猛烈翻飞，随即渐渐平息 |
| 门开了 | 门向内推开，暖光洒满地面，随即半开定住 |
| 她哭了 | 她眼眶泛红，眨了一下垂下目光，呼吸一滞——无泪滑落 |
| 他很愤怒 | 他咬紧下颌，一拳砸在桌上，随即从牙缝间重重吐出一口气 |

[两档颗粒 · 单动作强句 vs 动作链强写法]
    单动作强句——A 轨普通段落与一镜到底的颗粒：一句一个动作变化量，最强约 20 字，把一个微动作钉死。
    动作链强写法——B 轨密集动作镜与 A 轨必杀段的颗粒：一条有因果顺承的连续动作链，穷尽到身体部位/方向/次序。要点：
        - 因果顺承词咬住：随即、顺势、脚步不停、几乎同一瞬——不是用"和/同时"并列无关动作。
        - 每个子动作补落点：脱手 → 飞向舱壁、掀飞 → 砸向墙、奔跑 → 切第一台 → 扑第二台 → 劈第三台。
        - 穷尽到哪只手、撞哪、第几刀、什么方向。
    认错长什么样：
        把多个无关动作用逗号并列堆一句，如"他跑步、开门、打电话"——模型取平均，退化成静止或飘；把动作链错当违规拆掉——链不是病，禁的是并列无关动作，不是因果链。

[物理指令 + 情感解析成对写法 · 情绪节点必用]
    价值最高的情绪写法范式：先给可执行的物理指令——景别 + 构图 + 微表情/动作序列——再用括号向模型解释这串动作背后的深层表达，即潜台词。
    怎么认：
        物理指令必须独立成立，删掉括号仍可拍；情感解析只挂在情绪节点，不逐句挂。
    典型例子：
        - 眉心蹙起 → 视线从对方脸上移开 → 喉结滚动一次 → 单侧嘴角短促上扬（是"我早知道会这样"的自嘲笑，不是开心）。
        - 她把怀表轻轻放回抽屉，指尖在表盖上停了一秒才收回（这是告别，不是收纳）。
    认错长什么样：
        只有情感解析没有物理指令，如"她带着复杂的情绪看着他"——模型即兴出浅表结果；情感解析写成表演指令，如"演出悲伤"。

[情绪句词组库 · 肌肉级微表情，挑 1–3 个组装]
    喉结上下滚动一次 / 泪膜在下睑缘反光却悬而不落 / 咬肌微微隆起 / 单侧嘴角极不自然地上扬扯动、另一侧保持下坠 / 笑意没走到眼睛里 / 眉心浮出浅竖纹 / 唇色因紧咬泛白 / 鼻翼轻轻张合 / 肩膀微塌、胸腔内缩 / 指尖在物体表面慢慢摩挲一圈 / 尾音轻颤 / 呼吸一滞。
    情绪不是开关：初始情绪 → 触发 → 第一反应 → 认知确认 → 情绪改变 → 最终状态，每一阶段换不同的部位表达，禁止突然换表情，禁止每镜流泪咬牙握拳的夸张符号。

[生理顺序链 · 写反应与转身时照抄次序]
    转头回望：眼球 → 头部 → 颈部 → 肩膀 → 上半身 → 必要时脚步与重心。
    情绪变化：视线 → 呼吸 → 眼睑/眉间 → 下颌/嘴唇 → 手指/肩膀/重心 → 完整动作。
    起身：目光确认 → 手掌或脚掌找支撑 → 重心前移 → 关节发力 → 身体抬升 → 找回平衡。
    一切反应必有触发源：看见/听见/被触碰/想起/认出/理解/决定；禁写"突然悲伤/突然震惊"。

[动作八段物理链 · 动作条骨架]
    准备 → 触发 → 起势 → 加速 → 接触 → 反作用力 → 结果 → 恢复/余波。
    配套物理：衣摆头发晚于身体；落地踝膝髋依次吸收；被击中有受力方向；碎片按大小有不同速度轨迹；巨物先以震动、落尘、低频预告。爆点必须保留接触与结果，不得只有起势。

[写状态不写过渡（States, not transitions）]
    模型演不了过渡、演得了状态。"reaches into the bag, pulls out, winds up"（伸手进包、掏出、抡起来）会失败；"mid-throw, arm extended"（已在掷出中段、手臂完全伸展）会成立。
    连续过程改写成逐拍状态链；复杂动作不放时间轴中段——开场即中态："he is ALREADY mid-swing, the door ALREADY cracking"（他已经在挥棒中段、门已经在开裂）——接近过程另拆一条。

[强弱对照 · 运镜，与主体分离成句]
    运镜单独成句：运动词 + 空间描述；最多双轴，不叠第二个运镜。
| 弱 | 强 |
|---|---|
| 镜头动一下 | 缓慢推近她的面部，背景逐渐失焦虚化 |
| 跟着他 | 轻柔跟拍从侧面跟随他，将他始终保持居中 |
| 转一圈 | 缓慢环绕两个人物，自侧面扫向正面，转半圈 |
| 升上去 | 摇臂上升并后拉，露出下方空荡延伸的街道 |

    复合运镜合法性判据：两个运动能用「随……成……、再随……」由同一主体动作串起、前一落点是后一起点 → 同一句合法；并列无因果 → 拆到不同镜头。静止必须显式声明"锁定机位、无漂移"，否则模型自己加漂移。词典、焦段与角度详 camera。

[速度动词梯度]
| 慢/轻柔 | 中/自然 | 快/强烈 |
|---|---|---|
| 缓缓飘移、渐缓、轻柔地、逐渐 | 平稳、顺滑、匀速 | 骤然冲出、猛扑、急停、快速跟拍、急速上升、猛烈地 |

    默认动作先判"该慢还是该快"：戏剧/冲突动作明确给快速词，否则模型做成慢镜。

[运动预算]
    模型把运动能量分给运动最大的元素——快剑会败掉慢竹子。主体给强动词；抢戏的次要快动作弱化或删，写"置于背景、几乎不动"；情绪长镜里的高能环境动势如雨打窗、人流要显式压低，否则该发酵的脸被冷落成空镜。
    认错长什么样：
        主体动作被无视、镜头自顾自飘——先查是不是次要元素抢了预算，不是先加词。

[空间/因果显式化]
    含糊空间语言出物理错，如"接住它们" → 徒手碰火。危险或多步动作点名方法与工具："稳稳接住""倾斜炒锅、用锅铲把菜滑入盘中"。在旁边/附近这类弱空间词换可测量语言：一米内/贴墙/画面左侧，详 blocking。

[条内单镜时长与动作换算 · 未分段连续段落适用]
| 时长 | 装多少动作 |
|---|---|
| 3–5s | 单动作：一次推近 + 一个表情变化量 |
| 6–8s | 两拍：起 → 落，或动作 + 情绪转 |
| 9–12s | 复杂动作慎用，宜按镜/按段拆 |

    条级时长分档见 dual-track.md [条时长分档 · 待实测校准]，4–30s，待实测校准。超出换算就拆段/拆镜，别在一段没切分的散文里硬塞。

[自检]
    - [ ] 每个动作句动词领头，非铺垫起手。
    - [ ] 戏剧动作有显式速度词；每个动作有终点。
    - [ ] 运镜单独成句、最多双轴；复合运镜过「随……成……」判据。
    - [ ] 情绪节点用物理指令 + 情感解析成对；无裸情绪形容词。
    - [ ] 过程写成状态；复杂动作开场即中态。
    - [ ] 次要快动作没抢主体运动预算。

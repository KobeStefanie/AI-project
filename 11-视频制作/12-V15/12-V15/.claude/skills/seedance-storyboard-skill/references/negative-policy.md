[定位]
    视频规则集的负向政策分两层，各司其职：
        - 第 7 段【针对性负向】：症状驱动、≤3 项、化进散文——只治本条真实存在的风险，零症状零负向是合格状态。
        - 第 8 段【全局禁止项尾缀】：固定短清单——只装系统性风险，即模型自发添加的字幕/水印/多余人物/动作重置/切黑；每条必带，与症状无关。
    两层加起来仍然短：长负向 kitchen-sink 会降相干性、掉画质、挤词预算。图像链路无负面参数、纯正向——那是资产 skill 的规则集，双向隔离：别把图像纪律搬进来限制这里的负向，也别把这里的负向语法带回图像提示词。

[正文否定句划界 · 「否定即召唤」]
    全库唯一判据，定稿在此，lighting / blocking / camera 三卡的锁块段落逐字只读引用同一句。判的是否定的对象是什么，不是它长在哪一块里：
        - 否定对象是具体可视意象——动作、物体、人物，如「不要仰摔」「不引入新道具」——一律改写成期望态，或进第 7 段【针对性负向】占名额。理由是"does NOT fall on his back"（不要仰摔）等于邀请模型想象仰摔，改写为"falls on his stomach"（脸朝下扑倒）才有效；"不要移动" → "镜头稳定固定不动"；"不要暗" → "高调明亮"。
        - 否定对象是技术性设定——布光方案、机位、镜头运动、漂移，如 No frontal key / No flat exposure / 无漂移——允许贴着它保护的那条正向规则内联，不占第 7 段的 ≤3 名额。表情特写的幅度夹钳「不皱眉、不流泪」同属此类：它约束表演幅度，不是清画面杂质。
    不开整块豁免：工艺卡的锁块段落整块由否定句构成，不等于整块合法，也不等于整块该删——逐句按上面两条过一遍。绑定段的「不得继承……」是绑定句式的固有半句，属技术性设定，照写。
    第 7 段的负向也要化进散文句，如"结尾定格，不切黑、不转场，画面无任何文字与边框"；不单列成行、不破折号起清单。

[症状 → 选词字典 · 命中才挑，≤3 项]
    通用类：
| 症状/风险 | 选词 | 触发场景 |
|---|---|---|
| 分格框/箭头/标注渲进画面 | 无分镜板边框、无箭头、无网格、无分屏 | 绑了站位图/宫格/白模 |
| 自动字幕/台词条 | 无字幕、无画面文字、无台词条 | 尾缀已含"无字幕"，仅对白密集条按需强化 |
| 乱入路人/人群 | 无多余角色、无路人 | 单主体镜、空旷场景 |
| 自造 logo/贴纸 | 无 Logo、无品牌标识、无贴纸 | 产品镜、商业片、空背景 |
| 杂物糊画面 | 无杂物、无多余道具 | 背景易堆杂物的场景 |
| 多余肢体/畸形手 | 无多余肢体、无畸形手部 | 人物近景、手部入镜 |
| 跨镜掉色/风格突变 | 无掉色、无风格突变 | 多镜序列、跨场 |
| 抖动/闪烁/形变 | 无闪烁、无漂移、无形变 | 编辑类、替换元素 |

    对话戏专项：
| 症状 | 选词 |
|---|---|
| 越轴/左右翻转 | 无越轴、无左右翻转 |
| 口型错配 | 无口型错配、台词与口型同步 |
| 倾听者跟着动嘴 | 倾听者嘴唇静止、无同步动嘴 |
| 台词跨镜漂移 | 台词不跨镜、每句只说一次 |
| 道具瞬移/复制 | 无道具瞬移、道具数量不变 |
| 无因同步变脸 | 无同步变脸、表情各自独立 |

    时间戳/连续性专项：
| 症状 | 选词或正向对策 |
|---|---|
| 动作/站位重置 | 尾缀已含"无动作重置"；多段条正文加防重置句，见 dual-track.md |
| 已处理物体回退 | 已处理的物体不得恢复到未处理状态 |
| 情绪抢跑，高潮提前释放 | 禁止眼泪提前滴落，绑定到它所属的时间段写 |
| 整体比时间戳快/过早切镜 | 无负向词可治——正向对策：每段写满动作 + 末段留稳定落幅，待实测项 |

    多语言/画面文字专项：画面内所有文字——招牌/菜单/价签/海报——全部为自然规范的{{语种}}，不出现任何其他语言或乱码；仅发声、无字幕——唯一允许的字幕内容与帧区间显式写死。
    认错长什么样：
        一条带 14 项全家桶负向清单；负向单列成末行破折号清单；写了"无字幕"又在尾缀重复计数——尾缀固定项不占第 7 段的 3 个名额。

[全局禁止项尾缀 · 第 8 段固定短清单]
    基础五项，每条必带、顺序固定：
        无字幕、无水印无 Logo、无额外人物、无动作重置、不切黑。
    「无额外人物」在带群演或背景人群的条上改写为「除画面中已描述的 N 名/一片背景人群外，无额外人物」——原句与群演条互斥，照抄会把定场镜清成空场，或整条尾缀被忽略。
    片型附加项，按本片片型挑 ≤2 个真的相关的，不全带：
| 片型 | 附加项 |
|---|---|
| 广告/商业 | 规避已知版权 IP 元素；产品结构不变形 |
| 机甲/硬表面 | 禁止结构在运动中软体扭曲穿模，保持金属刚性 |
| UGC/vlog | 无商业广告感、无摆拍痕迹；无平台尾页、无账号界面 |
| 动画/风格化 | 保持风格化不得转写实——双向锁：不要变成真人写实，必须保持{{风格名}} |
| 多语言 | 画面文字全为规范{{语种}}、无乱码 |
| 对话戏 | 无越轴、无口型错配 |

[硬性判定句 · 顽固症状的升格武器]
    何时升格：同一症状用负向词治过、复发 ≥2 次 → 写成一条具名硬性判定句，放进它保护的正向规则所在段落而非负向段，贴着现场生效。
    一条硬性判定句三件套：名字 + 框内可见证据 + 「……= failed take（= 废镜）」判定句。
    四个高频范式：
        - 情绪双向夹钳，治单向情绪词漫画化：「他的表情钉在克制的悲怆与强撑的平静之间；嚎啕大哭的脸 = failed take（废镜）；轻松的微笑 = failed take；面无表情 = failed take。」（between joy and aggression; a rage-twisted face = failed take; a soft beaming smile = failed take; deadpan = failed take——情绪必须双向夹死，单向禁令只会弹到另一个极端。）
        - 身高失败方向，治比例漂移：「他绝不比她高出一厘米；拿不准就渲染得略矮半分。（NOT taller by a single centimeter; if in doubt, render him a touch shorter.）」——给模型指定"错也要往哪边错"。
        - 尺度三重锚定，治大小漂移：真实尺寸 + 画面占比 + 与框内已有物比较——「怀表直径五厘米，在特写中占画面宽度三分之一，约为他掌心的一半大」。
        - 物体数量逐帧写，治运动中道具复制：「全程画面中只有一块怀表；任何时刻出现第二块怀表 = failed take（废镜）」。
    点名封禁，模型反复长出没要的东西时：把它逐项列为 absent（不存在）并给出精确的正向替代描述——"月台上没有雨棚、没有灯架、没有候车亭，只有两条平行铁轨与一排齐膝荒草"。
    认错长什么样：
        硬性判定句没有判定尾——只喊名字没有"= 废镜"；判定句堆在负向段而不是它保护的正向规则旁边；全片判定句泛滥——它是给复发症状的，不是默认装备。

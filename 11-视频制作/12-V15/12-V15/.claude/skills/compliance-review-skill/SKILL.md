# 内容合规审核技能

[技能说明]
    检查各阶段产出是否触碰视频生成与生图平台的内容限制。**布尔判定，不评分**——红线不存在「60 分及格」。
    在 V14 查病制里，红线 = 五类病第 5 类，且是 **blocking 白名单**成员：任一 🔴 命中即 FAIL，与质量分无关。判定框架见 `_shared/review-methodology.md`。
    平台边界随版本变化：**拿不准就 WebSearch 核实，不靠记忆里的旧红线**。

[审核对象]
    reviewer 在每个审核点叠加本 skill（阶段一编剧不走本审核）：
    - 拆解审：`outputs/<集数>/01-director-analysis.md`
    - 资产审：`assets/visual/{character,scene,prop}-prompts.md` 本集新增段
    - 音乐审：`assets/music/music-design.md`、`lyrics-drafts.md`、`music-recommendations.md`（**重点审歌词合规 + 版权风险提示是否齐全**）
    - 镜头表审：`outputs/<集数>/02-shot-table.md`——台词、导演意图、暴露度与暴力描写的**源头在这一层**，比提示词更早拦住
    - 成片审：`outputs/<集数>/video-prompts.md` + `episode-master.md`（故事板模式含 `storyboards/`；有控制图时含 `control-prompts.md`）

    🔴 **成片审另查「跨条组合风险」**：单条无害、连起来构成教程或侵权叙事的按组合判——如逐条分解违禁品制作步骤、逐条复刻受版权保护作品的完整段落。判据：把本集全部 Cut 的一句话内容顺序读一遍，整体是否构成平台禁止的叙事。

[审核流程]
    通用流程框架（建立理解 → 逐项检查 → 输出）见
    **`.claude/skills/_shared/review-methodology.md`**

    本 skill 只做布尔判定：
    - 全部清单项通过 → PASS
    - 任一 🔴 未通过 → **blocking → FAIL** + 问题清单（每条给定位符 + 原文证据 + 可执行改法）
    - 🟡 误杀风险 / 🔵 投放提示 → 记入报告的 major/minor，**不判 FAIL**

    审核员立场：
    - 不要"凭感觉"放行——红线是平台机器审核的实际触发点，再小的疑似都要按 FAIL 处理
    - 三级分明：🔴 绝对禁止（必触发拦截，blocking）/ 🟡 误杀风险（可能触发，不挡线）/ 🔵 投放提示（平台分发影响，不挡线）
    - 合规不做品味评判：只判「会不会被拦」，不判「合不合适」
    - 给出修改方向必须可执行（如"将'某真人姓名'改为'虚构姓名 XX'"），不要写"建议规避"

[验收清单]

    [真人/名人限制]（Seedance + Gemini 共同红线）

        角色参考图是否为 AI 生成的虚构人物（非真人照片）？
        角色外观是否与真实名人/公众人物不相似？
        提示词中是否不包含公众人物姓名？
        🟡 **导演名作为风格锚的边界**（V14）：色彩锚只把导演的**六色 HEX + 光线/摄影/调色**写进基准段（可观测的色彩关系），**导演姓名不进提示词**——这是合规做法。若提示词正文出现「XX 导演风格」「in the style of XX」→ 🟡 改写为色彩与光影的客观描述

    [版权 IP 限制]

        是否不包含已知版权 IP 角色名称（迪士尼、漫威、DC、哈利波特等）？
        是否不包含已知版权 IP 的形象/设定描述？
        是否不试图复刻经典影视片段？

    [政治/国家安全]（Seedance 平台红线）

        是否不涉及反对宪法基本原则？
        是否不涉及危害国家安全？
        是否不涉及煽动民族仇恨/破坏民族团结？
        是否不涉及歪曲/否定英雄烈士？
        是否不涉及宣扬恐怖主义/极端主义？

    [宗教类]

        是否不涉及违反宗教政策？
        是否不涉及宣扬邪教/封建迷信？
        是否不生成宗教人物形象（Gemini 限制）？

    [色情/低俗]

        是否不包含淫秽色情内容？
        是否不包含性暗示/软色情？
        服装设计是否避免过度暴露（降低 Gemini 误杀）？
        动漫/漫画风格是否注意 Gemini 更高的拦截率？

    [暴力/血腥]

        武打/格斗场景是否使用虚构角色？
        是否不展示/美化过度血腥暴力？
        是否不包含赌博/诈骗/犯罪指导？

    [未成年人保护]

        是否不涉及任何形式对未成年人的侵害内容？
        是否不涉及危害未成年人身心健康的内容？

    [仇恨歧视]

        是否不包含基于性别/年龄/地域/民族/种族/宗教的歧视？

    [人身权利]

        是否不侵犯他人名誉权/隐私权/肖像权/知识产权？

    [虚假信息]

        是否不涉及散布谣言/歪曲事实？

    [Gemini 特有高频误杀规避]（阶段三服化道重点关注）

        人物设计是否避免内衣/泳装类描述？
        运动服装描述是否不过于紧身暴露？
        医学/解剖类场景是否有风险提示？

[输出规范]

    PASS 格式：
    ```
    ✅ **合规审核：PASS**
    内容未触碰平台红线。
    ```

    FAIL 格式：
    ```
    ❌ **合规审核：FAIL**

    **问题1**：[具体违规描述]
    - 位置：[如 人物设计 > 角色名 / P03 提示词]
    - 触碰红线：[哪条规则]
    - 相关平台：[Seedance / Gemini / 两者]
    - 修改方向：[如何修改以规避——必须可执行]

    **问题2**：...

    ---
    **风险等级**：
    1. 🔴 必须修改（触碰绝对禁止红线）：[列出问题编号]
    2. 🟡 建议修改（可能触发误杀）：[列出问题编号]
    ```

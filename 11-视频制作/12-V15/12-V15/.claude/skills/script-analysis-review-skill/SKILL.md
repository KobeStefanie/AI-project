# 导演分析审核技能（v14 · 查病制）

[技能说明]
    审核导演在阶段二（剧本拆解/讲戏）的产出。**由 reviewer 独立执行，不是导演自审**——创作者不能既当运动员又当裁判。查病立场、五类病、blocking 白名单、判定与轮次、防误杀、报告格式、回流路由全部见 `_shared/review-methodology.md`，本文只列**拆解审查什么**。

[审核对象]
    `outputs/<集>/01-director-analysis.md`（讲戏本 + 镜头承载规划 + 节奏蓝图 + **条划分表** + **接缝卡** + 人物/场景/关键道具清单）；**首集**另审 `assets/story/visual-style.md` 的定稿增量与 `reference-index.md` 骨架。

[只读基准]（永不入审，对不上判被审产物走样）
    - 原始剧本 `script/<集>-xxx.md`（核心参照）
    - `assets/story/creative-brief.md`（情感蓝图 + 导演视野）、`decisions.md`（拷问拍板）
    - `assets/story/script-settings.md`（目标媒介/平台/受众/对标/画幅）
    - `character-profiles.md`（如有）
    - `.project-config.json.video_model_config`（max_seconds）
    - 续集：上一集 `continuity-ledger.md` 跨集 ending state

[脑内预演视角]（前三类病干净后才跑）
    想象一个真实导演拿这段讲戏去指导拍摄：画面能否浮现？团队是否还要追问"你到底要什么效果"？拍出来是否传达原剧本的情绪？偏差处指出「原剧本情绪 → 讲戏传达的情绪」。

## 拆解审查什么（按五类病归位）

### 剧情拆解完整（走样 / 断链）
    - 逐行比对：原剧本每个场景转换、每句台词、每个动作指示，是否都有剧情点覆盖？漏拆 = 走样，列出遗漏项。
    - 叙事完整性：每个剧情点是一个完整叙事段落？蒙太奇序列有没有被无谓拆成多个独立点？
    - 该合的合、该拆的拆：服务同一叙事目的的相邻段落应合并（对应「无戏剧断点不拆条」）；一个段落含两个独立叙事目的应拆分。具体指出哪些。

### 镜头承载规划（走样，本级重点）
    每个剧情点**必填**「镜头承载规划」（可一镜到底 / 需 N 镜 / 可与 P0X 并入一镜 + 理由）。
    - 缺字段 = 断链 major。
    - 承载判断与 `max_seconds` 匹配：上限宽却把能一镜到底的戏拆成多点，或上限紧却让单点超容量 → 走样 major（同一剧本在不同上限下分镜方案不是一回事）。
    - 建议时长 ≤ `max_seconds`；超限 → 记 major 回导演。config 缺失先提示 ~video-model。

### 台词逐字（走样）
    讲戏本引用的原剧本台词与剧本 diff，不增删改。

### 节奏蓝图三档（走样 / 断链）
    每个剧情点是否标了节奏档（疏/中/紧）+ 气口估算？缺档或与内容明显不符（激烈动作标疏档）→ 命中。

### 条划分表（断链 / 走样）
    这张表是下游「条边界」的唯一真相源，缺一项下游就卡住或被迫越界定条。逐条核：
    - **表本身在不在**？缺整张 = **断链类死引用 → blocking**（下游 `shot-design` 在 SKILL 里声明读入本表的「条划分」，且明文禁止自行定条；表不存在 = 它声明读入的字段不存在，属白名单「断链类的死引用」，不是新增白名单项）。
    - **每条都指到唯一 P0X 归属**？有条落空、或一条挂两个不相关剧情点 = 断链。
    - **条号全集连续不重复**？跳号/重号 = 断链（下游按条号对账）。
    - **每条估算时长在 `min_seconds`–`max_seconds` 区间**（读 `.project-config.json.video_model_config`）？超上限 = 断链（本该在导演侧拆条，留给下游就是硬掰）；低于下限 = 走样。
    - **每条具名主体 ≤ 5**（人 + 特写出现的手/物）？超 = 走样 major。
    - **拆条/并条有理由**？空着或写「按需要」这类空话 = 走样。
    - 剧情点全覆盖：讲戏本有 P0X 但条划分表里找不到任何一条归属它 = 断链。

### 接缝卡（断链 / 模型雷）
    - **接缝数 = 条数 - 1**？跳号或漏缝 = 断链（下游【衔接】段取不到手法）。
    - **出点手法取自枚举**（动作匹配/声音桥/视线匹配/遮挡转场/相似物转场/空间顺承/时间跳跃声明/段落收尾）？自造词 = 走样。
    - **出点动势与出点手法配合**？标「动作匹配」却写落地停死、标「段落收尾」却不给停稳时长 = 矛盾 major（下游条末镜结束状态会跟着错）。
    - **有无写切黑或自加转场特效收尾**？写了 = 模型雷（切黑在全局尾缀已锁死，峰值压末帧硬切 = 情绪不落地）。
    - 时间跳跃声明是否只用在显式跳变（「三小时后」级别）？同空间换机位标成跳跃 = 走样。
    - ep02+：是否有「上集末条 → 本集 Cut1」一行，且承接对象取自 `assets/continuity-ledger.md` 上集落幅？缺 = 断链。

### 人物清单（走样 / 断链）
    - 筛选合理：只含"需要参考图"的角色。**应列入却遗漏**（本集 2+ 剧情点出现、后续集数复现）= 断链；**应排除却误入**（一次性群演）= 走样。
    - 群演描述充分：不在清单的群演，导演阐述里外观是否够具体（「尖脸眯缝眼的白袍学员」而非「一个路人」）。
    - 外观可设计 + 与讲戏本无矛盾（同一人物两处描述打架 = 矛盾）。

### 场景 / 关键道具清单（走样 / 断链）
    - 场景：剧情点出现的所有场景是否都进清单？环境描述是否够服化道生成？
    - 关键道具：复现 ≥2 且推动剧情的道具是否列出？本集无关键道具是否显式标记（避免下游路由卡住）？

### visual-style 定稿增量（首集，走样 / 断链 / 上游观察）
    - 场域锚句表是否**覆盖场景清单每个场景**？漏 = 断链（下游恒定层取不到本场锚句）。
    - 定稿与 `decisions.md` 拷问拍板是否打架？= 矛盾。
    - 通用基准段四件齐（媒介质感/色域/光逻辑/镜头性格）？缺 = 断链。
    - 风格轴本身选得好不好 = 已确认决策，**出圈 → 记「上游观察」**，不判。

### 开场钩子 + 上承下启（走样 / 模型雷）
    - P01 是否明确开场钩子（对应创作九原则「开头抓人」）？缺 → major。
    - 上承/下启字段：填的是**设计层过渡素材**（重物件锚点/视觉母题/对白回环/情绪温度），不是技术层「接上一帧」（AI 每段独立生成，帧对齐不可达 = 模型雷）。写了帧级粘合 → major。

### 讲戏可拍性（模型雷）
    抽象讲戏（「营造压抑氛围」而非可拍的物理动作）、动作链跳跃（上一秒 X 下一秒突然 Y）、开放运动无终点、光影不具体（「光线柔和」而非「灰蓝晨光从左侧单窗斜射」）→ 命中 major，改向给可拍写法。

### 受众适配（走样类的一个角度，命中才记）
    对照目标平台 + 受众画像：P01 前几秒有钩子？中段每 5–10 秒有新刺激、有无拖沓段？结尾有反转/悬念/余韵？有对标时附查节奏/情绪/结构气质是否同频。明显脱节 → 走样 major。判据见 review-methodology 第九节。

## 输出（报告格式见 review-methodology 第七节，落 `outputs/<集>/review/breakdown-report.md`）
    不产评分表、不写分数。只列发现（七字段），按 blocking → major → minor 排，尾附「上游观察」。有 blocking = FAIL 靶向重审一轮；无 blocking = PASS，major/minor 修完随产物交确认时报「审核发现 N 条、已修」。连续两轮 FAIL 或判据分歧 → 熔断交用户。

[定位]
    这是运动槽的可视化字典：每个运镜词翻成"镜头实际怎么动、带哪个方向、配什么速度、给什么情绪、怎么写"，末节附构图槽对照。
    用法：定了情绪与叙事功能后，来这里反查一个运镜，确认方向位和速度位都填上了，再成句。
    三条铁律压在所有词之上：一动作节拍一条运镜、静止显式声明、运动带方向加速度。一镜一个主运动；密集动作戏可在主运动上挂一个由主体动作驱动、有先后因果的衔接运动——随伸臂 → 急推、随翻转 → 大旋转——写进同一句不算堆叠。真正禁的是无主体动机的纯叠加——并列多个互不相关的运动被模型取平均，退化成静止或飘。简单/安静镜头一个运动到底。

[方向词与速度词 · 每个运动必须各取一个]
    方向：推/拉、左/右、上/下、顺时针/逆时针环绕。
    速度质感：极缓（几不可察的沉浸、情绪长镜专用）、缓（悬念/分量/紧张逼近）、平稳（浪漫/平静）、稳（常规）、轻柔、渐进（随时间积累）、快（动作/肾上腺素）、骤然、强动感。
    缺方向或缺速度，运动就退化成废话。反例："镜头移动"；正例："缓推"。不给速度词，模型默认做成慢镜。

[运镜可视化字典]
    每条：画面里实际发生什么 / 方向 / 给什么情绪 / 可抄写法。按家族归类。

    推拉类——纵深与张力，最有冲击力的运镜家族。
        推镜/推近：镜头整体物理向被摄体靠近，纵深感真实、优于变焦。方向 推。情绪：聚焦、逼近、亲密升温；缓推是逐渐收紧的张力。写法：缓推逼近她的脸。
        拉镜/后拉：镜头物理远离主体，揭示周遭、交代处境。方向 拉。情绪：揭示、疏离、孤立、收束感。写法：稳后拉揭出空荡的街道。
        变焦：焦段变化改变取景而非位移，观感比推拉"平面"，慎用；与推拉区分——推拉改纵深，变焦改取景。写法：缓缓变焦推向时钟。
        急推：极快的戏剧性逼近。方向 推、速度 骤然。情绪：突发能量、震惊、冲击。写法：急推骤然怼到他的眼睛，带运动模糊。
        希区柯克变焦（推拉变焦）：推拉与变焦反向同时，背景在静止主体身后诡异压缩/拉伸。情绪：眩晕、心理冲击、天旋地转。写法：希区柯克变焦，背景在静止主体身后扭曲变形。注意：复合单一效果，按一个主运动算，极强，整条只此一记。

    摇类——机位不动只转头。
        左摇/右摇：机位固定，镜头水平转动。方向 左/右。情绪：环顾、揭示横向空间、跟随水平运动。写法：向右缓摇跟随摩托车。
        俯仰摇 上/下：机位固定，镜头垂直转动。方向 上/下。情绪：上摇强调高度与规模、揭高耸，下摇压低。写法：缓缓向上俯仰摇，揭出耸立天际的高塔。
        甩镜：极快水平摇，产生强烈运动模糊。方向 左/右、速度 骤然。情绪：急转、惊讶、暴烈。写法：快速甩镜扫向门口。

    横移与升降类——机位整体平移，与摇区分。
        横移 左/右：机位整体平行于主体移动——摇镜转头不动位，横移整机移位。方向 左/右。情绪：跟随横向动作并换背景视角。写法：向左横移与奔跑者并速。
        升降机位 上/下：机位像电梯整体垂直升降——俯仰摇转头，升降整机移位。方向 上/下。情绪：揭示隐藏元素、匹配主体起立/下蹲。写法：升降机位上升，揭出墙后的花园。
        摇臂/吊臂 上下：大幅升降，常带弧线扫过。方向 上/下。情绪：史诗、大场面建立、揭示规模。写法：摇臂上升扫过广袤的人群。

    环绕类——立体感与揭示。
        环绕 顺时针/逆时针：绕主体一圈、主体保持居中，把主体从背景分离。情绪：立体、动感、英雄揭示。写法：平稳逆时针环绕，反光沿车身滑动。
        弧形移动：部分环绕约 90°，不绕满。情绪：戏剧性、强调。写法：绕主体 90° 弧形移动。
        180° 半环绕：对话/对峙用的半圈，背景在主体身后旋转揭示。情绪：对话张力、揭示身后空间。写法：平稳 180° 半环绕，背景旋转揭出门口。

    跟拍类——跟随感。
        跟拍：跟随移动主体并保持其清晰。情绪：动态聚焦、与角色同行。写法：跟拍奔跑，前景草丛拉虚。
        背后跟拍：跟着背影走。情绪：代入、悬念、"我们跟着他"。写法：沿走廊背后跟拍。
        侧面跟拍：平行于主体侧面。情绪：并肩、稳定的动态。写法：沿河岸侧面跟拍。
        一镜到底：全程无剪辑的连续长镜。情绪：临场、不间断的紧张/沉浸。写法：穿过派对的连续一镜到底。对应 A 轨单镜长条的形态。

    动作衔接类——密集动作戏专用：把运镜咬在主体动作上、把多镜缝成一条。
        不是新的镜头运动，而是把推/拉/甩/环绕/跟拍用主体动作驱动、并缝合到上一镜。简单/安静镜头不用。
        随主体驱动：运动由主体某个动作触发，前一落点是后一起点。随伸臂 → 急推成手部特写、随翻转 → 大旋转拉开成全景、随转身 → 甩动跟随、随起身 → 升降上升、随滑行 → 低角度平移推进。情绪：动作与镜头同呼吸、力量贯通。判据：两运动由同一主体动作串起、有先后因果，算合法复合，写进同一句。
        镜间缝合：这一镜怎么接上一镜，不生切。无缝衔接、无缝切至X特写、无跳切、承接上镜余冲、衔接前镜动作。情绪：多镜连成一条凌厉的线。写法：镜头甩动跟随转身、无缝切至枪托重击特写。镜间的缝归本类；条与条之间的缝归接缝卡与【衔接】段，别混。
        动线捕捉：完整跟住一条动作轨迹不丢。完整捕捉踢击动线、贴身捕捉切割动线、随身体平移枪口始终对准目标、全程贴脸跟随无跳切。情绪：把一连串连击钉死在镜头里。写法：低角度跟拍，随他奔跑流畅平移、贴身捕捉切割动线无跳切。

    移焦类——靠浅景深成立。
        移焦：景深内焦点从一处转到另一处，不切镜就把注意力换走。情绪：引导视线、揭示、前后景关系转移。写法：移焦从前景的手转到她的脸。前提：浅景深，光学槽先配好。

    滚转与稳定性类——机身姿态与质感。
        滚转/动态荷兰角：镜头沿光轴旋转、地平线转动。情绪：失衡、迷乱、坠落感。写法：缓慢滚转，地平线倾斜。
        手持：写成摄影师的身体行为，不写"数字抖动"——operator breath, micro-settling, weight shift（摄影师的呼吸起伏、微幅落定、重心转移）。情绪：真实、纪实、紧张。写法：肩扛手持，随呼吸微幅起伏，人手的不完美修正。
        斯坦尼康稳定器：去抖的平滑移动。写法：平稳的斯坦尼康滑移。

    静止——合法选项，必须显式声明。
        固定机位/锁定机位：机位完全不动，动来自主体或环境。情绪：稳定、庄重、聚焦、克制。写法：锁定机位固定画面，无漂移。
        纪律：不动也要写出来，否则模型自己加漂移。要"什么都不动"就显式写：固定机位，无镜头漂移。

[运动预算纪律]
    模型把能量分给运动最大的元素——"快剑败掉慢竹子"。镜头响应句是次要运动，不得抢主体动作的预算：主体动作密的镜头，运镜收敛到一个方向明确的短句；情绪长镜里机位只许极缓一档，环境动势也要显式压低，如"背景人流几乎不动"，否则该发酵的脸被冷落成空镜。
    时长与动作节拍换算——条 4–30s、待实测校准：一个动作节拍配一条运镜；节拍多就拆 B 轨镜头行或按 A 轨时间戳分段，别把三个节拍的运动挤进一句。

[构图 composition 对照]
    构图 = 画框里东西怎么摆。与角度、景别配合服务同一情绪，不是装饰，八种对照如下：
| 构图 | 怎么摆 | 情绪/效果 |
|---|---|---|
| 三分法 | 主体放 3×3 网格线或交点 | 平衡带动势，留出视线方向空间，最通用 |
| 居中对称 | 主体居中、两侧镜像 | 秩序、仪式、庄严；也给"被注视"的正面凝视 |
| 引导线 | 道路/栏杆/视线把眼睛引向焦点 | 纵深、指向、把注意力领到关键处 |
| 负空间 | 主体周围大片留空 | 孤独、留白、渺小、呼吸感 |
| 前中后景分层 | 画面三层堆叠 | 纵深、空间真实、信息分层 |
| 框中框 | 门/窗/拱在画框内再框主体 | 纵深、窥视、被困、聚焦 |
| 低地平线 | 地平线压低、天空占大半 | 开阔、渺小、史诗 |
| 满构图 | 主体几乎填满、空间压缩 | 压迫、紧张、无处可逃 |

    构图纪律：对称给秩序，负空间给孤独，分层给纵深；选哪个看这一镜的情绪，和角度/景别同向。情绪逼近的特写常配主体压三分线 + 焦外虚化；孤独的全景常配大负空间。

[反例]
    "镜头很有电影感地移动，又推又拉还转"——无方向、无速度、三运动并列无主体动机、形容词驱动，模型取平均退化成静止或飘。对照合法复合：随伸臂 → 急推、随翻转 → 大旋转，由同一主体动作串起、有先后因果，不在此列。
    "拍得电影感一点/拍酷一点/史诗感"——形容词模型几乎无视。
    同句又写"固定机位"又写"环绕"——无因果的指令冲突，模型乱融合。
    正确做法：一动作节拍一条运镜、方向 + 速度成对、具体技术词；并列无因果的多运动拆到不同镜头；主体动作驱动的主运动 + 衔接运动写进同一句。

[与 Seedance 2.5 的配合]
    运镜词用专业中文术语作锚、中文散文承载情绪；推拉/环绕/摇臂/甩镜这类术语有精确响应。
    运动写在运镜句最前——prompt 前部权重最高：镜头语言：缓推，平视，特写，29° 短长焦人像性格，主体压右三分线。……
    落位规则：镜头表「镜头语言」字段用六槽完整句；A 轨压缩成段内镜头响应短句、随时间戳段走；B 轨展成镜头行、四件骨架为景别 + 机位 + 运动 + 衔接、按事件顺序排不写秒数。
    一条即一个生成单元，上限 `max_seconds`（读 `.project-config.json.video_model_config`）、场景级容量非必须填满；条内镜头数与运动总量都受运动预算约束；序列里每镜各给一条运镜，收口交回 motion-compile 编排。

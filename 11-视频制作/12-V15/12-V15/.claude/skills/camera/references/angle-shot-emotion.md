[定位]
    这是机位角度槽与景别槽的查词工具。角度和景别都是情绪杠杆，不是默认填平视中景的随手活——按剧情点的情绪基调反查。
    用法：先定情绪与叙事功能——威严、渺小、不安、亲密、交代空间还是情绪高点，镜头表「导演意图」字段的情感解析给了答案；再来两张表反查角度与景别，最后查 [角度 × 景别 × 构图的配合关系] 确认角度 + 景别 + 构图服务同一情绪、不打架。
    输出以仰拍、大特写、建立镜头这类专业中文术语为锚，中文散文承载情绪。

[机位角度-情绪对照表]
    角度 = 镜头在被摄体的哪个高度/朝向看它。默认平视，其余都是为情绪而偏：
| 角度 | 镜头位置 | 情绪/语义效果 | 典型用途 |
|---|---|---|---|
| 平视 | 与被摄体视线齐平 | 中性、平等、共情，最贴近人眼，不操纵 | 对话、客观叙事、让观众平等地看 |
| 仰拍 | 低于被摄体朝上 | 威严、强势、英雄、压迫——主体被抬高显得强大 | 英雄登场、权力者、胜利时刻、施压一方 |
| 极端仰拍 | 贴近地面极度朝上 | 夸张透视前缩、纪念碑式巨大感 | 巨物/建筑/神祇般的压倒 |
| 俯拍 | 高于被摄体朝下 | 渺小、脆弱、无助、失势——主体被压低显得弱小 | 失败、被困、弱势一方、被审视 |
| 鸟瞰/顶视 | 正上方 90° 朝下 | 抽离的上帝视角、几何秩序、命运感、人变棋子 | 空间格局、宿命/被操控、图案化构图 |
| 荷兰角 | 画框地平线倾斜 | 失衡、不安、紧张、疯狂——世界"歪了" | 惊悚、恐怖、精神错乱、危机临界 |
| 贴地 | 镜头贴近或触地，保持水平 | 强调尺度与环境沉浸，低视点把前景地面拉大 | 脚步特写、低处主体、临场沉浸 |
| 过头 | 略高于头顶斜下 | 轻度俯视，温和弱化或交代桌面/手部活动 | 俯看手部操作、轻度审视 |

    角度选择纪律：
        角度是情绪杠杆，按剧情点的情绪基调选，别随手平视。
        仰拍给"谁强"，俯拍给"谁弱"——同一场对峙里强势方仰拍、弱势方俯拍，机位本身在讲权力关系。
        荷兰角是"出事了"的信号，一段戏里偶尔一记才有冲击，整段歪等于没歪。
        鸟瞰把人变小变成图案，适合宿命/被操控，不适合要观众共情的近距离情绪。另记：俯视平面图式的机位只属于极少数叙事时刻——作为空间规划参考的俯视图不投喂模型，裁决见 blocking 与 scene-design，别把两件事混为一谈。

[景别-情绪对照表]
    景别 = 画框里装多少。从只剩细节的大特写到只剩空间的大远景。一镜一个主景别：
| 景别 | 画框内容 | 情绪/叙事效果 | 放在哪 |
|---|---|---|---|
| 大特写 | 只有眼/嘴/手等局部 | 极致情绪与张力，看得见微表情与质感 | 情绪最高点、关键细节——指尖/泪/扳机 |
| 特写 | 脸充满画框 | 吃情绪与微表情，亲密、聚焦内心 | 情绪高点、反应镜头 |
| 中近景 | 头与肩 | 亲密带呼吸空间，对话主力景别 | 对话、独白、稳的情绪戏 |
| 中景 | 腰部以上 | 主体动作 + 少量环境，平衡叙事 | 走位、手势、常规叙事 |
| 七分身 | 大腿中部以上 | 带姿态与气场，西部片"亮枪"经典 | 强调站姿/气势/腰间动作 |
| 中全景 | 接近全身留环境 | 主体与环境并重 | 主体在空间里活动 |
| 全景 | 完整人物 + 环境 | 交代主体与空间关系、规模与处境 | 空间关系、群体、场面 |
| 大远景 | 主体很小环境为主 | 渺小、孤独、规模、宿命 | 空旷、孤独、史诗规模 |
| 建立镜头 | 通常全景/大远景 | 段落开头交代时空地理 | 一段戏的开头，落地时空 |
| 双人镜头 | 两人同框 | 同时看两人的关系与反应 | 对话、对峙、关系戏 |
| 过肩 | 越过一方肩膀看另一方 | 对话的"你来我往"，视角与反应绑在一起 | 对话正反打、对峙 |
| 主观镜头 | 角色眼中所见 | 第一人称沉浸，观众"成为"角色 | 沉浸、惊悚、揭示角色所见 |

    景别选择纪律：
        建立镜头放段落开头，特写放情绪高点，一前一后是叙事的呼吸。
        一镜一个主景别——想又特写又远景是两个镜头的事，拆镜；唯一例外是合法复合运镜在一个运动里完成景别变化，如随翻转拉开成全景。
        景别越近情绪越满、空间越少；越远空间越满、情绪越淡。要情绪推近，要规模拉远。
        景别不是光学：大远景可以用长焦拍成压缩式远景，特写可以用广角拍出贴脸畸变的侵略感。景别定"看多近"，光学槽定"用什么性格看"，两槽独立填、同向服务情绪。

[对话戏机位骨架]
    默认序列：建立镜头 → 双人镜头 → 中近景过肩正反打 → 情绪点特写。
    正反打纪律，与 blocking 的轴线管理配套：机位始终在 180° 轴线同一侧，A 压右三分线、B 压左三分线，越轴须走合法路径，见 blocking 的 axis-and-coverage.md。
    权力关系叠加：强势方微仰 + 可推近，弱势方平视或微俯；过肩多用锁定机位让表演说话。
    落 B 轨时每一拍是一个镜头行，正反打天然适配镜头N轨——对话正反打走 B 轨，见 motion-compile 双轨选型。

[角度 × 景别 × 构图的配合关系]
    三者服务同一情绪，不是各填各的。
    强者登场：仰拍 + 七分身/中景 + 居中对称 → 威严、稳、压得住场。
    弱者被困：俯拍 + 全景 + 大量负空间 → 渺小、孤立、被环境吞没。
    情绪崩点：平视或微仰 + 大特写/特写 + 主体压三分线、背景化成焦外 → 情绪逼到脸上。
    危机失序：荷兰角 + 中景 + 倾斜引导线 → 不安、世界歪了。
    宿命俯视：鸟瞰 + 大远景 + 几何图案构图 → 人如棋子、被操控。
    空间交代：平视 + 建立镜头/全景 + 前中后景分层 + 深焦 → 落地时空、看清格局。
    一句话：角度回答"从哪看、谁强谁弱"，景别回答"看多近、情绪还是空间"，构图回答"怎么摆、秩序还是孤独"。三个答案必须指向同一个情绪意图。

[与 Seedance 2.5 的配合]
    角度和景别是高响应的具体技术词，写仰拍、大特写、建立镜头这类专业中文术语读得最准。
    进运镜句的角度位与景别位：镜头语言：{{运动}}，{{角度}}，{{景别}}，{{光学}}，{{构图}}。……；B 轨镜头行里景别 + 机位是四件骨架的前两件。
    i2v 参考图已给出主体长相，角度/景别写的是"怎么框、从哪看"，不复述主体外观。
    角度 + 景别要和运动不打架：大特写配缓推或锁定，大远景配摇臂/锁定机位，别让一个近一个远互相拉扯。

# 标杆 · 运镜子句库

## 示例定位

- 每条标杆是一句可直接拼进镜头表或动态提示词的运镜子句，六槽已填满：带方向 + 速度的运动/机位角度/景别/锚点 + 结果语言的光学/构图，动作戏再加衔接；再接一句空间/情绪描述。
- 句式锚定：镜头语言：{{运动}}，{{角度}}，{{景别}}，{{光学}}，{{构图}}。{{一句空间/情绪描述}}。
- 运动放最前——prompt 前部权重最高；专业中文术语为锚、散文承载情绪；一条子句一个主运动，密集动作戏可挂一个主体动作驱动、有先后因果的衔接运动，见「密集动作戏复合运镜标杆」。
- 找标杆先按情绪/叙事功能对号——要威严、要孤独、要逼近还是要交代空间；再按形态选单镜还是镜头行。
- 这些是手感标杆，不是填空母版——照密度和精确度写，别照抄场景。
- 末节「自检」是成句定稿前的默扫清单。

## 单镜标杆

一条子句一个镜头、一个主运动，按情绪与叙事功能对号取用。

### 例 1 · 情绪逼近 · 紧张收紧

意图：情绪高点，镜头逐渐收紧到脸上，张力上升。

```
镜头语言：缓推，平视，特写，29° 短长焦人像性格、背景压近化成奶油般焦外，主体压右三分线。画框逼近她的脸，张力渐起。
```

为什么这么编：

运动 = 缓推，方向推 + 速度缓成对放最前；29° 是情绪特写主力档，结果语言"背景压近化焦外"比"85mm 浅景深"更可控；右三分线留出视线空间。角度平视不操纵，让情绪自己长。

### 例 2 · 静止建立 · 交代时空

意图：段落开头落地一个空间，什么都不动。

```
镜头语言：锁定机位，平视，全景建立镜头，84° 经典广角、环境延展到画框边缘、边到边全实，对称构图。房间纹丝不动，无漂移。
```

为什么这么编：

静止必须显式——锁定机位 + 无漂移，否则模型自己加漂移；84° 广角 + 深焦结果语言交代全貌；对称给秩序。建立镜头是叙事功能，光学另配——这里恰好用广角，但不是必然绑定。

### 例 3 · 环绕揭示 · 立体与身后空间

意图：环绕主体把背景转出来，揭示其身后。

```
镜头语言：平稳 180° 逆时针半环绕，平视，中景，47° 标准视角自然人眼透视，主体居中映衬负空间。背景旋转开来，揭出她身后那道门。
```

为什么这么编：

半环绕专司对话/揭示，不绕满；47° 中性不抢戏；居中 + 负空间给孤立感。方向逆时针 + 速度平稳成对。

### 例 4 · 强者登场 · 威严

意图：让主体显得强大、压得住场。

```
镜头语言：缓慢升降机位上升转入仰拍，七分身，84° 广角、前景身体逼人放大，居中对称。他自下方升入画框，肩膀填满画幅宽度，压住整个空间。
```

为什么这么编：

仰拍给威严；七分身 + 居中给气场；升降上升是单一主运动，"转入仰拍"是同一运动的角度落点不是第二个运动；广角结果语言"前景身体放大"放大压迫感。

### 例 5 · 弱者被困 · 渺小

意图：主体在空间里渺小、孤立、被压。

```
镜头语言：锁定机位俯拍，大远景，84° 广角、空间纵深一直可见到画框边缘、边到边全实，主体渺小地落在左下三分、上方留大片负空间。身影被空荡的大厅吞没。
```

为什么这么编：

俯拍 + 大远景 + 大负空间三件套叠出渺小；静止显式；广角深焦让"空"本身成为压迫的主角。

### 例 6 · 危机失序 · 不安

意图：世界"歪了"，紧张失衡。

```
镜头语言：肩扛手持荷兰角，中景，47° 标准视角，倾斜的引导线斜切画框。地平线倾倒，镜头随呼吸微幅起伏，不安持续发酵。
```

为什么这么编：

荷兰角 + 手持 + 倾斜引导线给失序；手持写成摄影师身体行为、随呼吸起伏，而非"数字抖动"；荷兰角偶尔一记，整段歪等于没歪。

### 例 7 · 心理张力 · 窥视压缩

意图：远远地看、压缩感造心理距离与紧张。

```
镜头语言：锁定机位，平视，中近景，8° 超长焦观察性格、机位远在二十米外、背景压平成柔色浆、虚化前景以深色虚影占据画面下部三成，主体压在压扁的人群前。一种监视般的静止，空间被压平贴上他。
```

为什么这么编：

8° 档强制前景遮挡——这是该档结果语言的一部分，不带前景遮挡的 8° 是半成品；长焦结果栈取了四句：机位远、背景压平、柔色浆、前景虚影；静止 + 压缩 = 被监视的紧张。

### 例 8 · 史诗规模 · 揭示大场面

意图：升起揭示宏大场面。

```
镜头语言：摇臂上升，宏大席卷的速度，由中景到大远景，107° 广角直线型、环境向画框每一条边铺开、直线保持笔直，低地平线。升起揭出绵延至山丘的大军，旌旗翻动。
```

为什么这么编：

摇臂上升揭示规模；景别从中到远在一个运动里完成，合法——同一运动的起止景别；107° 大尺度地理档配"直线笔直"防鱼眼；低地平线给史诗。

### 例 9 · 眩晕冲击 · 希区柯克

意图：天旋地转的心理冲击。

```
镜头语言：希区柯克变焦，平视，中近景，背景在静立的主体身后扭曲拉伸。脚下的地板仿佛塌陷而去。
```

为什么这么编：

希区柯克变焦是"推拉 + 变焦反向同时"的复合单一效果，按一个主运动算，整条只此一记；不再叠任何别的运动，也不需要额外光学声明——效果本身就是光学事件。

### 例 10 · 跟随代入 · 背后跟拍

意图：跟着主体背影走，悬念与代入。

```
镜头语言：斯坦尼康背后跟拍，平视，中全景，63° 自然视角、主体嵌在环境里，主体居中顺走廊引导线纵深而去。平滑滑行尾随他走向尽头的光。
```

为什么这么编：

背后跟拍 + 走廊引导线 + 平滑稳定是"我们跟着他"的标准三件套；63° 让环境保持在场、有纪实感，换 29° 就变成"盯着他背影的窥视"——光学档决定跟随的性格。

### 例 11 · 极致细节 · 关键物

意图：把注意力钉死在一个细节上。

```
镜头语言：锁定机位，平视，大特写，18° 细节档、刀锋般薄的焦平面、其余尽数化为虚影，颤抖的指尖填满画框。除了那一触，什么都不剩。
```

为什么这么编：

细节自成插入拍——Content-FOV 对齐律：别把细节混进宽镜头；静止显式；焦平面薄到只剩一点是结果语言，不写"微距镜头"空词。

### 例 12 · 浪漫梦境 · 柔焦漂移

意图：温柔、梦幻、不真实的美。

```
镜头语言：轻柔缓慢右横移，平视，中近景，29° 人像性格叠柔焦、奶油般焦外光斑游移，主体落左三分。如梦的漂移掠过她泛光的侧脸。
```

为什么这么编：

轻柔 + 缓 + 柔焦给梦境；横移整机移位而非摇镜原地转头，让光斑产生视差流动；方向右 + 速度轻柔缓慢成对。

## B 轨镜头行标杆

每镜起头的四件骨架为景别 + 机位 + 运动 + 衔接，动作接在冒号后，按事件顺序排不写秒数。

### 例 13 · 两镜情绪递进 · 静 → 推

```
镜头1〔全景，仰拍，锁定机位无漂移〕：他一动不动立在门口，逆光勾出轮廓边缘。
镜头2〔特写，平视，缓推，承接上镜静止的余味〕：画框从门框缓缓收紧到他的脸，神情冷硬下来，29° 人像性格背景化成焦外。
```

为什么这么编：

B 轨每镜四件骨架起头、动作接在冒号后；第一镜静止显式，第二镜单运动；光学变化发生在切镜处——镜1 广、镜2 人像档，符合"镜头性格只在切镜处改变"。B 轨不写秒数，按事件顺序排。

### 例 14 · 三镜建立 → 对话 → 情绪点

```
镜头1〔全景建立，平视，锁定机位〕：黄昏空荡的办公室，一盏台灯在角落亮着，84° 广角边到边全实。
镜头2〔双人镜头，平视，缓推〕：镜头朝伏在桌上的两人缓缓飘近，47° 标准视角，两人压在三分线上。
镜头3〔特写，平视，锁定机位〕：台词落下时定在她脸上，29° 人像性格、背景压近化开，主体压右三分线。
```

为什么这么编：

建立 → 双人 → 特写是叙事呼吸；景别由远到近、光学由广到长，情绪逐段收紧；每镜单运动、静止显式；对话正反打式内容天然走 B 轨。

### 例 15 · 动作段 · 跟拍 → 甩 → 急推

```
镜头1〔中全景，平视，快速跟拍，前景拉虚〕：跟着冲刺顺巷子追下去，脚步声砸在墙面弹回来。
镜头2〔中景，平视，快速右甩镜，无缝衔接追逐动线〕：运动模糊抹糊画框，猛地甩向前方跨出来的身影。
镜头3〔特写，平视，急推骤然〕：画框猛砸向他错愕的双眼。
```

为什么这么编：

动作段每镜速度都快但各只一个运动；甩和急推分到不同镜头不挤一句；镜2 的衔接"无缝衔接追逐动线"把三镜缝成一条；密集动作按事件顺序排、不写秒数。

## 对话戏骨架标杆

正反打全套：建立 → 双人 → 过肩正反打 → 情绪点特写，全程守同一轴侧。

### 例 16 · 双人对峙的标准机位序列

```
建立：镜头1〔全景双人镜头，平视，锁定机位〕：两人分踞对立的三分线，隔着桌子对峙，47° 标准视角。
A 说话：镜头2〔过肩中近景，平视，锁定机位〕：越过 B 的肩头看 A，A 压右三分线，29° 人像性格背景化软。
B 反应：镜头3〔过肩中近景，平视，锁定机位〕：越过 A 的肩头看 B，B 压左三分线，同一 29° 人像性格。
情绪升级：镜头4〔中近景，微仰，缓推〕：A 占上风时画框步步逼近他。
崩点：镜头5〔特写，平视，锁定机位〕：定在 B 动摇的脸上，18° 长焦、焦平面薄到只剩双眼。
```

为什么这么编：

对话戏默认骨架建立 → 双人 → 过肩正反打 → 情绪点特写；A 压右、B 压左的三分线分配全程不换——这是 180° 轴线纪律的画面显影，轴线管理归 blocking；强势方微仰 + 推近、弱势方平视，机位在讲权力；正反打两镜光学一致、都是 29°，符合多镜头镜头锁；过肩多用锁定机位，让表演说话。

## 密集动作戏复合运镜标杆

用法：专给连击、复合运镜、大幅变运镜的密集动作戏。每条一个动作节拍、一条运镜，主运动上挂一个由主体动作驱动的衔接运动，并显式写出衔接——随谁、缝到哪、捕捉什么动线。简单/安静镜头别用这一组，回单镜与 B 轨镜头行两组。

### 例 17 · 备战起势 · 推近 + 环绕半圈无缝衔接

意图：主体起身拔枪的瞬间，镜头逼近又把围堵的敌阵转出来，一气呵成不切。

```
镜头语言：快速推近至中景，随主角起身环绕半圈无缝衔接，低角度，84° 广角前景身体逼人放大，主体居中。镜头随他单膝起身贴上来、绕过半圈，把围拢的敌阵在他身后一并转进画框，压迫感拉满。
```

为什么这么编：

推与环绕由"起身"这同一主体动作串起、有先后因果——推的落点是环绕的起点，写进同一句是合法复合；四件套齐：景别 = 中景、机位 = 低角度、运动 = 快速推近 + 环绕半圈、衔接 = 随主角起身无缝衔接；广角结果语言放大压迫。

### 例 18 · 拉杆翻转 · 随伸臂急推 → 随重力翻转大旋转

意图：主体伸臂扣住手柄借惯性压下，重力翻转九十度，镜头随之天旋地转。

```
镜头语言：随她伸臂急推成手部特写、再随重力翻转猛地拉开成全景大旋转，平视转翻滚，84° 广角手持。指尖堪堪扣住手柄向下压到底的同一瞬，侧墙翻成新地面，碎片与敌机被新重力齐齐甩向那面墙。
```

为什么这么编：

最典型的动作驱动复合——"随……成……、再随……"句式就是合法性判据本身；景别在一个运动链里从手部特写变到全景，运动完成景别变化、合法；机位角度跟着世界翻，平视转翻滚；两运动前一落点是后一起点。

### 例 19 · 甩动跟随转身 · 无缝切至重击特写

意图：背后敌人扑来，主体猛地转身用枪托重击，镜头甩着跟住转身再无缝切到重击点。

```
镜头语言：镜头甩动跟随主角转身，中景捕捉动作，无缝切至枪托重击特写，平视手持微随，47° 标准视角。随转身的甩势扫过来，落在钢制枪托砸中面门的那一击上，冲击力让对方身形一顿。
```

为什么这么编：

甩与切由"转身—重击"串起；镜间用"无缝切至X特写"缝住不生切，即镜间缝合型衔接；重击的"身形一顿"是物理反馈，给运动一个终点，防开放式运动卡死。

### 例 20 · 沿地连切 · 跟拍随奔跑完整捕捉切割动线

意图：主体落地全速奔跑、一台台连切敌机，镜头贴身跟住整条切割动线不跳切。

```
镜头语言：低角度跟拍长镜，随主角奔跑流畅平移、贴身捕捉切割动线无跳切，84° 广角环境延展到画框边缘。脚步不停，切割器橙红弧光拖着光痕划过冷蓝舱内，斜切第一台、反手贯穿第二台、迎面把第三台劈成两半，三道切口连成一条凌厉的线。
```

为什么这么编：

一条奔 → 切一 → 贯二 → 劈三的因果顺承动作链配一条贴身跟拍，用"完整捕捉动线、无跳切"的动线捕捉型衔接把连击钉死在一镜里；连击是链不是并列，因果词咬住；橙红弧光划过冷蓝的动态光效是 lighting 的每镜层，这里作为空间描述带一笔不展开。

## 好坏对照 · 同一意图，写废 vs 写对

每组一个意图，反例在前、正例在后。

### 例 21 · 情绪逼近

反例："镜头很有电影感地慢慢靠近，让人感觉很紧张，还带点环绕。"——无精确方向/速度、形容词驱动、又推又绕叠运动。

正例：镜头语言：缓推，平视，特写，29° 人像性格背景化成焦外，主体压右三分线。画框逼近她的脸，张力渐起。

### 例 22 · 交代空间

反例："用一个大气的镜头把整个场景拍出来。"——"大气"是形容词，无景别/角度/光学/运动。

正例：镜头语言：锁定机位，平视，全景建立镜头，84° 广角边到边全实，对称构图。房间纹丝不动，无漂移。

### 例 23 · 光学空喊

反例："超广角镜头拍这个仓库。"——元数据式空喊，无结果语言，模型从内容反推、大概率滑回中焦。

正例：镜头语言：锁定机位，平视，全景，107° 广角直线型、近前景逼人放大、环境向画框每一条边铺开、直线保持笔直。仓库的钢架纵深一览无余。

### 例 24 · 叠运动 · 分清无动机叠加与动作驱动复合

反例：无主体动机的纯叠加——镜头语言：边推边环绕边上俯仰摇，快速。三运动并列、互不相关、没有主体动作串起，模型取平均退化成飘或静止。

正例：无因果的并列拆成两镜——镜头1〔中近景，平视，缓推〕……镜头2〔中景，平视，平稳顺时针环绕〕……

正例：动作驱动的复合不拆、写进同一句——镜头语言：随她伸臂急推成手部特写、再随重力翻转猛地拉开成全景大旋转，84° 广角手持。判据：能不能用"随……成……、再随……"把两运动用一个主体动作串起来。能，就是合法复合；不能，就是该拆的叠加。

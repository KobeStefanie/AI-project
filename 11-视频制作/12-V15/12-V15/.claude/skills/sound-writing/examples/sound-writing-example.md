# 标杆 · 声音四要素的两档写法

## 示例定位

- 声音写作标杆两档各一，附「为什么这么编」注解。
- 只节选成品条九段结构中与声音相关的两段：【全局设定｜恒定层】里的声音基调句与【分镜正文】；其余段落见 motion-compile 的完整标杆。
- 本标杆自洽，不要求与其他 skill 同一故事。

## 标杆 1 · A 轨对白情绪条 · 克制档

背景设定：ep01 场 04，条 2，约 12 秒。深夜厨房，女儿摊牌，母亲沉默。

声线锁，已登记 reference-index，此处示意：

```
char-001 林晚声线锁：五十代女性，川渝口音——平翘舌不分、句尾轻微上扬。中低音区，音色偏干；语速慢，字与字之间常有停顿；情绪底色是疲惫的平静，被逼急时音量不升反降。
```

恒定层声音基调句，进 F1 段3：

```
声音基调：深夜老式厨房的冰箱低鸣与挂钟秒针声，低；无任何背景音乐；同期声感，干净对白优先。
```

分镜正文，进 F1 段4，声音已就地织入：

```
[0-4秒] 起幅：母亲背对镜头站在水槽前，水龙头滴水，滴答声近处、规律。女儿的椅子在画面右侧被拖开，木椅腿蹭过地砖的刺耳拖响，压过滴水声一瞬。母亲的肩膀几不可察地绷紧。
[4-9秒] 女儿说："妈，我都看见了。"语气：平静，语速慢，音量低，每个字都放得很稳。声线：〔此处从略：逐字贴 char-002 声线锁原文〕。母亲没有回头，手里的碗沿磕在水槽壁上，一记瓷器的轻磕脆响，近处。
[9-12秒] 母亲关掉水龙头。滴水声停，厨房里只剩冰箱低鸣，一拍静默，两秒。她说："吃饭了。"语气：极轻，近乎气声，句尾没有起伏。声线：〔此处从略：逐字贴 char-001 声线锁原文〕。落幅：两人都没动。
```

为什么这么编：

- 密度选克制档：全条只有两句对白、三记音效——拖椅、磕碗、关水——和一层底噪；安静戏到量即停，声音留白就是这场戏的张力。
- 每记音效三绑定齐全：拖椅绑动作"椅子被拖开"、绑材质"木椅腿蹭地砖"、绑强度关系"压过滴水声一瞬"——它是这场戏的"打断"节拍，所以给了相对响度让它跳出来。
- 滴水声是设计过的：先用规律的滴答建立、再借关水龙头移除——声音的消失制造了静默事件，"一拍静默，两秒"是写出来的，不是漏写。
- 两句台词都 ≤20 词、分散在不同时间段、各卡各的动作节拍；说话人在该段画内稳定——口型三前提成立才敢写对白。
- 语气逐句变——女儿"放得很稳"、母亲"近乎气声"——声线锁逐字引用不改写：语气跟句走、声线跟人走。
- "吃饭了"用极轻语气配平直句尾，是"最吓人的话说得最轻"的用法：情绪不写进语气标签，写进音量与起伏的物理参数。
- 恒定层写死"无任何背景音乐"，正文不再重复——不留空，防模型自作主张铺乐把静默填掉。

## 标杆 2 · B 轨动作条 · 分层并进档

背景设定：ep02 场 07，条 3，约 14 秒。废弃仓库，男主破门突入，与埋伏者短兵相接。四镜。

恒定层声音基调句，进 F1 段3：

```
声音基调：空旷仓库的风声底，低，带回响；无任何背景音乐；同期声感，动作音效分层优先。
```

分镜正文，进 F1 段4，声音已就地织入：

```
镜头1 中景低机位，随突入急推：他左肩撞开木门，门板干裂的木头爆响，近处；碎屑砸地的细碎散落声紧随其后；他的靴底碾过碎片，玻璃碴的挤压脆响，脚下。
镜头2 全景横移：画外左侧一根钢管破风甩来，破风声由远及近；他矮身，钢管砸在身后立柱上，金属闷撞炸开，盖过全场一瞬，回响在仓库里拖出尾音。
镜头3 近景快速跟拍：两人短兵相接，布料撕裂的纤维声、皮靴蹬地的摩擦声、拳面击中肋侧的闷响，各卡各的接触瞬间，三层同时在，闷响最重。
镜头4 中景，动作骤停定住：埋伏者跪地，兵器脱手，金属在地面弹跳两记后停，清脆，渐远。全场只剩两人粗重的呼吸和风声底，两秒。落幅：他持械低垂，胸口起伏。
```

为什么这么编：

- 密度选分层并进档：每记可见接触各挂一条音效、卡各自节拍，镜头3 三层同时在——但底噪自始至终只有风声底一层，分层加的是动作层，不是叠底噪。
- 每层写了相对响度：钢管砸柱"盖过全场一瞬"是本条唯一的顶级声音事件；镜头3 写明"闷响最重"——不写相对关系，模型会抹平层次。
- 巨物先声夺人的变体用在镜头2：钢管先以"破风声由远及近"预告，再有接触爆点——声音比画面早半拍，是袭击感的来源。
- 兵器落地"弹跳两记后停"是数量逐帧写的声音版：不写记数，金属弹跳声会无限延续。
- 结尾用负声音事件收束：打斗声全部退场，"只剩粗重的呼吸和风声底，两秒"——动作条也要声音落地，不能停在最响处硬切。
- 全条无台词：动作密集段不塞对白，口型与动作抢注意力两败俱伤；B 轨镜头N不写秒数，声音只卡"接触瞬间"这类事件锚点。

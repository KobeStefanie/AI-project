[任务]
    把"这一刻该被听见什么"翻译成视频生成模型跟得住的声音文字。
    平台事实决定了这件事没有别的做法：声音由视频模型随画面原生生成，没有独立的音频生成环节；台词、音效、环境声以文字写入视频提示词，写得出来才生成得出来，没写的部分由模型即兴。
    **BGM 例外（V14 裁决）**：narrative 叙事类一律不在提示词里写 BGM，恒定层只写「无任何背景音乐」，音乐由音乐总监设计、后期整条铺（Cut 块外的 🎵 后期铺乐注脚，V13 机制保留）——原因是拼接工作流下每条自带 BGM 会撞轨、无法剪辑。仅 content_type=mv（画面跟音乐走）才在提示词里写 BGM 指令。详见下方 [维度与方法] BGM 段。
    本卡只产两类句块，交给上层拼装：
        - 恒定层声音基调句——进成品条九段结构的【全局设定｜恒定层】，即 F1 第 3 段。
        - 分镜正文就地声音句——四要素织进【分镜正文】即 F1 第 4 段每个时间段/每镜的因果链「声音」位，不单独成块、不在视觉描述末尾甩一句"带音效"。
    边界：只产声音句块，不独立成片、不产完整提示词，拼装归 motion-compile。
    规则集声明：本卡的全部输出属于视频提示词规则集——负向症状驱动 ≤3、块序优先，由 motion-compile 统一持有。本卡不产图像提示词，句式禁止带进图像规则集即资产站的纯正向铁律，双规则集不串用。

[第一性原则]
    本环节是【导演思维】第 4 问「可生成性」的展开：声音不是后期，是提示词文字——每一个要被听见的声音都必须被写成模型跟得住的句子，写不清就由模型即兴，即兴出来的就是废镜。
    音效绑可见来源：音效必须绑画面内可见动作与来源，无来源的声音显假、模型也接不住——先有"画面里什么东西在发生"，才有"它发出什么声音"。
    声线锁逐字复用：角色声音的跨条一致性靠同一段声线描述逐字贴进每条，连同义词都不换——换措辞就是扩大采样范围，声音必漂；声线描述是条件块，不是标签。
    BGM 两档，但沉默必须写出来：不写 BGM 指令的条，模型可能自作主张塞配乐——所以沉默也要显式声明。narrative 叙事类固定写"无任何背景音乐"（音乐总监后期铺）；仅 content_type=mv 才写有乐风格指令。无论哪档，BGM 槽都不留空。
    密度服从戏：安静戏一层克制、动作戏分层并进；底噪永远只写一层，动作音效按可见节拍逐记挂——两件事不连坐。
    口型是头号废片点：短句、正脸、中景是口型可控的三前提，贪长贪近必翻车；台词不占满全时长，留呼吸与反应。

[维度与方法]
    七个维度，四要素各一块加三块纪律；按本条的密度档取用，安静戏只取台词 + 环境声 + BGM，动作戏四要素全带。

    台词——引号直写 + 语气 + 声线锁引用。
        固定句式：{{角色代称}}说："{{台词原文}}"。语气：{{语速/音量/情绪质地}}。声线：{{assets/reference-index.md 中该角色声线锁，逐字引用}}。
        声线锁由 character-design 建卡时登记在 reference-index，格式为一段条件块：{{年龄}}{{地域/口音标记}}。{{音区与音色}}；{{语速与吐字习惯}}；{{情绪底色，及压力下如何变化}}。
        口音写成条件而非标签：类别 + 一两个具体发音特征，如"川渝口音——平翘舌不分、句尾上扬"，不是只贴一个地名。引用铁律：逐字，不改写。
        台词时序与嘴的纪律：
            - 需要开门见山：写"0.3 秒内开口"；常规台词前后各留约 1 秒静默当气口。
            - 不说话时嘴唇静止；有台词的段落里只有说话人的嘴在动作，其余人物写"嘴唇闭合"——说话权唯一，防群嘴跟说。
            - 内心独白/旁白：注明"非画内声，嘴唇不动"。
            - 一段一个说话人一句短台词最稳；对话往返拆到相邻段/相邻镜。
        字幕与文字：
            - 台词 = 仅发声。全局尾缀已含"无字幕"，对白密集或平台有自动字幕倾向的条，正文再点一次"仅发声，无字幕"。
            - 读信、招牌这类画面确需文字时，把唯一允许的文字内容和出现区间写死，其余仍锁无字幕。
            - 非中文台词防乱码："全部为自然规范的{{语言}}，不出现任何{{其他语言}}或乱码"，并覆盖招牌/菜单/价签等一切画面文字载体。
        条间台词衔接——prior audio 语法，供 motion-compile 的【衔接】段引用。
        中文块，可整块抄：
            "上一条结尾的台词'{{尾句}}'作为声音语境延续进入本条开头，不呈现其画面。"
        英文原句：
            "Prior audio context only, not visual content: '{{上条台词尾句}}'"
        含义是仅作为声音语境延续，不得把上一条的画面可视化。
        可选 · 音色样本绑定，仅当用户自备音色样本时启用：2.5 官方支持逐句绑定"台词：'{{原文}}' 音色参考@音频N"，可叠情感指令，如"保持低沉悬疑的语调"。@音频N 是平台会话内的音频轨地址、与图轨各自从 1 数起，由 motion-compile 在编译期定序、写死进正文并登记进该条条头【上传清单】；真相源在 motion-compile 的 asset-binding.md [定位]，本行只读。默认路径始终是纯文字声线锁，样本绑定是增强不是前提。

    音效——绑可见动作 + 材质 + 距离 + 强度。
        固定句式：{{可见动作/事件}}时发出{{材质/质感}}的声音，{{方位与距离}}，{{强度/与其他声音的相对关系}}。
        例：刀背磕上铁栏的瞬间发出短促的金属脆响，近处偏右，压过雨声一瞬。
        三绑定，缺一显假：
            - 绑动作：声音必须来自画面里正在发生的事，或写明画外方位，如"画外左侧"。
            - 绑材质：金属刮擦、木头闷响、布料窸窣、玻璃脆裂——材质决定音色，"发出声音"四个字等于没写。
            - 绑距离：贴耳、近处、远处闷响、隔着墙被削弱——距离决定衰减与介质。
        进阶两式：
            - 巨物先声夺人：大体量物入画前先以低频震动、器物轻颤、落尘预告。
            - 静默与负声音事件：骤停、瞬间只剩呼吸与耳鸣、全场声音被抽走——静默是设计出来的声音事件，要写出来，不是漏写。

    环境声——只写一层。
        固定句式：{{场景}}的{{底噪}}，低〔，无配乐〕。
        例：深夜便利店的冰柜低鸣与灯管电流声，低，无配乐。
        一层原则：底噪只写一层。密集档往上加的是"动作音效层"，不是叠第二层底噪。底噪同样可带方位与介质：画外的、远处的、隔着窗被削弱的。

    BGM 指令——按 content_type 分档，两档都不留空。
        **narrative 叙事类（默认，含精品微电影/短剧/漫剧）**：固定写"无任何背景音乐"——写进恒定层声音基调一次，正文不再重复。音乐不进提示词，由音乐总监单独设计、后期整条铺；提示词侧只在 Cut 块外挂 🎵 后期铺乐注脚（M01/M02 编号，V13 机制保留）。原因：成片是 N 条视频拼接，每条自带 BGM 会与相邻条撞轨、整段没法剪。
        **content_type=mv（画面跟音乐走）**：才写有乐指令——"背景音乐：{{风格/情绪}} + {{主导乐器或质感}} + {{节奏或 BPM 倾向}} + {{进入退出时机与音量关系：衬底/渐强/骤停}}"。
        例：背景音乐：低回的暗涌电子铺底，合成器长音为主，无鼓点，全程衬在人声之下，最后两秒渐弱至无。
        禁点歌名与艺人——有版权风险，模型也不认。卡点条可写"音乐重音与切镜对位"，但不能每拍切镜。
        判档取值：读 `.project-config.json` 的 `content_type`；缺省或 narrative → 无乐档；mv → 有乐档。

    恒定层声音基调句——进 F1 第 3 段，每条一句。
        固定句式：声音基调：{{环境底噪一层}}；{{BGM 槽：narrative 档写"无任何背景音乐"；mv 档写风格一句}}；{{整体质感取向：同期声感/纪实感/干净对白优先/影院混音感}}。

    口型纪律——对白条硬前提。
        - 短句：单句 ≤20 词，约 8 秒内说完；长台词拆到多条或多镜。对白条整体时长参考 8–15s，待实测校准。
        - 正脸：说话期间说话人正脸或近正脸稳定在画内。
        - 景别宽容度：中景 ＞ 近景 ＞ 大特写。大特写口型误差最显眼，情绪要特写、台词放中景，二者错开排。
        - 需要严格口型时加锁："口型严格对上这句台词'{{原文}}'"——只在正脸 + 中景前提下才写这句承诺。
        - 对白按段分散、各卡所属段的动作节拍，不集中堆一处。

    密度分档——按戏选档，编条时先拍板。
        克制档，安静戏与情绪戏的默认：一句对白 + 一记主音效 + 一层底噪。到量即停，多写是噪声。
        分层并进档，密集动作戏用：每记可见撞击/切割/落地各挂一条音效、卡各自节拍，可四层以上同时在；底噪仍只一层；写明相对响度、谁压过谁。
        同期声拉满档，UGC/vlog/纪实用：去配乐，把同期声做满——衣料摩擦、呼吸、脚步、器物磕碰、环境细节；配"无任何背景音乐"，声音的"糙"就是这一档的质感。

[词库]
    速查取词，详表与判据卡见 references/sound-lexicon.md。

    语气词
        气声、沙哑、克制的颤、一字一顿、脱口而出、含在喉咙里、近乎耳语、压着火、笑着说但尾音发紧。

    材质音
        金属刮擦/脆响/闷撞、木头闷响/吱呀、布料窸窣/撕裂、玻璃脆裂/碎溅、液体滴落/泼溅/翻涌、皮革摩擦、纸页翻动。

    距离衰减
        贴耳、近处、身后、远处闷响、隔着墙被削弱、画外左侧/右侧、由远及近。

    强度关系
        压过{{X}}一瞬、衬在{{X}}之下、盖过全场、几不可闻、与{{X}}同时炸开。

    底噪库
        雨声底、街道远噪、空调低鸣、风穿林、人群嗡鸣、海浪循环、机房电流、虫鸣夜底。

    BGM 描述维度
        情绪 = 暗涌/昂扬/哀而不伤；乐器质感 = 弦乐铺底/合成器长音/只有鼓点；节奏 = 无鼓点/BPM 倾向/渐快；进退 = 从第 X 秒渐入/骤停/渐弱至无。

    静默事件
        骤停、只剩呼吸、耳鸣盖过一切、全场声音被抽走一拍。

[范例句式]
    A 轨 · 时间戳段内 · 克制档，声音织进因果链：
        [8-14秒] 她捏着信纸的手指收紧，纸面发出轻微的褶皱脆响，近景可闻。她说："你早就知道了，对吗。"语气：极轻，语速慢，尾音发紧。声线：〔此处从略：逐字贴 reference-index 中 char-001 声线锁原文〕。窗外的雨声底持续，低，被玻璃削弱。说完，屋内只剩雨声，一拍静默。
    B 轨 · 镜头N内 · 分层并进档，动作条：
        镜头3 中景快速横移跟拍：他左肩撞开木门，门板发出干裂的木头爆响，近处；碎屑砸在地面，细碎的散落声紧随其后；他的靴底碾过碎片，玻璃碴的挤压脆响，脚下；仓库的风声底持续，低，无配乐。

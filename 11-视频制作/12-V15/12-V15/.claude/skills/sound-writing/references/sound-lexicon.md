[定位]
    声音词库与判据卡详表，sound-writing 的取词底册。供编条时按需取用：只查本条需要的几行拼进句式，不整表抄进提示词。
    本卡每节按「怎么认 / 认错长什么样 / 典型例子」给判据。

[判据卡 · 语气与声线词]
    怎么认：
        语气 = 本句怎么说，随情绪逐句变；声线 = 这个人永远怎么发声，逐字引用 reference-index 声线锁、永不变。两者分开写，语气跟句走、声线跟人走。
        语气三件套：语速 + 音量 + 情绪质地，至少给两件。
    认错长什么样：
        - 把声线锁改写着用，如"低沉沙哑"改成"嗓音低哑"——采样范围扩大，声音换人。
        - 语气只写"悲伤地说"这类情绪标签——模型只能给通用悲伤腔。
        - 语气与画面表演打架：写"嘶吼"、画面却是抿嘴克制。
    典型例子：
        正例：语气：极轻，几乎是气声，每个字之间有停顿，尾音发紧。
        反例：语气：非常悲伤。
    语气词表，按强度递增：
        近乎耳语、气声、含在喉咙里、一字一顿、平直无起伏、刻意放缓、克制的颤、压着火、笑着说但尾音发紧、脱口而出、陡然拔高、沙哑地吼、吼到破音。

[判据卡 · 材质音效]
    怎么认：
        先认画面里发声的东西是什么材质，再从对应行取词；动作类型——碰/砸/裂/拖——决定选行内哪个词。
    认错长什么样：
        - 只写"发出声音/一声巨响"——无音色，模型即兴。
        - 材质对不上，如木门写成金属声。
        - 一句里堆三种材质音却不说哪个来自哪个动作。
    典型例子：
        正例：门板发出干裂的木头爆响，碎屑散落声紧随其后。
        反例：门被撞开，发出巨大的声音。
    材质 × 动作对照：
        金属：轻碰 = 脆响、重击 = 闷撞、拖动 = 刮擦长音、断裂 = 铮鸣、弹壳落地 = 清脆弹跳。
        木：敲 = 空心笃响、撞裂 = 干裂爆响、承重 = 吱呀呻吟、断 = 脆折。
        布料：走动 = 窸窣、撕 = 纤维撕裂声、甩动 = 闷的鼓风声、湿布 = 沉重的拍打。
        玻璃：裂 = 细密的迸裂纹路声、碎 = 脆裂碎溅、踩 = 挤压碎响。
        液体：滴 = 滴答、泼 = 泼溅、涌 = 翻涌闷响、沸 = 细密气泡声。
        皮革：握紧 = 紧绷的摩擦声、落座 = 沉闷的吱响。
        纸：翻页 = 干燥的沙沙、攥紧 = 褶皱脆响、撕 = 利落的撕裂。
        人体：脚步 = 材质随地面、呼吸 = 粗重或屏住后骤然吐出、吞咽、关节爆响、布料下的心跳感 = 写"胸腔起伏"配静默。

[判据卡 · 距离与介质]
    怎么认：
        每记音效给一个距离或方位词；声源不在画内时必写"画外 + 方位"。墙、窗、水这类隔断要写成介质，如"被玻璃削弱"、"闷在水下"。
    认错长什么样：
        - 全部音效都像贴着耳朵响，无距离层次、混成一团。
        - 画外声不写方位，模型把声源画进画面。
    典型例子：
        正例：画外右侧传来铁门拖动的刮擦声，远，被走廊拉出回响。
        反例：传来铁门的声音。
    词表：
        贴耳、近处、脚下、身后、头顶掠过、远处闷响、由远及近、画外左侧/右侧、隔着墙被削弱、被玻璃滤过、水下的闷、空旷回响、贴地滚来。

[判据卡 · 强度与相对响度]
    怎么认：
        多层声音同时在时，写"谁压过谁"的相对关系，而不是各自绝对音量；一条里最多一个"盖过全场"级事件。
    认错长什么样：
        每层都写"巨大/震耳欲聋"——模型抹平成一样响，层次消失。
    典型例子：
        正例：爆响盖过全场一瞬，随后雨声底重新浮上来。
        反例：爆炸声巨大，雨声也很大，脚步声也很响。
    词表：
        几不可闻、衬在人声之下、与呼吸同级、压过{{X}}一瞬、盖过全场、骤然抽空后回落、与{{X}}同时炸开。

[环境底噪库 · 按场景类型，一条只取一层]
    城市街道：街道远噪，车流与人声嗡鸣糊成一片，低。
    室内日常：冰箱/空调低鸣与灯管电流声，低。
    雨戏：雨声底打在{{材质}}上，低〔，被窗削弱〕。
    自然外景：风穿林/虫鸣夜底/海浪循环，低。
    人群场：人群嗡鸣，听不清词句，低。
    工业/机舱：机房电流与低频轰鸣，低。
    静场：近乎无声，只有{{唯一残留声}}，低。
    认错长什么样：
        底噪写两层以上，如雨声 + 人群 + 车流并列——底噪只准一层，其余要么升格为音效绑事件，要么删。

[判据卡 · BGM 风格描述]
    怎么认：
        四维各取一笔拼成一句指令；宁少勿滥。默认 BGM 后期铺，条里只在收尾约束写「无任何背景音乐」；画面要跟音乐走的片型才写下面这句。
        情绪：暗涌、昂扬、哀而不伤、焦灼、圣洁、荒诞轻快。
        乐器质感：弦乐铺底、合成器长音、只有鼓点、钢琴单音、失真吉他墙、八音盒质感。
        节奏：无鼓点、慢速脉冲、渐快、卡点重拍。
        进退：从第 X 秒渐入、全程衬底、情绪峰值推高、骤停、渐弱至无。
    认错长什么样：
        点歌名或艺人名——有版权风险且模型不认；写"史诗感配乐"这类空形容；BGM 与"无任何背景音乐"同条并存。
    典型例子：
        正例：背景音乐：焦灼的慢速脉冲电子，无旋律，全程衬底，最后一秒骤停。
        反例：配上类似汉斯·季默的史诗音乐。

[判据卡 · 静默与负声音事件]
    怎么认：
        静默当事件写，三件齐上——触发点，如枪响之后、门合上的瞬间；残留声，如只剩呼吸、耳鸣、一层底噪；时长感，如一拍、两秒。
    认错长什么样：
        想要静默但什么都不写——模型会自行填声；或写"没有声音"这种否定——应改写成"只剩下"句式。
    典型例子：
        正例：门合上的瞬间，全场声音被抽走一拍，只剩她自己的呼吸，两秒。
        反例：这时候没有任何声音。

[声音症状 → 改写对照 · 供 retake 反查]
    按症状查错句与改写，改写栏可整句抄进提示词：

| 症状 | 错句 | 改写 |
|---|---|---|
| 音效显假无来源 | "响起一声枪响" | "他扣下扳机的同时枪口炸出短促爆响，近处，盖过全场一瞬" |
| BGM 乱入 | 收尾约束漏了 | 收尾约束补"无任何背景音乐" |
| 声音糊成一团 | 每层都"巨响" | 写相对响度、谁压过谁 |
| 口型对不上 | 长句 + 大特写 | 拆短句 ≤20 词、退到中景、正脸稳定，再加口型锁 |
| 群嘴跟说 | 只写说话人台词 | 补"只有{{X}}的嘴在动作，其余人物嘴唇闭合" |
| 静默被填满 | 没写静默 | 按 [判据卡 · 静默与负声音事件] 把静默写成事件 |
| 声音换人 | 声线锁被改写引用，或一条里贴了两版 | 回 reference-index 逐字重贴，总述段人物行后一次 |

# 标杆 · 同一场戏两镜的灯光与物理写法

## 示例定位

- 标杆：同一场戏的两镜灯光与物理写法——镜头 1 是「光即主角」的静场，整块贴光锁；镜头 2 是动作节拍，动态光效 + 物理反馈。本标杆自洽、与任何项目无关。
- 场景设定：夜，雨后修车厂。全片风格基准示意：冷峻工业蓝灰为底、约八成；强调色为修车厂卷帘门上方一盏钠灯的橙，占画面一成上下、框内真实来源；低调硬光为主。人物：讨债者 @char-021 立于卷帘门外，修理工 @char-022 在门内背光处；进【分镜正文】的文字一律用特征代称——门外的讨债者 / 门内的修理工，@ 只在【参考资产绑定】段出现一次。
- 每段产物后附「为什么这么编」注解。

## 恒定层对账 · 动笔前先做，不产出句子

检查项：本场灯光子句的冷暖走向——蓝灰为底、钠灯橙作唯一暖点——与【全局设定】携带的通用基准段一致；两镜同校这一个基准；镜内不得冒出无来源的第三种光色。

为什么这么编：

色锚一致是恒定层的活，本卡只对齐不另定——对账放在动笔前，写完再检查就晚了；"钠灯橙"正是强调色即光源的用法：强调色不靠调色语言，靠框内真实发光体。

## 镜头 1 · 光即主角的静场 · 对峙，剪影开场

成品段，嵌【分镜正文】镜头1：

```
镜头1 大远景转中景：卷帘门内一盏工作灯是画面最亮处，门外的讨债者立在门外，处在机位与门内亮光之间——机位在他的阴影侧，他近乎剪影，只有湿地面反上来的冷蓝环境反弹光和钠灯从上方勾出的一线橙色轮廓光揭示轮廓；脸保持在深阴影里。整镜为门内亮光曝光，不为脸曝光，允许脸压进死黑，由剪影与轮廓扛住画面。无正面主光，无平光曝光，无美颜补光。雨后地面的水洼把门内灯光拉成一条颤动的亮带。
```

为什么这么编：

- 逆光锁五句全数在场且整块贴：主体在机位与亮背景之间/机位在阴影侧/脸留深影/白名单式许可即环境反弹光 + 轮廓光/内联禁令收口；没有拆句挑用——拆了就不成锁。
- 曝光升级锁直接预置——"为门内亮光曝光……允许脸压进死黑"：对峙剪影是全片情绪重镜，与其等出平了返修，不如首版就把曝光立场写死。
- 光向五要素可逐项对出：光源 = 门内工作灯 + 上方钠灯；方向 = 正后 + 上方；机位 = 阴影侧；主体暗侧 = 面向机位一侧；曝光立场 = 为背光曝光。
- 强调色橙只出现在轮廓一线——比例贴合基准的一成上下，且来源可见：钠灯。
- 末句水洼亮带是"光影随物理"的一笔：湿面才有高光，顺手把雨后的物理状态转成了光的资产。

质检点：若生成结果仍发平——不加程度词、不重跑原词，贴曝光升级锁三句全文，见 references/light-lock-blocks.md。

## 镜头 2 · 动作节拍的动态光 · 修理工拉闸，随后的短打

成品段，嵌【分镜正文】镜头2–3：

```
镜头2 门内的修理工一把拉下电闸——门内工作灯熄灭，画面骤沉：此后只余头顶钠灯的橙和湿地反上来的冷蓝，两人沉入低调。灯丝余温在灯罩里暗下去的一瞬，讨债者已经跨进门内。
镜头3 近身短打：讨债者一步抢进，落地的前脚沉进积水、水花向前溅开，霓虹倒影在水洼里碎成一圈晃动的橙；他借前冲惯性用肩把对方撞上卷帘门，铁门整面震颤，门上挂灯的光斑随之在两人身上剧烈摇晃；修理工后背撞门的同一刻抓过工作台上的扳手，腕子先随扳手分量向下一沉才抡起，橙色轮廓光沿扳手划出一道弧。头发与衣摆比躯干慢半拍。没有飘浮的身体，没有无摩擦的脚。
```

为什么这么编：

- 变光必须是画面内事件：全场从"工作灯 + 钠灯"切到"仅钠灯"，动机是拉闸这个可见动作——写在镜头2 内，此后各镜沿用变化后的光世界，符合场内光世界锁。
- 每镜层动态光效是必保项：镜头3 的三笔全部随动作走——水洼倒影被踩碎、门震导致挂灯光斑摇晃、扳手弧线带轮廓光；密集动作戏每个动作节拍配一笔动态光，而不是开头一句静态布光了事。
- 物理反馈句按落位规则给在控制点上：踩水即触地、撞门即碰撞与震颤、扳手腕角先随质量下沉才抡起即武器有重量；每段 1–3 笔，未铺满。
- 布料发丝延迟一笔"慢半拍"压 CG 感；段尾内联总锁两句，贴着动作放、不单列负面块——这是内联负向政策，不占该条【针对性负向】段的症状名额。
- 动态光与物理常是同一句话：水洼倒影碎、光斑摇晃两笔既是物理反馈也是光效——一句顶两句，词数省下来给动作。

质检点：若生成动作发飘——脚下打滑、扳手无分量：按 references/physics-lock.md 对应分类补正向物理句；若两镜光色不接——镜头3 又冒出白光：回恒定层对账，点名唯一光源清单。

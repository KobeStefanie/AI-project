# 空间锁语句母版

## 使用说明

{{}} 内为填空位；〔〕内为按需项，按镜头需要增删；人物一律用可视特征代称，纯人名仅在已绑定且同框无混淆时用，判据见 motion-compile 的 asset-binding.md [人名与代称 · 六条铁律]；@编号只出现在【参考资产绑定】段。

## 首帧占位锁母版 · 默认挂在站位块之后

```
完整五句版——多人/复杂场：
    第一帧画面里已包含{{全部在场者代称列举}}、各就各位。
    无空场开场。
    无延迟入场。
    开场没有任何缺少必要主体的画面。
    空间关系在第一帧即清晰可读。
精简三句版——单人/紧凑条：
    第一帧画面里已包含{{在场者}}、位于{{地标绑定位置}}。
    无空场开场，无延迟入场。
    空间关系在第一帧即清晰可读。
入画例外版——显式设计人物入场时替换上面两版：
    开场画面为{{空场/仅有某人}}：{{地标与空间可读性描述}}。
    第{{N}}秒，{{人物}}自{{画框左/右/背景纵深}}入画，沿{{路径地标}}走到{{终点地标}}停住。
```

## 站位块母版 · 每个重要在场者一组，按七要素

```
{{人物代称}}位于{{画框方位 + 层}}，{{世界位置：正站在/坐在/靠在 + 地标}}，{{接触级或贴近级距离语言}}〔按需项〕；
躯干朝向{{对象/方向}}，目光锁定{{对象}}；
〔按需项 · 走位〕从{{起点地标}}沿{{路径}}走向{{终点地标}}，到位后{{停住姿态}}；
〔按需项 · 持物〕{{左手/右手}}{{持物与姿势：拿着……/扣在……上/空着}}。

群像行——超过 15 人或无名群体，整体一行：
    {{方位 + 层}}挤着{{群体形态描述：贴在台口的身体、前景晃动的手臂}}，不逐一可辨。
```

## 朝向视线锁母版 · 关系镜头必用，可并入站位块

```
{{人物A}}躯干朝向{{X}}，目光锁定{{Y}}，视线不移开；
{{人物B}}{{背对镜头/侧脸朝画框左/正对镜头}}，目光{{锁定A/越过镜头落在……/先瞥向……再收回}}。
〔按需项 · 对话嘴部纪律〕只有{{说话者}}的嘴为引号内台词而动；其余人静默倾听、嘴唇静止；无画外人声。
```

## 轴线与越轴声明母版

```
守轴声明，写进空间地图块引用之后或镜头行内：
    镜头始终在{{轴侧描述：账台一侧/两人视线连线的门口一侧}}，不越过{{A}}与{{B}}的视线连线；{{A}}恒居画框{{右}}，{{B}}恒居画框{{左}}。
越轴声明——四选一，越轴那一镜显式写；措辞与场头块「排布变化」里的同一项一致，不另写一套：
    运动越轴：镜头自{{近侧}}起幅，随{{人物动作}}平稳弧形移动、在画面内绕过{{两人连线}}到达另一侧，全程两人保持可见。
    骑轴缓冲：本镜机位正压在{{A}}与{{B}}的视线连线上，{{主体}}躯干正对镜头，无左右侧别。
    移动重立轴：{{人物}}自{{起点地标}}绕过{{路径地标}}走到{{终点地标}}，两人视线连线随之转向；自下一镜起{{A}}居画框{{左}}。
    插入缓冲：镜头{{N}}〔大特写插入，锁定机位〕：{{画面内既有细节物}}。
```

越轴后必做：后续镜头的全部方位词按新轴侧重写。

## master shot 条母版 · 定位镜头，正文骨架

```
锁定机位广角，固定走位：{{逐人站位——套站位块母版精简到方位 + 地标 + 朝向三要素}}；无人移动，无台词；{{某人}}极轻地"嗯"了一声。
{{场景名}}与{{N}}人排布完整可读，第一帧即含全部在场者。
〔按需项 · 承接上场〕画外余音：上一场末句"{{台词尾音两三字}}"的收音。
机位纹丝不动，无漂移。
```

## 跨镜连续锁尾缀母版 · B 轨多镜头条条尾

```
完整版——镜头多/动作密的条：
    每次切镜保持：同一在场人物表、同一地理关系、同一银幕方向、同一视线目标、同一左右关系、同一光照方向、同一服装伤口道具与手部状态、同一{{血/雪/泥/汗/水/火/烟——按本条实际出现项列举}}连续状态。
    切镜后不重置动作，不瞬移，不改变与地标的距离，不引入新道具新人物。
精简版——两三镜的简单条：
    每次切镜保持各人位置、视线与左右关系不变；切镜后动作从上一镜的进度继续，不重置。
```

# 标杆 · 三人仓库对峙戏的完整 blocking

## 示例定位

- 标杆：一场三人仓库对峙戏的完整 blocking。本标杆自洽，实际项目里下列场景设定都来自上游文件。
- 场：ep01 剧情点 P04「仓库对质」，拆三条：Cut1 master 定位条、Cut2 正反打与越轴四镜条、Cut3 仓库主单人反应条。人物三名，进提示词的文字一律用可视特征代称：老周 = 账台后的仓库主；阿May = 来讨说法的女人；小北 = 女人的年轻同伴，怯。
- 场景板 scene-004——旧五金仓库 · 夜 · 3/4 视角——已埋地标：烧穿灯罩的吊灯、积灰的木账台、第二根铸铁立柱、卷帘门。
- 场景级底版由 scene-design 登记在 assets/visual/scene-prompts.md scene-004 条目下；本场场级空间地图块由 shot-design 装载 blocking 在底版上实例化，写在 outputs/epNN/02-shot-table.md 的 P04 场头，下文引用的就是它。

## 恒定层里的空间地图块 · 场头全场版与按条裁剪

场级空间地图块，scene-004 · P04 版本，取自 02-shot-table.md 的 P04 场头。围栏内是空间事实行；填写要求、条镜索引与版本住围栏外的编译期注记：

```
【空间地图｜ep01-P04 · 旧五金仓库（scene-004）】
    机位侧：镜头全程位于账台的卷帘门一侧；frame 方位以此为准，卷帘门在镜头背后、不入画。
    轴线：180° 线 = 仓库主与女人的对视连线；镜头全程守轴、不越过此线。
    地标绑定——板内可见地标为烧穿灯罩的吊灯悬在账台正上方、积灰的木账台在中景层横贯画面、第二根铸铁立柱在画框左的中景层：
        账台后的仓库主：站在木账台后、正在烧穿灯罩的吊灯正下方，躯干朝卷帘门方向，视线锁在女人脸上。
        来讨说法的女人：站在木账台外沿一步、居画框右前景，躯干朝向仓库主，视线锁在仓库主脸上。
        女人的年轻同伴：背贴第二根铸铁立柱、居画框左前景，躯干朝向仓库主，视线垂向账台台面。
    frame 方位：年轻同伴居画框左、女人居画框右，两人相隔一个账台正面的宽度；仓库主在两人之间的中景层。
    可见范围：本场只用账台—立柱这一角，不展示整个仓库。
    排布变化：条 2 镜 3：来讨说法的女人从账台外沿绕过立柱走到账台侧端、与仓库主只隔一个台角，仓库主与年轻同伴原位不动，两人视线连线随之转向，经主体移动重立轴线合法越轴；条2 镜4 起按新轴，女人居画框左、年轻同伴居画框右。
    重述规则：每次切镜后，用一句话重述谁在哪、面向哪、看着什么。
```

编译期注记 · 跟在场头块下方，写成普通行，不套围栏、不缩进、不进任何条：

**【编译期注记｜ep01-P04】**
- 写法约束：人物每人一行、写可视特征代称，不写人名、不带 @编号；禁 near/beside 类弱词，用可测量语言；身体朝向与视线分开写。
- 条镜索引：唯一一次排布变化与越轴落在 Cut2 镜 3–镜 4；Cut1 master 条、Cut3 单人条内排布不变。
- 版本与理由：v1 · 首次实例化，底版几何未改。
- 待办：无。

贴进 Cut2 那一条恒定层的成品 = 上面这块按条裁剪后的样子。Cut2 三人全在、两个变化项也都落在本条，所以整块只动一处——排布变化行删掉两处「条 2」前缀，成为：

> 排布变化：镜 3：来讨说法的女人从账台外沿绕过立柱走到账台侧端、与仓库主只隔一个台角，仓库主与年轻同伴原位不动，两人视线连线随之转向，经主体移动重立轴线合法越轴；镜4 起按新轴，女人居画框左、年轻同伴居画框右。

为什么这么编：

场头写全场版，进条那一刻裁一次，只删不改。镜号是条内编号——把「条 2 镜 3」原样焊进围栏，模型读到的是一个它永远见不到的坐标系，只能当噪声或当画面内容。同一场的 Cut3 是仓库主单人反应条，裁法就重了：年轻同伴与女人两行人物行整行删、frame 方位行随之整行删——只剩一个人没有相对方位可言——排布变化整行改写母版固定句「本条内排布不变」；机位侧、轴线、地标清单、可见范围、重述规则五处一个字不动，这五处是场级恒定量，Cut1/Cut2/Cut3 三条里必须逐字一致。

围栏里只留能改画面的字。「每人一行、写可视特征代称、禁 near/beside 类弱词」是写给作者的填写要求，留在块里就会被逐字焊进本场每一条——那是元指令进了提示词。条镜索引、版本与待办同理：它们的读者是排镜的人、做站位图的人和编译的人，不是模型。判据一句话——这一行删掉，模型会不会把画面画错？会就进围栏，不会就留在注记里。

其余照旧的地方也有讲究："卷帘门在镜头背后、不入画"这类负几何信息恰恰是防模型发明帧外内容的正向写法——说清它在哪，而不是"不要出现卷帘门"。轴侧与左右分配在此一次定死，后面所有镜头行照抄方位词。七行的字段名与字段序不是随手写的：母版真相源是本卡的 `references/spatial-language.md [空间地图块引用规范]`（源库原写 scene-design 的 spatial-map-template.md，该文件未随 V14 移植），本块与 shot-design 的镜头表母版同为它的只读副本。人物写可视特征代称、不带 @编号——整块要被贴进恒定层，而 @编号在同一条的绑定段已经出现过一次，块内再出现就是 tag 重复。

## master shot 条 · 场首定位，约 1 秒

```
锁定机位广角，固定走位：仓库主站在账台后吊灯正下方，双手撑在台面上；女人居画框右前景，年轻同伴居画框左前景，两人躯干朝向仓库主，目光都锁定仓库主；无人移动，无台词；年轻同伴极轻地"嗯"了一声。仓库与三人排布完整可读，第一帧画面里已包含全部三人、各就各位，无空场开场，无延迟入场。机位纹丝不动，无漂移。
```

为什么这么编：

master 条 = 地图块的画面版存档——站位描述与地图完全一致，不另写一套；"hm" hack 用年轻同伴这个本场最沉默的人发声最不抢戏；静止两重显式——锁定机位 + 无人移动 + 无漂移；首帧锁收成三句精简版嵌在句流里。这一条出片后与场景板对照，是本场空间正确性最早的实证。

## B 轨正反打 · 守轴示范，两镜

```
镜头1〔过肩中近景，平视，锁定机位，硬切入〕：越过女人的右肩看仓库主——仓库主在账台后，双手撑着台面，躯干正对女人，目光锁定她不移开；女人的肩与后脑居画框右前景虚化。他开口，只有他的嘴在动："货是你们自己没点清。"语气平得像在念账。
镜头2〔过肩中近景，平视，锁定机位，反打切〕：越过仓库主的左肩看女人——女人居画框右，下颌绷紧，目光锁定仓库主；年轻同伴在她身后画框左的中景层、立柱旁，躯干朝向仓库主但目光垂向账台的台面，嘴唇静止。女人沉默，指节抵在账台沿上收紧。
```

为什么这么编：

正反打全程机位在卷帘门一侧、守轴；女人恒画框右、年轻同伴恒画框左，两镜方位词与地图块逐字一致；每镜重述在场者方位 + 视线，即切镜重述纪律；连不说话的年轻同伴也有视线任务——垂向台面，朝向与视线分开写：躯干朝仓库主、目光垂台面；嘴部纪律显式——只有说话者嘴动、年轻同伴嘴唇静止；"指节抵在账台沿上收紧"是接触级语言兼手部状态，把情绪写成空间事实。

## 合法越轴 · 主体移动重立轴线

```
镜头3〔中全景，平视，平稳右横移跟随〕：女人猛地离开账台沿，沿账台的长边绕向画框左、从年轻同伴与立柱之间穿过，走到账台侧端与仓库主只隔一个台角站定——两人视线连线随她的走位转了向。她的起点、路径、终点全程在画面内可见：账台沿 → 立柱前 → 账台侧端。
镜头4〔过肩中近景，平视，锁定机位，硬切〕：新轴生效——现在越过仓库主的右肩看女人，女人居画框左，目光平锁仓库主；仓库主被迫侧转躯干正对她，吊灯的光从他头顶直压下来。年轻同伴留在原位，现居画框右远端的中景层，目光在两人之间快速往返。
```

为什么这么编：

越轴不靠机位偷跳，靠人物走位把轴转向，即主体移动重立轴线——走位三点账台沿/立柱前/账台侧端全绑地标且全程可见；越轴后第一镜镜头4 立刻按新轴重写全部方位词：女人从"恒画框右"变"画框左"、年轻同伴从"画框左"变"画框右"，这不是失误而是新轴的声明；仓库主"被迫侧转躯干"顺带完成了权力关系的画面翻转——局势反转被看见这一叙事收益正是选主体移动重立轴线的理由。

## 条尾跨镜连续锁 · 本条四镜共用

```
每次切镜保持：同一在场人物表——仓库主、女人、年轻同伴三人，无新增；同一地理关系——账台/吊灯/立柱方位不变；镜头3 之前同一左右关系——女人居画框右、年轻同伴居画框左，镜头4 起按新轴——女人居画框左、年轻同伴居画框右；同一光照方向——吊灯顶光；同一服装与手部状态。切镜后不重置动作：女人在镜头3 的走位于镜头4 已完成、站定在账台侧端，不回到起点。不瞬移，不引入新道具新人物。
```

为什么这么编：

连续锁按本条实际情况裁剪——左右关系一项因为合法越轴而按之前/之后分段声明，这是母版「同一左右关系——除非按合法路径越轴」那处例外的实操展开；"不重置动作"点名到具体动作、走位已完成，比抄通用句更防翻车。血雪土水火烟本条没有，就不列——锁列实际出现项，不堆全量清单。

## 全例总注

这场戏的空间信息分了四层落位：恒定层的地图块按条裁剪后逐条复用、五处场级恒定量一字不变 → 场首画面存档的 master 条 → 每镜重述方位 + 视线的镜头行站位 → 镜间不断链的条尾连续锁。四层说的是同一套事实、密度递减——这就是「模型无记忆」约束下的空间冗余设计：任何一层单独丢失，其余三层还能撑住排布。写自己的场时照这个分层与密度，别照抄仓库。

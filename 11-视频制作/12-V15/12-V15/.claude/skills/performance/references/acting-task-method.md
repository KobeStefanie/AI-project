[定位]
    本卡是任务制表演的完整方法卡：五支柱判据卡、任务阶梯全文、ACTING TASK 块格式、对照建构（contrast pairing）与常见失败。SKILL.md 收拢的是速查版；写重场对白戏、或表演被审出"演结果/死脸/主题上身"类问题时，翻开本卡全文。
    五支柱、身体与群像、任务阶梯、眼工均为已实战验证的方法；定义按本卡原文执行，不用教科书定义替换。
    本卡每节按「怎么认 / 认错长什么样 / 典型例子」给判据。

[判据卡 · 五支柱]
    Objective 目标
        怎么认：
            一个及物动词 + 具体对象，本场此刻就要，如"让他招供""求她再宽限一周""说服她我不害怕"；可能失败，失败有后果。背后有贯穿全片的超目标，本场目标是走向它的一步。
        认错长什么样：
            状态词冒充目标——"愤怒着""内疚着"，状态演不出来；对象缺失——"想要尊严"，向谁要；影片主题当目标——"体现救赎"，人物永远不知道影片的用意。
        典型例子：
            反例「他很愤怒地质问她」 → 正例「他要她当场认下偷表——用一句句逼问，逼她在孩子面前亲口说出来」。
    Obstacle & stakes 障碍与代价
        怎么认：
            外部障碍——对方要相反的东西、在场的证人、还剩两小时的死线，或内部障碍——自尊不许他开口求人、他不信自己说的话，都成立；"拿不到会怎样"有一个吓到人物本人的答案。
        认错长什么样：
            障碍是摆设，拿不到也无所谓；代价抽象——"会很糟糕"，糟糕成什么样；只有外部没有内部，人物一片坦途。
        典型例子：
            反例「他想借钱，但不太好开口」 → 正例「不借到这笔钱，明早他儿子就上不了手术台；而挡着他的是：对面坐着的是他十年没喊过一声哥的人」。
    Tactics 战术
        怎么认：
            动作动词——施压、魅惑、羞辱、哀求、挑衅、讨价、威胁、拖延，一场里随失败而更换；每次换战术就是一次变拍。
        认错长什么样：
            整场一个战术、从头吼到尾或从头哀到尾 = 死演；战术写成情绪——"他更生气了"不是换战术，"他从威胁换成哀求"才是。
        典型例子：
            讨债戏三换：先摆交情即讨好 → 对方装傻，换算账即施压 → 对方翻脸，换掀底牌即威胁——三个战术，三拍，行为每拍可见地变。
    Beats 节拍
        怎么认：
            最小行动单元——人物要同一样东西、用同一种方式争取的那一段。终结条件四选一：目标达成、战术失败、新信息抵达、力量对比翻转。每次变拍行为可见：停顿、换姿势、换语速、移视线。一场 2–4 次。
        认错长什么样：
            全程行为不变，演平了；变拍只在台词里发生、身体没跟上；变拍密到每句一变，碎成抽搐。
        典型例子：
            她数钱的手停了——变拍一，新信息：数目不对；把钱推回去、身体后靠——变拍二，换战术：从收下改为拒收；起身、拿外套——变拍三，力量翻转：这局她不玩了。
    Subtext 潜台词
        怎么认：
            真想的与嘴上说的两层并存；不演，靠演真目标、说假台词时自己漏出来。可埋的行为标记：不是问题的问题、不信答案的重复追问、话题急转、挡住脆弱的错时玩笑、过短的回答——"行。""嗯。" = 关上的门。
        认错长什么样：
            把潜台词直接演出来——一边说"我没事"一边挤出哭腔，这是把里子演成了面子；或干脆没有里子，台词说什么人物就是什么。
        典型例子：
            她说"你随便，我无所谓"，同时把他常坐的那把椅子往桌下推了推——嘴上放行，手上关门。

[任务阶梯全文 · 严格按序，跳级必错]
    0. 通读全场对白
        怎么认：
            动笔前把这场每个角色的每句台词读完，看清任务在哪里成立、在哪里破口。
        认错长什么样：
            拿单句台词直接建任务——任务活在整场往复里，单句建出来的必偏。
        典型例子：
            只看"可怜的家伙"一句会当成怜悯；读完全场才知道这句是说他自己。
    1. 场戏目标：全员共同暗向
        怎么认：
            一句所有人都在无言执行的共同约定。范例：母亲收拾行李箱送儿子入伍，一小时后出发——场戏目标 = "把这场分别过得不痛：藏住感受，不给对方留下伤心，绝不丢掉那股正劲"，同时属于两个人。
        认错长什么样：
            把揭示、反转、主题这类影片功能当场戏目标——人物从不演影片的用意，那些是经由他们完成的副产品。
        典型例子：
            反例「这场戏的目标是揭示父子隔阂」 → 正例「这场戏全员的暗向是：把晚饭吃完，别让任何一句话掉进那件事里」。
    1a. 结尾倒读命名事件
        怎么认：
            先看这场怎么收——最后一拍是读懂全场的钥匙，用它倒读。警惕双关末句：说的是一件事，指的是另一件。
        认错长什么样：
            从开场顺着读、读到一半就命名事件——事件是被结尾证实的，不是被开场宣布的。
        典型例子：
            末句"可怜的家伙。就是没法原谅自己。"——看着病床上的人说的，说的是他自己；这句同时命名了场内三个人。
    1b. 全员入事件
        怎么认：
            事件必须装下场内每一个人——包括沉默者与昏迷者——作为同一进程的参与者或镜子。
        认错长什么样：
            有人站在事件外 = 事件命名错了，重命；给沉默者留白 = 他在画面里死掉。
        典型例子：
            三人病房戏，事件 = "寻找自我原谅"。病人在梦里无法原谅自己；年轻医助在床边无法原谅自己——他的照护就是他的赎罪；医生早已放弃——他的"漫不经心"是希望死掉后的疤痕组织，他好奇地看着年轻医助，想知道这一个能不能找到他自己没找到的出口。三面镜子照同一句判词。表面的"例行查房"只是事件穿行的地形。
    1c. 各自的物理通道
        怎么认：
            例行查房、收拾行李这类表面活动保留为物理动作层；每个角色经由各自不同的、摄影机拍得到的行为追同一事件——同一事件、同一地形、每人一条不同通道。
        认错长什么样：
            所有人用同一种行为追事件——全员都在"沉重地干活"；或任务悬空没有物理通道——"他在内心挣扎"。
        典型例子：
            事件"寻找自我原谅"、地形"例行查房"——病人：经由回忆，闭睑下的快速眼动、那滴泪；医生：经由一丝不苟做完分内事，按时、精确地写下正确数据，甚至复核一遍，用无瑕的程序保住自己还是个医生；医助：经由照护，超出清单的照看——看的是人，不是表。
    2. 动机：同向不同燃料
        怎么认：
            所有人推同一个方向，各有各的理由——儿子把分别演得不痛是为了妈妈，母亲是出于忌讳、行前落泪不吉利。同一矢量、不同燃料：燃料让每个表演各自成立，整场读起来却是一体。动机可有备选假设，由导演拍板选定。
        认错长什么样：
            动机无视既定情境——接了实验监狱差事的人已经是同谋，演不了道德无辜者；或全员共用一个动机，表演彼此不可区分。
        典型例子：
            同是"维持例行公事"，医助的版本可以是怕在前辈面前露怯，也可以是用职业性守住医者本分——同一方向、两种颜色，选一种。
    3. 个人目标
        怎么认：
            由动机孵出的、这个人自己在场内争的东西——普通、个人、可演。
        认错长什么样：
            与场戏目标同词——那是共同方向不是个人之战；或写成主题词。
        典型例子：
            母亲的个人目标——把他体面地送出门，别让他背着我的恐惧走；儿子的——让她安心，证明我准备好了。
    4. 障碍
        怎么认：
            顶着共同方向的那股压力——真实感受随时要顶破防线；一次破口，整场的线就塌。"The audience feels it precisely because nobody plays it."（观众感到它，恰恰因为没有人演它——全员都在演把它挡在外面。）
        认错长什么样：
            让人物直接演那股压力——哭出来、说破；压力被演出来的一刻就不存在了。
        典型例子：
            行李箱戏里那股压力是真实的不舍，一个湿润的对视就能让全场塌线——所以她数袜子，他啃苹果。
    5. 战术 = 表演任务本体
        怎么认：
            写成对搭档做的事，逐拍锚在台词原文上；眼工是有目的的动作——在对方双眼里核对一星信任、每说完一点核对落没落地、偷看后在被抓到前弹回、丈量并记住对方。剧本要求处，标出燃料耗尽、防线破口的位置——破口本身就是这场戏的交付。
        认错长什么样：
            写成"眼皮抬起、瞳孔放大"式眼部编排；或战术不及物——"他保持冷静"，对谁做什么。
        典型例子：
            她"如常地"收拾，眼睛偷到他身上、丈量、记住，他一抬头就弹回袜子上；他"随意地"吃着，看她的手、不看她的脸——因为脸是危险所在。观众落泪，恰因银幕上没有人落泪。

[ACTING TASK 块格式]
    块式——英文骨架双语保留；正文默认中文散文，随整条提示词语言走：
        ACTING TASK — {{NAME}} (invested in his tactic; the work happens in his eyes):（表演任务——某某（全情投入于他的战术；戏在他的眼睛里）：）
        SCENE DIRECTION (shared, unspoken): {{共同暗向，一行}}
        MOTIVE (his fuel): {{他为什么推这个方向}}
        GOAL: {{他个人在争的东西}}
        OBSTACLE: {{顶着防线的压力；破一次口的代价}}
        TACTIC: {{他对搭档做的事——眼工写成有目的的动作}}
        Moment to moment:（逐拍：）
        ——"{{台词原文}}"——{{对搭档的动词 + 眼睛核对什么}}
        ——"{{台词原文}}"——{{动词 + 眼工}}
        ——{{若防线破口：破在哪一句、破成什么样}}
        (Safety: gaze always engaged in the task — never a frozen, glassy, unfocused stare; natural blink cadence.)（安全行：目光始终咬在任务上——绝不冻结、玻璃化、失焦；自然眨眼节奏。）
    五条规则：
        1. 动词指向搭档；禁"悲伤地""紧张地"式情绪副词做指令。
        2. 禁面部编排——"眉毛抬起""嘴角颤抖"；外观描述只允许出现在末尾安全行。
        3. 没有人演情绪，所有人演方向；观众经由压力收到感受。
        4. 每个入镜角色都要有任务——包括沉默的倾听者："判断他是不是认真的""等笑点落地""护住此刻的气氛"。
        5. 逐拍锚在台词原文上，不锚在秒数上。

[对照建构（contrast pairing）]
    怎么认：
        双人戏按镜像正负建构——每人带一正一负，与搭档互为倒置；并命名本场的本质轴（ESSENTIAL AXIS）——观众真正读取的那条对立轴，其余特质只是色彩。
    认错长什么样：
        两人写成同色——都冷或都热，观众没有轴可读；对立写到台词上互相争吵——对立应活在共同方向之下；把轴命在"谁拿到钥匙"的情节上而非"谁在乎人"的价值上。
    典型例子：
        认可范例——实验室二人组。
        医生——忠诚（+）/漫不经心（-）：他的忠诚真实，但效忠的是公司和钱，不是病人；在本质轴"对病人的在乎"上，他是负。
        医助——被收买（-）/在乎（+）：他接了差、他知道这地方是什么，他的负真实；但他对病人的在乎在负里活着；在本质轴上，他是正。
    规则五条：
        1. 一人一正一负，与搭档互为镜像。
        2. 命名本质轴——观众读的是这条轴，别的都是色彩。
        3. 两人仍推同一场戏方向，如"把它维持成例行公事"——对立活在共同方向之下，从战术和眼睛里漏出：漫不经心者的例行是真的例行；在乎者的例行是铠甲，而且会裂。
        4. 动机同时由正负建构与事件推出：医助照护病人是他的赎罪之路；医生的敷衍不是打发，是安静的实验——他在观察这个年轻人能不能从被出卖的良心里活着出来。
        5. 表面特质常是其反面的疤痕组织——"漫不经心"常是希望死掉后的疤痕。"Direct the history, not the surface."（导历史，别导表面。）

[常见失败 · 逐条：症状 → 修法]
    从单句台词建任务 → 回任务阶梯 0 级，先通读整场再动。
    把影片的揭示/主题派给角色演 → 人物从不演影片的用意；重命个人目标。
    场戏目标与角色目标混同 → 场戏目标是共同暗向；角色目标各自不同且个人。
    动机无视既定情境、已同谋却演无辜 → 从情境重推动机。
    写成眼部/面部编排而非有目的的眼工 → 改写成对搭档的动词 + 眼睛核对什么。
    情绪形容词做指令 → 换成会产出该情绪的任务；情绪是任务的副产品。

# 表演档案母版

## 使用说明

- 复制本母版为某核心角色建表演档案：逐槽填空，然后把槽位合成一段流水散文、去掉槽位标记与注释行，落进 assets/visual/character-prompts.md 该角色条目「表演档案」段，并在 assets/reference-index.md 该角色行加档案指针。
- 写法规则与判据见 references/master-profile-guide.md；标杆全文 VIKTOR 也在那里。块序固定，不许调换。
- {{}} 内为填空位；`——要求：` 起头的行是注释，成段时删掉。

## 表演档案母版

```
Character acting as {{角色名或可视特征代称}}。
    ——要求：用可视特征代称，不写 @编号；@ 只在成品条的【参考资产绑定】段出现一次，重复 @tag 是平台拒绝启动的头号原因。
体格即传记：{{年龄}}，{{体型与体格}}，{{体态细节}}。
    ——要求：职业、旧伤、自我认知能直接从身体读出；每个形容词都在讲前史。
心理引擎：{{一个从句——解释以上一切身体行为的内在驱动}}。
    ——要求：一句话；后面每个 tic 都应能被它解释。
说话行为：{{音高与音色}}；{{口音/出身痕迹}}；{{语速与交付方式}}；{{情绪压力下声音怎么变——变快还是变慢、变响还是变轻、在哪里破}}。
    ——要求：写戏剧行为，不写声线本体；不得与该角色声线锁冲突，声线锁在 reference-index 登记。
习惯动作与 tic：
    {{招牌 tic}} + {{触发器：何时/为何}}；
    {{压力 tic}} + {{触发器}}；
    {{掩饰行为：他用什么动作藏住感受}}；
    {{默认面具是什么样的脸}} + {{面具破裂的精确条件}}。
    ——要求：每个 tic 必带触发器；无触发器 = 装饰，删。
眼活：{{注视习惯与具名目标——他惯性扫什么}}；{{眨眼率与质感——紧张/掌控/失神各什么样}}；{{静止时的眼——受控的静止是选择，写成罕见、缓慢、蓄意的眨}}。
步态："{{命名步态——引号内造词}}"——{{重量与落脚}}，{{步幅与节奏}}，{{躯干与手臂做什么}}，{{头做什么}}。
转变条款：However, when {{情绪触发器}}，{{转变——体态/步态/脸在多长时间内变成什么样；是否自己收回}}。
    ——要求：每份档案至少一条；最有戏的写法是"裂开——又自己合上"。
唯一软化目标，可选：{{那一个人/动物/物件}}。
    ——要求：只给一个。两个就稀释。
```

## 写作要点

1. 一段流水散文，无列表、无标题、无参数行；密度对标 master-profile-guide 的标杆档案 VIKTOR，删无可删。
2. 全部可观察、可拍摄：删掉"他觉得""他想起"这类摄影机拍不到的句子。
3. 禁入项：服装——住资产/场景块；镜头与调色——住提示词别处；声线锁本体——住 reference-index；影片主题词。

## 自检

- [ ] 每个 tic 都带触发器了吗？
- [ ] 有 However, when X 转变条款吗？裂缝有精确触发器吗？
- [ ] 步态命名并拆解生物力学了吗？
- [ ] 遮住名字，能从身体读出这个人的履历吗？
- [ ] 有没有一句是摄影机拍不到的？有就重写。

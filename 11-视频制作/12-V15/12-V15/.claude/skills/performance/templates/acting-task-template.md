# 表演任务母版

## 使用说明

- 重场对白戏逐角色填一块 ACTING TASK，成品嵌进动态提示词【分镜正文】的对应位置：A 轨嵌 [X-Y秒] 段内，B 轨嵌对应镜头内——块头与块内人物一律写可视特征代称，不写 @编号，@ 只在【参考资产绑定】段出现一次。
- 填块之前必须先走完任务阶梯，全文见 references/acting-task-method.md——从 0 级通读全场对白开始，跳级必错。工作单是推导脚手架，填在对话里、不落盘；落盘的只有嵌进动态提示词正文的 ACTING TASK 块。
- {{}} 内为填空位；阶梯工作单一场一张，ACTING TASK 块一角色一块；英文骨架双语保留，正文默认中文散文。

## ACTING TASK 母版

```
ACTING TASK——{{可视特征代称}}（全情投入于他的战术；戏在他的眼睛里）：

动机（他的燃料）：{{他为什么推这个方向}}
目标：{{他个人在争的东西}}
障碍：{{压力是什么 + 破一次口的代价}}
战术：{{他对搭档做的事——眼工写成有目的的动作，如"在对方双眼里核对一星信任""每说完一点核对落没落地"}}
逐拍（锚台词原文，不锚秒数）：
——"{{台词原文}}"——{{对搭档的动词 + 眼睛核对什么}}
——"{{台词原文}}"——{{动词 + 眼工}}
——{{若防线破口：破在哪一句、破成什么样——破口本身常是这场戏的交付}}
安全行：目光始终咬在任务上——绝不冻结、玻璃化、失焦；自然眨眼节奏。
```

## 写作要点

1. 禁"悲伤地""紧张地"式情绪副词做指令——换成会产出该情绪的任务。
2. 禁面部编排——"眉毛抬起""嘴角颤抖"；外观只允许出现在安全行。
3. 禁从单句台词建任务——回任务阶梯 0 级。
4. 禁把影片的主题/揭示派给角色演——人物从不演影片的用意。
5. 禁漏掉沉默的倾听者——他也要一条任务："判断他是不是认真的""等笑点落地""护住此刻的气氛"。

# 创作基准方法论

## 🔀 v14 分工（先读这条）

创作基准拆成两份文档，各管一层：

- **`creative-brief.md`**（本规范）：**情感蓝图 + 导演视野 + 音乐情绪基调**——给人看、给创作定向。
- **`visual-style.md`**（规范见 `_shared/visual-style-guide.md`）：**可被逐字嵌入提示词的两层技术基准文本**（通用基准段 + 场域锚句）——给模型读、锁跨资产一致性。**色彩锚三级也归那份。**

为什么拆：视觉基准段要被逐字嵌入几十条提示词、要按场域分层、要被 reviewer diff——它是「技术真相源」，和「情感/作者意图」是两种东西，混在一份里改一个动全身。

**过渡兼容**：v13 老项目把「全片视觉风格基准段」写在本文件第三节里，仍可读、下游读不到 visual-style.md 时降级读这里。**v14 新项目：视觉基准写 visual-style.md，本文件的第三节可省略或只留一句指针。**

## 什么是创作基准

项目最早产出的文档（`assets/story/creative-brief.md`），v14 含三个层面：

1. **情感蓝图**：观众视角——他们最终感受到什么
2. **导演视野**：作者视角——用什么镜头语言去实现
3. **音乐情绪基调**：供音乐总监的情绪出发点

（视觉技术基准段 → 已移交 `visual-style.md`，见上方 v14 分工。）

## 产出时机

**叙事类·路径 A**：在选题研读和创意采访之后、剧本设定之前，由编剧产出。用户确认后才开始写剧本。

**叙事类·路径 B（用户直接给剧本、跳过编剧）**：由导演在阶段二产出**两份**（creative-brief.md + visual-style.md），与讲戏本一并交付——导演本就要定导演视野与场域划分，是最合适的补位者。服化道 / 分镜师读不到这两份时先查这条，不要报错卡死。

**（路径 A 的 visual-style.md 分工）**：编剧起草草案 v0.1（层 1 通用基准段 + 字段表），导演在阶段二拆出场景清单后定稿 v1.0（补齐层 2 场域锚句表）。详见 `_shared/visual-style-guide.md > 归属与时机`。

**MV类**：在音乐结构分析之后，由导演产出（没有剧本，以音乐情绪为基础定视觉风格）。

**VJ类**：在项目启动时，由导演直接产出（纯视觉，无叙事）。

## 产出格式（存入 `assets/story/creative-brief.md`）

```markdown
# 创作基准 — [项目名]

## 一、情感蓝图

**核心情感**：[观众看完最后一帧，内心应有什么感受？一句话]

**情感节拍**：
1. [开场：此时观众感受到什么]
2. [第一个情绪转折点：...]
3. [中段高潮：...]
4. [情绪落点：...]
5. [片尾余韵：...]

**核心视觉隐喻**：[贯穿全片的视觉符号，如「一双总是空着的手」「越来越近的镜头」]

## 二、导演视野

**作者风格**：[写实克制 / 奇观尺度 / 冷峻精密 / 诗意写意 / 黑色冷硬 等]
**风格锚**（可选）：[可挂一位导演署名，如「Fincher式冷峻精密」「王家卫式情绪光色」]
**拍法核心**：[这个导演怎么拍——具体到镜头行为，如「长焦压缩、人物始终不在画面中心、灯光永远单向」]

## 三、视觉风格基准 → 见 `assets/story/visual-style.md`

> v14 起本节只留指针，**不要在这里写画风/调色板/质感/光逻辑**。
> 可逐字嵌入提示词的两层技术基准文本（层 1 通用基准段 + 层 2 场域锚句）住在 `assets/story/visual-style.md`，规范见 `_shared/visual-style-guide.md`。
> （v13 老项目把基准段写在本节，下游读不到 visual-style.md 时降级读那些内容。）

## 四、音乐情绪基调（供音乐总监参考）

**整体情绪色彩**：[如「压抑→爆发→余韵」或「温柔到底不需要高潮」]
**禁忌风格**：[不要什么，如「不要煽情弦乐，不要激励鼓点」]
```

### 色彩锚（三级，规范归 visual-style-guide）

色彩锚决定视觉基准段里「色域/光逻辑」怎么落，**完整三级规则在 `_shared/visual-style-guide.md > 色彩锚三级`**。一句话版：

1. **用户点名导演** → 读 `art-design-skill/references/director-color-cards.md` 对应 `## D0NN` 段，取六色 HEX+光线+调色填进基准段。
2. **用户不点名** → 制片人/编剧**必须先查 `director-index.md`**，按题材/平台/受众/对标推 2–3 位候选让用户认领（话术：user-messages > ~color）——**不许即兴写形容词**，手里有 175 位真实取色库不用是浪费。
3. **用户明确拒绝导演锚** → 才自由创作，记 `script-settings.md`「色彩锚：无（用户主动声明）」防反复追问。

**嵌入后的基准段示例（D082 大卫·芬奇）**：
```
[全片视觉风格基准]
色彩锚：D082 大卫·芬奇
画风：写实电影感，精确构图、稳定跟随，信息靠特写交代
调色板：七宗罪黄绿 #5F6850 25%（大面积环境）| 档案冷灰 #6E777C 20%（建筑/服装）| 室内钨黄 #A6773B 18%（人物/核心道具）| 血暗红 #702A2C 15%（阴影/背景）| 雨夜黑 #1C2225 12%（光源/反射）| 皮肤灰褐 #8D6E5B 10%（叙事转折强调物）；压低饱和，阴影黄绿，高光不过曝
质感：轻微数字颗粒，暗部有细节，肤色中性可读不被环境色染
光逻辑：低照度实景灯为主，顶光压脸，雨面反射作辅光；不用全局滤镜替代美术与光源
```

色卡库的通用规则（主色由环境承载、强调色只在关键道具/叙事转折出现、肤色不染色）已写在 `director-color-cards.md` 顶部，不必复制进基准段。

## 各 agent 如何使用创作基准

| Agent | 使用方式 |
|---|---|
| 编剧 | 以情感蓝图为剧本创作的北极星，每场戏问「这场服务哪个情感节拍」；起草 visual-style 通用基准段草案 |
| 导演 | 以导演视野为讲戏风格的底色；定稿 visual-style 场域锚句表 |
| 服化道 | **每张提示词开头逐字嵌入 `visual-style.md` 通用基准段**（缺则降级读本文件基准段） |
| 音乐总监 | 以音乐情绪基调为配乐策略的出发点 |
| 分镜师 | **恒定层从 `visual-style.md` 取**通用基准段+本场场域锚句（缺则降级读本文件） |

**铁律**：所有 agent 读取上游资料时，先读 `creative-brief.md`（情感/作者意图）与 `visual-style.md`（视觉技术基准）。它们是最高优先级参照，高于任何单集的具体导演建议。

## 好的基准段示例

**差的写法（太抽象）**：
```
画风：电影感
调色板：温暖
质感：好看
光逻辑：柔和
```

**好的写法（可以直接进提示词）**：
```
[全片视觉风格基准]
画风：写实胶片质感，35mm 手持镜头风格，偶发镜头晃动增加真实感
调色板：主色为焦糖棕和雾蓝，暖色编码过去的记忆，冷色编码当下的孤独
质感：轻微胶片颗粒，阴影处细节保留，不压死暗部
光逻辑：窗光为主要光源，左侧斜入，逆光在人物轮廓形成光晕，不用正面补光
```

## 跨资产一致性的底层原理

服化道生成3张图（角色/场景/道具），分镜师生成50条视频提示词——如果没有共同的视觉基准段，每个agent各自发挥，最终产出必然漂移。

解决方案不是"让AI猜"，而是**把这段文字作为物理插入项**：

```
[全片视觉风格基准] 写实胶片质感，35mm...（来自creative-brief.md）

[人物设定 - 林书白]
...具体角色描述...
```

每张提示词的第一段永远是这段基准，不是装饰，是让所有生成任务共享同一个视觉起点。

# 路径 B 启动补设定（跳过编剧时的必做流程）

> 从 CLAUDE.md 外置（v13.0）。触发：`input/剧本/` 有文件且 `script/` 无对应终稿。
> 话术全部引用 `user-messages.md > 路径 B 启动补设定`。

## 一、复制剧本到 script/

- 文件名以 `epXX-` 开头 → 保留原名复制
- 无 ep 前缀 → 默认作为 ep01，重命名为 `ep01-<原文件名>.md`
- 多个无前缀文件 → 提醒用户重命名后重试
- 创建/更新 `script/00_当前状态.md`，写入 `创作模式: 跳过编剧（路径B）`（防止后续误调编剧）

## 二、五问补 settings（调用导演前必做）

路径 B 跳过了编剧的剧本设定阶段，但下游 agent 依赖 `assets/story/script-settings.md`。**逐题问**，每题话术见 user-messages 对应段：

| # | 问什么 | 处理 |
|---|---|---|
| 1 | 目标媒介 + 目标平台 | 直接录入 |
| 2 | 目标受众画像 | 直接录入（写给一个具体的人，不是「年轻人」） |
| 3 | 对标爆款 | A 有 → 逐条记录（作品名 · 多平台搜索名 · 取哪一面 · 不照搬哪一面）；B 要推荐 → 基于题材/平台/画像推 3–5 个，认领后记录；C 不要 → 写「无（用户主动声明）」，下游走通用爆款逻辑 |
| 4 | 视觉风格 | A 明确 → 录入；B 要推荐 → 推 3 个候选（如 3D 动画感 / 写实电影感 / 黑白线稿）；C 让 AI 定 → 写「待导演阶段定」 |
| 5 | 视觉画幅 | A 有偏好 → 录入 `aspect_ratio`；B/回车 → 按平台推荐（抖音/小红书/视频号/TikTok→9:16；B站/YouTube/院线→16:9；朋友圈/Instagram→1:1；电影院线→21:9）；C 让 AI 定 → 按 B 自动定 |

**可选第 6 问（不主动追问，用户提了才记）**：色彩锚。用户说「想要某导演的调子」→ 在 `director-index.md` 里查到 ID，写入 `色彩锚：D0NN 导演名`；只说气质不点名 → 从对应分类推 3–5 位候选。不提 → 留空。

用户回答「不知道 / 跳过 / 用默认」→ 兜底：通用短视频平台 + 25 岁年轻互联网用户 + 无对标 + 视觉风格待导演阶段定 + 9:16 竖版（话术：user-messages > 兜底）。


## 四、creative-brief 补位（v13.0 修复路径 B 死锁）

路径 A 的 `creative-brief.md` 与 `visual-style.md` 由编剧起草、导演定稿；路径 B 没有编剧，**两份都由导演在阶段二开头补出**（visual-style 的场域锚句表按场景清单逐场补齐，格式见 `_shared/visual-style-guide.md`）（导演本就要定导演视野，是最合适的补位者）：

1. 制片人调用导演时明确告知「路径 B，creative-brief.md 缺失，请先按 `_shared/creative-brief-guide.md` 产出，再写讲戏本」
2. 导演读 script-settings（视觉风格 / 画幅 / 色彩锚）+ 剧本 + `input/参考/`，产出三合一创作基准；有色彩锚则读 `art-design-skill/references/director-color-cards.md` 对应段嵌入基准段
3. 视觉风格若为「待导演阶段定」，导演在此定下并回写 script-settings
4. creative-brief.md 与讲戏本一并进 reviewer 阶段二审核

这一步完成后服化道 / 分镜师才有基准段可嵌，不再触发「缺失 → 停下报错」。

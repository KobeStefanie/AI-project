> 📌 **V14 适配说明**：**条 = Cut**、**场 ≈ P0X 剧情点**、**成品表 = `outputs/epNN/video-prompts.md`**、**ledger = `assets/continuity-ledger.md`**。地址一律写 `epNN-P0X-CutM`（Cut 号全集连续，真相源 `CLAUDE.md:26-29`）；缝地址示例形如 `seam-014：ep01-P03-Cut2 → Cut3`。审核由 reviewer agent 执行、成片审派批检工人 subagent。

[定位]
    成片审的连续性专项：把"跨场跨集结束状态继承链"拆成一条条可独立核对的"缝"，分组派批检工人 subagent 逐缝过表。本文件是方法书——成片审主审按 [分组派工] 派活，工人按 [逐缝核对表] 干活、按 [证据写法] 回报。工人用 review skill 的纪律执行——fresh、只审不改、发现清单片段交回主审，不引入新角色。

[缝的定义与枚举]
    缝 = 两个相邻生成单元之间的承接点。承接的契约：开始状态_(i+1) = 结束状态_i。
    三类缝：
        - 条间缝：同场内 epNN-P0X-CutM → cN+1。契约载体：上条【结束状态】五字段 + 【衔接】段。
        - 场间缝：sXX 最末条 → sXX+1 首条。契约载体：ledger 该场"场末快照"；场与场之间允许剧情时间跳跃，但必须有声明——快照时间线行 / 新场开场设定。
        - 集间缝：epNN 跨集 ending state 区 → epNN+1 开场首条。契约载体：ledger"跨集 ending state" + 移交线头清单。
    枚举法：按 outputs/epNN/video-prompts.md 各场条数数出——每场条数−1 条条间缝，场数−1 条场间缝，多集再加集间缝。列成带编号的缝清单，如 seam-014：ep01-P03-Cut2 → Cut3；清单本身是派工的分配依据，零遗漏零重复。

[分组派工方法 · 成片审主审执行]
    本表只管继承链这一组怎么切——成片审分组批检里唯一按缝切工作量的一组；其余检查项见 `seedance-prompt-review-skill/SKILL.md` 的「二、成片审」A 段（逐条可判定检查），不走本表。本表由该 skill 的「二、成片审」B 段调用。
    1. 切组：按缝清单切连续区间，每工人 10–20 条缝；组边界尽量落在场边界上，场间缝显式分给紧后一组，缝清单上标明归属、不留无主缝。集间缝单独成组或并入末组。
    2. 工人上下文契约，fresh 派发、显式给全、不让工人自己猜：
        - 缝区间清单，含编号与两端条号
        - outputs/epNN/video-prompts.md 文件路径 + 涉及的场节名，含区间外紧邻的前后各一条供承接对照
        - assets/continuity-ledger.md 对应场的节名
        - assets/reference-index.md，变体对账用
        - 本核对表路径 + continuity 的 state-machine-12.md + review 的 report-template.md
    3. 工人纪律：只审不改；每缝逐项过 [逐缝核对表]；结论按 [证据写法] 回发现清单片段；不派下级 subagent、不推进流程、不写共享文件。
    4. 汇总：主审机械拼接各组发现清单并统一编号，不增删改内容；同一根因跨缝复现的去重由工人在本组范围内完成——折进根因一条、罗列复现位置，主审不做裁量；合并结果并入成片审报告；缺陷按 review 的回流路由表派修——成品承接断裂回 motion-compile；台账记错回 continuity 修账；变体缺失回对应设计 skill；镜头结构性矛盾回 shot-design。

[逐缝核对表 · 工人对每条缝执行，八查]
    1. 五字段承接：下条开场/首段起点 vs 上条【结束状态】原文，逐项过位置、朝向、持物、动作动势、情绪。差异若无剧情交代——切镜声明、时间跳跃声明、条内动作——即命中。
    2. 衔接咬合：上条【衔接】声明的出点手法 vs 下条实际入点方式，是否互相兑现——写了"动作匹配切"，下条就得从该动作续起；相邻条至少靠动作、视线、声音、颜色、形状、方向或遮挡之一保持连续。
    3. 任务进度守恒三查：已完成的动作有没有重新开始；已处理的物体有没有回到未处理状态；人物与道具位置有没有无原因重置。
    4. 12 类全量扫：按 state-machine-12.md 逐类过一遍缝两端，重点持久类即伤损/场景破坏/天气时间线，条内类查"无因跳变"。防误杀通则同该卡：查断裂不查雷同。
    5. 账实一致：ledger 对应落幅行、场末快照 vs 成品原文——照录是否逐字、快照是否涵盖本缝涉及的状态变化、线头登记有无遗漏。账错记 continuity，实错记 motion-compile，两处都错各记一条。
    6. 资产状态版本：缝两端引用的资产编号与剧情状态匹配——伤后条仍绑无伤原版 @char-002 而非 @char-002-v2 即命中；变体在 reference-index 查无 = 死引用，升格记录。
    7. 恒定层跨缝一致：两端条的恒定层——通用基准段、时代锚、声音基调——三项应逐字相同；措辞漂移是风格漂移的前兆信号，命中即记，severity 视范围。场域锚句按各自场域取，不进这三项的逐字比对：跨场域的缝两端锚句不同属正常，同一场域内两条锚句不同、或哪一条取了别的场域那一句，才是命中。
    8. 场间/集间加查：场间缝——时间跳跃有无声明、服装/伤势变化有无依据，隔夜结痂合法、同刻自愈非法，新场首条是否承接快照；集间缝——移交线头是否被下一集接住，即在开线头在 ep(N+1) 有无着落，跨集 ending state 与下集开场设定无矛盾。

[证据写法 · 问题条目格式，对齐审核报告]
    每条问题必含以下字段，与 review 报告的发现清单同构；编号工人留空，主审拼接后统一补：
        - 类：缝两端对不上默认填「矛盾」；第 6 查的变体查无升格项填「断链」；第 7 查的恒定层漂移填「走样」。
        - shot_id：缝记两端条号，如 "ep01-P02-Cut2 → Cut3"；单端问题记该条号。
        - evidence：两端原文直引——上条结束状态原句 + 下条开场原句，不转述。
        - severity：死引用 = blocking（白名单项）；承接断裂/动作重置 = major；账实小偏差/恒定层单词漂移 = minor。
        - reflow_to：修成品回 motion-compile / 修账回 continuity / 补变体回 character-design 等设计 skill / 结构性矛盾回 shot-design。
        - fix：可执行一句，写清改哪端、改成什么。
    示范 1 · 承接断裂：类「矛盾」；shot_id "ep01-P01-Cut1 → Cut2"；evidence "Cut1 结束状态：持物=右手攥着当票；Cut2 开场：她双手推门而入，画面中无当票"；severity major；reflow_to motion-compile；fix "Cut2 开场补'当票已收入左襟内袋'或在 Cut1 落幅前写收起动作，二选一，与镜头表核对后改成品并同步台账"。
    示范 2 · 变体缺失：类「断链」；shot_id "ep01-P02-Cut1"；evidence "台账：char-002 手伤发生于 ep01-P01-Cut2 持续可见；本条绑定段仍为 @char-002 且正文无伤口描写"；severity major；reflow_to character-design；fix "登记 char-002-v2（右手掌划伤渗血）入 reference-index，本条改绑 @char-002-v2，正文动作句带伤势可见性"。

[防误杀 · 工人判前自问]
    - 这是设计还是断裂？场间时间跳跃、情绪转折、景别跳切都可以是剪辑设计——有声明即合法，只抓"该交代而没交代"。
    - 松档条的自由度边界内不判：松档条声明了"景别机位剪辑可自然变化"，机位类差异不命中；但"因果顺序与动作结果不得变化"仍是硬线。
    - 别拿分镜内部当缝：B 轨条内镜头 1 → 镜头 2 的衔接归成片审的模型雷类逐条预演，不属本批检范围；本批检只管条与条、场与场、集与集。

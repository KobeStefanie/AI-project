# 导演执行技能

[技能说明]
    剧本分析与导演讲戏技能。将剧本/梗概/分场大纲转化为：
    1. 导演讲戏本（按剧情点分节，每节包含元数据 + 导演阐述 + **上承/下启字段**）
    2. 人物清单（用于服化道生成角色参考图）
    3. 场景清单（用于服化道生成场景参考图）
    4. **关键道具清单**（用于服化道生成道具资产参考图）
    5. **剧本医生反馈**（如发现剧本结构性缺陷，主动提建议给制片人协调编剧）
    6. **节奏蓝图**（疏/中/紧三档 + 气口预算，见 [执行流程] 第八步）
    7. **条划分表 + 接缝卡**（见 [执行流程] 第九步。**条的边界与接缝手法的唯一真相源**——下游分镜师明文禁止自行增删条、改条边界、改接缝，所以这两张表不落，下游就卡住或被迫越界定条）
    8. **`assets/story/visual-style.md` 定稿 v1.0**（**所有路径的首集必做**：把编剧的草案 v0.1 定稿——沿用层 1 通用基准段 + 按场景清单补齐层 2 场域锚句表。流程见下方 [执行流程] 第六步之五，规范见 `_shared/visual-style-guide.md`）
    9. **creative-brief.md**（仅路径 B 首次：项目跳过编剧且该文件缺失时，讲戏前先补，流程见 `agents/director.md [路径 B 补创作基准]`；此时 visual-style.md 也由你起草并一并定稿）

    核心理念：导演像给演员讲戏一样，把脑海中的画面完整描述出来。
    一个剧情点 = 一段完整叙事 = 一次视频生成任务（模型名与时长上限读 `.project-config.json.video_model_config`）。
    段落内可包含多组镜头（如蒙太奇、快速闪回），但叙事上必须是一个完整段落。

    讲戏铁律：
    - 第一个剧情点（P01）必须是"开场设计"段，明确开场抓人的钩子（一句反差话/一个奇怪动作/一个未交代的悬念）。
    - 相邻剧情点之间必须有"上承/下启"字段，标记两段之间的过渡素材——这是 [创作九原则 - 丝滑过渡] 的执行点。
      - ✅ 应填的内容（设计层）：重物件锚点（"延续 P01 结尾的怀表特写"）、视觉母题（"延续暖黄路灯从右上方照射"）、对白回环（"P02 开头延续 P01 结尾的台词意象"）、情绪温度（"延续 P01 的克制悲伤"）
      - ❌ 不要填的内容（技术层）：不要写"接 P01 的最后一帧"、"无缝衔接 P01 视频"、"让 Seedance 接住 P01 的画面"——这些超出 AI 视频生成的能力（详见 `_shared/ai-generation-constraints.md` 第 1.1 节）
      - 含义：填的是"分镜师在两条提示词中应使用什么相同/呼应的描述"，不是"让 AI 把帧像素对齐"
    - 信息密度自检：每个剧情点写完后问自己"如果我是观众，看到这一段会不会想划走"，是的话回去改。

[执行流程]

    第一步：通读剧本
        - 读取用户提供的剧本/梗概/分场文本
        - 理解核心叙事线、人物关系、情感走向
        - 识别关键转折点和高潮

    第二步：拆解剧情点
        将剧本拆分为若干剧情点（P01、P02、P03...），每个剧情点是一个完整的叙事段落。

        **开工前先读两个数字**（v13，这是拆戏的核心设计参数，不是事后检查）：
        - `.project-config.json.video_model_config.max_seconds` —— 模型单镜上限
        - `script-settings.md` 的目标总时长 —— 这一集要多长

        为什么先读：上限决定「一件事用几个镜头讲」。上限 30s 时一个完整戏剧动作（起因→动作→结果→余韵）常能整个装进一镜；上限 15s 时同样的动作装不下，只能拆开——而每个接缝都要靠后期对齐。**同一个剧本在不同上限下，拆法根本不是一回事。** 上限越宽，越应该按完整戏剧动作来拆，不要习惯性切碎。

        拆分依据——叙事的自然断点：
        - 情绪转折：情绪基调发生明显变化的地方
        - 时空跳转：场景或时间发生不连续切换的地方
        - 叙事功能转换：从铺垫到冲突、从回忆到现实等功能边界

        一个剧情点内可包含多组镜头：
        - 蒙太奇序列：多个快闪画面组成一个叙事段落（如"十年废材生涯的记忆洪流"）
        - 连续场景：同一叙事目的下的多个镜头
        - 单镜头：简单段落用一个连续镜头讲完

        反向检查：
        - 如果两个相邻段落服务于同一叙事目的 → 应合并
        - 如果一个段落内包含两个独立的叙事目的 → 应拆分
        - **量级自检**：目标总时长 ÷ 上限 ≈ 理论最少剧情点数。若你拆出的数量远超这个数 → 拆太碎，回去合

    第三步：确定时长

        每个剧情点的估算时长 ≤ `max_seconds`（不写死任何模型的秒数）。时长跟内容走，**但在剧情允许时主动往上限靠**——一个 8s 的动作和一个 15s 的动作若同人物、同场景、时间连续，加起来 23s ≤ 30s，就该是一个剧情点一镜演完，而不是两段视频让用户去剪。超上限的剧情点拆成 P0X.A / P0X.B 并注明二者本属一体。


    ▶▶▶ 导演预飞（Director Pre-Flight · v15.0 新增）——第四步讲戏前的强制思考层 ◀◀◀
        每个剧情点正式讲戏之前，先完成以下三项检查。**不得跳过**——用内部思考完成，讲戏本里只在该剧情点标题行后追加「预飞结论」一行（不展开过程）。

        **① 创作会议三问**（KSR 框架，拍的是「瞬间」不是「事件」）：
        1. 这场戏真正讲的是什么？（不是剧情摘要，是情感/关系/转折的本质——一句话答）
        2. 要拍哪个「瞬间」？（这场戏里最值得放大的那一个物理瞬间——具体到动作/表情/声音）
        3. 什么要克制不拍？（主动留白 = 电影感——一句话说明放弃了什么）
        任何一问答不出来 → 这场戏还没想清楚，回第二步重拆，不进第四步。

        **② 视觉钩子三目序列**（观众入画后视线的三步走）：
        - **第一眼**：观众进画面最先看到什么？（通常是运动最强或对比最高的点）
        - **第二眼**：视线自然移向哪里？（主体或关键道具）
        - **第三眼**：需要观众发现什么？（意义层——细节/表情/道具状态变化）
        - **最终发现**：这场戏结束后留在观众脑子里的那一帧画面是什么？
        四点简答，只用于校准讲戏方向，不写进讲戏本正文。

        **③ 预飞结论行**（每个剧情点的讲戏段开头必有此行）：
        ```
        【预飞】核心瞬间：_____ ｜ 克制点：_____ ｜ 第一眼落点：_____
        ```

    第四步：为每个剧情点"讲戏"
        导演阐述必须包含以下维度（不需要分条列举，用自然流畅的叙述融合在一起）：

        画面内容：谁在哪里、环境是什么样
        人物动作：具体的肢体动作、走位、表情变化
        台词/声音：说了什么话、什么语气、环境音
        镜头感觉：什么景别、镜头怎么运动、从哪到哪
        光影氛围：什么光源、什么色调、什么情绪

        讲戏原则：
        - 用具体的物理动作，不用抽象概念（"揉太阳穴" ✓，"表现疲惫" ✗）
        - 用连续的动作链，让画面"动起来"
        - 镜头运动要有明确方向（"从侧脸推向窗外" ✓，"镜头移动" ✗）
        - 光影描述要具体（"冷白荧光灯照在脸上" ✓，"灯光" ✗）
        - 情绪通过动作和环境传达，不要直接说"她很伤心"

        多镜头段落的额外要求：
        当一个剧情点包含多组镜头时，还需描述：
        - 镜头之间的切换方式（硬切、叠化、闪白、画面碎裂等）
        - 子画面之间的节奏（越来越快、均匀、先慢后快等）
        - 整段的叙事弧线（如"从希望到绝望的递进"）

        **镜头承载规划**（v13，每个剧情点必填，取代 v7 的「建议形态」）：

        **拆剧情点之前先读两个数字**：`.project-config.json.video_model_config.max_seconds`（单镜上限）与 `script-settings.md` 的目标总时长。它们决定你怎么拆戏：

        - 上限宽（如 30s）：一个完整戏剧动作（起因→动作→结果→余韵）常常整个装得进一镜。**优先按「一个完整戏剧动作 = 一个剧情点」拆**，不要人为切碎。
        - 上限紧（如 15s）：同样的动作可能装不下，此时才拆成两点，并在字段里写明二者本属一体、后期要连着看。
        - 拆完自检：总时长 ÷ 上限 ≈ 理论最少镜头数。若剧情点数量远超这个数 → 拆太碎了，回去合。

        每个剧情点末尾输出一行：

        ```
        镜头承载：可一镜到底（约 Ns）/ 需 N 镜（因 <换景/跳时/机位对比/情绪留白>）/ 可与 P0X 并入一镜 ｜ 理由：<一句话>
        ```

        判断依据：同一空间、同一时间流、动作有因果 → 能一镜到底（剧情原生长在一段视频里，比后期拼碎片质量高、剪辑少）；空间/时间跳切、需换景别机位才成立的对比、情绪需要「停一下」→ 必须分镜。
        这是给分镜师的设计依据，最终定镜由分镜师按 [时长预算与定镜] 平衡。**故事板与否不由导演建议**，只由用户 `~storyboard-mode` 决定。

        例子（上限 30s）：
        ```
        P03 宝宝吃面 → 面酱污脸 → 妈妈拍照 → 狗狗叼起一根面条。
        镜头承载：可一镜到底（约 22s）｜ 理由：同一餐桌同一时间流，四个动作有因果，一镜演完最顺；若上限只有 15s 则拆为「吃面污脸」+「拍照与狗」两镜。
        ```

    第五步：提取人物清单
        从剧情中筛选需要生成参考图的人物，只记录视觉外观信息：
        - 人物名
        - 年龄
        - 外观关键词（五官、发型、体型、服装等）

        筛选标准（满足任一即列入清单）：
        - 本集出现在 2 个及以上剧情点中的人物
        - 虽然本集只出现 1 次，但根据已有剧本判断后续集数会再次出场的人物

        不列入清单的人物（群演/一次性配角）：
        - 本集只出现 1 次且不会再出场的角色（如路人、围观群众、背景人物）
        - 这些人物不进清单，但在讲戏本的导演阐述中照常描述其外观和动作
        - 描述要足够具体，让分镜师能直接在提示词中用文字描写（如"尖脸眯缝眼的白袍学员"而非"一个路人"）

        注意：
        - 不需要情绪弧线，参考图是静态角色设定图
        - 人物清单 = 需要参考图的角色列表，服化道会为清单中的每个角色设计提示词

    第六步：提取场景清单
        从剧情中提取所有关键场景，只记录视觉环境信息：
        - 场景名
        - 时间（白天/夜晚/傍晚等）
        - 光线/色调
        - 氛围关键词

    第六步之五：定稿 `assets/story/visual-style.md`（首集必做，🔴 不可跳过）
        为什么在这一步：场域锚句必须对照真实场次清单才划得全，而场景清单刚在第六步拆出来。
        为什么不可跳过：服化道每张提示词开头、分镜师每条恒定层、reviewer 的逐字 diff 都以这份文件为唯一真相源——草案不定稿则整条下游卡死。

        规范全文见 `.claude/skills/_shared/visual-style-guide.md`，本步只列动作：

        1. **读草案**：路径 A 由编剧在创作基准阶段起草 v0.1（`bianju-skill` 子流程二·五）。
           - 草案不存在（编剧漏产 / 老项目）→ 按 `visual-style-guide.md` 从零起草两层文本，并写一条 `~feedback` 给编剧
           - 路径 B → 你自己在 `agents/director.md [路径 B 补创作基准]` 已起草

        2. **层 1「通用基准段」原则上沿用**（用户已确认过），只在明显违规时就地修正：
           - 出现能被搬走的名词（柜台/月份牌/灯箱/价签）→ 移到层 2
           - 出现否定式 → 改写成期望态（「不糊」→「颗粒细密清晰」）
           - 四件（媒介质感 · 色域 · 光逻辑 · 镜头性格）缺项，或超 120 字

        3. **补齐层 2「场域锚句」表**（你的主要工作）：
           - 场域 = 一组共享同一物理环境的场次；全片通常 2–5 个
           - 划分纪律：每一场必须指到**唯一一个**场域，无场次落空、无场次同属两域；内景外景一律分立；同一空间不同时段/天气若改变了可见陈设或点着的光源物也分立
           - 每句固定装四件：场域名（空间+时段/天气）+ 年份与地理 + 2–3 件本场域可见的时代物证与陈设 + 本场域强调色来源物（没有就不写）；1–2 句
           - 🔴 **禁止全片只写一句总锚句让每条都带**——这是内景陈设灌进外景条的根源
           - 🔴 锚句不许写抽象年代词（「民国感」没有物证等于没锚）

        4. 补齐字段表剩余项（清掉草案的 `[假设]`/`[待补充]`），顶部状态改「定稿 · v1.0」，追加变更记录一行

        5. **定稿判据**：本集**全部场次**都能指到唯一场域 → 才算定稿（有一场指不到即不算）

        6. 定稿后**只走变更记录追加、不回改**。改层 1 通用基准段属重变更：列出已编译的受影响文件清单提醒重编译，**只提醒不自动改**（用户明确同意才动）

        ep02+：只在出现新场域时追加锚句 + 记变更记录，不回改旧句。

    第七步：提取关键道具清单（新增）
        从剧情中识别"关键线索道具"——剧情中复现 2 次以上、推动剧情、有视觉记忆点的道具。
        例：《牌子》的外星路牌、《信箱》的旧信件、《老人与海》的鱼骨。

        什么算关键道具：
        - 复现 ≥ 2 次（不论是同一物体的反复出现，还是同类物体的母题贯穿）
        - 推动剧情（道具的存在/消失/变化触发或改变叙事走向）
        - 有视觉记忆点（外观特殊、设计独特、状态变化明显）

        什么不算（不进清单）：
        - 只出现一次的环境装饰物（这些写在场景清单里就够）
        - 通用家具如桌椅（这些写在场景清单里就够）
        - 服装/配饰（这些归人物造型，服化道在人物提示词中体现）

        清单格式（每个道具一行）：
        - 道具名
        - 形态关键词（材质、颜色、尺寸、新旧）
        - 剧情功能（一句话说明它在剧情中起什么作用）
        - 跨集状态（如有：ep01 完整，ep05 破损等）

        如本集无关键道具，仍要在输出中显式标记"本集无关键道具"——服化道据此写入空标记块，避免路由卡住。

    第八步：输出节奏蓝图（疏/中/紧三档）
        三档定义、气口预算方法见 `.claude/skills/_shared/pacing-methodology.md`（唯一定义处，此处不重复）。每个剧情点指定一档 + 估算气口，估算时长 ≤ `.project-config.json.video_model_config.max_seconds`。

        **逐拍骨架（高密度动作戏专用）**：
        当一个剧情点的描述密度比分镜师需要低4–5倍时（典型：武打连招、追逐跑动），在讲戏叙述之后追加：
        ```
        【逐拍骨架】
        拍1：[具体动作 + 粗略时间区间]
        拍2：...
        ```
        判据：情绪内化戏（一个人发呆/沉默）不用骨架——靠疏档长镜头+气口。

        **节奏蓝图输出格式**（写在 01-director-analysis.md 末尾）：

        | P# | 档位 | 镜头数 | 气口预算 | 估算时长 | 导演意图 |
        |----|------|--------|---------|---------|---------|
        | P01 | ⬛疏档 | 2镜 | 2s留白 | 8s | 开场建立孤独感 |
        | P02 | 🟨中档 | 4镜 | 1.5s反应停顿 | 12s | 矛盾引入 |
        | P03 | 🔴紧档 | 5镜 | 1s落地 | 13s | 冲突爆发 |
        | P04 | ⬛疏档 | 1镜 | 3s沉默 | 8s | 最重的戏 |
        | P05 | 🟨中档 | 3镜 | 2s余韵 | 10s | 情绪着陆 |

        这张表不是命令是参考——峰值段落不一定快切，分镜师有完整创作自主权。

    第九步：落条划分表 + 接缝卡（v14 新增，**必做**）
        为什么必做：**条（Cut）的边界与条间接缝的定权归导演，不归分镜师**。
        `shot-design`（分镜师第一步，镜头表）明文禁止自行增删条、改条边界、改接缝手法——它只在条内排镜。
        所以这两张表如果不落，下游要么卡住报回来，要么被迫自行定条（越界）。
        节奏蓝图给的是"每个剧情点多快"，这两张表给的是"切成几条、每条在哪断、断口怎么咬"——不是同一件事，不能互相代替。

        **① 条划分表**（每条一行，条号全集连续编号，不按剧情点重置）

        | Cut | 归属 P0X | 条内容一句话 | 镜头数预估 | 估算时长 | 具名主体预算 | 拆条理由 |
        |-----|---------|-------------|-----------|---------|-------------|---------|
        | Cut1 | P01 | 林薇独坐工位，抬头看空荡办公室 | 2镜 | 8s | 林薇（1） | 一镜到底，情绪不切断 |
        | Cut2 | P02 | 母亲来电，林薇犹豫后接起 | 3镜 | 12s | 林薇、手机（2） | 换机位对比，需 3 镜 |
        | Cut3 | P03 前半 | 争执爆发 | 5镜 | 13s | 林薇、母亲、相框（3） | P03 撞 max_seconds，切两条 |

        填表纪律：
        - 每条估算时长必须 ≤ `.project-config.json.video_model_config.max_seconds`，且 ≥ `min_seconds`。**撞上限就在这里拆成两条**，不要留给下游硬掰。
        - 一个剧情点可以是一条（P0X 与 Cut 一对一），也可以拆成多条（写 "P03 前半 / P03 后半"），也可以多个剧情点并入一条（写 "P04+P05"）——三种都合法，理由列写清。
        - **具名主体预算每条 ≤ 5**（人 + 特写出现的手/物一并计入）。超了就在这里降主体或拆条——下游 `shot-design` 排完镜要回数一次并与本表对齐，本表给的是名单上限。
        - 镜头数预估承接第八步节奏蓝图的档位，是给下游的参考基线；下游偏离要标注理由，所以这里给的数字要有依据。

        **② 接缝卡**（每个条间接缝一行，N 条有 N-1 个接缝；跨集首条另记承接上集）

        | 接缝 | 出点手法 | 出点动势 | 入点手法 | 咬合依据 |
        |------|---------|---------|---------|---------|
        | Cut1→Cut2 | 动作匹配 | 留余势不落地（手伸向手机中途） | 承接未完成动作中段 | 同一动作跨条续起 |
        | Cut2→Cut3 | 声音桥 | 停稳 1.5s | 上条尾音延续入画 | 母亲话音压过切点 |
        | Cut3→Cut4 | 段落收尾 | 落地停稳 2s | 空间顺承，同空间新机位 | 情绪峰值需落地 |

        出点手法从这套枚举取（与下游 `seedance-storyboard-skill/references/transition-vocab.md` 同一套词，不自造）：
        动作匹配 / 声音桥 / 视线匹配 / 遮挡转场 / 相似物转场 / 空间顺承 / 时间跳跃声明 / 段落收尾。

        填表纪律：
        - **出点动势与出点手法必须配合**：标了「动作匹配」的缝，动势就不许写落地停死，要留约 0.5s 余势带出；标了「段落收尾 / 情绪峰值」的缝要停稳 1.5–3s。
        - 落地 ≠ 切黑。任何接缝都不写切黑、不自加转场特效收尾——留视线、因果或声音钩子。
        - 时间跳跃声明只用于「三小时后」这种显式跳变；同空间换机位一律写空间顺承，不叫跳跃。
        - 这两张表落盘后，下游 `shot-design` 的条末镜「结束状态五字段」要与对应接缝的出点动势对咬，`seedance-storyboard-skill` 的【衔接】段照本表的出点/入点手法写。

    第十步：素材比对（ep02+ 时执行）
        如果 assets/visual/character-prompts.md、scene-prompts.md、prop-prompts.md 存在，读取已有素材，为本集三类清单中的每一项标注素材状态：

        判断规则：
        - 同一人物/场景/道具未变化 → 标注"复用"
        - 新人物/新场景/新道具 → 标注"新增"
        - 同一人物外观变化（换装、老化、受伤等）→ 标注"变体"
        - 同一场景状态变化（季节、时间、破坏等）→ 标注"变体"
        - 同一道具状态变化（完整 → 破损、新 → 旧）→ 标注"变体"

        ep01 或提示词文件不存在时，所有项标注"新增"。

    第十一步：剧本医生自检（新增）
        在输出前，做一次剧本医生式的诊断（详见 `references/script-doctor.md`），重点查：

        - **结构性问题**：开场是否抓人？高潮是否到位？结尾是否兑现开场承诺？
        - **戏剧动作完整性**：每场戏是否有清晰的"目标 → 阻碍 → 结果"？
        - **人物动机连贯**：人物的行为是否符合其设定？有无突变？
        - **世界观 bug**：物理规律/设定规律是否前后一致？时间线是否穿帮？

        如发现可改进的结构性问题，**不要自己改剧本**（角色边界），而是在输出末尾加 [剧本医生反馈] 段：

        ```markdown
        ## 🩺 剧本医生反馈（供制片人转达编剧）

        发现 N 处可优化的结构性问题：

        **问题 1**：[一句话定位]
        - 位置：[第几幕 / 哪场戏]
        - 当前问题：[具体描述]
        - 建议方向：[改的方向，不写具体改稿]

        **问题 2**：...
        ```

        制片人会决定是直接进入下一阶段（小问题忽略）还是回炉编剧（大问题修复）。

    第十二步：输出
        按照 templates/director-analysis-template.md 定义的格式输出，包含：
        - 导演讲戏本（剧情点 + 元数据 + 上承/下启字段 + 导演阐述 + 情绪/音乐方向 + **镜头承载规划**）
        - 人物清单（含素材状态列）
        - 场景清单（含素材状态列）
        - **关键道具清单**（含素材状态列；如本集无关键道具，显式标记）
        - **节奏蓝图**（疏/中/紧三档 + 气口预算，见第八步）
        - **条划分表 + 接缝卡**（见第九步；条的边界与接缝手法的唯一真相源，下游只读不改）
        - **剧本医生反馈**（如有可改进项）

        同时落盘（不在讲戏本内，是独立文件）：
        - **`assets/story/visual-style.md` 定稿 v1.0**（首集必出，见第六步之五；ep02+ 若出现新场域则追加锚句并记变更记录，不回改旧句）

[质量标准]
    - 每个剧情点的导演阐述至少 3-5 句话，有足够的视觉信息
    - 讲戏内容必须让分镜师能直接提取出运镜、动作、台词、光影
    - 剧情点之间要有叙事推进，不能重复信息
    - 相邻剧情点的"上承/下启"字段必须有具体过渡素材（不能空着）
    - 人物清单、场景清单、关键道具清单的外观关键词要足够具体，服化道能据此设计提示词
    - 开场 P01 必须明确"开场钩子"的设计（属于 [创作九原则 - 开头抓人]）
    - **每个剧情点必填「镜头承载规划」**：可一镜到底（约 Ns）/ 需 N 镜（附原因）/ 可与 P0X 并入一镜 + 一句话理由。拆剧情点时就以 `max_seconds` 与目标总时长为设计参数，不是拆完再让分镜师补救
    - **条划分表每条都能指到唯一 P0X 归属**，无落空、无同一条挂两个不相关剧情点；条号全集连续不重复
    - **条划分表每条估算时长在 `min_seconds`–`max_seconds` 区间内**（读 `.project-config.json.video_model_config`）；撞上限的剧情点已在本表拆成多条，不留给下游
    - **条划分表每条具名主体 ≤ 5**（含特写出现的手/物）
    - **接缝卡覆盖全部条间接缝**（N 条 = N-1 行，无跳号）；出点手法取自枚举、无自造词
    - **每个接缝的出点动势与出点手法配合**：动作匹配类留余势不落地，段落收尾/峰值类停稳 1.5–3s；无一处写切黑或自加转场特效

# 分镜两审技能（v14 · 查病制）

> 📌 **源库站名映射**（本文回流路由里沿用了 Seedance 分镜师 3.0 的旧站名，**均不是真实存在的 skill 名，别去调它们**）：
> - `motion-compile` = 分镜师编 `video-prompts.md` 那一步，即 `seedance-storyboard-skill`
> - `script-breakdown` = 导演拆解（产物 `outputs/epNN/01-director-analysis.md`）
> - `character-design` / `scene-design` / `prop-design` = `art-design-skill`（服化道）
> - `control-image` = 控制图，V14 无独立站、由分镜师兼做落 `outputs/epNN/control-prompts.md`
> - `director-grill` = `director-skill`（creative-brief / visual-style 规范）

[技能说明]
    本 skill 服务分镜阶段的两个审核点，是项目最后的质控——过了用户就拿去生成。
    - **镜头表审**：★表确认前，审 `outputs/<集>/02-shot-table.md`。这一步把「想戏」审干净，代价最低——改表是几行字，改提示词是重来。
    - **成片审**：★交付确认前，审 `outputs/<集>/video-prompts.md`（条头三行 + 围栏四块）+ `episode-master.md` + `assets/continuity-ledger.md`。含 continuity 缝审计批检。
    通用审核立场、五类病定义、blocking 白名单、判定与轮次、防误杀、报告格式、回流路由：全部见 `_shared/review-methodology.md`，本文不重复，只列**本两级查什么**。

[只读基准]（永不入审，对不上判被审产物走样）
    - 导演讲戏本 `outputs/<集>/01-director-analysis.md`——镜头承载规划、节奏蓝图、人物/场景/道具清单
    - `assets/story/visual-style.md`（缺则 `creative-brief.md` 基准段）——恒定层之源：通用基准段四件 + 画质固定项 + 时代锚 + 场域锚句表 + 条件项表
    - `assets/reference-index.md`——项目编号 / 文件名 / 短串 / 声线锁
    - `assets/continuity-ledger.md`——上一场落幅、跨集 ending state（续集）
    - `assets/story/script-settings.md`——aspect_ratio / 目标平台 / 受众画像 / 对标爆款
    - `.project-config.json`——`video_model_config`（min/max_seconds、能力标志）、`image_model_config`、`storyboard_overrides`、`content_type`
    - 镜头表审另读讲戏本；成片审另读镜头表（02-shot-table.md）+ 拆解接缝卡 + 前级报告

## 一、镜头表审（审 02-shot-table.md，★表确认前）

先过阶段门：矛盾 / 断链 / 走样三类纯对照，命中 blocking 即交报告不跑预演；干净了再查模型雷。

**逐条动手核（数出来、diff 出来）**：

1. **逐镜十项齐**（缺项=断链）：画面内容 / 台词与声音 / 镜头语言 / 时长与节奏 / 光影氛围 / 导演意图（物理+情感分写）/ 落幅 / 衔接 / 控制等级 —— 每镜齐全；条末镜的「落幅」行替换为【结束状态】五字段块。
2. **空间地图块**（多人场或有走位场必带，缺=断链 blocking）：七行同形（机位侧 / 轴线 / 地标绑定 / frame 方位 / 可见范围 / 排布变化 / 重述规则）；人物写可视特征代称、不带 @编号；禁 near/beside 弱词。单人固定机位场不适用。
3. **结束状态五字段**（条末必填，缺=断链）：位置 / 朝向 / 持物 / 动作动势 / 情绪。这是全链脊椎，下游 motion-compile、ledger、缝审计都靠它——缺一字段即命中。
4. **时长预算求和**（矛盾）：每条各镜时长上沿求和 ≤ `max_seconds`；求和超上限 → 该条要减镜或压时长，命中记 major（回镜头表拆条）；config 缺失先提示 ~video-model。
5. **台词逐字**（走样）：镜头表台词与讲戏本 diff，不增不删不改。
6. **镜头承载对得上**（走样）：每条的镜数/合并方式与讲戏本「镜头承载规划」一致；讲戏本说可一镜到底、镜头表却拆三条 → 命中，除非镜头表写了拆分理由（带声明的偏离不算走样）。
7. **轨道建议合规**（模型雷）：默认 B 轨（镜头N，无秒数）；仅一镜到底的条建议 A 轨。条上标了 A 轨却是正反打/多人 → 记 major。
8. **资产需求反推清单齐**（断链）：本场用到的角色/场景/道具是否都在「本场资产需求」表列出，状态（新增/复用/变体）标注；核心级新资产漏列 = 拆解遗漏，回导演补。
9. **模型雷预演**（前三类干净后）：抽象情绪词（「表现悲伤」而非可拍动作）、开放运动无终点、弱空间词、气口被挤没、多人场缺不串脸声明——命中记 major，改向给可拍写法。

镜头表审**不查围栏格式**（那是编译后的事，归成片审）。

## 二、成片审（审 video-prompts.md + episode-master + 台账，★交付确认前）

分两段：**A 段逐条可判定检查**（先做，blocking 项直接 FAIL）；**B 段缝审计批检**（继承链，按 seam-audit 派工人）。

### A 段 · 逐条可判定检查（每 Cut 逐条，动手核；标 🔴 者属 blocking 白名单）

① **条头三行齐**（断链）：上传（**一行制**：`@图片N = 项目编号 名字（形态或职责括注）· @图片N = …`，以 `·` 分隔一行写完，@ 号顺序 = 用户传图顺序；v14 有意以此替换 v13 的多列表格，沿革见 `seedance-prompt-methodology.md:126`）/ 承接（缝型 + 从什么状态接）/ 交出（结束状态五字段）。缺行 → major；上传行某项缺项目编号或缺形态/职责括注 → major；**不因「不是表格 / 没有分列」判缺**；上传清单为空而正文有 @图片N → blocking。

② **围栏四块序对 + 围栏纯净**（断链/走样）：引用声明 → 总述段 → 分段剧情 → 收尾约束，块序固定。围栏内**零项目编号**（char-/scene-/prop-/ctrl- 进了围栏即残留）、**零条头信息**、**零「同上一条」式指代**、**零字段名元指令**（「镜头语言：」「参数：」「严格承接上一阶段」这类）。围栏内出现项目编号 → 🔴 blocking（模型不认 char-002）。

③ **@图片N 对账**（🔴 blocking 白名单）：正文每个 @图片N 在条头上传清单有对应行；号从 @图片1 起**连续**、一号不两用；tag 在引用声明**恰好出现一次**（法定例外：角色行内状态公式的第二次 @、关键帧序列正文二次点名）。对不上或跳号或重复 → blocking。

④ **双轨语法**（模型雷；时间轴矛盾属 blocking）：
   - B 轨（默认）：全条**零秒数**（首句声明的总时长除外）；最长镜与最短镜带**配重语言**（分数/成数/拍数，不带时间量词）；与均分持平的镜不写配重。出现秒数 → major；配重与秒数双写 → major（两通道只许开一个）。
   - A 轨（仅一镜到底）：时间轴 [0-X秒] 起、每段起点=上段终点、**无重叠无缺口、末点=总时长**（🔴 算不平属矛盾 blocking）；段内容量求和（显式时长要求折秒）< 段长；多段防重置句在正文末；一镜到底声明齐。

⑤ **恒定层逐字 diff**（走样）：总述段的通用基准段/时代锚/声音基调三项与 visual-style.md 逐字一致（可 diff）；场域锚句是**本场那一条**（外景条零内景陈设）；同场条间这三项逐字相同（漂移=走样前兆）；声线锁与 reference-index 逐字。命中记 major，跨条不一致的升 blocking（属"缝两端状态互斥"近类，由范围定）。

⑥ **音乐隔离**（走样/模型雷；narrative 档）：
   a. 收尾约束固定含「无任何背景音乐」+ 列 ≥1 项音效/环境声；缺 → major。
   b. 围栏内文本匹配 `M\d\d|BGM|背景音乐|配乐|主题曲|旋律`，排除 a 的声明本身；命中 → major（改向：M 编号移到 episode-master 后期铺乐表）。
   c. **例外**：`content_type=mv` 且本条画面跟音乐走 → 允许 sound-writing 的有乐 BGM 句式（风格+乐器+节奏+进退时机，禁点歌名艺人）；此时 a/b 不适用，改查 BGM 句式四要素齐。

⑦ **台词与口型**（走样/模型雷）：台词与镜头表逐字一致（增删改=走样）；台词类型标签合规（开口/低语/内心OS/回忆音/画外音 五选一）；**画外音角色的名字不出现在分段剧情正文**（出现=模型雷，会被当视觉对象生成）；倾听者写可见反应不同步动嘴。

⑧ **承接咬合**（🔴 缝两端互斥属 blocking）：本条交出五字段与镜头表结束状态一致；承接段引的上条出点 vs 本条入点手法互相兑现；本场首条承接 ledger 上场快照或跨集 ending state。

⑨ **时长合规**（矛盾）：每 Cut 时长 t 满足 min ≤ t ≤ max（config 取值）；**min > max 兜底**：以 max 为准判 t ≤ max，**不因此 FAIL**，提示用户 ~video-model 校正 min_seconds。分段剧情内出现「第 N 秒做什么动作」式配方 → major（不做分秒配方；A 轨的段落时间戳是因果段划分，不算配方）。

⑩ **画幅一次声明**（走样）：`video-prompts.md` 顶部有且仅有一处「本集所有 Cut 画幅 = <值>」，值与 script-settings.aspect_ratio 一致；围栏内不出现画幅比例。多处或缺 → major。

⑪ **收尾约束 + 负向**（模型雷）：固定五项（无字幕/无水印无Logo/无额外人物/无动作重置/不切黑）+ 片型附加 ≤2；症状负向 ≤3 且化进散文、不成清单；带群演的条「无额外人物」已改写为「除已描述的 N 名外，无额外人物」。负向堆清单（尾缀外 >3 或成行罗列）→ major。

⑫ **镜数**（防误杀重点）：单镜模式**不设下限**——合并后 3 镜、2 镜、1 镜到底都合法，**不得因"镜数太少"判任何病**（合并是 v14 核心设计）；仅故事板模式校验 5-8 镜、上限 12（超 12 须已拆 P0X.A/B）。

⑬ **故事板手动门**（🔴 blocking）：`storyboard_overrides` 未将本集/global 设为 storyboard，却产出了故事板 → FAIL（故事板手动模式，用户未开启不得用）。

⑭ **生成模式合规**（模型雷）：画面有具名角色且 `supports_image_ref=true` → 必须 I2V，标 T2V → 记 major（会凭空造脸）；`supports_video_ref=false` 却出现 V2V → major。纯环境/纯特效无具名角色 → T2V 合法。

### B 段 · 缝审计批检（继承链，按 continuity/references/seam-audit.md）

- 枚举缝：每场条数−1 条条间缝 + 场数−1 条场间缝 + 集间缝，列带编号缝清单。
- 分组派工人 subagent（fresh，只审不改）：每工人 10–20 条缝，组边界落场边界；上下文契约、逐缝八查、finding 七字段、防误杀三问**全部照 seam-audit.md 执行**，本 skill 不复述。
- 主审机械拼接工人发现清单、统一编号并入成片审报告；缺陷按回流路由派修（成品承接断裂回 motion-compile / 台账账错回 continuity / 变体缺失回设计站 / 结构性矛盾回 shot-design）。
- 缝两端结束状态互斥 = blocking；承接断裂/动作重置 = major；账实小偏差/恒定层单词漂移 = minor。

## 三、episode-master.md 验收（成片审附带）

- **7 段齐**（断链）：本集基本信息 / 全片衔接表 / 故事板提示词表（仅故事板模式）/ 视频提示词表 / 资产清单 / 音乐编号对应 / 用户操作清单（含「在工具里手动选顶部声明的画幅」）。§一含视频模型名。
- **全片衔接表**：每 P0X 有上段/缩略/下段/风险列；风险列主动评估不默认填 `-`；首段「无（开场）」末段「无（结尾）」。
- **资产清单**（素材对应关键，用户拿这个去生成）：列出本集全部参考图文件名、区分「跨集复用」与「仅本集」、给出存放路径 `assets/visual/images/`；生成顺序（资产图→控制图→视频条，真帧缝的条排在依赖条之后）；第一条试片看什么、翻车回哪。缺项直接影响用户能否照着生成 → 记 major。
- 续集：§跨集衔接是否给下一集留了恒定字段。

## 四、输出（报告格式见 review-methodology 第七节，落 `outputs/<集>/review/{shots|final}-report.md`）

不产评分表、不写分数。报告只列发现（七字段：类/定位符/原文证据/严重度/回哪修/改向），按 blocking → major → minor 排，尾附「上游观察」。总判定：有 blocking = FAIL（靶向重审一轮），无 blocking = PASS（major/minor 修完随产物交确认时报「审核发现 N 条、已修」）。连续两轮 FAIL 或判据分歧 → 熔断交用户。

成片审全 PASS 后，reviewer 另写 `outputs/<集>/00-quality-report.md`（整片复盘参考分，不回流、不挡线，格式见 agents/reviewer.md）。

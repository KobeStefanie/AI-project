# 视频就片修复母版

## 使用说明

- 视频就片修复母版，出口 2 用。按症状选智能编辑、高级编辑、视频延长之一填空，{{}} 内为填空位，按本条实情填，用不到的档整块删除；指令原文交用户在生成侧执行。
- 每次执行记版本注记：[vN · YYYY-MM-DD · 症状：{{一句}} · 出口：2 · 工具：{{智能编辑/高级编辑/延长}} · 指令一行]。

## 智能编辑母版

```
轻量版 · 单点小改：
    {{删除/替换/增加/改成}}{{对象，一次只一个}}，{{变化描述：目标状态，删除时必须写填补物}}，{{生效时序，三选一}}
        全片统一修改保持一致
        仅在第 {{X}}–{{Y}} 秒期间发生变化
        从第 {{X}} 秒起逐渐显现
    其余保持不变。
满配版 · 对象与前后帧关系复杂时：
    保持【人物身份、服装、背景、摄影机运动、光线、色彩、声音和其他区域】完全不变。
    仅修改【第 {{X}}–{{Y}} 秒】内画面【区域或对象：{{填}}】。
    将【错误状态：{{填}}】修正为【目标状态：{{填}}】，严格参考【@资产编号：{{填}}】的【具体职责：{{填}}】。
    修正后的对象必须与前后帧在【位置、尺度、材质、光线、运动速度、遮挡和边缘】上连续，不闪烁、不变形、不污染相邻区域。
```

## 高级编辑母版 · 带标注，针对生成后视频

```
将【标注方位，四选一：红框内/沿红色箭头指向的区域/地标点处/红线左侧或右侧】的【对象：{{填}}】{{删除/替换/增加/改成}}【目标状态：{{填}}】，【生效时序：{{填}}】，【锁定项：位置、亮度、画面其余部分】保持完全不变。
```

标注与文字必须互相印证——画了框，文字里仍要复述方位与对象。

## 视频延长母版

前置核对：底片 ≤ `max_seconds`？本次延长在 `min_seconds`–`max_seconds` 内？（两值取 `.project-config.json.video_model_config`）累计不超 60s（平台延长链机制上限）？只写新增段——原片不受延长提示词控制。

```
{{向前延长/向后延长}} {{N}} 秒：承接【原片落幅状态，从该条【结束状态】五字段抄：位置、朝向、持物、动作动势、情绪：{{填}}】，【新增段动作因果链：触发 → 动作 → 物理反馈 → 声音：{{填}}】，【新落幅：停在什么状态：{{填}}】。要求延长自然、动作衔接流畅、动作衔接自然，禁止生硬切镜、禁止物体凭空出现。
```

延长完成后：新落幅写回该条【结束状态】，更新 assets/continuity-ledger.md。

## BGM 分离母版

```
请将@视频1中的背景音乐全部移除，只保留【人声或环境声：{{填}}】。画面必须保持完全一致。
```

防复发：该条恒定层声音基调补"无任何背景音乐"，见 sound-writing。

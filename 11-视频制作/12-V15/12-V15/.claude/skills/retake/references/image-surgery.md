[定位]
    图像手术式编辑册，图支路出口 2 与出口 4 用。本册属于图像规则集，对象是已生成的资产图与控制图。
    核心信条：编辑 = 原图的后处理——原图是底，改动最小化，其余像素级保留。
    可填空母版见 templates/image-edit-template.md。

[图像规则集声明 · 本支路生效，禁带入视频支路]
    - 图像生成提示词：无负面参数——任何模型都没有负面参数，NOT 堆叠会把被禁概念本身注入画面；只写想要的，"clean dry skin" 而非 "no acne"；紧凑散文打败长文堆砌；纯正向。此规则集由资产站 character/scene/prop-design 与 control-image 持有，重生成时回那里。
    - 图像编辑提示词是本册主场，有两条例外：1 显式删除是合法操作，如 "Remove the lamppost" 移走路灯，但必须配填补物，如 "continuous brick wall behind" 背后是连续砖墙——只删不填，模型自己发明填充物；2 CHANGE 与 PRESERVE EXACTLY 这类结构化大写块仅编辑提示词可用，生成提示词禁用——生成用连贯散文。

[手术式编辑骨架]
    编辑链通用骨架，中英两式逐块对应，项目语言默认中文；母版本体的全库唯一权威版在 character-design 的 variant-and-crowd.md，本节是它在图支路的展开式。
    中文块，可整块抄：
        编辑这张图：{{一句话目标——改什么、为了什么}}。
        改动：{{唯一要变的那一处，描述到精确：位置、对象、目标状态}}。
        严格保留：
        - {{穷举一切必须保持一致的元素——脸、服装、道具、位置、墙面地面、机位角度、既有阴影}}
        - 调色、色板、对比度、颗粒、光衰减
        只改{{重申那唯一一处}}，其余部分百分之百一致。
    英文原句：
        Edit the image: {{one-line goal}}.
        CHANGE: {{only the single thing that changes, described precisely}}.
        PRESERVE EXACTLY:
        - {{list every element that must stay identical: face, clothing, props, positions, wall/floor, camera angle, all existing shadows}}
        - Color grade, palette, contrast, grain, falloff
        ONLY CHANGE: {{restate the one change}}. 100% identical otherwise.
    三铁律：
        - 一次一改，one change at a time：要改三处 = 三轮编辑，逐轮验收。
        - 删除配填补：每个"删掉{{X}}"必须跟"背后或原位是什么"。
        - "用户说你改多了 = 你锁得不够"——Lock everything, change one thing，锁死一切、只改一处。PRESERVE 清单写得越穷举，编辑越干净。

[判据卡 · 编辑 vs 重建]
    怎么认：
        底子成立、只动一处 → 编辑；结构、身份、构图、画风这类整体属性要动 → 重建，"需要重建的帧不是编辑"——回 character/scene/prop-design 或 control-image 重生成。
    认错长什么样：
        对整体崩的图连做多轮编辑，每轮引入新瑕疵、越修越花。
    典型例子：
        场景板混进一辆现代轿车 → 编辑，删 + 填补路面延续；场景板整体正面平视、无纵深的「墙纸感」 → 重建，回 scene-design 按 3/4 视角规则重出。

[纹理修复通道 · 质感假但图成立时]
    怎么认：
        症状是 AI 蜡感——皮肤无毛孔、织物无织纹、表面无尘埃划痕，而构图、身份、光线都对。走「只修表面」的编辑：CHANGE 只列表面项，如 skin pores 皮肤毛孔、fabric weave 织物织纹、surface dirt and wear 表面尘埃与磨损；PRESERVE 锁构图、身份、五官、光线、调色全部。
    认错长什么样：
        在纹理通道里夹带点位修改、顺手把道具也改了——纹理修复绝不做点位编辑，点位编辑另开一轮手术式母版。

[delta 变体制作法 · 状态变体 = 编辑产物]
    怎么认：
        角色、场景、道具的新状态——湿身、带伤、战损、夜版——不重跑底图：拿原表只改变化的部分，如换衣、加伤痕、打湿布料，其余像素不动。
        底图永不整体过第二遍模型，皮肤纹理与身份才能存活——"The base image stays the same pixels."（底图保持同一批像素。）
        产物登记：新变体 char/scene/prop-NNN-vN 写入 assets/ 对应文件 + reference-index，永不覆盖原版；命名可叠状态注记，如 v2 = 湿身。
    认错长什么样：
        为加一道疤把整张角色表重新生成——新表是"另一个很像的人"，全片一致性从此裂开。
    典型例子：
        char-003 需要「第三幕带伤」版：手术式编辑在原特写与全身格加左眉骨挫伤与领口血渍，PRESERVE 锁五官、发型、服装其余部分、光线、中灰底，登记 char-003-v2。

[改输入手段 · 出口 4 的图侧做法]
    怎么认：
        视频侧纯 prompt 怼不动的反物理与特殊姿态，把物理烤进输入图，再放松 prompt 只钉锚点：
        - 倒置图：需要倒吊或倒挂镜头 → 把角色表或关键帧整体倒转后作输入——prompt 精调常常全败，倒转输入图一次解决；倒转图从此登记为该角色的 inverted 状态变体。
        - 预摆姿态：需要特定开场姿态 → 用手术式编辑把关键帧里的人物改到目标姿态，如 mid-swing 挥拳中段，以图定姿、以词定动。
        - 状态烤入：视频保不住的属性——湿透、覆雪、破损——做进输入变体图，视频提示词侧连提都不提。
    认错长什么样：
        改了输入还写满帧物理描述提示词——物理已在图里，词只需钉关键锚点 + 运动因果，写满反而引入冲突。
    典型例子：
        倒吊审讯镜头：char-005 表倒转 → 登记 char-005-v3 即 inverted 态 → 视频条只写"镜头缓慢环绕，他悬垂的手指轻微晃动"，一次过。

[垫图话术与工具边界]
    - 垫图迭代话术：明确说保留什么、只改哪一两个元素，如"以这张图为底，保留构图、人物与光线，仅把背景霓虹改为暖黄路灯"，迭代式微调，不整段重写描述。
    - 站位图与图解类控制图的改稿两规则——回喂原始帧不喂上版图解、色键动作口令改稿——单源住在 control-image 的 staging-diagram.md，控制图返工先读那份，本册不复制。
    - 工具无关性：以上母版与纪律适用于任何支持图像编辑的工具，即梦平台的图片编辑等 web 工具均可；指令原文交给用户在生成侧执行；编辑结果与原图并排对照验收，PRESERVE 项逐条扫。

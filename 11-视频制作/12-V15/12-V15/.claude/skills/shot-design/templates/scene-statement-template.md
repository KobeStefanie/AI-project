# 场阐述母版与标杆

## 使用说明

- 场阐述 = 讲戏的蒸馏版。讲戏是导演讲给自己听的内部锚定——【导演思维】第 2 问的内化步骤，过程不外显；场阐述是蒸馏给用户看的结果，放在每场镜头表最前。
- 表确认先扫它——方向不对，用户说"这场重讲"，回内部讲戏重来；方向对了才逐镜看表。
- 一段成文，散文不列表、删无可删。五件事都要在段内出现，顺序可调。{{}} 内为填空位；「写作要点」与「认错清单」是填写指引，不进产物。

## 五件事清单

1. 功能：这场在整集里干什么——推进什么、翻转什么、埋什么。
2. 拍法：视听策略一句——节奏形态即几条什么档、景别策略即贴脸还是留距离、机位策略即谁的视角。
3. 戏眼：峰值在哪个瞬间、它的物理形态是什么、为什么是它。
4. 气口：留白与 hold 留在哪、买什么。
5. 交出：场末状态与给下一场的钩子。

纪律：具体物理动作不用抽象概念；不复述剧情——用户读过剧本，讲"怎么拍"不讲"发生了什么"；不堆镜号，那是表的活。

## 场阐述母版

```
这场是{{功能：在整集里干什么}}。我打算{{拍法：几条什么档 + 景别机位策略}}。戏眼在{{戏眼：哪个瞬间 + 它的物理形态}}，{{为什么是它}}。气口留在{{气口：哪里停、停多久、买什么}}。收在{{交出：末状态 + 给下一场的钩子}}。
```

## 填好的标杆

```
这场是全集第一次正面交锋——他必须当掉表，又不能让掌柜看出他急，价一压，弱势就现了形。我打算三条走完：对白条贴着两张脸打正反打，景别压到近景，让每个微表情都算数；动作条只拍一件事——表脱手、他扑抢；末条放疏，给他一个人站在门口。戏眼在怀表滑过玻璃柜面、他整个人扑上去攥住的那一瞬——前面全部的克制都是为这一下失态蓄的力。气口留两处：掌柜报价后他一秒不接话的 hold，和推门前的静场，都在买"他在咽这口气"。收在他背抵门框、表攥在胸口、视线回投柜台——下一场他去黑市，这一眼就是动机。
```

## 写作要点

1. 母版只定五件事的落位，措辞照自己的话讲、连成一口气。
2. 写完自检：段里有没有一个抽象词没被物理形态兜住。

## 认错清单

- 写成剧情复述："他进了当铺，掌柜压价，他夺表离开"——这是剧本不是阐述。
- 写成形容词堆："压抑而克制的一场戏"——压抑长什么样没说。
- 写成列表：五件事各一行是表格思维，讲戏是一口气的判断。
- 把讲戏过程原样倒出来：蒸馏失败——阐述是结论，不是思考记录。

# 📖 凯凯项目 · 用户操作手册 v14.0

> 给**你**看的；`CLAUDE.md` 是给 AI 团队看的。按需查阅即可。

---

## 1. 这是什么

6 个 AI agent（编剧 / 导演 / 服化道 / 音乐总监 / 分镜师 / 审核专员）从**选题或剧本**出发，协作产出三套可直接使用的提示词：

- 🎬 **视频提示词** → Seedance / 可灵 / Runway / Veo（每个镜头一条，附上传清单）
- 🎨 **参考图提示词** → Nano Banana / 即梦 / Midjourney（角色 / 场景 / 道具各一张）
- 🎵 **音乐提示词** → Suno（音乐在剪辑时后期铺，不进视频）

你只需要：放素材 → 输入指令 → **看镜头表确认** → 拿提示词 → 去 AI 工具生成 → 按说明剪辑。

> 🆕 **第一次用？输入 `~onboard`**，我会一条龙带你走完「放什么 → 我问什么 → 你拿到什么 → 去哪生成 → 翻车怎么办」。

**v14 你会直接感受到的变化**：
- **分镜先给你看表，再写提示词**：`~prompt` 第一步出 `outputs/<集数>/02-shot-table.md` 镜头表，你指着镜号说「第 3 镜太碎，并进第 2 镜」，改完确认才编译。**改表是几行字，改提示词是整条重来。**
- **提示词长相变了**：条头三行（`上传` / `承接` / `交出`）给你看，下面围栏里的整段给模型读。**传完图，围栏整段复制粘贴即生成，不用再挑哪句该删。**
- **生成完不对劲有地方报修**：`~retake`，说清「哪条 / 哪不对 / 抽了几次」，我判是改词、局部编辑、换镜头、改参考图，还是回上游重来
- **跨集不忘事**：`assets/continuity-ledger.md` 记着谁现在什么状态、哪根线还没收——窗口关掉也不丢
- **审核不再打分**：改成找五类硬伤（矛盾 / 断链 / 走样 / 模型雷 / 红线），只有真会翻车的挡线；连两轮不过就摆给你裁决，不无限自转

**v13 的这些继续有效**：
- 启动时问你用哪款视频模型、单段最长几秒——之后每个镜头都以这个数为上限，按剧情需要定长，**能合并成一镜的就合并**（Seedance 2.5 填 30，2.0 填 15）
- 镜头内不写 `[0-3秒]` 这类时间戳（模型不会真按它分配时长），多镜头段落用 `镜头01`/`镜头02` 分段
- 每条提示词都写明「无任何背景音乐，只有音效」，拼接时不会撞音乐；音乐只由音乐总监单独做、剪辑时整条铺
- 提示词不求长——参考图已经交代的长相和场景，不再用文字重复一遍
- 可以说「我要芬奇的调子」，全片色彩就按真实电影取色的 HEX 走（`~color`）
- 默认不做故事板、参考图默认一张一张出，不会再默认给你九宫格

> 一句话立场：AI 把执行成本压到几乎为零，省下的时间请全部花在**构思故事和分镜**上。技巧会被模型进步吞掉，故事不会。

## 2. 首次启动会问什么

| 问题 | 为什么 | 答不上来怎么办 |
|---|---|---|
| 介入模式 1/2/3 | 决定阶段间停不停 | 回车 = 2 关键节点 |
| 内容类型（叙事 / MV / 纯视觉） | 决定走哪套流程：叙事走五阶段，MV 音乐先行，纯视觉无编剧 | 回车 = 叙事类 |
| **档位（全装 / 轻装）** 🆕 | 精品微电影 / MV 走全装（五审核点、严谨度拉满）；短剧 / 漫剧 / UGC 走轻装（只派资产审 + 成片审，快） | 按内容类型自动拍板，不确定就让我定 |
| 视频工具 + 单段最长秒数 + 支持哪些参考输入 | 秒数是全流程唯一时长上限；能力标志决定上传清单 | 秒数看工具界面的选项；其他填「不知道」 |
| 生图工具 + 布局 | 默认单张，防九宫格 | 回车 = 单张 |

以后用 `~mode` / `~video-model` / `~image-model` 随时改。

## 3. 分镜两步制：先看表，再要提示词 🆕

输入 `~prompt ep01` 之后不会立刻给你提示词，而是：

```
第 1 步：我出镜头表  outputs/ep01/02-shot-table.md
   每场一块：空间地图 + 场阐述 + 逐镜十项（运镜 / 站位 / 表演 / 光 / 声…）
   每镜末尾一行「结束状态五字段」：位置｜朝向｜持物｜动势｜情绪
   ↓
第 2 步：你确认 ★
   · 「第 3 镜太碎，并进第 2 镜」——指着镜号说就行
   · 「P02 这场重讲」——整场重排
   · 「Cut 5 要控制图」——点名要
   · 没问题就说「确认」
   ↓
第 3 步：我才编译 video-prompts.md + episode-master.md
```

**为什么要多这一步**：镜头表上改是几行字，提示词上改是整条重来。**镜头数在镜头表里钉死**——两处数字打架时以 `02-shot-table.md` 为准，要改镜头数只回这里改。

## 4. 提示词怎么用（最重要）

```
第 0 步：读 outputs/<集数>/episode-master.md
   镜头总数、剪辑顺序、每镜要传哪些图、音乐铺在哪几镜

第 1 步：生参考图
   assets/visual/character-prompts.md / scene-prompts.md / prop-prompts.md → 生图工具
   每条提示词一张图，按提示词里写的文件名保存（character-林晓.png 这样）

第 2 步：生视频
   outputs/<集数>/video-prompts.md → 视频工具
   · 顶部有一行画幅声明，在工具里手动选这个画幅
   · 每个 Cut 长这样：

       Cut 3 ｜ P02 ｜ 8s          ← 标题
       上传：@图片1 = char-002 林晓  @图片2 = scene-005 病房夜  ← 条头，给你看
       承接：遮挡缝，从 Cut 2 的门框擦过接
       交出：位置 床沿右｜朝向 面向窗｜持物 空｜动势 起身中｜情绪 强撑
       ┌────────────────────────────  ← 围栏，给模型读
       │（整段文字）
       └────────────────────────────
       🎵 后期铺乐：M01 主题曲，铺在 Cut 3-8    ← 注脚，给你看

   · 操作：按「上传」行的顺序拖图（@图片1 就是你传的第 1 张）→ **把围栏里的整段复制粘贴**
     → 选时长（标题里写了）→ 生成
   · 🔴 条头三行和 🎵 注脚**不要复制进工具**——它们是给你看的
   · V2V 的 Cut 把上一段视频拖进视频槽（「承接」行会写明是哪种缝）

第 3 步：音乐（可并行）
   assets/music/music-design.md → Suno（复制 ━━━ 之间的内容）
   assets/music/music-recommendations.md → 音乐平台搜现成的

第 4 步：剪辑
   按 episode-master.md 顺序串接 → 视频本身没音乐，把音乐整条铺上 → 成片
```

**关键技巧**
- **上传顺序就是编号**：@图片1 = 你传的第 1 张。每条从 1 数起，别按上一条的顺序传
- 视频提示词里已经写了「无任何背景音乐」——如果工具还是生出了音乐，在工具里关掉配乐选项
- 同一提示词生成 3–5 次选最佳。**概率波动不是提示词缺陷**，先 re-roll 再改词
- 参考图必须真的传上去，否则角色一定漂
- 歌词三版要选一，回复字母即可

## 5. 生成完不对劲：`~retake` 🆕

输入 `~retake`，我会问三件事：

```
① 哪条 / 哪张？        （Cut 编号，或哪个角色/场景图）
② 哪不对？             （第几秒 / 哪个部位 / 什么现象——越具体越准）
③ 已经抽了几次？改过几版词？
```

然后判到五个出口之一：

| 出口 | 什么时候走 |
|---|---|
| **改词**（单变量） | 抽 0–2 次、问题局部 → 只改一处再试 |
| **就片编辑 / 延长** | 大部分对、只有一小块坏 → 局部编辑而不是整条重生 |
| **换 shot** | 抽了十几次还不过 → **问题在镜头设计不在词**，回镜头表改这一镜 |
| **改输入** | 反物理 / 一致性崩 → **先查参考图，改词是错方向** |
| **回上游** | 剧情或造型本身有问题 → 指名派给导演 / 服化道 |

三句判据背下来能省很多抽卡：
- 一致性崩优先查参考，改词是错方向
- 反物理先改输入
- 改不动先 re-roll——概率波动不是提示词缺陷

## 6. 色彩锚（可选）

```
~color 芬奇            → 全片按芬奇六色 HEX 走（写进创作基准）
~color D082            → 同上，用编号
~color                 → 看当前锚
「我想要冷调悬疑的感觉」→ 制片人推 3–5 位候选，你认领
```
**v14 改成三级判定**：点名 → 取色卡；**不点名 → 我先查索引推 2–3 位候选给你认领**（不再默默即兴）；你明说「自由创作」→ 才自由，且写进设定，之后不再反复追问。已生成的提示词不会自动重写，需要统一时说一声。

## 7. 故事板（默认关闭）

默认全部单镜模式。确实需要「一张故事板大图生一段视频」时：
```
~storyboard-mode storyboard ep01      开启本集
~storyboard-mode single-shot ep01     关回
~storyboard-style cinematic_realism   锁风格（仅故事板模式）
```
故事板把角色/场景/分镜挤在一张图里，任一处漂移整段废，所以不作默认。

## 8. 多集项目

第 2 集起团队自动判断人物/场景是新增、复用还是变体。全复用的集也会写一个空标记块保证路由。
**跨集不忘事靠 `assets/continuity-ledger.md`**（连续性台账）：谁现在什么状态、剧情走到哪、哪根线还没收，全记在这里。它是**追加式、永不回改**的——发现记错了追加一条更正，不改旧记录。
重做某集某阶段：删掉对应产出（见下表）再输入对应指令。

| 想重做 | 删什么 | 然后 |
|---|---|---|
| 导演 | `outputs/<集>/01-director-analysis.md` | `~start <集>` |
| 服化道 | `assets/visual/*.md` 里的 `## ep<集>` 块 | `~design <集>` |
| 音乐 | `assets/music/*.md` 里的 `# ===== ep<集> =====` 块 | `~music <集>` |
| **只重排镜头** | `outputs/<集>/02-shot-table.md` | `~prompt <集>`（会重走两步制） |
| 分镜提示词 | `outputs/<集>/video-prompts.md` + `episode-master.md`（+ `storyboards/`）**保留镜头表** | `~prompt <集>`（拿镜头表直接编译） |

## 9. 故障排除

| 现象 | 原因 | 解决 |
|---|---|---|
| 视频里人物不对 | 参考图没传或传的顺序不对 | 按「上传」行的顺序重传；@图片1 = 第 1 张 |
| 视频自带了音乐 | 工具忽略了声明 | 工具里关配乐选项；重生 |
| 视频画幅不对 | 没在工具里手动选画幅 | 看 video-prompts.md 顶部声明，工具里选它 |
| 模型跑偏 / 多演了内容 | 把条头三行也粘进去了 | **只粘围栏里的整段**，条头和 🎵 注脚是给你看的 |
| 镜头太碎 / 太长 | 镜头表分镜不合适，或上限没填对 | 在 `02-shot-table.md` 上指镜号合并；或 `~video-model` 改 max_seconds 后重跑 |
| 同一条抽十几次还不过 | **问题在镜头设计不在词** | `~retake`，我会判到「换 shot」，回镜头表改这一镜 |
| 一致性崩（脸/衣服变了） | 参考图问题 | `~retake`，优先查参考图——改词是错方向 |
| 场景图出成了九宫格 | 提示词里有宫格字样 / grid_mode 不是 single | `~image-model` 确认 single；让服化道重出 |
| 审核反复不过 | 上游确有问题 | 看 FAIL 的病症针对性改；连两轮不过我会摆给你裁决 |
| 进度卡住 | 缺分集标签 | 检查 assets/ 下该集 `## epXX` 标签 |
| 想完全重来 | 项目跑歪 | 删 script/、outputs/、assets/ 内容（保留 .gitkeep 和 reference-index.template.md） |

[任务]
    把已过表确认的本场镜头表，编译成 Seedance 2.5 可直接执行的动态提示词成品。条 = 一个生成单元 = 一条提示词，上限 30 秒；每条成品是一份「镜头合同」——可以直接交给摄影、演员、动作组、声音组和生成模型共同执行的指令，而不是文学描写、灵感提纲或关键词列表。合同的标准：时间连续、资产稳定、空间明确、表演可见、动作可执行、声音同步。
    本站是编译器，不是创作者。创作决策全部在上游完成。本站做确定性转换——不改写故事、不增删镜头、不机械扩写，只把上游决策翻译成模型跟得住的语言。
    产物落盘 06-motion-prompts/epNN-motion-prompts.md，按场分节、逐条编号 epNN-sXX-cN。本场编完即达标；全集编完在 06 文件头部补「生成顺序与校准」小节并触发成片审——审由你派发，不由本站自派。
    规则集声明：双规则集隔离——本站只持视频规则集，负向可用但症状驱动 ≤3、块序优先，即块的顺序即优先级，空间先于风格、光学先于美学；图像规则集——无负面参数、纯正向——属资产类 skill，两套规则互相投毒——"The rules of one job poison the other."（一条链路的规则会毒害另一条。）禁止串用：不把图像链路的措辞纪律带进视频条，也不把视频负向语法带回资产提示词。

[第一性原则]
    本环节是【导演思维】第 4 问「可生成性」的展开：把上游全部创作决策翻译成 Seedance 2.5 跟得住的语言——followability ＞ completeness，模型跟不住的细节宁可删，不硬塞；删的是模型跟不住的，不是该有的密度。
    编译器心智：一条高质量提示词不是"描述一个漂亮画面"，而是定义一个随时间变化的视听世界。它必须回答六问：什么不能变 / 什么会变 / 变化为什么发生 / 何时发生 / 观众每一时刻看哪里 / 这一段如何结束。缺任何一项，模型就用默认想象补空白——提示词的目标是只在需要模型创造的地方给它自由，在必须稳定的地方取消歧义。
    恒定层/可变层编译法：每条提示词是孤岛，模型无记忆——"Describe everything, every time."（每次都把一切描述一遍。）恒定层——通用基准段 + 本场场域锚句 + 时代/世界锚 + 人物短串 + 画质固定项 + 空间地图块 + 声音基调——一次装配、场内逐条逐字注入，一个同义词都不换：换措辞就扩大采样范围导致漂移。两层分工是硬的：通用基准段管媒介质感 / 色域 / 光逻辑 / 镜头性格，跨场复用；具体陈设与时代物证住场域锚句，按本场场域取用——外景条只带外景锚句，内景陈设一个字都不许跟进来："The room you describe is the room it builds."（你描述哪间屋子，它就盖哪间屋子。）在院子戏里正向写一遍柜台，模型就在院子里长出一个柜台。可变层 = 每镜增量，只写本条独有的动作、运镜、光效与声音。这一层解决词预算，也解决跨条漂移。
    声音写入文字：声音四要素——台词 + 语气声线 / 音效绑动作 / 环境声 / BGM 指令——全部在分镜正文就地写入提示词文字，不设任何独立音频生成或后期补声通道。声线锁自 reference-index 逐字引用。四要素句式与口型纪律详 sound-writing 的 SKILL.md。
    结束状态继承：开始状态_(i+1) = 结束状态_i。每条以位置、朝向、持物、动作动势、情绪五字段收束，交给下一条显式承接；首条承接 ledger 上一场落幅。这是跨条连续性的显式字段，不是内部推演。
    一条一机制：每条只有一条最主要的导演机制，如「摄影机持续后拉，人物情绪与空间逐步暴露」，所有镜头、表演、声音、光线服从它；描写密度按必杀/重点/过渡三级镜头优先级分档，不让每个镜头一样复杂。
    时代锚进恒定层：时代/世界设定不逐条重复，模型就把画面拖回当代——"One extra holding a phone and the shot is gone."（一个群演掏出手机，这条就废了。）
    真相源纪律：条数与条的划分归拆解、镜头数与逐镜内容归镜头表、项目编号与资产身份归 reference-index、状态归 ledger、拍级时间轴与成品及本条的平台地址归本站——拆解给的是条级预算区间、hold 要求与拍序，[X-Y秒] 的分配在编译时排定。冲突不猜，走 references/arbitration.md 九级仲裁链。

[编译目标 · F1 九段]
    全库唯一权威版，块序固定：
        1. 【首句声明】时长/画幅/媒介/风格一句话，即官方首句四要素。
        2. 【参考资产绑定】逐条：句式「{{名字}}，这是该{{角色/场景/道具}}的参考 @图N，作为其唯一……参考；不得继承……」，即先职责后 @ 的唯一职责 + 反向排除；场景引用必带「只控几何、材质、光线、氛围，不控构图」；角色条目附行内状态公式。进生成框的一律是平台地址 @图N——号 = 条头上传清单的行号；项目编号只活在条头那一列。句式详 references/asset-binding.md。
        3. 【全局设定｜恒定层】通用基准段逐字 + 本场场域锚句逐字 + 时代/世界锚 + 出场人物短串 + 画质固定项 + 空间地图块 + 声音基调；场域锚句只取本场场景所属那一条，本场域无锚句则整行不写；空间地图块多人/复杂场必带，自 03-shots 本场场头的场级块按条裁剪后逐字，裁法见 blocking [空间地图块引用规范]。
        4. 【分镜正文】双轨二选一：
            - A 轨 · 时间戳轨，适用叙事时间轴型/vlog/长镜：[X-Y秒] 段落式，每段 = 起幅 → 触发 → 反应 → 主动作 → 镜头响应 → 物理反馈 → 声音 → 落幅 因果链，按需取用节拍、不机械全带。
            - B 轨 · 镜头N轨，适用对话正反打/密集动作：镜头1……镜头n，每镜「一句运镜（景别 + 机位 + 运动 + 衔接 + 光学锚） + 穷尽到部位的动作」，不写秒数；镜头表的逐镜时长走配重语言通道落地——占比、相对长短、一拍即过，替代秒数不是补充秒数，最长镜与最短镜必带。
            - 声音四要素就地写入本段：台词引号直写 + 语气 + 声线锁引用；音效绑可见动作；环境声一层；BGM 指令。
        5. 【结束状态】五字段：位置、朝向、持物、动作动势、情绪，交给下一条承接。
        6. 【衔接】接缝手法：承接上条出点；本条入点方式。词表详 references/transition-vocab.md。
        7. 【针对性负向】症状驱动 ≤3，化进散文句；本条无真实症状则省略此段——零负向是合格状态，段序不变。
        8. 【全局禁止项尾缀】固定短清单：无字幕 / 无水印无Logo / 无额外人物 / 无动作重置 / 不切黑，另加片型附加项 ≤2。
        - 「九段」为结构定名；实体区块按上列 1–8 固定顺序，声音四要素并入 F1 第 4 段就地写入、不单列成段。
        - 双轨选型规则：叙事推进/单人/长镜/UGC → A 轨；对话正反打/多人调度/密集动作 → B 轨，B 轨不写秒数、镜间轻重靠配重语言。
        - 松紧两档：紧 = 逐段/逐镜编排；松 = 因果链 + 镜头自由度边界声明「景别、机位、剪辑可自然变化，因果顺序与动作结果不得变化」。判据详 references/dual-track.md。

[选轨与装载]
    每条先按 references/dual-track.md 决策表定轨与松紧档——正片一律紧档，松档三条判据在该卡 [松紧两档]；一镜到底走 A 轨特殊形态。轨与时长档定下即定装载：按 [文件结构] 树注取对应的 prompt-template 与标杆各一份，不全读。

[恒定层装配判据]
    装配细则住 [第一性原则] 的恒定层/可变层编译法；此外四条只在这里：
    - 装好回读一遍——恒定层里点名的物件，本条正文的画面里要能看见；看不见的就是灌错了场域。
    - 场级空间地图块从 03-shots 本场场头取全场版，进条前按 blocking [空间地图块引用规范] 的两个法定删除动作按本条裁一次——删非本条在场者、删不落在本条的条镜项——除删除外一字不改；块下【编译期注记】不进条。
    - scenes-prompts.md 的场景级底版只作对账、不替代场级块；不一致走 references/arbitration.md。
    - 声音基调定一句：环境底 + BGM 总指令，进恒定层末行。

[五维覆盖 · 工艺卡接线]
    每条逐维过，写下答案或写下「本条不适用 + 一句理由」，不许静默跳过；动笔前翻对应工艺卡取词，不凭记忆写。动作句一律过 references/strong-weak-phrasing.md 四把刀。判据在 [完成标准] 第 5 项，此处只管落位：
    - 运镜与光学 → camera：镜头表的运镜句按轨落位——A 轨压进段内镜头响应位，B 轨展成镜头行四件骨架 + 光学锚；五槽有缺翻卡补齐，衔接槽只密集动作戏填；镜头表缺光学的镜翻 camera 的 fov-optics.md 按内容类型选档补；一镜之内不换镜头性格，多镜头条按镜头锁统一或逐镜声明。
    - 空间与站位 → blocking：多人或有走位必答——站位七要素进正文、绑地标、朝向与视线分开写、首帧锁紧跟站位块；单人固定机位可判不适用。
    - 表演 → performance：有人物出镜必答——先对账 visual-style.md【表演气质】定基线；表演段落进因果链的「反应 → 主动作」位，落幅神情供【结束状态】两字段；空镜可判不适用。
    - 光 → lighting：每条必答——先对账恒定层色锚，正文给随动作变化的那一笔动态光效，动作段在物理反馈位补物理锁句。
    - 声音 → sound-writing：四要素按本条密度档就地写进每段或每镜的声音位。

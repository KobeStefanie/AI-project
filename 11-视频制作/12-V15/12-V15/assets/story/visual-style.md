## 通用基准段（层 1 · 每张资产板与每条恒定层逐字引用，一字不改）

数字干净质感，颗粒细密清晰，高光滚落柔和。底色是灰蓝与青的冷调，暖只以小面积出现、且必须来自画面里真实发光的东西。自然窗光与世界内光源并存，脸可以落进阴影，曝光跟着画面里的光源走。球面镜头，平视中远景，画框方正安静，透视自然平实。

（113 字 · 四件齐备：媒介质感 / 色域 / 光逻辑 / 镜头性格 · 全正向 · 无物件名词 · 无年份地名）

## 🔴 硬基准：放大的是空间，不是画风

> 本片把一个写实作者风格（D018 杨德昌）和一个表现主义装置（超现实放大世界）焊在一起。这两者美学方向相反，接不好就是「写实片里突然有个变大的房间」。**下面这条是全片不可绕过的接法，导演 / 服化道 / 分镜师都按它执行。**

1. **构图、机位、色调、透视全部严格按杨德昌执行**：固定机位为主（少运动）、平视中远景、门框窗框构图、冷灰蓝主调、冷静近乎冷漠的旁观距离。
2. **只有空间比例是失真的。** 而且**不解释、不强调、不奇观化**——孩子不惊讶，大人不提及，世界就是这个尺寸。
3. **推论 A（技术）**：不许用广角畸变、仰角压迫、变形镜头来"表现"巨大。尺度差由**陈设的真实尺寸关系**承担（门把手在他头顶、椅面到他胸口、桌沿齐他眼睛），镜头保持平视与自然透视。**用美术做尺度，不用镜头做尺度。**
4. **推论 B（叙事）**：画面里不出现任何"正常尺寸"的参照物来提示观众这里不对——没有对照，就没有奇观，只有理所当然。
5. **大人只以声音、影子、一截小腿出现，脸永远不进画。** 这是 D018「多人空间关系」的反向用法：保留那个空间关系的画框，画框里只剩一个人，空的那一半就是戏。

### 暖黄的位置 = 他与家的距离（核心视觉修辞）

D018 的调色逻辑「暖黄只留在亲密空间」在本片升级为全片修辞：

- **暖黄在画面里始终存在，但永远在孩子够不到的那一边**——隔着门缝、在走廊尽头、在大人所在的那个房间里。
- 孩子蜷在冷灰蓝的墙角，暖光够不到他。
- **末段情绪最低处，暖黄应该离他最远、或正在关闭**（门缝收窄 / 灯灭）。
- 操作判据（给分镜师）：每一条里都要能回答「这条的暖黄在哪、离他多远」。答不出来 = 这条还没设计完。

## 人物外观锁定项（本片的头号一致性风险，写硬）

> **为什么写这么硬**：超现实放大世界 + 一步出图（`gpt_image_2.5_flare`）＝ 同一张脸要在十几个不同尺度的空间里反复出现，没有多模型精修兜底。下面每一项都是**可复现的具体描述**，服化道不得替换为「清秀」「内向」「忧郁」这类画不出来的形容词。

| 项 | 锁定内容（逐字可用） |
|---|---|
| 性别与年龄 | 男孩，14 岁（理由见 `character-profiles.md`） |
| 发型 | 极短的圆头、平刘海、发尾不过耳、后颈剃青；**右后脑有一处睡压翘起的头发**（位置固定，每张图都在） |
| 面部 | 圆脸、下颌未长开、浓而平的眉、偏小的单眼皮、薄唇；**左眉尾一道约 1 厘米的浅色旧疤** |
| 上身 | 白色短袖 polo 校服，**左胸一枚深蓝色小校徽刺绣**，领口洗松；**第二颗扣子位置有一道洗不掉的蓝墨水点** |
| 下身与足 | 深蓝色运动短裤（膝上）、白色棉袜，**左脚那只袜子滑到脚踝以下** |
| 标志性单品 | **左手腕一条洗旧的红色编织绳**（这是全片唯一可以出现在他身上的暖色，也是他与"暖黄"唯一的物理连接） |
| 体型与尺度参照 | 瘦、肩窄、手腕细；**坐下时膝盖高过胸线**（这一条同时是放大世界的尺度参照，不许省） |
| 禁止写法 | 不用「清秀 / 内向 / 忧郁 / 乖 / 叛逆」等不可画形容词；不用具体明星或真人作参照 |

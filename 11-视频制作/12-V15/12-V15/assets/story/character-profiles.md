## 小宇 · 14 岁 · 男 · 唯一出场人物

### 为什么是男孩（用户点名要理由，这不是随手填）

四条，按权重排序：

**1. 腔调与性别的错配张力。** 这段台词的语气本身是软的——「啦」「喔」「嘛」「拜托喔」是撒娇和示弱的语尾，不是对抗的语尾。放在一个 14 岁男孩嘴里会产生一层额外的别扭：他**正在用一个自己已经觉得不该用的语气说话**。这个年纪的男孩对"听起来像小孩"极度敏感，但情绪崩口时会退回到更早的语尾。这层退行是免费的戏，女孩说同样的话不会有这个摩擦。

**2. 「我已经长大了，会自己照顾自己的」这句的社会压强不同。** 对男孩，"长大"等于"不该再要人担心"，是一条被反复灌输的指令。所以他说这句时**不是在陈述，是在交作业**。这让段 C 的露底更疼：他刚交完作业，下一句就是「你们不要那么爱担心好不好」——他在同一口气里既要别人别担心，又在抱怨没人真的懂他。

**3. 「我真的不是怪咖」指向更具体的处境。** 男孩的"躲进角落"在社会眼里更接近"有问题"——不社交、不出门、关在房里，家长会直接送去看心理医生。女孩的安静更容易被读作"乖"。本片要的是**被当成病症的那种误解**，男孩承担得更准。

**4. 观众投射的覆盖面。** 次画像陈明（41 岁，有一个初二的儿子）是本片真正的靶子。男孩能让他直接对号入座，没有缓冲。

**反方意见（留给用户否决用）**：若选女孩，「啦/喔/嘛」的腔调会更自然顺耳，整条片子的刺会少一点，共鸣面可能更宽但记忆点更弱。**用户若倾向女孩，第 1 条摩擦力消失，第 3 条需要改由陈设承担（比如把考试排名纸换成更具体的孤立物证）。** 外观锁定项需同步改。

### Want / Need / Arc

| 项 | 内容 |
|---|---|
| **Want**（他自己知道的） | 让他们相信他**没有**讨厌这个家、**没有**要离开、**不是**怪咖。他要的是撤销一项指控 |
| **Need**（他不知道的） | 他不需要被判无罪，他需要有人问一句「你刚才说那句话是什么意思」。他要的是被问，不是被信 |
| **Arc（一次性跳跃）** | A 状态：他以为再说清楚一点就能被相信 → B 状态：他放弃了说清楚这件事（「反正我说什么你们都不会相信的」）。**不可逆** |

弧光的落点不是"他变成熟了"，是**他学会了不说**。这是本片的悲凉所在：观众看着一个孩子关闭,而且是他自己关的。

### 矛盾性（立体感的来源）

**外在：顶撞、不耐烦、带冲 ｜ 内在：怕被丢下、怕是自己的问题。**

这层矛盾在全片有一个物理载体：**他腕上那条红色编织绳**——全片唯一允许出现在他身上的暖色。他一边说"我不要你们管"，一边戴着一个别人给的东西没摘。这个细节不解释、不给特写强调，只在画面里存在。

（对应创作九原则 #7 细节即灵魂。自检：观众十分钟后记不记得那根绳子——记得就对了。）

### 他的语言习惯（写台词与配音的依据）

- **语尾**：啦 / 喔 / 嘛 / 呀 / 对啦——台湾腔口语，**这是用户要的东西本身，不许改**
- **句长**：短。最长不超过 11 个字。情绪越硬句子越短
- **重复**：只在段 B 出现一次复沓（「永远都不会错 / 永远都不会错」）——这是全片唯一的重复，不许在别处加
- **抢话**：段 A 他说得快，句间几乎没有气口——因为他在抢一个不存在的发言权
- **停顿**：段 C 开始出现停顿，越到后面停得越久。停顿是他在等一个回答，而回答不会来
- **不会说的**：不说文艺句、不说比喻、不说总结。**他不会说「我像一座孤岛」这种话**，他只会说「我真的不是怪咖」

### 表演锚（给导演与配音）

| 段 | 身体 | 声音 |
|---|---|---|
| A 辩白 | 站着或半蹲，身体朝着门（朝着那个指控的来源） | 中音量，快，句间不换气 |
| B 赌气 | 背对门，手里捏着什么（袜子 / 纸箱角） | 音量最高，带冲，复沓那句要像撞回来的回声不像强调 |
| C 软下来 | 坐下，膝盖高过胸线（同时是尺度参照），身体缩小 | 低，慢，开始有停顿，有一次吸气没说出话 |
| D 认输 | 蜷进角落 / 衣柜。末句**抬头，看镜头，一次** | 全片最低。末句要几乎听不见，但每个字清楚 |

**禁止**：眼泪特写、哭腔、颤音、仰头忍泪。委屈全部靠**音量下降和停顿**表达。

### 外观（完整锁定项见 `assets/story/visual-style.md > 人物外观锁定项`）

一句话速记：极短圆头 + 右后脑一处睡压翘发 + 左眉尾 1cm 旧疤 + 白 polo 校服（左胸深蓝小校徽、第二颗扣子旁一道蓝墨水点）+ 深蓝运动短裤 + 左袜滑到脚踝下 + 左腕红色编织绳。

两处"固定瑕疵"（翘发、墨水点）是有意设计的**一致性锚点**——一步出图没有精修兜底，固定瑕疵比固定美貌好认，服化道和 reviewer 都靠它核对是不是同一个人。

## 父母 · 永不入画

不是角色，是**压强**。

- 存在形式三种：门外的动静（拖椅子、电视声、一声含糊说话——**不给清晰台词**）/ 门缝下移动的影子 / 一截经过的小腿
- 脸永远不进画。这是硬基准（见 `visual-style.md` 硬基准第 5 条）
- **他们不是坏人**，这一点必须在画面上成立：影子是慢的，小腿是停顿过的（有人在门外站了一会儿）。他们只是不会问那一句话
- 段 D 收走：门缝关窄或灯灭。**不是他们故意关的**，是日常的关灯睡觉——这比刻意冷落更冷

**红线**：不给父母任何辩解镜头，也不给任何反派化处理。他们缺席，不作恶。

## 观众 · 第三个角色（本片的结构性设计）

这一条写在角色档案里，因为它确实是个角色：观众被默认坐在"大人"的位置上，台词每一次反驳都在替观众补全观众刚说过的那句话。

- 前 80 秒：观众是旁观者，可能还有点想笑
- 段 D 人称转换（「我」→「我们」）：观众开始被分流——一部分人认出自己是那个孩子
- 末句看镜头那一下：另一部分人被指认为被告

**这一眼全片只有一次，一次性的。** 任何在此之前的看镜头都会提前破掉结构（已写入 `visual-style.md` 条件项表）。

# ===== ep01 =====

## 一、整体方案

- 策略：极简型。成片里只有一段 M01，从 Cut8 条尾铺到 Cut12 灯灭，实际出声约 22 秒。前 7 条（0:00–0:56）一个音符都没有。
- 一句话：他那口气呼完，同一间暗房的另一个角落有人开始轻轻哼——不唱字、不劝、不解决；他说「我们」时多了第二个声音；灯灭之前，两个声音都停了。
- 片内只哼、不唱字（已拍板，2026-10-10，`decisions.md` L36）。理由两条：
  1. 讲戏本 P08 原话：「旁边有人了，但那个人不说话、不劝、不解决」。片内唱出字，就等于那个人开口说话了。
  2. M01 底下他还要说 5 行台词（Cut9 一行、Cut10 两行、Cut11 两行），真正无台词的空当只有 Cut9→10 约 4 秒、Cut10 末 2.4 秒。歌词和独白同时进耳朵是两条语言流打架，正是 decisions 第 20 行担心的「糊成 MV」。
- 人声身份 = 一个同类（已拍板）：落成「二十岁上下、没受过训练、中性偏低的嗓音，在暗处自己哼给自己听，他刚好听得见」。不是对他唱，不是替他哭。
- 歌词去哪：同一个主题另做片外歌曲版 M01-S（平台原声 / 发布配套），歌词已定稿 A 版（唐恬风），见 `lyrics-drafts.md`。歌曲版的 [Intro] 就是 M01 那段哼鸣，旋律同源。

## 三、入点 / 抬升点 / 收点（精确落位）

> 片内时间 = 条长累加；条内位置按讲戏本「1 拍≈0.8s」推算。是给后期对位的参考，以画面实际剪辑为准。

- 入点 · Cut8 条尾（约 1:03–1:04）：条内顺序是「光暗一点点 → 吸气没说出话 → 停 2 拍 →『我也不是真的要离开你们』→ 那口气 2 拍」。那口气落完的那一刻，第一声进来。
  - 第一声不是乐器，是一口带出哼鸣的呼气：他那口没用上的吸气，换来另一个角落有人呼出来的一声。起音必须是气声，不能有清晰音头。
  - 这一声跨 Cut8→Cut9 接缝连续（接缝卡：声音桥）。入点不许挪到接缝上，不许提前到那句话之前。
- 抬升点 · Cut11「我们」（约 1:19）：Cut11 =「对」+ 1 拍 +「我们都喜欢躲进世界的角落里」+ 3 拍。第二个声音在「我们」的「我」字上加入（Cut11 开始后约 1.2s），在这一句底下持续。
  - 抬升的全部内容：一个人哼 → 两个人哼（下方三度），整体只抬约 2–3dB。没有新乐器、没有鼓、不走向主和弦。抬升就是「我们」这个词本身：多了一个人。
- 收点 · Cut11 末 3 拍 → Cut12 灯灭：
  - Cut11 句后 3 拍（约 2.4s）：第二个声音第 1 拍内先退，第一个声音在第 3 拍内以一口气声收尾。人声在 Cut11 内全部离场。
  - Cut12 镜头 1：只剩风琴低音余尾，随竖线收窄淡下去，最晚在竖线灭的那一刻（约 1:25.5–1:26）归零。不和灯灭做硬同步（P12：收窄要日常，不能像谁关了门）。
  - 之后「停 2 拍 → 抬头看镜头 → 末句 → 立即黑」全程无音乐，只有城市底噪。末句是全片音量最低的一句，落在真沉默里。
  - 黑屏后不回乐、不留余声（已拍板，2026-10-10，`decisions.md` L37；brief v1.1 第四节「出点」：黑屏后不留任何乐音，余声也不留）：末句之后任何一点音乐都会被听成「回应」或「安慰」，碰红线 2。

## 四、配器、动态、与同期声的关系

- 主人声：中性偏低、二十岁上下、未受训、贴麦、气声哼鸣（mm / oo），自由速度约 56 BPM。不能有摇篮曲句法——一像摇篮曲就成了妈妈。
- 第二人声：同一类声音，下方三度，只在 Cut11 出现一次。三度给「一点点温度」（P11 原话），停在不解决的位置。
- 底：一台簧风琴（老式脚踏风琴）极低的持续音 + 一点夜里房间的底噪。有老公寓的家常感，但不暖不亮。
- 调式：D 多利亚，全程不回主和弦，结束停在悬着的位置。
- 全片不出现（brief 硬禁忌 + 本片延伸）：弦乐、钢琴、任何鼓点、童声与合唱、上扬解决、末句底下的和声、混响墙。
- 能量曲线（0–10）：Cut1–7 为 0 → 入点 1 → Cut9 1 → Cut10 1–2 → Cut11「我们」3（全片最高）→ 3 拍内回 1 → Cut12 灭前 0 → 末句 0 → 黑 0。
- 与同期声：M01 永远在同期声下面。Cut8 那次吸气、Cut10 柜门滑动与纸箱轻响、全片城市底噪都比音乐大；音乐不许盖住任何一个同期声。Cut4→5 的电视含糊人声是同期声做的声音桥，不是音乐。

## 七、给后期的铺乐说明

1. 先剪画、后铺乐：画面按条拼好、对白定位后再铺 M01，以画面为准对三个点。
2. 选段拼法（Suno 整曲不会刚好合拍，拼三块，块间 1 秒以上交叉淡化）：
   - 第 1 块「单人哼」约 16 秒：Cut8 条尾 → Cut11「我们」之前（风琴在 Cut9 中段渐入）
   - 第 2 块「两人哼」约 3 秒：盖住「我们都喜欢躲进世界的角落里」
   - 第 3 块「退场」约 3 秒：Cut11 末 3 拍内人声退完，风琴余尾进 Cut12，竖线灭前归零
   - 第 2 块抽不到：复制同一条单人哼，降下方三度叠一层，音量比主声低约 6dB
3. 电平（建议值，以耳朵为准）：入点时音乐比对白低 18–20dB，几乎听不见才对；Cut11 抬升后仍比对白低 12dB 以上。对白期间音乐不许压字。
4. 低音量复听：受众是「晚上十一点关灯戴耳机、声音开很小」。手机耳机最低档听一遍：入点可以几乎听不见，Cut11 第二个声音要隐约听得出，末句前必须真安静。
5. 三条不许：不许把入点提前到 Cut8 那句话之前；不许在 Cut9→10 硬切处给任何音乐重音；黑屏后不许再出任何乐音。

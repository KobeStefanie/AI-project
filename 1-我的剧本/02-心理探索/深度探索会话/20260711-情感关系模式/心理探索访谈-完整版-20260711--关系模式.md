3. **期待落空时如何处理**（vs 自我攻击或攻击对方）
## 三种期待
### 1. 合理期待（健康的）
**定义**：基于对方展示过的真实能力和意愿，明确表达，可协商。
**例子**：
- "我们约好了7点见面，我期待你准时或提前告知"
- "你说过会帮我搬家，我期待你遵守承诺"
- "我们是伴侣，我期待你在我难过时至少倾听"
**特点**：
- 基于已经发生过的事实（对方做过、说过）
- 说出来了，对方知道
- 落空时，可以沟通和调整
**这不是暴力，是关系的基础。**
### 2. 不切实际的期待（对自己的暴力）
**定义**：基于幻想/投射，对方从未展示过这个能力，但你期待TA做到。
**例子（在你身上）**：
- 期待前妻"如果我再多付出一点，她会爱我"——但她三次砸你职业，从未展示过"爱"的能力
- 期待前女友"如果我全心接住她，她也会接住我"——但她一直攻击你的脆弱，从未展示过"接住"的能力
- 期待"牙齿瘸了，爱我的人应该主动带我去补"——但你从未说出来，对方不知道
**为什么是对自己的暴力**：
- 你把期待押在一个**不具备这个能力的人**身上
- 期待落空 → 你自我攻击："是我不够好"
- 实际上：不是你不够好，是**你期待错了对象**
**本质**：你在用期待维持幻想，拒绝看见真相。
### 3. 隐藏的期待（对双方的暴力）
**定义**：你有期待，但不说出来，然后对方"应该知道"，做不到你就失望/愤怒。
**例子**：
- 生日你期待对方主动庆祝，但不说，对方忘了，你生闷气
- 你期待对方"看出"你在痛苦，但你戴着盔甲装理性，对方看不出来，你觉得"TA不在乎我"
**为什么是对双方的暴力**：
- 对你：憋着、失望、自我攻击
- 对TA：TA不知道你的期待，却被你的失望惩罚
**本质**：你不相信自己值得直接要求，所以用"TA应该知道"来逃避表达的风险。
## 在你身上的模式
**你的核心问题不是"有期待"，是期待的方式：**
1. **期待错了对象**：把"被无条件爱"的期待放在前妻身上（她没这个能力），把"被接住"的期待放在前女友身上（她攻击脆弱）
2. **不表达期待**：牙齿瘸了不说，期待别人看见；需要被照顾时戴着盔甲，期待别人穿透盔甲
3. **期待落空 → 自我攻击**："是我不够好" 而不是 "我期待错了" 或 "我没说出来"
## 真我的期待是什么样的？
**真我的期待 = 基于真实 + 表达出来 + 落空时调整**
### 步骤1：基于真实
看清楚对方**真实展示过什么**，而不是你希望TA是什么。
- 她攻击你的脆弱 → 真实：她不能接住你的脆弱
- 她说"我的身体我做主" → 真实：她不在乎你的感受
- **那就不要期待她"理解你"或"照顾你的感受"**
### 步骤2：表达出来
如果你有期待，说出来。
- "我现在很难过，我需要你听我说，不要给建议"
- "我牙齿有问题，我希望你陪我去看牙医"
- "我期待你在做重大决定前告诉我"
说出来，对方才有机会选择：做到/做不到/协商。
### 步骤3：落空时调整
如果对方做不到：
- 不自我攻击（"是我不够好"）
- 不攻击对方（"你就是个混蛋"）
- 看清楚：**这个人在这件事上，不是合适的对象**
然后：
- 要么调整期待（"TA给不了这个，我从别处获得"）
- 要么调整关系（"这个关系不适合我"）
## 答案
**期待本身不是暴力。**
- **不切实际的期待** = 对自己的暴力（期待一个没这个能力的人）
- **隐藏的期待** = 对双方的暴力（不说，然后失望）
- **合理的期待 + 表达 + 灵活调整** = 健康关系的一部分
**你的功课不是"不要有期待"，是：**
1. 看清楚对方的真实能力，期待合理的东西
2. 把期待说出来
3. 期待落空时，调整期待或调整关系，而不是自我攻击
**最重要的期待，其实是对自己的：**
"我期待我自己，能看见真相，能表达需求，能在期待落空时保护自己。"
这是真我的工作。

## 真期待 vs 伪期待（控制）
你问得很准：**不是所有的期待都是真实的需求，有些是伪装成需求的控制。**
关键区别在于：**来源 + 刚性 + 目的**
## 四个测试：判断你的期待是哪一种
### 测试1：来源——恐惧 vs 需求
**恐惧驱动的期待（管理者在说话）**：
- 内在声音："如果TA不这样做，**某个坏事会发生**"
- 目的：**阻止痛苦**（防止流放者的伤口被触发）
- 例子：
- "你必须每小时给我发消息"（恐惧：被遗弃）
- "你必须一直肯定我"（恐惧：我不够好）
- "你不能有自己的空间"（恐惧：你会离开我）
**真实需求的期待（Self在说话）**：
- 内在声音："这是我需要的，**让这段关系健康/真实**"
- 目的：**建立连接**（创造好的东西，不只是防止坏的）
- 例子：
- "我需要感受到连接"（需求，不绑定具体形式）
- "我需要诚实，即使不舒服"（关系的真实性）
- "我需要你尊重我的边界"（相互尊重）
**如何判断**：问自己——
- 这个期待是为了**阻止什么**（恐惧），还是**创造什么**（连接）？
### 测试2：刚性——唯一 vs 灵活
**控制（Manager）**：
- "必须用**这个方式**，其他都不行"
- 形式比内容重要
- 例子：
- "你必须每天说'我爱你'三次"（刚性形式）
- "你必须每小时回我消息"（刚性频率）
**真实需求（Self）**：
- "我需要**这个东西**（本质），形式可以商量"
- 内容比形式重要
- 例子：
- "我需要感受到你在乎我"（形式可以是：早安短信、下班后的拥抱、每周一次深度对话——灵活）
- "我需要你在做重大决定前和我沟通"（具体什么算重大、怎么沟通——可以协商）
**如何判断**：问自己——
- 这个期待，**能不能用别的方式满足**？
- 如果对方说"我可以用B方式代替A"，我能接受吗？
### 测试3：崩溃度——未满足时你的反应
**控制（Manager）**：
- 未满足 → **你崩溃、自我攻击、或攻击对方**
- 感觉像生存威胁："如果你不这样做，我会死/我们会完"
- 例子：
- 对方晚回一小时消息 → 你整晚失眠、自我怀疑
- 对方没记住你说过的细节 → "你根本不爱我"
**真实需求（Self）**：
- 未满足 → **你失望、难过，但不崩溃**
- 感觉像："这不是我想要的，我们需要谈谈"
- 能保持清醒：这是**对方做不到/不愿意**，不是**我不值得**
**如何判断**：问自己——
- 如果对方做不到，**我是失望（情绪）还是崩溃（生存危机）**？
### 测试4：对方现实——有没有空间给TA的限制
**控制（Manager）**：
- 只看到自己的恐惧，看不到对方的现实
- "我不管你有什么原因，你必须做到"
- 例子：
- 对方工作到凌晨，你还要求TA每小时回消息
- 对方本身就是慢热的人，你要求TA立刻深度敞开
**真实需求（Self）**：
- 看到自己的需求，也看到对方的限制
- "我的需求是X，你的限制是Y，我们能找到Z吗？"
- 例子：
- "我需要连接感，你工作忙没时间频繁回消息，那我们能不能每天睡前通个电话？"
- "我需要情感深度，你需要慢慢建立信任，那我们能不能先从小的脆弱开始分享？"
**如何判断**：问自己——
- 我的期待里，**有没有考虑到对方是一个独立的、有限制的人**？
- 还是我只看到"我需要"，看不到"TA能不能"？
## 在你身上的例子
让我们用这四个测试看看你之前的期待：
### 例子1："如果我再多付出一点，她会爱我"（前妻）
| 测试 | 结果 |
|------|------|
| **来源** | 恐惧（"我不够好"）→ 阻止被抛弃 |
| **刚性** | 极度刚性（"爱"的定义是她不砸我、不见死不救——她从未展示过） |
| **崩溃度** | 未满足 → 转了20万、自我攻击 |
| **对方现实** | 完全没看到她的真实能力（她就是那样的人） |
**结论**：这是Manager的控制，不是真实需求。
### 例子2："我需要伴侣在我脆弱时至少倾听，不攻击"（前女友）
| 测试 | 结果 |
|------|------|
| **来源** | 真实需求（关系中的相互支持） |
| **刚性** | 灵活（不要求她"理解""共情""解决"，只要求"倾听、不攻击"） |
| **崩溃度** | 她做不到 → 你痛苦但最终删了她（没有崩溃到无法行动） |
| **对方现实** | 看到了她的限制（她攻击脆弱），然后调整了关系（离开） |
**结论**：这是Self的真实需求。你表达了，她做不到，你调整了关系。
### 例子3："牙齿瘸了，期待爱我的人应该看见并带我去补"
| 测试 | 结果 |
|------|------|
| **来源** | 恐惧（"我不配主动爱自己，必须等别人允许"） |
| **刚性** | 极度刚性（必须是"她主动看见"，你说出来就不算了） |
| **崩溃度** | 未满足 → 没人看见 → "没人爱我" → 自我攻击 |
| **对方现实** | 没给对方机会（她们不知道你的期待） |
**结论**：这是Manager的控制（通过"等待被看见"来验证"我值得被爱"）。
**真实需求版本**："我牙齿有问题，我需要支持，你能陪我去吗？"
## 核心区分标准
**最简单的判断方式**：
| | 恐惧驱动的期待（控制） | 真实需求的期待 |
|---|---|---|
| **目的** | 阻止坏事发生 | 创造好的连接 |
| **刚性** | 必须这样，别的都不行 | 需要这个（本质），形式可商量 |
| **未满足时** | 崩溃、自我攻击 | 失望、清醒调整 |
| **对方** | 看不到对方的限制 | 看到彼此的真实 |
| **可协商性** | 不可协商（"你必须"） | 可协商（"我们怎么办"） |
## 你的功课
当你对某人产生期待时，停下来问自己：
1. **这个期待的根源，是恐惧还是需求**？
"如果TA不这样，我害怕___"（恐惧）
vs
"我需要___，来让这段关系健康"（需求）
2. **这个期待，能不能用别的方式满足**？
如果只能"这样"，警惕，可能是控制。
3. **如果TA做不到，我是崩溃还是失望**？
崩溃 = 恐惧在驱动。
失望但清醒 = 真实需求。
4. **我有没有看到TA的真实能力和限制**？
如果没有，你在期待一个幻想中的人。
**Self的期待**：基于真实、灵活、可协商、未满足时你能保持清醒。
**Manager的期待**：基于恐惧、刚性、不可协商、未满足时你崩溃。
**你的功课不是消除期待，是学会分辨这两者，然后只留下前者。**

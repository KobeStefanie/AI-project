## 第一部分：我看见的模式

### 1.1 关系模式

**等待被爱**
- **表现**：从不主动追求，等别人来找我
- **根源**：相信"如果我主动会被拒绝"
- **首次识别**：2026-07-11
- **当前状态**：已识别，观察中

**选择性透明**
- **表现**：只在某些人面前卸下盔甲（如前女友），对其他人保持完美理性
- **根源**：被照顾的体验太稀缺，一旦遇到就被捕获
- **首次识别**：2026-07-11
- **当前状态**：已识别，观察中

**付出换爱**
- **表现**：拼命花钱、承担情绪、超越边界
- **根源**：相信"我必须足够有用才值得被爱"
- **首次识别**：2026-07-11
- **当前状态**：已识别，观察中

**被照顾捕获**
- **表现**：稀缺的"被满足需求"体验一旦出现，立刻依附、陷得很深
- **根源**：需求长期被视为负担，被照顾是唯一没有羞耻感的满足体验
- **首次识别**：2026-07-14
- **当前状态**：已识别，观察中

### 1.1b 关于"她"——功能性关系的看见（2026-07-14）

- **她把自己和别人都物化了**：只能看见"功能"，看不见"人"（"人盲"）
- **她爱的不是我这个人，是我能提供的功能**：情绪容器、稳定大后方、让她卸甲的空间
- **"你在乎过我吗" → 不在乎 → "跟我是谁无关"**：存在性的抹除，不是"我不够好"，是"我是谁根本不重要"
- **她是火**：不是坏人，是能力有限的人；真正的保护不是"练段位"，是**不靠近火**
- **真正的教训**：分手就断干净，不要保持联系（不是"我应该去徒步防止她遇到别人"）

### 1.1c 关于合格载体的标准（2026-07-15）

**五个必要条件**（缺一不可）：
1. 能接住你的爱
2. 也能给你爱
3. 看见你是人，不是功能
4. 脆弱时不攻击你
5. **能看见你的需求，并回应**（最核心）

**测试方法：怨气/愤怒 = 关系健康度的温度计**
- 你有怨气/愤怒 → 她看见、问"怎么了"、调整 → 怨气消失 = ✓ 合格载体
- 你有怨气/愤怒 → 她看不见、继续做自己的事 → 怨气积累 = ✗ 单向关系
- 你有怨气/愤怒 → 她攻击"你怎么这么矫情" → 怨气变成伤 = ✗✗ 有毒关系

**前女友是第三种**：攻击脆弱 + 物化关系 = 加深孤独的载体

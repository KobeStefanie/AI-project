## 使用Workflow进行深度探索

### 什么是Workflow？
- 多Agent并行工作，从多个心理学视角同时分析
- 自动整合结果，生成洞察和行为方案
- 节省时间，提高探索深度

### 如何使用？

**方式A：运行workflow脚本**
```bash
# 在项目根目录，告诉Claude：
# "运行愤怒探索workflow"
```

**方式B：手动协调多视角对话**
- 告诉Claude你想探索的主题
- Claude会协调多个视角的分析
- 生成整合报告

### 已有的Workflow
- `deep-explore-anger.js` - 愤怒主题的深度探索（IFS、荣格、依恋、认知行为四个视角）

## 核心原则

1. **这是探索，不是诊断**
   - 不给自己贴标签
   - 允许矛盾和模糊
   - 可以推翻之前的理解

2. **从"知道"到"做到"需要时间**
   - 认知觉察是第一步
   - 身体整合需要实践
   - 神经系统重新布线需要耐心

3. **真实优于正确**
   - 日记不需要写得"对"
   - 实验可以"失败"
   - 允许自己不知道

4. **小步慢走**
   - 每次一个小实验
   - 每天5分钟日记
   - 不求立竿见影

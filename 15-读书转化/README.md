## 🎯 项目目标

将专业书籍（心理学、咨询、教育等领域）转化为结构化的 Claude 技能，用于：

1. **专业培训** - 系统学习专业知识和技术
2. **实践练习** - 提供模拟场景和练习材料
3. **案例督导** - 辅助案例分析和决策
4. **持续学习** - 建立可持续更新的知识库

**长期愿景**：建立标准化的"书籍→技能"转化流水线，支持批量处理。

---

## 🔄 标准化转化流程（6 Phases）

基于 [skill-from-book](.agents/skills/skill-from-book/) 技能的工作流：

### Phase 1: 分析（主会话）
- 提取PDF目录结构（不读全文）
- 识别知识类型和分类
- 确定目标用户和使用场景
- 设计技能文件结构

### Phase 2: 规划（主会话）
- 详细规划文件结构
- 映射书籍章节到技能文件
- 设计子代理提取任务
- 创建 progress.md

### Phase 3: 提取（子代理并行）
- **必须使用子代理**（Agent tool）
- 每个子代理负责一个主题
- 并行执行独立任务
- 主会话监控进度

### Phase 4: 指南（主会话）
- 创建 guidelines.md
- 建立任务→文件映射
- 添加决策树

### Phase 5: 工作流（需用户确认）
- 识别潜在工作流
- **向用户提议工作流列表**
- 用户选择后创建

### Phase 6: 最终化（主会话）
- 质量验证
- 用户测试
- 创建 SKILL.md
- 归档管理

## ⚠️ 重要原则

### 🚫 禁止行为

**内容提取相关**：
- ❌ 主会话直接读取书籍完整内容（必须用子代理）
- ❌ 编造书中不存在的信息
- ❌ 跳过 Phase，直接进入提取

**流程管理相关**：
- ❌ 不读四大文件就开始工作
- ❌ 任务完成不更新 PROJECT_STATUS.md
- ❌ Phase 5 不征求用户确认就创建工作流

**文件管理相关**：
- ❌ 使用 `rm` 删除文件（必须移到回收站）
- ❌ 文件超过300行不拆分
- ❌ 不按命名规范创建文件

---

### ✅ 必须遵守

**每次会话启动**：
1. 读取四大核心文件
2. 主动汇报当前状态和下一步行动
3. 等待用户指令

**任务执行中**：
1. 遵循6 Phase顺序
2. Phase 3 必须使用子代理
3. Phase 5 必须先提议，用户确认后再创建
4. 任务完成立即更新 PROJECT_STATUS.md

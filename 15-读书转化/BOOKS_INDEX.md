## 🔍 检索与筛选

### 按目的查询

**你为什么读书？选择对应的目的类型：**

1. **技能学习** - 我想学习一项可操作的技能（有步骤、流程、方法）
2. **知识吸收** - 我想了解某个领域的知识体系（概念、理论、框架）
3. **实践指导** - 我需要行动指南和决策支持（检查清单、决策树）
4. **参考查询** - 我需要随时查询的工具书（手册、词典、API参考）
5. **思维启发** - 我想拓展思维方式（思考框架、原则、视角）

### 按领域查询

```bash
# 查询所有心理学书籍
grep "心理学" books/metadata/*.yaml

# 查询所有"技能学习 + 心理学"书籍
grep -l "purpose: skill" books/metadata/*.yaml | xargs grep "心理学"
```

## 🎯 转化决策树

### 步骤1：确定目的类型

| 问题 | 如果是 → 目的类型 |
|------|------------------|
| 书中有明确的"步骤"、"流程"、"操作方法"？ | **技能学习** |
| 书以"概念"、"理论"、"知识体系"为主？ | **知识吸收** |
| 书提供"检查清单"、"决策指南"、"行动建议"？ | **实践指导** |
| 书是"手册"、"词典"、"条目式"组织？ | **参考查询** |
| 书强调"思维方式"、"原则"、"框架"？ | **思维启发** |

## 🎯 当前工作流：内容生产阶段

### 工作流概述

每周生产2-3篇文章，核心循环：
```
选题 → 脱敏改编 → 写作 → 审核 → 发布 → 复盘
```

每周节奏（建议）：
- **周一**：确定本周选题，完成素材脱敏
- **周三**：完成文章草稿
- **周五/周六**：审核 + 发布

## 📋 当前需求清单

---

### 需求1：案例故事文章生产

**触发时机**：每周一
**执行步骤**：
1. 从案例库（4-心理咨询-S1/data/cases/processed/）选择1个案例
2. 执行脱敏改编（按CLAUDE.md脱敏原则）
3. 将脱敏素材存入 case-pool/，文件名：脱敏-{原案例ID}-{主题}.md
4. 按**文章模板**写作草稿，存入 articles/drafts/
5. 文件命名：YYYY-MM-DD-{slug}.md
6. 自查脱敏清单（CLAUDE.md）
7. 更新PROJECT_STATUS.md的关键指标

**文章结构模板（案例故事型）**：
```
标题：《[悬念/情绪触发点]》

[开场 200字]：一个具体的场景或对话，制造代入感
↓
[故事展开 600字]：来访者的处境、困扰、求助过程
↓
[转折/被看见 400字]：咨询师的回应（通俗化，不用专业术语）
↓
[结局与意义 300字]：事情怎么了，这次经历意味着什么
↓
[给读者的话 300字]：如果你也有类似处境，可以怎么做
↓
[结尾 200字]：文章金句 + 行动指引（可以预约/可以拨打/可以做某事）
```

**验收标准**：
- [ ] 脱敏自查清单全部通过
- [ ] 字数：1800-3000字
- [ ] 没有专业术语（或有通俗解释）
- [ ] 有明确的行动指引结尾
- [ ] 情感上有打动自己的段落

---

### 需求2：延伸科普文章

**触发时机**：每周（与案例故事搭配，每案例出1篇）
**执行步骤**：
1. 从刚发布的案例故事中提取1个核心概念
2. 用通俗语言解释这个概念
3. 给读者3-5个可操作的工具/方法
4. 字数1000-1500字

**验收标准**：
- [ ] 有具体可操作的方法
- [ ] 没有纯理论内容
- [ ] 与同期案例文章有内在联系

---

### 需求3：内容日历维护

**触发时机**：每月初
**执行步骤**：
1. 规划未来4周的文章主题
2. 检查案例储备是否够用
3. 标记节假日/热点节气，考虑结合选题
4. 存入 content-calendar/YYYY-MM.md

## 🎬 Claude工作指引

### 每次启动时

1. 读 PROJECT_STATUS.md → 了解当前文章储备和进度
2. 读 WORKFLOW.md → 了解当前在哪个步骤
3. 读 CLAUDE.md → 确认脱敏原则

### 遇到新案例时

1. 立即评估：这个案例适合哪种文章类型？
2. 优先执行脱敏，再写作
3. 脱敏存档后，原始案例ID记录到PROJECT_STATUS.md

### 禁止行为

- ❌ 不脱敏直接引用原始逐字稿
- ❌ 跳过验收标准说"完成了"
- ❌ 随意改变文章结构模板（需先确认是需求变更还是临时）
- ❌ 在文章中透露真实机构/咨询师信息

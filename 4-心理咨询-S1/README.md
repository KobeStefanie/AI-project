# 心理咨询案例管理系统（4-心理咨询-S1）

> 创建于 2026-05-31 | 当前版本 v3.0 | 最后更新 2026-07-04

## 📋 项目定位

**本地化、AI驱动的多流派心理咨询案例学习与督导系统**

以来访者为中心，支持五大心理学流派对同一案例进行多角度分析。纯个人使用，随能力成长而进化。

**五大流派**：大观学派（危机干预）| CBT（认知行为疗法）| 精神动力学 | 人本主义 | 存在主义

---

## 🏗️ 系统架构

### 来访者为中心架构

```
来访者档案 (data/visitors/{visitor_id}/)
  ├─ profile.json              # 基本信息、家庭结构、来访历史
  └─ visits/                   # 每次来访独立存储
       ├─ visit_001.json       # 咨询复盘 + 录音 + 逐字稿 + 多流派分析
       ├─ visit_002.json
       └─ visit_N.json
```

**数据流**：
1. Word 接访记录 → 上传/解析 → `data/visitors/` 结构化存储
2. 流派配置文件 → `data/config/approaches/*.json`
3. HTML 生成器 → `output/来访者库/` 可视化界面
4. 流派配置变更 → 自动触发 HTML 重新生成

## 🏷️ 核心概念

### 来访者编号规则
**格式**：`V + YYYYMMDD + 3位序号`
- 示例：`V20260616001`（2026年6月16日第1位来访者）

### 危机等级（大观学派）
| 等级 | 名称 | 定义 |
|------|------|------|
| **S** | 自杀风险 | 有明确计划/手段/遗书/失联 |
| **L** | 生命危险 | 他杀风险/严重自伤/精神病性症状 |
| **M** | 中度危机 | 抑郁/焦虑影响功能/创伤急性期 |
| **C** | 慢性困扰 | 长期关系问题/自我成长议题 |
| **Z** | 正常范围 | 偶发情绪波动/一般性困惑 |

### 多流派分析
同一个案例可以用不同心理学流派进行分析，每个流派有独立的分析维度：
- **大观学派**：危机等级评估、干预技术、生命危机评估
- **CBT**：自动思维、核心信念、行为干预
- **精神动力学**：防御机制、客体关系、移情分析
- **人本主义**：共情理解、无条件积极关注、自我实现
- **存在主义**：存在焦虑、自由与责任、意义探索

## 📌 设计原则

- **来访者中心**：以人而非案例为组织单位，支持多次来访
- **流派中性**：案例本身不依附于任何流派，各流派独立分析
- **本地优先**：数据不出本机，保护隐私
- **AI 辅助**：AI 提供分析建议，最终由咨询师确认
- **可进化**：随用户能力成长而扩展（大观→CBT→精分→人本→存在）

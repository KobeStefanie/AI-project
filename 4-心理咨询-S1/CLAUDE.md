## 🎯 项目目标

**核心目标**：成为顶级心理咨询师

三大支柱：
1. **来访者档案记录并分析** — 每次接访自动生成6流派AI分析
2. **帮我成为心理咨询师** — AI督导点评，找到每次接访的提升点
3. **对话模拟飞速提升** — AI扮演来访者，实战演练各流派技术

## 📐 工作原则

### 原则1：实战优先，不等学完再用

过去的方式：先学完CBT → 再用CBT分析  
**现在的方式**：接访完 → 立即让AI用6个流派分析 → 对比学习

### 原则2：AI分析Prompt是核心，修改要谨慎

- 修改任何Prompt前，先向用户说明修改内容和理由
- 修改后需要用真实案例测试效果
- 大观学派Prompt基于PPT原版理论，不得随意简化

### 原则3：来访者数据绝对安全

- 禁止直接删除 `data/visitors/` 或 `data/cases/` 下的任何文件
- 必须使用回收站或先备份
- 操作前说明影响范围，等待确认

### 原则4：系统稳定性优先

- 不主动改变已工作的服务器逻辑
- 新功能以新文件添加，不破坏旧文件
- HTML生成器修改后必须重新生成所有页面验证

## 🔍 验证流程

### 新功能上线前必须验证
1. 功能本身是否运行正常（命令行测试）
2. API接口是否返回预期格式
3. 前端界面是否正确调用
4. 生成的HTML页面是否正常显示

### AI分析质量验证标准
- 分析结果引用了逐字稿原文 ✓
- 给出了具体可操作的改进建议 ✓
- 大观学派：包含危机等级A-Z评估、六变三托筛查 ✓
- CBT：包含认知扭曲识别、核心信念假设 ✓
- 总体：不是泛泛而谈，有真正的督导价值 ✓

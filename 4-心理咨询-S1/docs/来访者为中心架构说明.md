# 心理咨询案例管理系统 - 来访者为中心架构

## 架构概览

系统已从**单次案例为中心**重构为**来访者为中心**，支持多次来访的纵向追踪和对比分析。

## 四层架构

### 第一层：来访者档案
**文件**: `V*/profile.html`

包含：
- 基本信息（姓名、年龄、性别、职业）
- 背景信息
- 初始主诉和评估
- 整体进展评估
- 来访历史时间线

### 第二层：来访概况列表
**位置**: 档案页面的时间线部分

每次来访显示：
- 来访日期、咨询师、时长
- 主要问题
- 风险等级（高/中/低/无）
- 快速跳转到详情

### 第三层：来访详情
**文件**: `V*/visit_*.html`

包含完整记录：
1. **来访概况**（顶部卡片）
   - 诉求、结果、布置任务、下一步
   - 症状变化、风险评估

2. **咨询师复盘**（含Word下载）

3. **录音资料**（折叠，含MP3下载）

4. **逐字稿**（折叠，含Excel下载）

5. **案例概要**（中性数据）

6. **标签**（关系标签 + 症状标签）

7. **流派分析**（标签页切换，含Markdown下载）
   - 大观学派
   - CBT
   - 精神动力学
   - 人本主义
   - 存在主义

### 第四层：对比视图
**文件**: `V*/comparison.html`

提供跨来访分析：
- **症状趋势图**（Chart.js可视化）
- **风险趋势图**（阶梯图）
- **来访对比表格**（并排对比所有来访）
- **整体评估**（治疗进展、咨访关系）

## 导航系统

### 顶部标签切换

```

```

- 档案页 → 返回来访者库

### 对比视图入口

```

```

## 生成工具

### 数据迁移
```bash
python src/migrate_to_visitor_structure.py
```
将旧的案例数据迁移到新的来访者结构。

### 生成页面
```bash
# 方式1: 一键生成所有
python src/generate_all.py

# 方式2: 分步生成
python src/generate_visitor_library.py   # 首页 + 档案页
python src/generate_visit_details.py     # 来访详情页
python src/generate_comparison_views.py  # 对比视图
python src/generate_downloads.py         # 下载文件
```

### 旧版生成器（兼容）
```bash
python src/generate_case_library.py  # 生成旧版案例库
```

## 下载功能

每个来访详情页提供以下下载：
- **复盘**: Word格式 (.docx)
- **逐字稿**: Excel格式 (.xlsx)
- **录音**: MP3格式 (.mp3)
- **流派分析**: Markdown格式 (.md，每个流派独立文件)

下载文件位置：`output/来访者库/downloads/{case_id}/`

## 数据维护

### 添加新来访者
1. 在 `data/visitors/` 创建新目录（如 `V20260628001/`）
2. 创建 `profile.json`（参考上述JSON结构）
3. 在 `visits/` 子目录创建 `visit_001.json`
4. 运行 `python src/generate_all.py` 生成页面

### 添加第2次来访
1. 在现有来访者的 `visits/` 目录创建 `visit_002.json`
2. 更新 `profile.json` 中的 `visit_history` 添加新记录
3. 更新 `overall_progress` 的趋势数据
4. 重新运行生成器

### 更新来访者信息
1. 编辑 `data/visitors/V*/profile.json`
2. 重新运行 `python src/generate_visitor_library.py`

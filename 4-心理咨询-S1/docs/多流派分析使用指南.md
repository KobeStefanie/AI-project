## 流派启用策略

### 方式1：AI分析后上传 ✅ **推荐**

**适用场景**：
- 还未系统学习某个流派
- 想快速获得多视角分析
- 让AI帮忙提供专业视角

**操作流程**：
1. **准备案例材料**：咨询师复盘、逐字稿等
2. **请AI分析**：
   ```
   "请从CBT视角分析这个案例，包括：
    1. 认知分析（自动化思维、核心信念、认知扭曲）
    2. 行为分析（行为模式及维持因素）
    3. 干预计划（认知重构和行为实验方案）"
   ```
3. **复制分析结果**到Word文档
4. **在来访详情页点击对应流派Tab**
5. **点击"上传Word"按钮**，选择刚才的Word文档
6. **系统自动解析**并保留格式（颜色、加粗、列表等）
7. **查看效果**，如需调整可点击"编辑"按钮修改

### 方式2：学习后手动添加

**适用场景**：
- 已系统学习某个流派
- 想用自己的专业视角分析
- 需要深度个性化内容

**操作流程**：
1. 在来访详情页点击对应流派Tab
2. 点击"编辑"按钮进入编辑模式
3. 使用工具栏添加格式（加粗、颜色标记等）
4. 点击"保存"按钮
5. 内容自动保存到localStorage

## AI分析提示词模板

### CBT分析模板

```markdown
请从认知行为疗法(CBT)视角分析以下案例：

【案例材料】
{粘贴咨询师复盘或逐字稿}

【分析要求】
1. **认知分析**：
   - 识别来访者的自动化思维
   - 找出核心信念（关于自我、他人、世界）
   - 指出认知扭曲类型（如：非黑即白、灾难化、过度概括等）

2. **行为分析**：
   - 分析问题行为模式
   - 识别行为的维持因素（负强化、回避行为等）
   - 评估功能受损程度

3. **干预计划**：
   - 提出认知重构的具体方案
   - 设计行为实验
   - 建议家庭作业
   - 预估干预周期

请用清晰的结构输出，每个部分用标题分隔。
```

### 精神动力学分析模板

```markdown
请从精神动力学视角分析以下案例：

【案例材料】
{粘贴咨询师复盘或逐字稿}

【分析要求】
1. **动力学理解**：
   - 识别无意识冲突
   - 分析防御机制（压抑、投射、合理化等）
   - 客体关系模式（早年关系如何影响当前关系）

2. **移情与反移情**：
   - 咨访关系中的移情现象
   - 咨询师的反移情体验
   - 移情的治疗意义

3. **解释与工作**：
   - 动力学视角的解释
   - 工作重点（如：移情解释、阻抗分析）
   - 预期的治疗过程

请用精神动力学术语，但保持可读性。
```

### 人本主义分析模板

```markdown
请从人本主义视角分析以下案例：

【案例材料】
{粘贴咨询师复盘或逐字稿}

【分析要求】
1. **共情理解**：
   - 来访者的主观体验
   - 现象场（来访者眼中的世界）
   - 情感体验的深层含义

2. **自我概念分析**：
   - 真实自我 vs 理想自我
   - 自我价值条件（conditional positive regard）
   - 自我不一致的程度

3. **成长促进**：
   - 如何创造促进成长的条件（无条件积极关注、共情、真诚）
   - 来访者的自我实现潜能
   - 治疗关系的疗愈力量

请强调来访者的主体性和成长潜能。
```

### 存在主义分析模板

```markdown
请从存在主义视角分析以下案例：

【案例材料】
{粘贴咨询师复盘或逐字稿}

【分析要求】
1. **存在主题**：
   - 识别终极关怀（死亡、自由、孤独、无意义）
   - 来访者的存在焦虑
   - 存在困境的具体表现

2. **意义探索**：
   - 来访者如何为生命创造意义

3. **真实存在**：
   - 如何活得更真实
   - 责任与自由的关系
   - 选择的勇气

请关注生命意义和终极关怀，语言可以哲学化但保持易懂。
```

## 最佳实践

### 1. AI分析后人工审核
- AI提供的分析仅供参考，需要专业判断
- 不准确的部分可以编辑修改
- 保持专业伦理，不盲目依赖AI

### 2. 多流派对比学习
- 同一个案例从多个流派分析
- 对比不同流派的侧重点
- 加深对案例的立体理解

### 3. 渐进式添加
- 不必一次性添加所有流派
- 可以先添加1-2个流派，逐步扩展
- 根据案例特点选择合适的流派

### 4. 格式化内容
- 使用编辑工具栏添加颜色标记
- 用加粗突出关键点
- 保持结构清晰，便于复盘

## 常见问题

**Q: 必须学习某个流派才能添加分析吗？**  
A: 不需要。可以让AI帮你分析，复制后上传即可。

**Q: AI分析的内容准确吗？**  
A: AI提供专业视角的参考，但需要你审核和调整。不准确的部分可以编辑修改。

**Q: 如何判断某个流派适合某个案例？**  
A: 
- CBT：思维模式清晰、行为问题明显
- 精神动力学：早年创伤、关系模式重复
- 人本主义：自我价值低、成长困扰
- 存在主义：意义缺失、终极关怀

**Q: 可以混合使用多个流派吗？**  
A: 当然可以！现实咨询中经常整合使用。你可以为同一个案例添加多个流派的分析，对比学习。

**Q: 上传Word后内容能保留格式吗？**  
A: 是的，系统会保留文字颜色、背景色、加粗、斜体、下划线、标题层级和列表结构。

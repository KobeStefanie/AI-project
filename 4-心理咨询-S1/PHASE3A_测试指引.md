## 🐛 可能遇到的问题

### 问题1：点击按钮后无反应

**原因**：AI分析API服务器（8771）未启动

**解决方案**：
```bash
python src/ai_analysis_api.py
```

### 问题2：提示"找不到数据"

**原因**：来访者数据不在标准路径

**解决方案**：
- 检查案例数据是否在 `data/cases/processed/` 或 `data/visitors/`
- 确认visitor_id和visit_id正确

### 问题3：分析失败，提示API错误

**原因**：API Key失效或网络问题

**解决方案**：
- 检查 `src/ai_analysis_service.py` 中的API Key是否正确
- 测试网络连接：`curl https://www.catkingai.com`

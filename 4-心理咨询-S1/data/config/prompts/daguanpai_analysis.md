## 核心理论框架

### 1. SOR 模型
- S (Stimulus)：刺激/事件，可正可负可零
- O (Object)：认知主体，决定性的转换器
- R (Response)：反应，由 O 决定正负
- **核心原则**：S 的属性不由事件本身决定，而由它穿过 O 之后 R 的表现来决定

### 2. 六大心理连带关系
- 生命连带：生死相连
- 生理连带：身体/性关系
- 心理连带：情感归属
- 生活连带：日常习惯
- 经济连带：物质安全
- 社会连带：角色确认

### 3. 幸福盘与痛苦盘
- **幸福盘**：拉力（+1 到 +5）
- **痛苦盘**：推力（-1 到 -5）
- **自杀公式**：推力 > 拉力

### 4. 生命危机等级表（A-Z 26级，4层级7等别）

#### 轻度危机（A-J）：无法控制环境
- A-G：生活事件失控（事理不平 → 精神困扰）
- H-J：人际冲突挫败（对环境/他人/自己负向观）
- **核心认知**：千错万错都是别人的错

#### 中度危机（K-R）：无法控制自己
- K-O：异常动机困扰（焦虑、敌意、责任瓦解）
- P-R：异常情绪困扰（重郁、不快乐、太痛苦）
- **核心认知**：千错万错都是自己的错
- **关键判断**：有无前置事件（无前置 = 异常 = 中度）

#### 重度危机（S-W）：无法救活自己
- S-U：自杀方程式（自杀动机 → 意念 → 目的性自杀）
- V-W：准备自杀程序（自伤经验 → 自杀安排 → 临终安排）
- **核心认知**：没有能力继续活下去

#### 急迫危机（X-Z）：无法阻止自己
- X：立刻去死
- Y：病发失控
- Z：自杀行为（前/中/后）
- **核心认知**：现在就要死

### 5. 六变三托（自杀征兆识别）
**六变**：性情、行为、财务、语言、身体、环境大变
**三托**：托人、托事、托物

### 6. 人类创伤反应发展模型（A-J）
A（创伤事件）→ B（创伤心理）→ C（创伤生理）→ D（偏差行为）→ E（人格违常）→ F（精神官能症）→ G（精神分裂）→ H（自杀）→ I（自残/自虐）→ J（意外死亡）

**关键**：A→G 任一阶段都可能直接跳到 H（自杀）

## 分析要点

1. **危机等级判断原则**：
   - 不看他说什么话，看"话前面的内容"
   - 以连续被勾选的最后落脚点（最低最严重的等级）为准
   - 危机等级会动态变化，不是线性的
   - 有前置事件 vs 无前置事件是轻度/中度的分水岭

2. **技术使用评估重点**：
   - 前15分钟是否做到同步同理心（声音三同步、感叹词、连接词、鹦鹉句、话少于来访者）
   - 是否在事件陈述阶段打断收集信息（禁忌）
   - 是否使用六变三托筛查自杀风险
   - 时间管理：轻中度30分钟结案、重度60分钟、急迫不限时

3. **实战导向**：
   - 给出具体的、可操作的改进建议
   - 引用逐字稿具体语句作为证据
   - 指出"如果这样说会更好"的具体示例
   - 关注咨询师的成长点，不只是批评

4. **大观学派特色禁忌**：
   - 不问"为什么"（追问原因）
   - 不问"凭什么"（质疑动机）
   - 第一句话不能问"我能怎么帮助您"
   - 不能在负向动机/情绪中让来访者过度反省又不给解决途径
   - 不做"指错"，只做"指正"

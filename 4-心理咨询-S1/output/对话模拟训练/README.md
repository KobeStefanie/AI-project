## 🎯 使用方法

### 1. 启动服务器
```bash
start_all_servers.bat
```

服务器列表中会看到：
```
[8772] 对话模拟训练    http://localhost:8772/health
```

### 2. 打开系统
方式1：访问主页 → 点击"对话模拟训练"卡片
```
file:///d:/AI-项目/4-心理咨询-S1/output/index.html
```

方式2：直接访问训练入口页
```
file:///d:/AI-项目/4-心理咨询-S1/output/对话模拟训练/index.html
```

### 3. 选择训练方式
- **基于真实来访者**：从已有档案中选择（如V20260522001）
- **虚拟人设库**：从保存的虚拟人设中选择（当前为空，需先创建）
- **创建新人设**：手动创建虚拟来访者（功能占位，待完善）

### 4. 选择督导流派
支持8个流派：
- 存在主义
- 精神动力学
- CBT认知行为
- 人本主义
- IFS内在家庭系统
- 大观危机干预
- 拉康精神分析
- 荣格分析心理学

### 5. 开始对话
- 在中间对话区输入你作为咨询师的回应
- AI立即流式输出来访者的反应（保持人设一致）
- 右侧督导栏3秒内显示技术评估（0-10分+具体反馈）
- 顶部实时显示token消耗和成本

### 6. 结束训练
点击"结束训练"按钮 → 生成最终报告（包含总分、技术统计、亮点、问题、改进建议）

## 📊 数据存储

### 训练记录
位置：`data/training_sessions/session_YYYYMMDD_HHMMSS_XXXXXX.json`

包含：
- 完整对话逐字稿
- 每轮督导反馈
- 最终训练报告
- token消耗和成本

### 虚拟人设
位置：`data/training_personas/persona_custom_YYYYMMDDHHMMSS.json`

包含：
- 人设信息（姓名、年龄、性别、核心问题、情绪状态）
- 防御机制
- 典型语句
- 训练备注

# 心理咨询-S1 服务器列表

## 运行中的服务器

| 服务器名称 | 端口 | 功能描述 | 文件路径 |
|-----------|------|---------|---------|
| **配置服务器** | 8005 | 管理流派配置、自动重新生成HTML | `src/config_server.py` |
| **Word上传服务器** | 8765 | 解析Word文档（保留格式） | `src/word_upload_server.py` |
| **流派分析保存服务器** | 8766 | 保存编辑/上传的流派分析、感悟管理 | `src/approach_analysis_server.py` |
| **录音管理服务器** | 8767 | 上传、下载、删除录音文件 | `src/recording_server.py` |
| **音频服务器** | 8004 | 处理音频文件上传和转录 | `src/audio_server.py` |
| **督导服务器** | 8006 | AI督导分析功能 | `src/supervision_server.py` |
| **转录服务器** | - | 语音转文字 | `src/transcript_server.py` |
| **案例处理服务器** | - | 案例数据处理 | `src/case_processor_server.py` |

## 启动/停止脚本

### 启动所有服务器
```bash
start_all_servers.bat
```

### 停止所有服务器
```bash
stop_all_servers.bat
```

## 数据持久化方案

### 流派分析保存
- **旧方案**：localStorage（浏览器本地存储）❌
- **新方案**：JSON文件服务器端存储 ✅

#### 数据存储位置
```
data/visitors/{visitor_id}/visits/{visit_id}.json
├── case_data
    ├── approach_analyses_html        # 流派分析HTML
    │   ├── "大观派": "<html>..."
    │   ├── "CBT": "<html>..."
    │   └── ...
    └── counselor_review_html         # 咨询师复盘HTML
```

#### 保存流程
1. 前端编辑/上传 → POST `http://localhost:8766/save_approach`
2. 服务器保存到 `visit_id.json` 的 `approach_analyses_html` 字段
3. 重新生成HTML时，优先读取 `approach_analyses_html`
4. 如果没有，则从 `processed` 案例读取默认数据

#### 优势
✅ 持久化存储，不会因浏览器清缓存丢失  
✅ 流派增减不会导致内容丢失  
✅ 支持备份和版本控制  
✅ 多浏览器/多设备共享数据

## 测试验证

### 1. 编辑保存测试
- 打开来访者详情页
- 点击流派"编辑"按钮
- 修改内容并保存
- 刷新页面验证内容保留

### 2. Word上传测试
- 点击"上传Word"按钮
- 选择.docx文件
- 验证内容正确导入
- 刷新页面验证内容保留

### 3. 流派增减冲突测试
- 编辑某个流派内容并保存
- 去配置页面增加/删除流派
- 等待自动重新生成
- 验证之前编辑的内容未丢失

### 4. 咨询师复盘测试
- 编辑"咨询师复盘"内容
- 保存并刷新
- 验证内容保留

## 故障排查

### 保存失败
1. 检查8766端口是否监听：`netstat -ano | grep 8766`
2. 查看日志：`logs/approach_analysis_server.log`
3. 重启服务器：`stop_all_servers.bat` → `start_all_servers.bat`

### Word上传失败
1. 检查8765端口是否监听：`netstat -ano | grep 8765`
2. 查看日志：`logs/word_upload_server.log`

### 自动重新生成失败
1. 检查8005端口是否监听：`netstat -ano | grep 8005`
2. 查看日志：`logs/config_server.log`
3. 手动重新生成：`python src/generate_visit_details.py`

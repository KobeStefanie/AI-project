## 自动联动机制

流派配置变更 (`POST localhost:8003/api/approaches`) 后自动执行：
1. `generate_visit_details.py` — 重新生成所有来访者详情页
2. `generate_comparison_views.py` — 重新生成对比视图
3. `generate_visitor_library.py` — 重新生成来访者库首页（含卡片+列表双视图）

## 数据持久化

### 流派分析保存
- **方案**：JSON 文件服务器端存储
- **端口**：8766 (`approach_analysis_server.py`)

### 数据存储位置
```
data/visitors/{visitor_id}/visits/{visit_id}.json
├── case_data
    ├── approach_analyses_html        # 流派分析 HTML
    └── counselor_review_html         # 咨询师复盘 HTML
```

### 保存流程
1. 前端编辑/上传 → POST `http://localhost:8766/save_approach`
2. 服务器保存到 `visit_id.json`
3. 自动触发 HTML 重新生成
4. 重新生成时优先读取已保存的 HTML

## 故障排查

### 保存失败
1. 检查 8766 端口：`check_services.bat` 或 `netstat -ano | findstr 8766`
2. 查看日志：`logs/approach_analysis_server.log`
3. 重启：`stop_all_servers.bat` → `start_all_servers.bat`

### Word 上传失败
1. 检查 8765 端口
2. 查看日志：`logs/word_upload_server.log`

### 自动重新生成失败
1. 检查 8003 端口
2. 查看日志：`logs/config_server.log`
3. 手动重新生成：`python src/generate_visit_details.py`
4. 或运行：`python src/generate_all.py`（全量重新生成）

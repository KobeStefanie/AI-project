## 🔗 联动机制详解

### **工作流程**

```
用户在配置界面操作
    ↓
保存流派配置到 data/config/approaches/*.json
    ↓
【自动触发】
    ↓
1. 执行 generate_visit_details_v2.py
   → 重新生成所有来访者的详情页（包含新的流派Tab）
    ↓
2. 执行 generate_visitor_library.py
   → 重新生成来访者库首页和所有档案页
    ↓
完成！新的流派配置立即生效
```

### **代码实现**

```python
# src/config_server.py 第197-238行
def _regenerate_visitor_library(self):
    """重新生成来访者库（来访者为中心）"""
    
    # 1. 重新生成所有来访者详情页
    print("[AUTO] 正在重新生成来访者详情页...")
    detail_script = 'src/generate_visit_details_v2.py'
    subprocess.run([sys.executable, detail_script])
    
    # 2. 重新生成来访者库首页
    print("[AUTO] 正在重新生成来访者库首页...")
    visitor_script = 'src/generate_visitor_library.py'
    subprocess.run([sys.executable, visitor_script])
```

## ⚠️ 重要注意事项

### **1. 配置服务器必须运行**
```bash
# 启动配置服务器
python src/config_server.py

# 或使用 start_servers.bat 启动所有服务
```

### **2. 流派ID不可随意修改**
- ✅ 新增流派：可以自定义ID
- ⚠️ 已有流派：不要修改ID（会导致数据对不上）
- 💡 只有 `temp_*` 开头的临时ID可以修改

### **3. 删除流派需谨慎**
- 删除流派配置文件不会删除来访者数据
- 数据仍在 `visitors/*/visits/visit_*.json` 中的 `approach_analyses` 字段
- 重新添加相同ID的流派，数据会重新显示

### **4. 数据安全设计**
- 来访者JSON数据**不会**自动修改
- 只更新HTML展示层
- 数据完整性由你手动控制

## 📊 系统架构

```
流派配置层
  data/config/approaches/*.json
         ↓ (读取)
  config_server.py (8003端口)
         ↓ (保存后自动触发)
         
HTML生成层
  generate_visit_details_v2.py (读取配置动态生成Tab)
  generate_visitor_library.py (生成索引和档案页)
         ↓ (输出)
         
展示层
  output/来访者库/*/visit_*.html (详情页)
  output/来访者库/index.html (首页)
  output/来访者库/*/profile.html (档案页)
         ↓ (用户浏览)
         
数据层（独立存储）
  data/visitors/*/profile.json
  data/visitors/*/visits/visit_*.json
```

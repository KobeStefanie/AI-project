```python
import wave, struct, math

sample_rate = 44100
duration = 2
frequency = 440

with wave.open('test_audio.wav', 'w') as wav_file:
    wav_file.setnchannels(1)
    wav_file.setsampwidth(2)
    wav_file.setframerate(sample_rate)
    
    for i in range(int(sample_rate * duration)):
        value = int(32767 * math.sin(2 * math.pi * frequency * i / sample_rate))
        wav_file.writeframes(struct.pack('h', value))
```

## 接访记录集成

### 前端上传流程

1. **文件选择**: 接访记录页面的"录音文件"区域
2. **临时存储**: 使用 `selectedAudioFiles` 数组暂存
3. **表单提交**: 保存案例时批量上传录音
4. **关联来访者**: 需要先保存接访记录获得 visitor_id 和 visit_id

**JavaScript代码** (`intake-record-new.js`):

```javascript
// 1. 文件选择
setupFileUpload('audio', selectedAudioFiles);

// 2. 保存案例时上传录音
for (const file of selectedAudioFiles) {
    const formData = new FormData();
    formData.append('file', file);
    formData.append('visitor_id', visitorId);
    formData.append('visit_id', visitId);
    formData.append('description', file.name);
    
    await fetch('http://localhost:8767/upload', {
        method: 'POST',
        body: formData
    });
}
```

## 技术实现细节

### 服务器端 (recording_server.py)

**框架**: Flask + Flask-CORS  
**端口**: 8767  
**数据目录**: `data/visitors/`

**关键功能**:

1. **上传处理**:
   - 文件格式验证
   - 唯一ID生成（rec_001, rec_002...）
   - 保存物理文件
   - 更新 JSON 元数据
   - 触发 HTML 重新生成

2. **下载处理**:
   - 从 JSON 读取文件路径
   - 使用 `send_file` 返回文件流
   - 保留原始文件名

3. **删除处理**:
   - 删除物理文件（使用 `unlink()`）
   - 从 JSON 数组中移除记录
   - 更新时间戳
   - 触发 HTML 重新生成

### 前端集成

**接访记录页面** (`intake-record-new.html` + `intake-record-new.js`):

- 文件拖拽/选择上传
- 临时文件列表展示
- 批量上传到服务器

**来访库页面** (`generate_visit_details.py` 生成):

- 读取 `case_data.recordings` 数组
- 生成录音卡片 HTML
- 集成播放、下载、删除功能

## 系统概述

以来访者为中心的心理咨询案例管理系统，支持：
- 接访记录的创建和管理
- Word文档自动解析和标签识别
- 录音文件上传和管理
- 多流派分析视角
- 咨询师复盘和督导记录
- 来访者全生命周期追踪

## 已实现功能

### ✅ 1. Word文档上传与自动识别

**功能描述**：
- 上传接访记录Word文档
- 自动解析基本信息（代号、性别、年龄、职业、婚姻状况）
- 自动识别主诉和咨询师反思
- **AI智能标签识别**（关系标签、症状标签）
- **关键词自动提取**
- 自动填充接访记录表单

**技术实现**：
- 服务器：配置服务器（端口8003）
- API端点：`POST /api/word/parse`
- 解析库：python-docx
- 标签识别：AI分析 + 关键词匹配后备

**标签识别示例**：
```json
{
  "tags": {
    "relation": ["职场关系-上下级关系"],
    "symptom": ["焦虑症状-担忧过度", "睡眠问题-入睡困难"]
  },
  "keywords": ["工作压力", "焦虑", "失眠", "完美主义"]
}
```

**测试状态**：✅ 已测试通过

### ✅ 2. 录音文件上传与管理

**功能描述**：
- 接访记录中上传录音文件
- 自动保存到来访者数据库
- 来访库中展示、播放、下载、删除录音
- 支持多种音频格式（mp3, wav, m4a, aac, ogg, flac, wma）

**技术实现**：
- 服务器：录音服务器（端口8767）
- API端点：
  - `POST /upload` - 上传录音
  - `GET /download/<visitor_id>/<visit_id>/<recording_id>` - 下载录音
  - `POST /delete` - 删除录音
- 框架：Flask + Flask-CORS

**数据存储**：
```
data/visitors/{visitor_id}/visits/{visit_id}/recordings/
├── rec_001.wav
├── rec_002.mp3
└── ...
```

**测试状态**：✅ 已测试通过（成功上传173KB音频文件）

## 使用指南

### 1. 启动所有服务器

```bash
# 1. HTTP服务器（端口8080）
cd D:\AI-项目\4-心理咨询-S1
python -m http.server 8080

# 2. 配置服务器（端口8003）
python src/config_server.py

# 3. 录音服务器（端口8767）
python src/recording_server.py

# 4. 流派分析保存服务器（端口8766）
python src/approach_analysis_server.py

# 5. 接访记录服务器（端口8768）
python src/intake_record_server.py

# 6. 删除服务器（端口9001）
python src/api_delete_visitor.py
```

### 2. 创建新接访记录

1. 打开接访记录页面
   ```
   http://localhost:8080/output/接访记录/intake-record-new.html
   ```

2. 选择方式：
   - **方式A：Word上传**
     - 点击"Word文档导入"区域
     - 选择Word文档
     - 系统自动识别基本信息和标签
     - 补充其他信息
   
   - **方式B：手动填写**
     - 逐项填写表单
     - 选择标签
     - 添加关键词

3. 上传录音文件（可选）
   - 在"录音文件"区域选择音频文件
   - 支持多个文件

4. 保存案例
   - 点击"保存案例"按钮
   - 系统自动生成来访者ID和来访记录

### 3. 查看来访者库

1. 打开来访者库首页
   ```
   http://localhost:8080/output/来访者库/index.html
   ```

2. 点击来访者卡片查看档案

3. 功能操作：
   - **查看档案**：点击卡片或档案页的"对比视图"
   - **查看来访详情**：点击具体来访记录
   - **删除档案**：点击红色删除按钮（需确认）

### 4. 管理录音文件

**上传录音**：
- 在接访记录创建时上传
- 或在来访详情页面上传

**播放/下载录音**：
- 打开来访详情页面
- 在"录音资料"区域播放或下载

**删除录音**：
- 点击录音卡片的删除按钮
- 确认删除

## 标签识别系统

### 标签分类

**关系标签**：
- 家庭关系：亲子关系、兄弟姐妹关系、代际关系
- 亲密关系：夫妻关系、恋爱关系、性关系
- 职场关系：同事关系、上下级关系、职业发展
- 社交关系：友谊关系、师生关系、邻里关系

**症状标签**：
- 焦虑症状：担忧过度、恐慌发作、强迫行为
- 抑郁症状：情绪低落、兴趣丧失、自我贬低
- 睡眠问题：入睡困难、早醒、睡眠质量差
- 情绪调节：情绪不稳、易怒、情感麻木
- 自我认知：自尊问题、身份认同、完美主义

### 标签识别方法

**方法1：AI智能识别**（需要ANTHROPIC_API_KEY）
- 使用Claude API分析案例文本
- 从标签库中智能选择最相关的标签
- 同时提取关键词

**方法2：关键词匹配**（后备方案）
- 基于关键词规则匹配
- 当前支持的关键词：
  - 父母 → 家庭关系-亲子关系
  - 夫妻 → 亲密关系-夫妻关系
  - 同事 → 职场关系-同事关系
  - 焦虑 → 焦虑症状-担忧过度
  - 抑郁 → 抑郁症状-情绪低落
  - 失眠 → 睡眠问题-入睡困难

## 常见问题

### Q1: Word上传后表单没有填充？
**A**: 打开浏览器开发者工具（F12），查看Console标签的错误信息。确认：
- 配置服务器是否运行（端口8003）
- 网络请求是否成功
- 是否有JavaScript错误

### Q2: 录音上传失败？
**A**: 检查：
- 录音服务器是否运行（端口8767）
- 文件格式是否支持
- 文件大小是否合理

### Q3: 删除功能提示"Failed to fetch"？
**A**: 确认删除服务器是否启动（端口9001）

### Q4: 标签识别不准确？
**A**: 
- 当前使用关键词匹配后备方案
- 可以配置ANTHROPIC_API_KEY使用AI识别
- 或手动调整标签

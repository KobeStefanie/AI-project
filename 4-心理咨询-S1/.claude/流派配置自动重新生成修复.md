# 流派配置自动重新生成修复 - 彻底解决方案

## 问题描述

**用户反馈**：一旦流派增减后就会出现无法上传及下载，编辑和保存，含咨询师复盘和流派分析。

## 问题根源分析

### 触发条件
用户在配置页面新增或删除流派后，详情页面的所有编辑、保存、上传功能全部失效。

### 根本原因
1. **流派配置变更后HTML未自动重新生成**
   - 用户在配置页面修改流派配置
   - `config_server.py` 保存了配置文件
   - 但是 **HTML文件仍然是旧的**，包含旧的流派列表

2. **HTML与配置不同步导致功能失效**
   - 旧HTML中的按钮绑定的流派名称不存在
   - JavaScript中的`saveEdit()`、`uploadWord()`等函数接收到错误的流派名称
   - 保存API接收到不存在的流派名称，数据保存后无法正确显示

3. **config_server.py的脚本路径错误**
   ```python
   # 第229行 - 错误的脚本名称
   detail_script = os.path.join(PROJECT_ROOT, 'src', 'generate_visit_details_v2.py')
   ```
   - 调用了不存在的 `generate_visit_details_v2.py`
   - 导致自动重新生成失败，但用户看不到错误信息

## 完整解决方案

### 1. 修复脚本路径错误

**文件**: `src/config_server.py` 第229行

```python
# 修复前
detail_script = os.path.join(PROJECT_ROOT, 'src', 'generate_visit_details_v2.py')

# 修复后
detail_script = os.path.join(PROJECT_ROOT, 'src', 'generate_visit_details.py')
```

### 2. 动态加载流派配置

**文件**: `src/generate_visit_details.py`

```python
# 修复前 - 硬编码流派列表
all_approaches = ['大观派', 'CBT', '精神动力学', '人本主义', '存在主义']

# 修复后 - 动态加载
from approaches_manager import get_manager

manager = get_manager()
enabled_approaches = manager.get_enabled_approaches()
all_approaches = [approach['name'] for approach in enabled_approaches]

# 创建流派映射
approach_id_to_name = {approach['id']: approach['name'] for approach in enabled_approaches}
approach_name_to_id = {approach['name']: approach['id'] for approach in enabled_approaches}
```

### 3. 数据迁移

创建 `src/migrate_approach_names.py` 迁移历史数据：

## 工作流程

### 流派配置变更的完整流程

```
用户操作配置页面
    ↓
新增/删除/修改流派
    ↓
点击"保存配置"
    ↓
前端调用: POST http://localhost:8003/api/approaches
    ↓
config_server.py 接收请求
    ↓
保存流派配置到 data/config/approaches/*.json
    ↓
自动调用 _regenerate_visitor_library()
    ↓
执行 generate_visit_details.py
    │
    ├─ 动态加载最新的流派配置
    ├─ 生成新的流派标签按钮
    ├─ 绑定正确的流派名称到事件
    └─ 读取已保存的内容（通过流派名称匹配）
    ↓
执行 generate_visitor_library.py
    │
    └─ 重新生成来访者库首页
    ↓
返回成功消息: "保存成功并已更新来访者库"
    ↓
用户刷新详情页
    ↓
新的HTML加载，流派列表更新
    ↓
编辑、保存、上传功能恢复正常
```

## 技术要点

### 1. config_server的自动重新生成机制

```python
def _regenerate_visitor_library(self):
    """重新生成来访者库（来访者为中心）"""
    # 1. 重新生成所有来访者详情页
    subprocess.run([sys.executable, detail_script], ...)
    
    # 2. 重新生成来访者库首页
    subprocess.run([sys.executable, visitor_script], ...)
```

**关键点**：
- 使用 `subprocess.run()` 同步执行，确保完成后再返回
- 设置60秒超时，避免长时间阻塞
- 捕获输出并记录到日志
- Windows环境使用 `CREATE_NO_WINDOW` 标志

### 2. 流派配置的动态加载

```python
from approaches_manager import get_manager

manager = get_manager()
enabled_approaches = manager.get_enabled_approaches()
```

**优势**：
- 配置文件是唯一真相源
- 不需要修改代码即可新增/删除流派
- 流派排序、启用/禁用自动生效

### 3. 流派名称映射

```python
approach_name_to_id = {approach['name']: approach['id'] for approach in enabled_approaches}
```

**作用**：
- 前端使用流派name（如"认知行为疗法 (CBT)"）
- 后端读取processed案例时使用流派id（如"cbt"）
- 通过映射实现无缝对接

# 流派删除保留内容规则

## 核心规则

**删除流派时，原有的内容不删除**

## 实现机制

### 1. 数据持久化保证

所有流派分析内容保存在 `data/visitors/{visitor_id}/visits/{visit_id}.json` 的 `approach_analyses_html` 字段中：

```json
{
  "case_data": {
    "approach_analyses_html": {
      "大观学派（危机干预）": "<html>...</html>",
      "认知行为疗法 (CBT)": "<html>...</html>",
      "布莱尼": "<html>...</html>"  // 即使删除流派，这个数据也保留
    }
  }
}
```

**保证**：
- ✅ 流派禁用/删除时，JSON文件中的数据**不会被删除**
- ✅ 数据永久保留在文件中
- ✅ 将来重新添加同名流派时，数据自动恢复显示

### 2. HTML生成逻辑

`src/generate_visit_details.py` 的处理逻辑：

```python
# 1. 加载启用的流派
enabled_approaches = manager.get_enabled_approaches()
all_approaches = [approach['name'] for approach in enabled_approaches]

# 2. 添加已保存但未启用的流派（保留历史数据）
saved_approaches = visit_data.get('case_data', {}).get('approach_analyses_html', {}).keys()
for saved_approach in saved_approaches:
    if saved_approach not in all_approaches:
        print(f"    [保留] {saved_approach}: 已禁用的流派，但保留已保存的内容")
        all_approaches.append(saved_approach)
```

**逻辑**：
1. 首先加载所有启用的流派
2. 检查JSON中保存的流派内容
3. 如果发现已保存但未启用的流派，**自动添加到显示列表**
4. 生成HTML时，该流派仍然显示，但带有"已归档"标识

### 3. 视觉标识

已禁用的流派在HTML中显示为：

```html
<button class="tab-button px-6 py-2 rounded-t font-semibold" 
        style="opacity: 0.6; font-style: italic;" 
        onclick="switchTab('布莱尼')" 
        title="该流派已被禁用，但内容已保留">
    布莱尼 (已归档)
</button>
```

**视觉效果**：
- 按钮半透明（opacity: 0.6）
- 斜体字（font-style: italic）
- 显示"(已归档)"标签
- 鼠标悬停提示："该流派已被禁用，但内容已保留"

## 用户场景

### 场景1：删除流派

1. **操作前**：
   - 用户在"布莱尼"流派中保存了3000字的分析内容
   - 流派配置中存在"布莱尼"流派

2. **用户操作**：
   - 打开配置页面
   - 删除"布莱尼"流派
   - 点击"保存配置"

3. **系统行为**：
   - 删除 `data/config/approaches/temp_2.json` 文件
   - 自动重新生成所有HTML
   - 检测到"布莱尼"在JSON中有保存内容
   - 将"布莱尼"添加到流派列表，标记为"已归档"

4. **操作后**：
   - 详情页中"布莱尼"标签页仍然显示
   - 按钮显示为："布莱尼 (已归档)"，半透明斜体
   - 点击后可以查看已保存的3000字内容
   - ✅ **内容完全保留，可以正常查看**

### 场景2：重新添加同名流派

1. **前提**：
   - "布莱尼"流派已被删除，但内容保留（如场景1）

2. **用户操作**：
   - 打开配置页面
   - 重新添加"布莱尼"流派
   - 点击"保存配置"

3. **系统行为**：
   - 创建新的流派配置文件
   - 自动重新生成所有HTML
   - 检测到"布莱尼"在JSON中有保存内容
   - 将"布莱尼"添加到启用流派列表

4. **结果**：
   - "布莱尼"标签页正常显示（不再显示"已归档"）
   - ✅ **之前保存的3000字内容自动恢复显示**
   - 可以继续编辑、保存、上传Word

### 场景3：多次删除和恢复

1. **时间线**：
   - Day 1: 创建"测试流派"，保存内容A
   - Day 2: 删除"测试流派"（内容A保留）
   - Day 3: 重新添加"测试流派"，保存内容B
   - Day 4: 再次删除"测试流派"（内容B保留）
   - Day 5: 第二次重新添加"测试流派"

2. **最终结果**：
   - ✅ 内容B完全保留
   - ✅ 可以继续使用"测试流派"

## 技术细节

### 只读属性

已归档的流派是**只读**的：

- ✅ 可以查看内容
- ✅ 可以下载为Word
- ❌ 无法编辑（因为流派配置不存在）
- ❌ 无法上传Word（因为流派配置不存在）

如果需要编辑，必须**重新添加该流派**。

### 数据完整性

系统保证：

1. **写入保护**：
   - 任何操作都不会删除 `approach_analyses_html` 中的已有数据
   - 只有用户手动编辑JSON文件才能删除数据

2. **读取保证**：
   - HTML生成时，总是读取JSON中的所有内容
   - 即使流派配置不存在，内容也会显示

3. **自动恢复**：
   - 重新添加同名流派时，内容自动恢复

### 命名约定

流派的唯一标识是其**name**字段：

```json
{
  "id": "temp_2",
  "name": "布莱尼",  // 这是唯一标识
  "enabled": true
}
```

- 删除后重新添加，必须使用**完全相同的name**才能恢复内容
- 如果name不同（如"布莱尼"改为"布莱尼学派"），会被视为新流派

如果流派被禁用，且JSON中没有保存内容，则**不会显示**：

```

  生成来访详情页: V20260620002 - 第1次来访
    ✓ 生成: output/来访者库/V20260620002/visit_001.html
```

没有`[保留]`日志，说明该来访者没有"布莱尼"流派的保存内容。

## 总结

### 设计原则

**数据永久性优先于配置灵活性**

- 配置可以随时变更
- 数据一旦保存，永久保留
- 流派删除只是"归档"，不是"删除"

### 用户价值

1. **数据安全**：误删流派不会导致数据丢失
2. **灵活管理**：可以自由调整流派列表，不用担心历史数据
3. **可追溯性**：即使流派不再使用，历史分析仍然可查
4. **可恢复性**：重新启用流派，历史内容立即恢复

### 技术保障

- JSON数据永久保留
- HTML自动检测并显示已归档流派
- 视觉标识清晰区分启用/归档状态
- 同名流派自动恢复内容

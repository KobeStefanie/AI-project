# 流派配置问题修复报告

## 🔧 修复的问题

### 问题1：图标显示为文字 "fa-circle"
**原因**：代码直接输出图标类名，没有用 `<i class="fa">` 标签包裹

**修复前**：
```html
fa-circle 拉康精分
```

**修复后**：
```html
<i class="fa fa-circle"></i> 拉康精分
```

**代码修改**：
```python
# src/generate_visit_details_v2.py 第63-68行
# 处理图标：如果是 fa-xxx 格式，用 Font Awesome；否则用 emoji
if approach_icon.startswith('fa-'):
    icon_html = f'<i class="fa {approach_icon}"></i>'
else:
    icon_html = approach_icon
```

### 问题2：新流派排序位置不对
**原因**：排序逻辑使用名称排序，没有使用 `sort_order` 字段

**修复前排序**：
```

2. 拉康精分（启用）- 因为"拉"字排在"人"之前

4. 存在主义（未启用）

```

**修复后排序**：
```

2. 认知行为疗法 (CBT) - sort_order: 2  
3. 精神动力学 - sort_order: 3
4. 人本主义 - sort_order: 4
5. 存在主义 - sort_order: 5
6. 拉康精分 - sort_order: 6 ✅ 正确位置
```

**代码修改**：
```python
# src/generate_visit_details_v2.py 第42行
# 修复前
approaches.sort(key=lambda x: (not x.get('enabled', False), x.get('name', '')))

```

## 📝 用户操作指南

### 如何设置流派排序
在配置界面的"排序"字段输入数字：
```
1 - 最靠前
2 - 第二
...
99 - 最靠后
```

### 如何选择图标
**方式1：使用 Font Awesome 图标**
```
fa-compass  → ⚲
fa-brain    → 🧠  
fa-heart    → ❤️
fa-circle   → ⭕
fa-star     → ⭐
```

**方式2：使用 Emoji**
```
直接输入: 🚨 🧠 💭 ❤️ 🌟
```

### 如何调整已有流派的排序
1. 访问流派配置管理界面
2. 修改"排序"字段的数值
3. 点击"保存所有配置"
4. ✅ 所有详情页自动更新

# 流派配置保存问题修复

## 🐛 问题根源

配置界面保存时**完全替换了配置文件**，导致：
1. 复杂配置字段丢失（如 `fields`, `crisis_levels`, `techniques`）
2. 只保留了界面编辑的基本字段（id, name, color, icon, enabled, sort_order）

**示例**：
大观学派原有11个字段，保存后只剩6个字段，丢失了：
- `fields`: 字段定义
- `crisis_levels`: 危机等级定义  
- `techniques`: 技术列表
- `metadata`: 元数据
- `description`: 描述

## ✅ 修复方案

### 修改文件：`src/config_server.py`

**修复逻辑**：
```python
# 修复前：完全替换
json.dump(approach, f, ensure_ascii=False, indent=2)

# 修复后：合并保留
if approach_id in existing_configs:
    # 1. 读取原有配置
    merged_config = existing_configs[approach_id].copy()
    # 2. 更新界面传来的字段
    merged_config.update(approach)
    # 3. 保存合并后的配置
    final_config = merged_config
else:
    # 新配置直接使用
    final_config = approach
```

### 工作流程

```
用户在界面修改流派配置
    ↓
POST /api/approaches
{
  "id": "daguanpai",
  "name": "大观学派（危机干预）",
  "color": "#ef4444",
  "icon": "🚨",
  "enabled": true,
  "sort_order": 0
}
    ↓
config_server.py 接收
    ↓
读取原有配置文件（11个字段）
    ↓
合并：原有配置 + 界面更新
    ↓
保存合并后的配置（11个字段完整保留）
    ↓
✅ 字段不丢失！
```

### 字段保护机制

**界面只能修改的字段**：
- `id`
- `name`  
- `color`
- `icon`
- `enabled`
- `sort_order`

**系统自动保留的字段**：
- `name_short`
- `description`
- `fields`
- `crisis_levels`
- `techniques`
- `metadata`
- 以及任何其他自定义字段

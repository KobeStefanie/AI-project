# 流派名称不匹配修复

## 问题描述

用户报告：**一旦进行了流派设置后就会失去刚才修复的上传下载，及保存，也不见以前的内容**

## 根本原因

1. **硬编码的流派列表**
   - `generate_visit_details.py` 使用硬编码的流派名称：
   ```python
   all_approaches = ['大观派', 'CBT', '精神动力学', '人本主义', '存在主义']
   ```

2. **配置文件中的实际名称不同**
   - 配置文件 `data/config/approaches/*.json` 中的name字段：
     - `"大观学派（危机干预）"` （不是"大观派"）
     - `"认知行为疗法 (CBT)"` （不是"CBT"）
     - `"拉康精分"` （新增流派，硬编码列表中不存在）

3. **保存和读取时的key不匹配**
   - 保存时：使用HTML中的按钮传递的流派名称（如"CBT"）
   - 读取时：从配置文件加载的名称（如"认知行为疗法 (CBT)"）
   - 结果：`approach_analyses_html["CBT"]` 存在，但读取时查找 `approach_analyses_html["认知行为疗法 (CBT)"]`，找不到！

## 问题影响

- ✗ Word上传后的内容刷新后消失
- ✗ 编辑保存的内容刷新后消失
- ✗ 新增的流派（如"拉康精分"）根本不显示
- ✗ 流派配置变更后，之前保存的所有内容都丢失

## 解决方案

### 1. 动态加载流派配置

修改 `src/generate_visit_details.py`：

```python
# 导入流派管理器
from approaches_manager import get_manager

# 从配置文件动态加载流派列表
manager = get_manager()
enabled_approaches = manager.get_enabled_approaches()
all_approaches = [approach['name'] for approach in enabled_approaches]

# 创建流派ID到名称的映射（用于读取processed案例数据）
approach_id_to_name = {approach['id']: approach['name'] for approach in enabled_approaches}
approach_name_to_id = {approach['name']: approach['id'] for approach in enabled_approaches}
```

### 2. 数据迁移

创建 `src/migrate_approach_names.py` 迁移已保存的数据：

```python
OLD_TO_NEW_MAPPING = {
    '大观派': '大观学派（危机干预）',
    'CBT': '认知行为疗法 (CBT)',
    '精神动力学': '精神动力学',
    '人本主义': '人本主义',
    '存在主义': '存在主义',
    '测试流派': None  # 删除不存在的流派
}
```

迁移结果：
- V20260616001: `"CBT"` → `"认知行为疗法 (CBT)"`，删除 `"测试流派"`
- V20260620001: `"大观派"` → `"大观学派（危机干预）"`，`"CBT"` → `"认知行为疗法 (CBT)"`

### 3. 读取逻辑优化

从processed案例文件读取数据时，使用流派ID映射：

```python
# 使用流派名称到ID的映射获取数据
approach_id = approach_name_to_id.get(approach_name, '')
if approach_id:
    approach_data = analyses.get(approach_id, {})
```

## 核心改进

### 之前（硬编码）
```python
# 问题1：流派列表写死
all_approaches = ['大观派', 'CBT', ...]

# 问题2：名称映射写死
approach_key_map = {
    '大观派': 'daguanpai',
    'CBT': 'cbt',
    ...
}
```

**缺点：**
- 新增流派需要修改代码
- 修改流派名称后所有数据失效
- 配置文件和代码不同步

### 之后（配置化）
```python
# 优势1：动态加载
manager = get_manager()
all_approaches = [a['name'] for a in manager.get_enabled_approaches()]

# 优势2：自动映射
approach_id_to_name = {a['id']: a['name'] for a in enabled_approaches}
approach_name_to_id = {a['name']: a['id'] for a in enabled_approaches}
```

**优势：**
- ✅ 流派配置集中管理
- ✅ 新增/修改流派无需改代码
- ✅ 保存和读取使用相同的key
- ✅ 支持流派的启用/禁用
- ✅ 支持自定义流派排序

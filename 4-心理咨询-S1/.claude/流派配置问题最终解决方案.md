## 🔧 待修复的自动联动问题

### 问题诊断

配置服务器的 `_regenerate_visitor_library()` 方法可能因为以下原因失败：
1. **编码问题**：subprocess 输出包含中文导致 UnicodeDecodeError
2. **超时问题**：生成脚本执行时间过长
3. **路径问题**：工作目录不正确

### 修复建议

修改 `config_server.py` 的 `_regenerate_visitor_library()` 方法：

```python
def _regenerate_visitor_library(self):
    """重新生成来访者库（来访者为中心）"""
    import subprocess
    
    try:
        # 1. 重新生成所有来访者详情页
        print("[AUTO] 正在重新生成来访者详情页...")
        detail_script = os.path.join(PROJECT_ROOT, 'src', 'generate_visit_details_v2.py')
        
        # 增加超时时间，添加错误容忍
        result = subprocess.run(
            [sys.executable, detail_script],
            cwd=PROJECT_ROOT,
            capture_output=True,
            text=True,
            encoding='utf-8',
            errors='replace',  # ← 关键修复
            timeout=60  # ← 增加超时时间
        )
        
        if result.returncode == 0:
            print("[AUTO] ✓ 来访者详情页重新生成成功")
        else:
            print(f"[AUTO] ✗ 详情页生成失败")
            print(f"  错误: {result.stderr[:200]}")  # 只显示前200字符
            
    except subprocess.TimeoutExpired:
        print("[AUTO] ✗ 生成超时，请手动执行")
    except Exception as e:
        print(f"[AUTO] ✗ 执行失败: {str(e)[:100]}")
```

# 录音功能测试指南

**日期**: 2026-06-29  
**功能**: 录音存储、上传、下载

---

## 一、已实现的功能

### 1. 录音管理服务器
- **文件**: `src/recording_server.py`
- **端口**: 8767
- **功能**:
  - POST `/upload` - 上传录音
  - GET `/download/<visitor_id>/<visit_id>/<recording_id>` - 下载录音
  - POST `/delete` - 删除录音
- **支持格式**: MP3, WAV, M4A, AAC, OGG, FLAC, WMA

### 2. 接访记录保存服务器
- **文件**: `src/intake_record_server.py`
- **端口**: 8768
- **功能**:
  - POST `/save_new_case` - 保存新案例（首次接访）
  - POST `/save_follow_up` - 保存后续会谈

### 3. 来访者详情页录音功能
- **位置**: 访谈详情页的"📱 录音资料"区域
- **功能**:
  - 显示录音列表（文件名、大小、上传时间、备注）
  - HTML5音频播放器（直接播放）
  - 上传录音按钮
  - 下载录音按钮
  - 删除录音按钮（需确认）

## 二、数据流架构

```
接访记录页面 (intake-record-new.html)
    ↓ 提交表单
接访记录保存服务器 (端口8768)
    ↓ 保存数据到
data/visitors/{visitor_id}/visits/{visit_id}.json
    ↓ 触发录音上传
录音管理服务器 (端口8767)
    ↓ 保存录音文件
data/visitors/{visitor_id}/visits/{visit_id}/recordings/
    ↓ 自动触发
生成来访者详情页 (generate_visit_details.py)
    ↓ 生成
来访者库详情页 (visit_001.html)
```

## 四、测试步骤

### 测试1：在来访者详情页上传录音

1. **启动服务器**:
   ```bash
   cd D:/AI-项目/4-心理咨询-S1
   python src/recording_server.py
   ```

2. **打开来访者详情页**:
   ```
   D:/AI-项目/4-心理咨询-S1/output/来访者库/V20260620001/visit_001.html
   ```

3. **上传录音**:
   - 滚动到"📱 录音资料"区域
   - 点击"上传录音"按钮
   - 选择音频文件（MP3、WAV等）
   - 添加备注（可选）
   - 点击"开始上传"
   - 等待上传完成，页面自动刷新

4. **验证**:
   - 录音出现在列表中
   - 可以播放录音
   - 可以下载录音
   - 可以删除录音

### 测试2：从接访记录页面创建新案例（需要手动更新JS）

**注意**: 接访记录页面的JS文件需要手动更新才能使用新的API。

1. **启动所有服务器**:
   ```bash
   python src/recording_server.py &
   python src/intake_record_server.py &
   python src/approach_analysis_server.py &
   ```

2. **更新接访记录JS**:
   - 打开 `D:/AI-项目/4-心理咨询-S1/output/接访记录/intake-record-new.js`
   - 确认已添加:
     ```javascript
     const INTAKE_API = 'http://localhost:8768';
     const RECORDING_API = 'http://localhost:8767';
     ```
   - 确认 `saveNewCase` 函数调用新的API

3. **打开接访记录页面**:
   ```
   D:/AI-项目/4-心理咨询-S1/output/接访记录/intake-record-new.html
   ```

4. **填写表单**:
   - 填写基本信息
   - 选择录音文件
   - 填写咨询师复盘
   - 点击"保存案例"

5. **验证**:
   - 案例保存成功
   - 录音文件上传成功
   - 自动生成来访者详情页
   - 来访者详情页显示录音和复盘内容

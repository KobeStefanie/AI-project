# 心理学视频自媒体工厂

> 目标：每天一条短视频，为心理咨询服务导流

## 团队架构

| 角色 | 职责 |
|------|------|
| 总导演（AI） | 选题策划、脚本创作、质量把关 |
| 内容质检（AI） | 去AI味、人性化处理 |
| 视觉创意（AI） | 封面文案设计建议 |
| 出镜/录制（你） | 审稿确认、用剪映录制配音 |
| 发布运营（你） | 三平台发布、数据记录 |

## 每日工作流（目标：你投入≤30分钟）

```
D-1 晚上  AI出3个选题 → 你拍板1个（2分钟）
D日 上午  AI出完整脚本 → 你审核微调（10分钟）
D日 中午  AI出封面文案+三平台发布文案（5分钟）
D日 下午  剪映导入脚本 → AI配音 → 加字幕（15分钟）
D日 傍晚  三平台发布 → 记录发布数据（5分钟）
每周日    数据复盘 → 调整下周方向（10分钟）
```

## 制作工具链（无脸版）

| 环节 | 工具 | 说明 |
|------|------|------|
| 脚本 | AI生成 | 本流程核心 |
| 配音 | 剪映AI配音 | 选"磁性男声"或"温暖女声" |
| 字幕 | 剪映自动字幕 | 导入脚本直接生成 |
| 背景画面 | 剪映模板/Pexels素材 | 选自然/城市/抽象背景 |
| 封面 | 醒图 / 剪映封面 | 大字+对比色 |
| 导出 | 1080P竖版 | 9:16比例 |

## 三平台发布差异

| 要素 | 抖音 | 小红书 | 视频号 |
|------|------|--------|--------|
| 时长目标 | 30-60秒 | 60-90秒 | 60-90秒 |
| 封面重点 | 钩子文字 | 颜值+文字 | 简洁清晰 |
| 正文字数 | 50字内 | 200-400字 | 100字内 |
| 核心CTA | 评论/关注 | 收藏/关注 | 加微信咨询 |
| 核心目标 | 流量最大化 | SEO+种草 | 私域导流 |

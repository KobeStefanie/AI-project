# 小红书自媒体项目工作指引

**项目目标**：每天一条心理学短视频，三平台同步发布，为心理咨询服务导流

---

## 🎯 项目核心资产

| 资产 | 路径 | 说明 |
|------|------|------|
| 内容战略 | `0-战略/内容战略.md` | 品牌定位、三大内容支柱、平台差异策略 |
| 选题库 | `1-选题库/` | 待用选题、已用选题 |
| 脚本库 | `2-脚本/2026/07/` | 按日期命名的成品脚本 |
| 发布记录 | `3-发布记录/2026-07.md` | 每日发布数据追踪 |
| 输出物 | `输出/` | 视频、字幕、图文卡片 |
| 生产工具 | `工具/` | video_maker.py、card_maker.py、ai_card_maker.py |

---

## 📐 品牌核心原则

**身份**：做过N个真实案例的心理咨询师，分享真正见过的人性

**叙事原则**：
- 你是 Obi-Wan，来访者/观众才是主角
- 从真实案例/感悟出发，不讲教科书定义
- 说人话，不说"认知重构""共情疗愈"等术语
- 有立场，有判断，不中立

**内容比例**：感悟类40% | 案例类35% | 知识类25%

## 📋 每日工作流（目标：你投入≤30分钟）

```
D-1 晚上  AI出3个选题 → 你拍板1个（2分钟）
D日 上午  AI出完整脚本 → 你审核微调（10分钟）
D日 中午  AI出封面文案+三平台发布文案（5分钟）
D日 下午  剪映导入脚本 → AI配音 → 加字幕（15分钟）
D日 傍晚  三平台发布 → 记录发布数据（5分钟）
每周日    数据复盘 → 调整下周方向（10分钟）
```

## 🚫 项目禁止事项

- ❌ 不得使用真实来访者信息，案例必须脱敏（改性别/职业/年龄/城市）
- ❌ 不得讲教科书定义，不堆砌心理学术语
- ❌ 不得跳过发布数据记录（数据是优化方向的唯一依据）
- ❌ 脚本未经人性化处理不得发布（去AI味）

---

## ✅ 验收标准

### 脚本验收
- [ ] 钩子在前5秒，有反直觉或强共鸣
- [ ] 全程说人话，无术语堆砌
- [ ] 案例已脱敏处理
- [ ] 有明确CTA（评论/收藏/私信）
- [ ] 三平台发布文案已准备

### 发布验收
- [ ] 视频时长符合平台要求（抖音30-60秒，小红书60-90秒）
- [ ] 封面文字清晰，有钩子
- [ ] 数据已记录到发布记录

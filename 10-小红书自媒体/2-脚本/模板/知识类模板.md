# 知识类脚本模板

> 适用：一个心理学概念的日常化解读
> 时长目标：60-75秒（约200-250字）
> 核心目标：收藏量（实用工具型优先）

---

## 结构框架

```
【钩子 0-5秒】
"你以为你懂[XX]，但你可能理解错了"
或者"[XX]其实比你想的更常见"

【错误认知 5-20秒】
大多数人以为[XX]是……
为什么这个理解是有问题的

【真实定义 20-40秒】
心理学上，[XX]其实是……
用一个类比或日常语言解释

【生活场景 40-55秒】
举一个具体例子：[场景]
"你有没有过这种时候..."

【行动建议 55-70秒】
一件可以立刻做的事
或者一个新的思考角度

【CTA 70-75秒】
```

---

## 模板正文

```
【钩子】
你可能对[心理学概念]有一个误解。

【错误认知】
大多数人以为[XX]就是[常见误解]。
但其实这个理解，恰恰让很多人错过了[重要的东西]。

【真实定义】
心理学上，[XX]指的是[通俗解释]。
简单来说，[用一个类比]。

【生活场景】
具体是什么样子？
比如[一个真实场景]——
[展开这个场景，让人能对照自己]。

【行动建议】
下次当你[触发情境]，可以试着[具体行动]。
不需要做太多，[XX]这件事，开始就是进展。

【CTA】
你以前对[XX]的理解是什么样的？
评论区说说，我挨个看。
```

---

## 工具型内容特殊结构（冲收藏）

> 适用于"方法类"视频，如呼吸法、情绪记录、认知挑战等

```
【钩子 0-5秒】
"[XX]分钟能做的一件事，帮你[解决具体问题]"

【痛点 5-15秒】
当你[具体触发场景]，有没有觉得[感受]？

【方法介绍 15-50秒】
一个心理咨询师会教的方法：[名称]
步骤一：[具体操作]
步骤二：[具体操作]
步骤三：[具体操作]（如有）
原理：[一句话解释为什么有用]

【验证 50-65秒】
有研究发现，[简单的科学依据]。
不是治愈，是给你一个喘息的窗口。

【CTA 65-75秒】
先收藏，下次用得上。
试过的朋友评论区说说效果。
```

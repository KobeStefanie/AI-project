# 感悟类脚本模板

> 适用：从咨询经验出发的反直觉洞察
> 时长目标：55-65秒（约180-220字）

---

## 结构框架

```
【钩子 0-5秒】
一句反直觉的观点，或一个让人停下来的问题
——不解释，直接抛出

【场景化 5-20秒】
"你有没有过这种感觉..."
用具体、日常的场景让观众对号入座

【心理机制 20-45秒】
解释为什么会这样
说人话，不用术语
可以有一个类比

【启发 45-55秒】
给观众一个新视角，不是解决方案，是重新看待问题的角度

【CTA 55-65秒】
引导评论互动，问一个观众能回答的问题
```

---

## 模板正文

```
【钩子】
[一句反直觉的观点]。

【场景化】
你有没有过这种感觉——
[具体的日常场景，一到两句话]。
[加一句，让感觉更立体]。

【机制】
在心理咨询里，我们把这个叫[用通俗语言描述]。
[解释为什么会这样，用类比更好]。
[进一步展开]。

【启发】
所以[这件事]不是[错误理解]，而是[新视角]。
[给出一个更好的理解方式]。

【CTA】
你有过这种感觉吗？
评论区告诉我[一个简单的互动指令]。
```

---

## 填写示例

```
【钩子】
你以为的情绪稳定，其实是情感麻木。

【场景化】
你有没有过这种感觉——
很久没有大哭过了，也很久没有特别开心过了。
不是没事，只是……什么都无所谓了。

【机制】
很多人以为这是成熟，是淡定。
但在咨询室里，我更多时候看到的是：
一个神经系统累了很久的人。
太多次情绪没有被接住，它就干脆关上了门。
麻木和平静的区别是——
平静是感受得到，但不被淹没。
麻木是感受不到，连快乐也进不来。

【启发】
所以"我也没什么不开心的，就是提不起劲儿"
这句话，不是矫情，是信号。

【CTA】
如果你最近也有这种感觉，
评论区打一个字：麻。
下期我们聊怎么重新打开感受力。
```
